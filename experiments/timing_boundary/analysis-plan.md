# 冻结状态中的结束边界与内容

2026-11-04。接续 [结束监督位置实验](../../docs/finish-position-experiment-2026-11-03.md)。本轮不继续移动标签，也不更新原模型，先检验其状态中哪些信息可以跨请求读出。

## 问题与比较

上一轮保留最后一个应等待的监督点，把旧 A 的 FINISH 提前后，新 B 更常及时出手，旧 A 却重新抢答。这里比较三个训练终点 midpoint、interior、first，以及同结构的随机初始化 GRU。三个已训练模型具有相同规模，来自相同旧请求与预算，但其循环权重和读出权重均可能不同。

主要问题是同一个请求的相邻两步能否被正确分开。只有在请求仍活跃、已经启动，且上一 tick 不合法、下一 tick 首次合法时才组成一对。模型要分别判前者等待、后者就绪。另测正确版本与内容是否可读，以及到就绪还剩多少 tick。

## 数据边界

- 每个独立模型种子分别生成 train、validation、test 三条持续混合 A/B 流。每条有 32 个 actor、两个任务槽，先运行 512 tick，再观察 4,096 tick。三组 actor 身份不重叠。长条件、取消和替换沿用原生世界。
- 同一条中点教师实际执行的公开历史交给全部冻结模型，循环状态只在各自独立流开始时初始化，随后完整延续。新模型只能接收原有 56 维公开观察。
- 只对观察段新发、合格且已成熟的请求取样。请求的来源、完整分母、取消和不完整边界分别存档。每对两个点必须放在同一数据划分。
- 边界附近额外记录相对首次合法时刻的 −8、−4、−2、−1、0、1、2 tick。额外位置只有在同一请求仍活跃且已启动时才有效，不能凭事后补齐。−1 与 0 是主要读出的唯一训练位置。
- 另让每个训练终点在与 test 相同的外部请求上自行行动。这里的隐藏态由自己的真实动作回执形成。只把教师数据上已拟合的读出移入诊断，不在这些测试样本上再训练。原策略的严格完成和空闲误动作独立计数。

## 固定读出

两个任务槽分别拟合，因为原策略本来就有两个输出端口。每个读出在 A/B、符号和版本之间共用参数。训练集均值与标准差用于所有划分，验证和测试不参与阈值、超参数或轮数选择。

1. 固定 L2 逻辑回归读取就绪类别，输入分别为 192 维 h、当前 56 维观察、该槽的原始 11 维动作分数。分类阈值固定为 0.5。
2. 随机 GRU 的 h 使用相同线性读出。另在已训练 h 上随机翻转每个训练请求对的两个标签，保留成对平衡，检查无意义监督下的结果。
3. 固定一个 64 单元 tanh 隐层的就绪读出，检查简单非线性是否改变结论。没有结构或学习率扫描，未收敛须明确报告。
4. h 与当前观察另拟合八类版本加内容读出，比较原动作头在八个 FINISH 中的条件排序。正负时间位置都参与，正确内容不等同于正确动作。
5. 固定岭回归在可用的七个附近位置拟合距就绪的有符号时间，报告以 tick 为单位的误差。此项使用了比二分类更多的监督行，不能按相同预算比较其胜负。

精确数值设置、随机数种子、数据路径与源码哈希在各自运行协议中冻结。模型检查点只读，统计独立训练重复时仍是三个种子。

## 预定判断

主要同时报告逐行准确率、同请求两步都判对的比例、首合法分数高于末步分数的比例。第三项只说明方向是否变化，不能替代跨请求统一阈值的判断。平局单列，不把平局当作成功排序。按 A/B、冲突符号、任务槽和处理时长分层。

如果固定读出在陌生请求上能稳定分清两步，而原动作头不能，说明当前状态可供读出利用的信息多于原头实际利用的部分。仍需在实际行动中验证新的读出能否形成稳定策略。如果线性读出失败但小型非线性读出成功，应优先检查表征与读出形式的关系。若二者都失败，本实验最多说明这些受限读出未能恢复边界，不足以证明 h 中完全没有时间信息。

在教师轨迹上可读但在自身轨迹上失败，意味着公开回执和实际行动造成的状态分布值得处理。此处的读出始终不控制行动，因此不宣称完成率提高或已得到新的自主计时机制。
