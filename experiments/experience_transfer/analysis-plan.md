# 旧经验究竟帮到了 B 的哪一部分

在观察本轮测试结果前确定。比较单位是配对的训练种子，不把同一个种子的请求或连续快照当成独立重复。普通 GRU 的直接 B 分支用于区分相关前史的收益与不重合前史的干扰，它在前史阶段花费的总训练预算低于另外两组。

1. 单列接触 B 之前的成绩。主比较取自由行动的成熟长请求，分开看所有符号、与 A 重合的一半、与 A 冲突的一半。冲突的一半在 A 与 C 里有相同的旧答案。
2. 在相同的新 B 经验和梯度预算下，比两组的绝对严格完成率，并比从各自 B0 出发的增量。保留每个种子、样本的分子分母和全部预定阶段。首批示范反复训练后的进步与额外得到新请求的进步分别解释。不从许多时刻中挑一次领先来宣称加速。
3. 在 B 训练结束并且没有复习旧规则时，回测旧规则。以不同规则会给出不同答案的符号作为重点，同时看旧新交错测试、普通完成和空闲误动。测试中被世界接受且全程无错的行动决定主结论。
4. 另用真实 B 教师执行的共同测试轨迹定位错误。所有模型读同样的公开提示和回执，冻结权重，绝不把测试教师标签作为前向输入。在每个新请求首次被教师要求 FINISH 时，测模型的十一选一动作、八选一结束内容，以及在版本已知时四个载荷中 B 和共同旧答案谁得分更高。共同教师轨迹用于诊断，因为其动作和回执不由被测模型产生。模型自己的自由完成率另行计数。

状态分支是另一项考察。在固定的一段公开历史上，给两个初始 h 相同的观察和反馈，再在同一世界端点分别放开行动。比较 h 距离、动作分歧以及后续新请求的无错完成和空闲行为。只能就本次实际播放的历史和时长判定差异是否持续。

### 交换哪一组有关联

另设 B′，沿用两组已经学完 A/C 的相同存档。B′ 在共同难点上与 B 的正确答案完全相同，而在其他两个符号上改为与 C 一致。对每个种子，始终用相同两个难点比较。这使“哪一段前史和新规则比较接近”换边，但不改变难点本身或需要纠正的旧答案。两目标都给适当分支提供真实示范，示范内反馈匹配于同一目标的两臂。

在查看已训练 B 或 B′ 的自由行动得分前，固定用第 0、1、2、4 轮末计算早期学习曲线面积。横轴为梯度训练已经用到的不同 B 新发请求数（记录 NEW，另列 REPLACE），各段用梯形积分，再除以第 4 轮的累计新发数。报告相关前史减不重合前史的平均严格完成率差，以及各自减去零点成绩后的曲线差。也保留早期首遍两次和八次更新及第 8 轮末的实际成绩。两种目标的每种子结果对折取平均，以降低某个固定前史较强造成的差异；三个种子仍是三个独立重复，六个前史与目标组合不充当六个独立种子。该量描述给定预算和反馈下的曲线，不能单独识别普遍的学习速率。
