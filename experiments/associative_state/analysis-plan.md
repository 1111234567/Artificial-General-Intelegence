# 关联状态的最小机制验证

2026-11-07，正式留出评分之前固定。接续 [MemT 核验](../../docs/memt-research-2026-11-07.md)。

本轮测试一个明确有限的部件：冻结已训练的 192 维 GRU 和原动作头，以符号适配器翻译 NEW/REPLACE 的内容。绑定公开回执与原请求、选定写入时机、执行逆置换均由程序提供；没有声称这些能力已经由模型自主学会，也不改变旧实验。

## 比较与预算

- 主要对照 add / delta：相同键嵌入、写入强度、读出尺度、初始化、训练样本及更新数，只有外积累加与关联残差修正的更新式不同。
- recurrent：64 维 GRUCell 快状态，作为相同快状态容量参照；它参数更多，不能声称等参数或等 FLOPs。
- 三组均增加 64 个快状态标量。原执行器 h=192；公开回执绑定器另有每任务槽四个缓存量，共八个，单列，不藏进状态预算。
- 三个种子；每模型 384 次 Adam 更新、学习率 0.003、batch 64、48 次写入/查询事件。训练样本每次重采独立随机映射，状态仅在独立训练样本开头归零，样本内保持。固定最终步，禁止挑选最好检查点。
- 独立的符号预训练只监督后续查询内容，梯度经过此前写入。它不是动作端到端训练，也没有把 oracle 直接写入矩阵。

## 新关联和实际行为

参数冻结后，为每 actor 产生独立新 A/B 映射，恰好两个 raw 一致、两个冲突。所有模型的留出映射与外生请求相同。实际世界仍是原十一动作、两任务槽、56 个公开观察；时长 8–16、间隔 16–32、dt=0.25。

前 1,536 tick A 和接着 1,536 tick B 由中点教师实际行动。适配器只在下一步公开的成功 FINISH 回执中得到正确值；手写绑定器用先前公开 cue 确定 key。标签、当前私有 payload、oracle 函数或私有映射不得直接进入记忆写入。模型所见输入与训练标签分开。

翻译只在 NEW/REPLACE 处修改 payload，保留 context；使用原策略熟悉的映射逆置换，防止执行器二次映射。动作仍由完整原 GRU 十一类 argmax 决定，不能由符号准确率替代。

## 固定参数、参数变化和覆盖

从同一个教学终点分叉，全部保留数值 h、记忆、绑定器、世界和回执：

1. immediate：立即 A/B 自主评分。
2. delay：4,096 tick B 教学，仅前向写记忆，随后 A/B 自主评分。
3. adapt：相同 B 教学，同时用公开成功回执上的写入前预测误差更新适配器参数，原执行器仍冻结；随后评分。
4. theta_only：相同 B 参数更新但禁止写快状态。快状态数值必须逐位保持，诊断旧地址读取是否改变。
5. clear / no_read：在共同终点分别清快状态或禁止其读出，保留其它状态后评分。
6. no_write：从第一个教学事件之前禁写，重新处理相同真实教师观察以得到该组自己的执行器 h，然后评分。
7. revise：在共同终点只改 A 的两个映射，保留旧请求目标；1,536 tick A 示范新规则后 A/B 评分。更改规则不清记忆或世界。

延后学习只更新适配器，不能解释成原 GRU 共享参数遗忘已被解决。在线 Adam 学习率 0.003，每个有成功回执的 tick 最多一次更新；两条继续学习分支使用完全相同的回执样本。写入与参数更新依次进行，快状态保留旧参数下写出的数值，不重建历史。这里对已分离计算图的 M 做写入前读取监督，实际有梯度的是键/查询共用嵌入与读出尺度；eta 和递归更新器没有在线梯度。它诊断读出地址适应，不是全读写模块的在线端到端学习，也不提供跨长间隔的梯度信用。

每次评分 2,048 tick，原生自主行动，快状态只读、参数固定。评分开始前不预热或清 h；只纳入评分段内新发且在结束前成熟的外部合格请求，边界截尾单列。分别报告 A/B、共享/冲突的严格和普通完成、空闲动作/机会、翻译正确率、记忆范数及教学覆盖。私有映射只用于环境和只读指标。

## 核验和边界

保存源码和输入工件哈希、完整训练设置、最终权重、各阶段起终状态、请求账本与计数。测试覆盖解析更新、重复/覆盖、掩码、跨写入梯度、回执归属及版本/取消、逆置换、公开观察隔离、主流连续边界和分母。开发速度检查不使用正式留出成绩。

这是新映射的关联适配器实验，不是 MemT 复现、完全原生记忆、无限时间信用或终身巩固。普通递归参照参数更多；公开示例、手写绑定与固定执行器是明确假设。失败亦保留，结果不决定追加训练预算。
