# 共享地址变换的后续对照

2026-11-07。在第一版行为评估已经完成后，检查在线梯度路径发现：第一版采用八个独立的可训练键向量。B 回执只会更新 B 的键；A 键不变，公共正读出尺度也不改变 argmax。因此，在 M 固定的 theta_only 分支里，A 内容选择不变基本由结构保证。第一版不能据此支持共享表示在持续学习中稳定，也不能验证此前的表示漂移假说。

保留第一版所有源码、协议和结果。第二版单独写入 `data/associative-state/shared-v2/`，不覆盖 v1；这是一项看到前一版结果后追加、在自身训练及留出评分前固定的实验。

唯一架构变更：将可独立训练的 lookup 键换成固定随机码 c_i 与所有地址共用的可训练矩阵 W：

\[
k_i=\operatorname{normalize}(Wc_i).
\]

随机码等于第一版相同种子的初始 embedding，W 从单位阵开始，因而初始地址数值相同。B 的梯度现在可以改变 A 地址。add/delta 仍只有更新式不同，共用初始化、样本和全部预算；递归参照也使用相同地址生成器。每条流仍有 64 个快状态标量、192 个执行器 h 与八个绑定器缓存量。全局随机码为 128 个固定标量，单列；add/delta 各 258 个可训练参数，递归组 16,769 个。两版之间不宣称等参数。

其余沿用 [原方案](analysis-plan.md)：384 次预训练、相同样本、独立测试映射、八个固定分支、真实回执、十一动作自主评分和请求分母；原执行器仍冻结。先全部训练完并冻结，再做评分。在线仅训练共享地址矩阵和读出尺度；快状态不重建，写入率/递归写入器仍没有在线梯度。

主要比较仍是同一版内 add/delta 的真实完成、空闲误动和修改旧关联后的行为。theta_only 的 M 必须逐位相同；若旧 A 的原生读取发生变化，这次才有共享地址变化这一实际可能的机制。即使没有观察到变化，也只能约束这套有限配置，不能推断原 GRU 共享参数遗忘已经解决。

全部保留第一版与第二版结果，不挑其中更好的当作唯一结果。两版共同的手写绑定、监督符号训练、固定执行器和有限任务范围仍是限制。
