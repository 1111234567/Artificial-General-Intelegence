# 同样经历上只训读出，还是同时改变循环状态

2026-11-05。接续 [时间边界诊断](../../docs/reports/actions/timing-boundary-experiment-2026-11-04.md)。主要问题是给时机和内容分别提供监督后，允许循环状态学习是否比只训练读出更能改善实际行动。

## 两组和参照

三个种子均使用原 FINISH 教师时刻组 B008 的普通 GRU 循环参数。该来源在上一轮旧 A 冲突保持方面较好，选择发生在本轮训练前。新的每槽输出包含三个动作类型、两个启动版本、八个结束版本与内容分数，共 13 个数，两个槽共 26。推理时先选择 WAIT、BEGIN 或 FINISH，再选择该类型对应的具体版本与内容，直接形成原生 0–10 动作。没有私有就绪门控、外部计时器或评估时的教师。

两组新输出权重与偏置全部为零，初始函数都因相同的 argmax 平局规则选择 WAIT。frozen 只更新输出层；full 同时更新输出层和循环部分。原有输出头不移入新头，完整原策略另作未继续学习的参照。因此这是从已有循环表征重新学习行动读出的比较，不能把收益单独归因于分头结构，也不是保留原策略函数的微调。

分头模型有 149,018 个参数，比原 148,246 个多 772 个，两个实验组的结构和总参数相同。主要因果对照是 frozen/full，原策略没有接受本轮监督或更新预算。

## 连续训练与相同预算

每种子有一条新的原生 A/B 混合长任务流，32 个 actor、两个槽。实际教师选择最早合法动作。先连续运行 512 tick 形成隐藏状态，然后单次顺序学习 32,768 tick，不重播 epoch、不重置世界或请求状态。每 128 tick 更新一次，共 256 次。块边界只截断梯度，数值 h 继续保留。更新参数后不重算或替换刚形成的 h。

两个分支消费完全相同的公开观察、真实教师回执和监督标签。数据涵盖正在发生的所有请求，包括未来会取消或替换的请求；训练掩码不使用未来合格性字段。私有状态仅用于当前监督标签和事后评分，模型仍只接收 56 维公开观察。

损失有三个固定项，相加权重均为 1。动作类型在每个 tick/槽监督，WAIT 权重 0.25，按实际权重和归一化；启动版本在教师 BEGIN 行监督；结束版本与内容在全部当前活跃行监督，包括应当 WAIT 的处理期。后两项各按自身监督行数取均值，空掩码贡献零。各项预算和分母单独记录，不把相加后的多个标签算成一次标签。

两组新 Adam 的学习率均为 0.001，梯度总范数上限 1，采用 float32，不使用 AMP 或 TF32。冻结组的反向计算量较低，所以相同更新与样本预算不等于相同 FLOPs 或耗时。没有学习率、监督系数或训练轮数扫描。

## 自主评估

在全部终点冻结后，使用训练外 32 个 actor，先自行行动 512 tick，再测 4,096 tick。评估状态只在独立世界开始时初始化，随后连续保留，世界真实执行模型选出的动作。

- 主要条件沿用处理时长 8–16、空档 16–32。
- 次要外推条件只把处理时长改为 16–32，空档保持 16–32，不把它与主要条件混为同一批请求。
- 保存第 64 次更新作为次要学习进度观察，256 次更新是预先固定终点，不根据评估挑选检查点。
- 主要分母包含全部测试段新发、外部合格且成熟的请求，含从未启动及根本没有到达合法窗口的失败，不能沿用上一轮“具有完整相邻边界”的取样分母。
- 分开报告普通/严格完成、旧 A 与新 B 冲突请求、空闲误动、首错抢答、从未启动、已启动但无合法窗口，以及整个合法窗口内未发 FINISH。全程无错比最终允许重试的完成更严格。

本轮 A/B 都参与继续训练，不能称为没有复习时的旧规则保持，也不是新 B 从零学习的速度测试。它检验在给定示范与监督预算下，修改循环状态对形成可用行动策略的作用。只读出失败不证明状态中不存在信息，全训练失败也不证明该结构不能学会。
