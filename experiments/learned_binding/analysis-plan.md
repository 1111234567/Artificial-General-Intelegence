# 学习绑定与写入，并从自身行动结果继续学习

2026-11-07。正式训练及留出评分之前固定。接续[关联适配器](../../docs/associative-state-experiment-2026-11-07.md)，完整保留旧实现与工件。

## 问题与模型

此前程序按请求缓存 raw/context/version，只在成功 FINISH 时写入指定地址。本轮新模型不调用这个绑定器，不按 context×raw 查键，不按成功回执屏蔽写入，也没有内容、地址、绑定或 gate 的辅助标签。

每任务槽共享一个 32 维 GRU，输入为原有 28 个公开特征。将其状态与当前公开输入拼接，生成归一化 query/key、四维 value 概率及 sigmoid 写入门；两个槽按 0→1 顺序每 tick 都可以 delta 更新共享 16×4 矩阵。读出的概率通过可微逆置换送入原执行器的 payload 字段，仅在公开 NEW/REPLACE 接口生效，其余输入不变。这一兼容接口仍是程序提供的，不等于模型自主学会完整输入/输出协议。

原 192 维 GRU 及十一动作头保持权重冻结，但保留输入梯度。可训练参数 8,210；动态状态为 h192、两个 z32、M64，共 320 标量。手写版是 h192、M64、八个绑定缓存量，另有不同的训练参数；不能称两者等容量、等参数或累计训练成本相同。

开发阶段先检查过短序列与设备速度，发现短任务偏离原执行器适用范围，因此正式请求时长统一为 8–16。encoder 的 update bias 合计初始化为 +4，允许学习；heads 可直接读取当前公开输入，避免强迫瞬时回执先经过慢状态。这些是初始化和可学习通路，没有硬重置、TTL 或成功写开关。写入 gate bias 初始 -5。未根据正式留出结果选择模型或预算。

## 第一阶段：完整动作示范训练

每种子 16 条独立随机映射教师轨迹，每条 1,024 tick、32 actor，两个任务槽。八条间隔 1–4，八条间隔 16–32；全程混合 A/B，映射每 actor 独立，B 与 A 有两个共享、两个冲突符号。教师实际执行中点动作，下一 tick 才出现相应回执；私有映射、状态和教师动作标签不拼入模型输入。

512 次 Adam 更新，lr=0.001，梯度裁剪 5。前 128 次循环密集轨迹，余 384 次循环全部 16 条；每条轨迹完整反传 1,024 tick，无中途截断。独立轨迹起点 h/z/M=0，不宣称这是同一个无重置训练生涯。损失只为完整十一动作 CE，WAIT 权重 0.25，其余 1。动作 CE 使用教师答案，因此此阶段属于有监督学习，不能叫仅靠自身奖励。

三个终点全部完成并冻结后才评分，不选最好训练步。固定一条长间隔轨迹，检查最后四分之一动作损失能否到达较早成功回执时的 key/value/gate；只报告梯度可达性，不用它选模。seed0 使用严格 FP32 CUDA（禁 TF32），seed1/2 使用 FP32 CPU，各一数值线程并行；预算、目标和数据协议相同，设备分别记录。开发实测 T1024/B32 前向反向 CPU1约1.03秒、CPU4约1.04秒、GPU约0.81秒；混合调度避免三个任务争同一 GPU。

## 主线：自身经历与旧 A 保持

三个种子各建立全新的留出世界，h/z/M 从零开始，之后持续运行。自身 A/B 支持期 4,096 tick，所有模型都从全部十一动作的分布中采样，没有动作合法性过滤，没有教师替换。这部分经历可以包含失败；奖励不泄露正确答案。

主参照为原手写 hard 版本、相同手写读写但用软概率接口的 manual_soft，以及学习后的 native。soft 参照用于分开接口和绑定机制差异；保留 hard，避免把修改后的接口冒充旧版本。

native 自身支持终点完整复制为 frozen 与 outcome 两支，含参数、h/z/M、世界、回执和独立采样 RNG。未来 NEW 只产生 B，继承的 A 请求与修改自然收尾，不清空旧状态。手写两组也继续自己的 B 经历。每支 32 块×512 tick，自身动作及回执随策略变化；外部请求可配对，但不能声称所有组观察完全相同。

frozen 及手写组不更新参数，仍正常更新快状态。outcome 用下一 tick 的公开结果训练：成功 FINISH +1，任意被拒动作 -0.1，其余 0。无 oracle、内容标签、教师 CE 或额外熵项；不靠该奖励确定写入位置。两槽共享 M，故先把两槽奖励相加成 actor 总奖励，以 gamma=0.995 求块内回报，用其它 actor 的平均回报作基线，再乘两槽动作的联合 log probability。Adam lr=0.0001、梯度裁剪5；每块一次更新。

512 tick 内重放公开观察来计算所采动作的概率和梯度，重放状态不覆盖真实流的 h/z/M。块尾多 observe 一次取得最后动作回执，将该观察保存为 pending，下一块恰好消费一次；最后单列多执行一个收尾 tick。数值状态、世界、pending 与 RNG 在参数更新时保持不变。信用在块起点截断，不称无限时间信用。

## 行为评分与诊断

从自身支持终点、B frozen 终点、native B outcome 终点各自分叉，恢复未来 A/B 请求，自主 argmax 评分 2,048 tick。参数冻结，快状态仍由各模型继续更新；因此总体成绩允许在测试中继续从自己的回执更新状态。额外单列每 actor/family/raw 首次请求，辅助判断复访表现，不把整个评分段叫无新 A 经验的纯保持。

另做相同外部世界、相同映射下的 4,096 tick 实际教师支持诊断，三种模型接收相同原始观察与动作；随后自主评分。它只检查“有正确示范时是否能自行绑定”，不混进自身经历主线。native 在此终点再比较清 M、清 z、禁读；清状态后仍允许正常后续写入，因此不能把它们当永久删除全部记忆。

总计39份行为评分。主要指标为成熟外部合格请求的 A/B冲突与共享严格/普通完成、空闲误动/实际机会、实际回报及采样动作数。严格定义为成功 FINISH 前活跃期间无被拒动作，结束后的空闲误动另计。所有从未BEGIN/FINISH的成熟失败都进入分母，左继承和右截尾单列。新模型的 gate 在公开成功FINISH、命令与其它位置的分布只用于诊断，不能反向成为写入规则。

## 可复核性及预期失败

保存源参数/源码/数据哈希、完整状态、独立 RNG、动作概率、公开回执、全部384个B块、真实奖励及优化器。核对所有39份分母/账本，全部B块的奖励错位与状态链，至少三种子各首末一次真实PG更新独立重算；另固定九份评分完整重放。

可能出现：示范训练不能形成可用绑定；能利用教师经历却无法自行收集有效经验；PG学会少动而非完成任务；新规则收益伴随旧A下降；短暂z代替M存储。以上均作为结果保留，不据正式成绩追加训练、挑选种子或改目标。当前不测试自由拓扑、大模型、语言语义或自动长期巩固。
