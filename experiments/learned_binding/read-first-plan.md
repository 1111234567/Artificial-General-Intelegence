# 先读取旧状态、再写入当前输入的后续对照

2026-11-07，在第一版全部评分及审计完成后提出，在第二版训练之前固定。本方案不修改或替代第一版。第二版目录为 `data/learned-binding/read-first-v2/`。

第一版学习者在正确教师经历后总体严格完成约19.5%，禁读约21.1%，内容翻译约23.3%，未学会可靠关联使用。事后诊断显示：成功回执到达时，trained z+当前输入的固定线性读出仍能恢复约92.2%的请求身份；原CE的FINISH项已占90.6%–96.6%，不支持把WAIT数量直接当作主因。门在命令位置比成功回执位置更大，但这些关联现象还不是故障的因果定位。

一个待测解释是：原顺序允许当前命令先写M，再立即从M生成当前命令的翻译，优化可能偏向这条短路径，而未学会把早先经历与未来请求关联。

**只改一个架构因素：** 每tick先从进入该tick的M读取，再依原有两个job顺序写入本tick信息。当前观测仍参与z/query/key/value/gate生成；所有位置仍允许写入，未增加成功写mask、绑定标签、地址表、重置或硬门。写入产生的M完整传到下一tick。q/k/value/gate、encoder与执行器的参数数目、初始数值、总状态均与原版相同。

沿用原版16条训练流、512次更新、1024tick完整轨迹动作CE、优化器、设备分配和全部自身行动/PG预算。三个终点全部冻结后才评分。使用原先同一组世界、请求、采样种子及规则，便于对照，但这是**查看第一版结果后的追加试验，重复使用了评价集**，不是完全独立的新验证。无论结果如何，原失败版均保留。

手写hard/soft算法、参数、数据与采样在此变化中均不受影响，其18份评分及B阶段工件逐文件复制复用，保存原路径和SHA，不重复计为新的实验。第二版只新增三个native训练终点、21份行为评分和192个B块。两版比较限学习者的顺序因素；手写版依然有不同的先验结构和累计训练成本。

评分及诊断名称与[第一版](analysis-plan.md)相同，含自身支持、B frozen/PG、相同教师经历、清M、清z和禁读。此后不依据第二版成绩扩大本轮预算或再调整架构。先核对主动作与旧A是否已学会，再谈保持；评分上升也不单独证明绑定的内部机制已经确定。

审计必须实例化正确的read-first类，不能只换目录仍用write-first重放。参数更新仍只由实际动作CE或公开奖励产生，独立核对联合actor回报、pending回执、h/z/M连续链及首末PG/Adam更新。
