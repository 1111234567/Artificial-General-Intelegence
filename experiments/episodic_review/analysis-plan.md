# 同预算旧 A 复习与旧 B 重复对照

2026-11-07。接续 [规则撤出实验](../../docs/coverage-retention-experiment-2026-11-07.md)。本轮只推进旧规则保持，时长仍为 8–16，不同时扩大时长范围。

## 三组从同一完整状态出发

全部模型从上轮撤出开始前的三个中点动作终点出发，复制完整模型、已训练时间读出、Adam 第 256 步状态、数值 h 与 RNG。实际主世界沿用已冻结的 B-only 连续流，共 32,768 tick、256 个 128 tick 更新块，没有新预热。进行中的边界旧 A 任务照原流自然结束，暴露量与此前撤出对照相同。

| 组 | 256 次更新的来源 |
|---|---|
| none | 全部来自连续 B 流，必须逐位复现上轮 withdraw 的 0/64/256 存档 |
| replay_A | 224 次来自 B，每第 8 次更新用旧 A 片段替换，共 32 次 |
| replay_B | 相同 224 次来自 B，同一位置替换为等量旧 B 片段，共 32 次 |

主要对照是 replay_A/replay_B，用于分开旧 A 监督与重复训练本身。none 是完整 B 继续学习的参照。更新次数相同，但实际监督行数和额外前向成本不同，不能称为同样的全部标签量或 FLOPs。

## 固定旧经验库

经验来自撤出以前真实执行过的中点教师流，没有使用新测试数据或按当前预测筛选。每种子选 256 对已由教师成功完成的 A/B 请求，四种原始符号各 64 对。过去已完成是记忆库筛选条件，不代表保留了所有取消、替换或失败经历。

每对匹配任务槽、原始符号、版本、NEW/REPLACE 类型、cue 到 FINISH 的长度及首次合法位置。保留 128 tick 的原始公开历史，其中 32 tick 在 cue 之前。只监督目标槽从 cue 开始的 96 个位置，包括真正结束后的空闲 WAIT。逐对验证全部动作类别骨架、动作掩码、时间掩码及正负位置相同。结束后尾段必须真实无新命令、处于非活跃状态且教师为 WAIT。

其它槽和前史观察原样保留，但不为它们提供动作或时间标签。因此 replay_B 仍可能看见附带的旧 A 观察，不能说它完全没有 A 输入；它没有 A 目标槽的监督。

32 次重放每次选 32 对中的对应一侧，使用四个预先固定的 256 对排列，每对恰好重放四次。A/B 的顺序、动作监督量和掩码逐位匹配。每次重放有 3,072 个动作标签，32 次共 98,304 个；原完整 B 块有 8,192 个动作标签。原生十一动作 CE、WAIT 权重 0.25、停止梯度的时间读出、Adam 及分别裁剪保持不变。

## 复习状态不替换主状态

每个主流块的 B 观察都先真实前向运行，保留该块的数值 h 终点。普通更新按原方法反传；重放更新不对这一个 B 块反传，而在另一套状态上学习旧片段。更新参数后仍携带先前那个 B 终点，不重置、不重算，也不改成重放片段的 h。

旧片段没有保存或移入过期的隐藏态。每次重放使用当前固定权重，从旧历史的独立起点 h=0 重新读取到所需窗口之前，选中 actor 按索引去重排序；分块长度不超过 512，且在所需 anchor 位置分割。只在同一次更新内共享这次重建，不能跨不同权重缓存状态。随后对 128 tick 旧窗口反传，前史重建本身无梯度。额外前向行数与时间单列。

实际主世界仍由同一 B 教师产生回执，不因辅助重放改变。回放使用研究者保存的示范和固定日程，不是模型自主决定何时复习或自己评判旧经验价值。

## 评价与边界

所有终点冻结后，在新世界上比较源基线与三组固定终点。三个模型种子、两种处理时长 8–16 与 16–32，均为空档 16–32、32 个 actor，512 tick 自主预热后测试 4,096 tick。源基线没有这轮新增政策训练。16–32 只作未覆盖时长检查，不在本轮训练。

另外从同一实际 B-only 世界终点恢复各组自己的 h，只将未来请求恢复为 A/B，冻结权重后连续运行 512+4,096 tick。这九次返回检查不重置世界或 h，主分母只含测试段新发、合格且成熟的请求，继承请求单列。新世界与连续返回不是同一批请求，不能直接配对相减。

主要看旧 A 冲突严格完成能否高于 none 与 replay_B，同时记录 B 冲突、共享答案、普通完成、抢答、窗口漏发、空闲误动和首次合法窗口回答是否恰为另一规则答案。固定第 256 步终点，不调复习比例、学习率、阈值或选最好检查点。有限旧经验保护成功，也不能直接推断无限保持或自主终身学习已经实现。
