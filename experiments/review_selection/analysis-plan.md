# A、B 交替时的复习选择

本说明在查看任何新训练策略的自由评估成绩前确定。固定三个训练种子，从上一轮相关前史 A 的同一套 GRU、Adam、世界和连续状态开始。目标 B 对四种符号中的两种要求改变答案，另两种仍沿用 A 的答案。只使用此前实际遇到过、保留旧教师标签的 A 经历做复习。

主要比较三种等预算选择。均匀组从同一候选池均匀抽取。冲突组只选 A 与 B 答案不同的旧符号，这是研究者已经知道冲突身份的参照。误差组根据本组模型当前在旧 A 样本上的预测误差选择，不把冲突身份作为选样输入。无复习参照沿用已经完成的同源训练，它把全部更新都用于 B。总更新数相同，A 与 B 的监督位置数在无复习参照与三个复习组间不同。

1. 在未参与训练的 B-only 长任务上，以成熟请求的全程无错完成率测学习速度。分开重合符号和冲突符号。预定早期曲线取第 0、1、2、4 轮终点，按实际新增 B 请求数做梯形积分，再除以该段新增数，以百分点报告。在首轮只看过同样若干新经历但反复优化次数不同的快照另列。比较全部种子和终点，不以某个有利的阈值定义胜负。
2. 在同一世界各任务槽按请求交错分配 A、B 的测试中，分别计旧 A、新 B 的严格与普通完成，尤其是两个冲突符号，并列出实际空闲误动作。三种子先各自计算比率再等权平均。能兼顾两者应同时体现在 B 的早期曲线、末端新 B 和旧 A 的冲突成绩上。若改善其中一项却损害另一项，如实保留取舍。
3. 另测同一槽、同一符号连续两件事的状态切换。测试者安排 AA、AB、BA、BB，模型不见配对标记，整个世界运行时没有教师行动干预。只计两次新发且均成熟的完整对，以 AB/BA 冲突对的两次都全程无错为主，并拆分方向和重复情境。此测试不含取消和替换；上一步的随机混合测试保留原有干扰。
4. 单列每组实际复习过哪些旧样本、冲突比例、重复与覆盖，及预测误差来自哪类监督位置。使用已保存教师答案计算误差，因此该方案检验有监督的复习选择，不能据此声称模型已能独立判断对错。
