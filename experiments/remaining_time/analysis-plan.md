# 保留原策略后学习有符号剩余时间

2026-11-06。接续 [分开学习时机与内容实验](../../docs/reports/actions/action-split-experiment-2026-11-05.md)。上一轮重新训练的动作头未获得可靠性收益，本轮保留原循环和完整十一动作读出，从同一个初始策略检验时间预测监督。

## 四个对照

三个种子都从原 FINISH 教师时刻组的 B008 存档复制原 GRU 循环和动作头，只附加一个零初始化的线性时间读出，每个槽一个值。总参数 148,632，比原模型多 386。原动作 logits、隐藏态和动作选择必须在训练前逐位复现，时间预测不进入原前向路径、模型输入、动作选择或合法性门控。

| 组 | 政策参数如何更新 | 时间读出如何更新 |
|---|---|---|
| probe | 原循环和动作头均冻结 | 仅拟合时间读出，用于测可读性和不干扰行为的控制 |
| time | 仅循环接收时间损失，原动作头权重冻结 | 拟合时间读出 |
| action | 原循环和动作头接收原十一动作交叉熵 | 在停止梯度的 h 上拟合时间读出 |
| joint | 原循环和动作头接收动作损失，同时循环接收时间损失 | 拟合时间读出 |

probe 的实际策略应始终等同原策略。time 的动作头权重虽然冻结，但循环变化仍可能改变行为。joint/action 比较用于隔离增加循环时间梯度的作用；不能把 joint/probe 的全部差异都归于时间目标。

## 共同经历和监督

使用上一轮已独立核验的三条完整最早合法教师流，每条 32 actor、双槽，512 tick 预热后顺序学习 32,768 tick。每 128 tick 更新一次，共 256 次，没有重复 epoch。各组共用全部公开观察与真实教师回执。数值 h 在流内连续保留，更新处只截断梯度，更新后不重算过去的 h。

时间标签为 `(当前就绪时间 − 当前世界时间) / 16`，仅在当前活跃、已经启动且就绪时间有限的位置监督。原始数值先按原生 float64 时钟计算，再转 float32；无效位置填零且不参与损失。16 是固定的环境时间尺度，不是 tick 数。没有根据预测误差选样，也不使用未来取消/替换或成熟合格性来过滤训练行。

时间损失为有效行上的均方误差。动作损失是原十一动作交叉熵，WAIT 权重 0.25，按权重和归一化。joint 两项系数均为 1，没有参数扫描。各组时间读出都接受相同监督；action 中时间读出的梯度不进入 h，且时间读出与政策参数分别按范数 1 裁剪，避免时间读出的梯度通过共同裁剪间接改变 action 的更新。

各组使用新 Adam，学习率 0.001，float32，不使用 AMP 或 TF32。同样本和更新预算不等于同样运算量。零时间读出使 time 组第一次循环时间梯度为零，第二次才可能改变循环；action/joint 第一次仍可通过动作损失更新循环。原动作头保持复制而不清空。

最早合法教师通常在刚就绪时就结束，因此负时间训练标签只覆盖约一个 tick 的范围。本轮不声称覆盖整个过期区间。时间尺度与系数决定梯度大小，并不表示两个目标的重要性已经配平。

## 在独立世界中检验

全部终点冻结后，使用新的世界种子 853000+seed、actor 98000–98031，模型先自行行动 512 tick，再测 4,096 tick。每条独立流只在开始时初始化 h，之后不按请求重置。主要条件处理时长 8–16，次要条件处理时长 16–32，两者空档均为 16–32。使用固定第 256 次更新终点，64 次存档保留用于进度核对，不据评估选择模型。

主要行为指标包括所有测试段新发、外部合格且成熟请求的严格/普通完成，旧 A、新 B 冲突请求，空闲误动作，抢答首错、未启动、无合法窗口和整窗漏发。取样不能以已经启动或具有完整相邻边界为条件。probe 必须与原策略的完整原生行动流和结果逐位一致。

独立记录时间误差，按物理单位及 tick 报告，并分处理中、边界附近、合法窗口及处理时长。相邻最后非法/首次合法两步的符号判断只作诊断，零阈值固定，不将时间值变成外部控制器。另在共同的独立教师历史上比较所有终点，以区分可读时间与自身行动回执造成的状态变化。

本轮 A/B 都参与继续学习，仍是有监督训练。结果只能说明这项固定辅助目标在给定预算下的作用，不能单凭误差下降或失败宣称已经形成通用计时机制、长期自主学习，或断言状态没有相应信息。
