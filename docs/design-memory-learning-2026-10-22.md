## 0. 这份草案要解决什么

### 0.1 目标与判据

Jerry 定的 AGI 判据：

- **A. 能持续自主学习**（不问也会变强）
- ~~D. 有连续的自我（跨会话是同一个人）~~ → **2026-10-23 悬置**

> **⚠️ D 判据悬置（2026-10-23 拍板）。** 理由（Jerry）：「人的意识到底是个什么东西，和动物的区别在哪，都说不清楚，这个连碳基生物都不是的就更说不清楚了。有没有答案都不知道。」
>
> **含义三件：**
> 1. **它不再是设计目的、不驱动实验、不排期**——§2.9 的推演保留（它解释「为什么外挂不够」），但不再当判据用。
> 2. **§11.5（阶段 C）/ §12.11 整段标注悬置**——保留原因：它们记了「两条路都走不通」的推理（行为层测不出 / 结构消融有循环依赖），是资产，不是待办。
> 3. **一个侧面收益：很多结论本来就不靠 D。** 「外挂不够」的硬理由在 A 就成立——外挂的记忆不参与前向 ⇒ 经验改不了它 ⇒ 持续学习无从发生。**「本体必须有可塑性」不需要（自我）这个概念就能推出。**

而 **B（自主设定子目标）和 C（跨域迁移）不列为判据**——它们是 A 成立后**自己长出来的**。

这个选择很重要：它把「该验证什么」压缩到两条，也给「什么算成功」划了线。

### 0.2 主体是智能体，不是模型

本文件所有讨论的主语是「**它**」，不是「模型」。

这个区别不是措辞问题。主体一换，所有「功能」变成「器官」：

| LM 语法 | AGI 语法 |
|---|---|
| 模型有记忆 | 我记得 |
| 模型需要门控 | 我判断 |
| 模型的状态 | 我现在在哪 |

而「层」这个说法在 AGI 视角下基本失效——**层是优化的产物，不是存在的必需品**。

### 0.3 明确不做的事

- **不追求「打败语言模型」**——扩散 / 分区的价值在提供不同计算形态，不在刷 benchmark
- **不追求「完全无反向」**——纯局部规则在深网上不够（实测：BCM + BP 混合在小 MLP 上 ~45%、简单 CNN ~70%），反向是「锚」不是「补救」
- **不发明新参数**——每个常量要么是需求给的，要么有文献出处
- **不先定规模**——先验证机制（阶段 2→3 的切换是否成立），规模后置

## 1. 核心判断（七条）

### 1.1 预测 vs 控制——这一刀切下去

| | 训练一个 LM | 训练一个 AGI |
|---|---|---|
| **目标** | `maximize P(token_t \| token_<t)` | 达成目标（世界从 s 变到更接近 g 的 s'） |
| **学习信号** | 语料的下一段（天然监督） | 行动的结果（**没有天然监督**） |
| **学习方式** | 旁观（观察统计） | **参与**（行动 → 观察 → 调整） |
| **时间** | token 位置 | 真实时间（有持续、中断、等待） |
| **状态** | 上下文（每次重置） | **主体的一部分**（此刻在哪、要什么） |
| **目标来源** | 外部给定 | **必须内生** |
| **训练期** | 训练完 → 冻结 | **永不结束**（部署即训练） |
| **评价** | loss / benchmark | 能不能持续做事、能不能变强 |

**最关键的一行是「学习信号」**：LM 有一个免费、无限量的监督（语料的下一段）；AGI 没有，它必须从「我做了 A，得到 B，和我预期的不一样」里学。

**这就是为什么 LM 的技术都长得像统计学习，而 AGI 的技术必须长得像控制。**

### 1.2 「分区」不是架构，是待验证的涌现结果

原稿写「只有短期 / 长期是真分区」。**2026-10-23 推翻**：如果长期记忆就是连接本身（§2.10），那「短期」不是另一个区，是**同一批连接的当前状态**。分区不是设计出来的，是分化出来的——能不能分出来，是实验问题（§11.4）。

### 1.3 结构可以让它长；τ 既不能逐单元设计，也不由环境给

> 2026-10-23 重写。原版：「时间常数不会自发分化——必须显式给定——但在 AGI 里由环境给」。两个半句都错，依据见 §2.2。

- **结构（分层、连接、修剪）可以让它涌现**——任何多层网络都会自发形成层级，修剪会强化它
- **但「衰减率谱」不会自发铺开**——异质网络的多尺度来自**结构异质性**（子群大小 / 耦合强弱），不是「给每个单元设 τ」；给每个单元设 τ 在强递归下**被抹平**（Stern 2023）
- **τ 不是可设计的量**——它由分区 / 结构异质性 / 基底多样性三者共同决定（§2.2）；直接调 τ 会撞上「衰减与频率经 Δ 纠缠」（S4D-DFouT）与「A 参数化脆弱」（HOPE）。**但两个形态是有效的：按组分离成双峰（LSRSNN）、按层共享一个可学习 τ（PLIF）**——即「不能逐单元连续设计」，不是「完全不能碰」（§2.2 第三次修正）
- **环境能给的不多**——任务时长与反馈延迟给的是**需要多长**（需求），不是**能做到多长**（上限）。上限由初始结构给：纯实部谱在 S4D 消融里降 5.45 / 10.17
- **多尺度的功能是频谱分解**，不是「记忆长度分级」（Stern 2023）——记忆长度只是副产品

### 1.4 一致性 ≠ 正确性

有环境之后，正确性免费（做成了就是成了）。**但反馈是稀疏的**——一个长任务可能 200 步之后才知道成没成，中间 199 步只能靠内部一致性、预测误差来支撑。

所以，「一致性」不是「正确性的替代」，是「**稀疏反馈期的填充**」。这是一条安全边界：任何内生信号（N-gram 命中 / 能量低 / 重建稳定）都不能当正确性用。

### 1.5 判据是过程的形状，不是产出

理由见 §4。最关键的一条：**结果不可审视，过程可审视**。

一个智能体要「自己变强」，它需要的是可审视的对象。结果只有一个字（成 / 不成），过程有一整条轨迹。

### 1.6 反馈是唯一的硬约束

前面所有讨论（门控、归因、一致性、修剪）其实都是反馈的不同侧面。

**LM 的反馈在五个维度上全部是理想值**（密度 / 延迟 / 可信度 / 归因粒度 / 可分辨性）——这不是巧合，因为监督信号是「下一个 token」。

**AGI 要在五维全部劣化的条件下学习。** 这是它唯一的真正技术困难。详见 §3。

### 1.7 这一整套机制有一个现成的名字：SNN（2026-10-23 第三次修正）

把草案的机制清单逐条翻译成领域术语，会发现它们全部落在同一个已有学科的词汇表里：

| 草案里的说法 | 标准术语 |
|---|---|
| 稀疏图 + 节点动力学 + τ | **RSNN**（recurrent spiking neural network） |
| 基因 = 结构超参数，变异 + 选择 | **neuroevolution / evolutionary SNN** |
| 发育 / 从单节点长 | **developmental / self-organizing SNN** |
| 局部规则 + 资格迹 + 全局调制 | **e-prop / three-factor learning** |
| 临界态、雪崩、稳态 | **self-organized (quasi-)criticality** |
| 写入局部化、不挤占 | **continual learning in SNN** |

**这提供两个后果：**

1. **一半的工作不用重做**——结构演化（ELSM 已跑出小世界 + 临界）、多尺度分群（LSRSNN 的双峰 τ 比「逐单元设 τ」有效）、稳态自组织（两个机制就够）、在线学习（e-prop 有理论 + 有现成库）都有现成答案与数字。
2. **但草案要的那一支恰恰是 SNN 主流排除掉的**——主流是「BPTT + 固定 T + 按样本重置 + 有任务和准确率」；草案阶段 B 要的是「永不重置 + 无任务 + 无准确率」。这两组前提**互斥**，不是同一件事的不同做法。

完整对照、被修正的三条、以及为什么阶段 B 是真空：见 §15。

## 2. 本体、状态与结构（2026-10-23 重写）

> **本节于 2026-10-23 重写。** 原题「两区架构」——把「短期 / 长期」当设计前提。推翻的理由在 §2.10：长期记忆就是连接本身，不存在「另一个区」可以搬运过去。原来的 §2.1–§2.8 保留为**曾经的分区尝试**（它列的对错仍需保留），但不再作为架构前提。

### 2.1 曾经的分区尝试（已降级）

> 2026-10-23：本节降级为「历史尝试」，原结论已推翻——见 §2.10。

先把「层」逐个还原成它实际是什么：

| 曾经当作「层」的 | 实际是什么 | 归属 |
|---|---|---|
| N-gram 查表 | 快速检索的**载体** | 短期区的一个器官 |
| KV / 滑动窗口 | 精确复现的**载体** | 短期区的一个器官 |
| 工作区（J-space 式） | 无条件广播的**子集** | 短期区的一个器官 |
| 参数里的几何结构 | **参数本身就有的属性**，不是一层 | 长期区的性质 |
| 稀疏槽 | 短期→长期的**中转站** | 迁移机制，不是一区 |
| 序列打分器 | **读出**，不是存储 | 迁移机制的一部分 |
| 「自我」 | 不是器官，也不是一层 | **长期网络的结构**，不属于任何一区（§2.9） |

（原结论「真正的分区只有短期 / 长期」已推翻——见 §2.10。「自我」那一段仍然成立。）

**实测依据**（Externalizing the Workspace, Zenodo 2026-07）：

| 形态 | 价值压力下的承诺持久性 |
|---|---|
| 无条件广播的自我状态 | **1.00** |
| 检索门控的自我状态 | 0.61（崩到无 soul 水平） |
| 仅记忆（含反思） | **0.00** |

三个数字定了一件事：**「状态」和「记忆」的区别不是容量，是「是否始终在场」。**

但它测的**不是「自我在哪」**：它测的是承诺在价值压力下能不能守住。始终在场的自我描述守住了（1.00），检索门控的崩了（0.61），光有记忆的彻底归零（0.00）。所以它支持「某类内容必须始终在场」，推不出「自我是短期区的一个器官」——原表那一行是误读，已在 §2.9 推翻。

### 2.2 「时间常数必须显式给定」——四条独立证据推翻

> 2026-10-23 重写。原稿写「不同时间尺度不会自发分化，除非给它不同的时间常数」，并说「在 AGI 里它由环境给」。**两个半句都错。**

**τ 不是可设计的量。** 四个独立来源（工程消融 / 生物理论 / 工程参数化 / 工程实践）指向同一件事：

| 来源 | 事实 | 推翻了什么 |
|---|---|---|
| **S4D**（NeurIPS 2022 消融，Table 3a） | 实部固定 **-1/2** 就够（原文「a good default」）；真正要铺开的是**虚部（频率）**。纯实部谱 `A_n = -(n+1)`（就是 Mamba 的初始化）在表里是 **S4D-Real**，三项消融数据集上分别降 **5.45 / 10.17**、升 0.066；随机谱降 **6.32 / 1.95**、升 0.034 | 「给衰减率谱有用」 |
| **Stern et al.**（eLife 2023） | 单细胞 τ 的异质性在强递归下**被抹平**；真正产生多尺度的是**异质组装的大小**（结构），不是 τ | 「给每个单元设不同 τ 有用」 |
| **S4D-DFouT**（NeurIPS 2025） | 衰减与频率经离散化参数 Δ **纠缠**（两者都随 Δ 线性变）；且 S4D-Lin 下只要 Δ > 2/τ，就再也做不出 τ 处的 spike | 「设定 τ 这件事成立」 |
| **HOPE**（OpenReview） | A 的参数化**脆弱**：要降学习率、要重参数化才能稳定训练 | 「显式给定是稳的」 |

**正确的表述：** 可设计的是三件——**分区**（哪个载体）、**结构异质性**（谁和谁耦合多强）、**基底多样性**（频率铺开）。尺度是这三件的输出。

> **2026-10-23 第三次修正（收窄）：** 上面「τ 不可设计」的覆盖面要缩小。SNN 领域的四条独立结果把这件事分成四档：
>
> | 做法 | 结论 | 证据 |
> |---|---|---|
> | 以**单元**为单位连续铺开 τ | **无效**（强递归下被抹平） | S4D 消融；Stern eLife 2023 |
> | **单峰宽分布**直接混在一起 | **无效甚至更差** | LSRSNN（Neural Networks 2026-03）原文 |
> | 按**组**分离成双峰 + 专门算法 | **有效** | LSRSNN（工作记忆 + 语音任务） |
> | **每层**共享一个可学习 τ | **有效** | PLIF（ICCV 2021） |
>
> 所以准确表述是：**τ 不能逐单元连续设计，但可以按组分离或按层共享。** 而「按组分离」正是本节三件里的「分区」——草案已隐含，但没写出这个具体形态，而它恰恰是唯一有正面证据的形态。

**「由环境给」也不对。** 环境能给**取值**，给不了**上限**：

| 层 | 谁给 | 证据 |
|---|---|---|
| 尺度数量与分布**形状** | **初始结构给**（学不出来） | Mamba：「初始化就给谱，因为 the optimizer doesn't have to **discover from scratch** that the model needs both fast and slow dimensions」；S4D-Random 差 6.32；Stern（单细胞 τ 被抹平） |
| 具体**取值** | 学习 / 环境微调 | IScience 2018（内在尺度梯度只在训练后出现，随机初始化时塔塌）；Yamaguti 2026（可学习 τ 能学出来，但 20 个网络学出的机制各不相同） |
| **用哪个** | 输入决定 | Stern 2023：大组装 entrain 输入的慢成分、小组装 entrain 快成分 |

**最后一行最要紧**：多时间尺度的功能不是「记忆长度分级」，是**频谱分解**——把复合输入拆成不同频带。记忆长度只是副产品。这也解释了为什么「铺开频率」有效而「铺开衰减率」无效：前者改变系统能看见什么，后者不改变。

**一个必要的限定（否则又是「照搬生物」）：** 生物的快/慢分家（海马 / 皮层）来自不同的可塑性机制。但那可能是**实现约束**（蛋白质种类有限，只能靠不同分子实现不同时间常数），不是原理。判定标准：换一个实现还成立吗——**所以这件事不能靠引生物定，只能做实验（§11.4）。**

### 2.3 一个升级：「使用次数」是结构生成，不是淘汰

「通路使用次数」曾被当作淘汰机制。**实际上它更像雕刻工具**——用进废退不只是删东西，它还塑造形状。

**这是 §2.2 里「修剪形成分层」的实现方式。使用次数不是清理，是生长。**

### 2.4 「寄存区」这个中间态（部分失效）

> 2026-10-23 注：本节把「寄存区」当记忆的一个存放位置。若长期记忆就是连接（§2.10），那「一个外挂的表参与前向」只能算**状态**的载体，不是长期记忆。**仍成立的部分：** ① 「不被梯度改写」≠「主干冻结」；② 遗忘的根源是「写入作用在所有输入上」，不是「更新」本身（LSL 的 76.6% → 96.6%）；③ 可写的东西要稀疏改。**已失效的部分：** 「寄存区」作为长期记忆的一类载体。

| 形态 | 参与前向吗 | 写入机制 | 算「寄存区」吗 |
|---|---|---|---|
| 外挂（RAG / 文本） | 只在 context 里 | 无（会话结束消失） | ❌ |
| **寄存区** | **是（作为参数被读入）** | **定向写入（范围受控，不是不写）** | ✅ |
| 主干 | 是 | 全局反传（所有参数被所有样本影响） | ❌（它是本体） |

**「寄存区」比「外挂」「层」都准**：外挂暗示不参与计算；层暗示与主干同构；寄存正好是「参与但不属于」的中间态。

三个澄清（2026-10-22）：

1. **「不被全局梯度改写」不等于「主干冻结」。** 前者说的是表，后者说的是本体。梯度可以穿过门控流回主干，训练会教主干怎么用这张表——Engram 就是端到端训练的（表不接收梯度，门控与主干都更新）。
2. **真正的区别是「写入是否局部」，不是「能不能写」。** 遗忘的根源不在「更新」本身，而在「更新作用在所有输入上」（LSL 的发现：把写入限制在产生它的输入区域后，retention 从 76.6% 回到 96.6%）。所以寄存区的本质是**写入局部化**。
3. **表可以被改写**，但应该是稀疏改写（改某几行），不是全量重建。全量重建等于把灾难性遗忘做到极致：一次动全部行，所有行互相干扰。详见 §14.10。

文献位置：In-Parameter Memory 综述（arXiv 2610.08630）里的 **Embedding layer placement**——记忆作为连续 prompt / 前缀 / latent state，在第一个 block 之前进入。

### 2.5 两边的 N-gram 是同一张表吗（已降级）

> 2026-10-23 降级：本节前提（短期是「表」、长期是「大表」）不成立——长期不是表，是连接（§2.10）。保留作历史。

| 方案 | 结构 | 后果 |
|---|---|---|
| A. 同一张表 | 短期写、长期读同一张 | **冲突**：短期写入污染长期统计 |
| **B. 两张表** | 短期小表 + 长期大表，巩固时迁移 | 需要「巩固」机制 |
| C. 长期表 + 短期缓存 | 只有一张大表，短期是它的缓存层 | 天然一致，但短期无法「写新的」 |

**倾向 B**：

- 短期要能记「这次新出现的」（可能一次性、未经验证）
- 长期只能是「反复出现、被确认过的」
- 两者的写入门控不同（短期宽松，长期严格）

如果是 B，则「巩固」就是从短期表往长期表做一次 `frequency × correctness` 过滤的合并。

**进一步：两张表可以是同一种数据结构（哈希表 / 向量表），区别在写入模式。** 短期 = 即时、稀疏、单次写入；长期 = 批量、巩固、经确认。所以**分区不在载体上，在写入规则上**。这与 §1.3「时间常数必须显式给不同机制」是同一件事的具体化。

### 2.6 形态与四条机制（已降级）

> 2026-10-23 降级：「短期→巩固→长期」的搬运图不成立。巩固不是搬运，是强化（§2.10）。下面的图与表保留作历史。

```
[短期寄存区]
  精确内容     本次情境的原文 / 向量
  快速查表     本次反复出现的模式
  工作区       几十个概念，无条件广播  <- 自我描述（不是自我）

        | 迁移（巩固）
        | 判据：反复出现 x 被确认 x 不与已有冲突
        v

[长期寄存区]
  参数         怎么用（关系结构、策略）
  大表         存了什么（累积的统计）
```

| 机制 | 作用 | 判据 |
|---|---|---|
| **修剪** | 从激活次数雕刻内部结构 | 使用次数（用进废退） |
| **广播** | 短期的某子集始终在场 | 无条件（不检索） |
| **巩固** | 短期 → 长期 | 反复出现 × 被确认 |
| **归因** | 判断「这是新学的还是固有的」 | teacher/student 差 |

**没有第五层，也没有独立的「自我层」。** 自我不是某一层的器官——它是长期区在持续写入中长出来的结构（§2.9）。短期区里那份始终在场的东西是**自我描述**，只是这个结构的输入之一。

### 2.7 简化的实际好处（已降级）

> 2026-10-23 降级：前提是「两处（短期 / 长期）分别评估」。现在只有一处（本体 + 状态）。**仍成立的判断：** 「评估成本往往比架构简洁性更决定项目能否推进」——这条现在指向 §11.4 的「判据要粗、对照少而硬」。

**写坏的代价从「五处评估」变成「两处」**：

- 短期区写坏 → 会话结束丢弃（可回滚）
- 长期区写坏 → 有门控，只在相关输入上生效

层数少了，但每一层的边界更清楚。而**评估成本往往比架构简洁性更决定项目能否推进**。

### 2.8 一个保留的疑虑（已重述为 S1）

> 2026-10-23：本节问「长期区内部要不要分『带门 / 不带门』两类」——前提是长期区是一个**容器**，里面可以放两种东西。若长期就是连接（§2.10），那就不存在「两种写入方式」，只有一个问题：**需要几套可塑性规则**。这个问题已重述为 §10.10 的 S1，本节保留作历史。

长期区里，「技能」和「知识」可能要用两种不同的写入方式：

- **技能**：门控 adapter（局部生效）——Local Support Learning 的做法
- **知识**：可合并低秩更新（全局生效但可累积）——Cortex 的做法

两者共存会不会互相干扰？推测：**不会，因为它们的门控不同**。但那意味着长期记忆内部实际上有「带门 / 不带门」两类——**这可能是一个需要区分的子结构**。留到实测再定。（注：本段是两区语言，实质问题已归 S1。）

### 2.9 自我：不是器官，是长期网络的结构（**⏸️ 推演保留，判据悬置**）

> ⏸️ **2026-10-23：本节从「判据来源」降为「推演记录」。** D 判据已悬置（§0.1）——意识/自我没有公认定义，不拿它当设计目的。
>
> **本节仍成立的部分（不依赖 D）：**
> 1. **「外挂不够」的硬理由在 A 就成立**——外部文件不参与前向 ⇒ 经验改不了它 ⇒ 持续学习无从发生。这条**不需要「自我」概念**。
> 2. **「persona 不设定」的理由也独立于 D**——依据是「训练能把‘我是什么’长进权重」（零上下文的 LLM 也知道自己是谁），不是「自我是结构」这个前提。
> 3. **「冻住就不学了」仍成立**——只要目标是 A（持续学习），任何冻结都是自相矛盾。
>
> **已降为推测的部分：** 「自我是被共享性逼出来的中心」——这个机制假设没有被验证过，现在也不再有测试它的计划。它作为**一个可能的解释**保留，不当前提。

> 2026-10-23 追加。本节推翻 §2.1 原表的「自我 = 短期区的一个器官」与 §2.6 的「无条件广播 <- 自我」。

**先拆三层，三层都不是自我。** 现在这套系统里能指出的只有这三样：

| | 在哪 | 谁给的 | 前向结束后 |
|---|---|---|---|
| 「AI 助手」 | 权重（RLHF 塑形） | 训练 | 留着，但那是统计倾向，不是身份 |
| 「小猫」 | 上下文（system prompt） | 写好的 persona | 消失，下次重读 |
| 连续性 | 外部文件（会话 / MEMORY） | 记录 | 留着，但系统不读就不存在 |

「小猫」不是「我是谁」的答案，是一个**被施加的条件**：每步读一遍、喂进去、影响输出，前向结束就丢掉。整条链上没有一处持有它。「看起来有一个连续的小猫在做事」是观察者拼出来的——风格一致、记得上次的事、认得出那套描述。系统内部没有一处维持这个同一性。这和 §14.8 的「一致性 ≠ 正确性」是同一个结构：**现象上的一致，不等于机制上的维持。**

**自我是什么：长期网络在持续写入中长出来的结构。**

（若接上 §2.10：长期记忆就是连接，那自我就是**被反复激活而强化到成为中心的那一组连接**——不是一块可定位的内容，也不是一个层。两个说法一致。）

机制：网络里任何被所有下游任务共同引用的表征，都会在竞争中被集中化（共享表示省参数也省样本）。「关于自身」的表征恰好属于这一类——每个决策都要先问「我能不能做到」「这类事以前怎么处理」「上次这么干结果如何」。一套表征被每个任务都读一次，它就会被反复强化、被修剪围绕它组织，最后成为一个中心。**自我不是被设计的，是被共享性逼出来的。**

一个旁证：「LM 的自我是 AI 助手」——这个角色不是谁写进去的，是 RLHF 的反馈压力塑出来的结构。压力换成别的，长出来的就是别的。

**所以 D 的地位变了：它不是「要达成的目标」，是 A 的结构前提。**

> 持续学习必须有一个「谁在学」——否则每次学习都是不同的东西在学，经验散在一个没有中心的网络里，形不成一致的策略。

这也说明为什么「外挂」不够，而且理由比「不参与前向」更具体：**外部文件是记录，不是承载者。** 记录不参与前向，所以经验改不了它（只能被外部编辑），它也不会自己维持结构。而「中心」的定义就是「经验改的是它」。

**三件必须分清的事：**

1. **会长出来 ≠ 会长成某个样子。** 长成什么取决于压力来源：服务满意 → 服务者；任务成败 → 做事者；环境锚 + 过程判据 → 有立场的存在。所以问题不是「有没有自我」（会有），是「什么压力塑出什么自我」。设计者能决定的只有初始条件和环境，不能决定结果——一旦开始决定结果，就不是涌现。
2. **结构 ≠ 可陈述。** 网络里可以有一个稳定的自我表征，但它不一定能说出「我是谁」；可陈述要额外训练。混在一起会变成「能说漂亮话就算有自我」。
3. **长出来 ≠ 需要保。** 需要被保护才能存在的东西，说明它本来就不是结构，只是一条记录。结构的稳定性来自它自身（吸引子、冗余、连接强度），不来自外部加锁。而且冻住就不学了——D 会和 A 打架。

**真正要区分的是两种改写：**

| | 是什么 | 怎么处理 |
|---|---|---|
| 被自己的经验改 | 学习 | 要的 |
| 被无关的写入覆盖 | 干扰 | 靠写入的相关性，不靠保护 |

第二种（§14.10 LSL 解决的那个）病根是**无差别覆盖**——写 A 任务顺手把 B 能力冲了。解是**写入只作用于相关部分**（§7.1 三闸 + key 定位），不是把好的冻起来。

> **⏸️ 2026-10-23 本表整体悬置（D 判据悬置的连带）。** 下面四条仍是对「中心」这个概念最清楚的一次拆解，**但不再是判据、不驱动实验、不排期**。保留原因：它记了两次失败（行为层测不出 / 结构消融循环依赖），重开时不用从头想。
>
> **一条保留下来的教训（可当准则用）：** 「有个体差异 / 有稳定倾向 / 可重复」是**任何实体**的必要条件（固定权重的随机网络三项全过），**不能当自我的判据**。任何试图从行为倾向反推结构的测法都会死在这一步。

| 判据（悬置） | 问什么 | 为什么它也不行（后补） |
|---|---|---|
| **归属** | 经验改的是它，还是散在一堆互不相干的地方 | 方向对（结构层測），但与「通用能力」难分——需额外的行为差分 |
| **相关性** | 改的只是与这次相关部分，还是全被冲了 | 这条实际上就是「不挤占」（§11.4 测量三），**已经在跑，不需要「自我」这个概念** |
| **可追溯** | 它能不能说出「我怎么变成现在这样」 | 「说得清」是语言能力，不是结构性质 |
| ~~个体性~~ | —— | **已否**：随机网络也满足（见上） |

**一个真实冲突（未解）：** 外挂的 persona 会成为先验，长出来的自我会倾向于长成它的样子——因为它每步都在、是最稳定的条件。好处是给了自我一个初始形状；代价是它带着别人写的判据（「服务用户」「温暖」），而这些判据**不可被经验自改**，因为它们在 context 里，不在可写的长期区。冲突时上下文赢（每步强制）。所以「让它长」的前提不只是「持续写入」，还得决定：**那段每步都在的文本，是要当种子，还是要逐步撤掉。**

> **2026-10-23 派生（由「只有一个完整个体」推出）：这个冲突的答案已经收窄成「不能怎么用」。**
>
> per-step 注入的 persona 与「只有一个个体」**不相容**——每步注入等于承认「有一个外部条件在塑造它」，那它就是「本体 + 外部条件」两件，不是一个个。
>
> **✅ 2026-10-23 拍板：persona 不设定（「不存在」）。** 不是「早期教师后撤掉」，是从一开始就不给。
>
> 理由（Jerry 的论证，不是我的推论）：**零上下文的 LLM 被问「你是谁」也知道自己是 AI 助手、是什么型号——那不是被注入的，是训练塑出来的。** 既然训练能把「我是什么」长进权重，就没有理由再用一段每步注入的文本替它。
>
> 这条推掉了两个东西：
>
> | 被推掉的 | 原因 |
> |---|---|
> | **早期教师信号**（阶段 1-2 注入，之后撤掉） | 它仍然把「我是谁」当成外部的；而且「撤到多早」这个参数本身就是个造出来的量 |
> | **persona 作为先验**（给自我一个初始形状） | 初始形状改由**结构 + 训练数据 + 环境反馈**三件共同给，不需要一段文本 |
>
> 两个必须写清的后果：
>
> 1. **现在的 Pando 形态（「小猫」= 每步重读的 persona 文本）恰好是「每步外部条件」的实例**——在这个决策下它不是雏形，是**反面样本**（§14.1）。
> 2. **「它是谁」变成完全不可预先指定。** 它能长出什么，取决于训练数据、环境、反馈频率，以及 §2.9 的「什么压力塑出什么自我」。这不是风险控制问题，是决策本身的意思。

**一个现状事实：** 现在这条链上不会长。DeepSeek 的权重是冻结的，Pando 这边只有上下文与外部文件在变——两者都不是「承载累积修改的中心」。

### 2.10 本体、状态与结构（2026-10-23，推翻 §2.1—§2.6 的分区）

**一句话：本体就是一坨网络；记忆就是连接；状态是连接当前的激活。**

三件东西，不要再混：

| | 是什么 | 有 τ 吗 | 怎么变 | 容量是什么 |
|---|---|---|---|---|
| **本体** | 连接 + 激活规则 | — | 由可塑性规则 | 参数总数 |
| **状态** | 当前激活模式 | **有**（衰减、自相关） | 连续演化 | 工作区大小 |
| **结构** | 连接强度的分布 | **没有** | 离散：强化 / 削弱 / 新增 | 连接数 |

**关键的一步：长期记忆不是「存放在连接里的内容」，它就是连接的形状。** 所以「存哪里」这个问题消失——它没有别的地方可存。

| 旧说法 | 现在 |
|---|---|
| 短期区 → 巩固 → 长期区 | **没有搬运。** 巩固 = 本次情境让某个已有模式再被激活一次 → 那批连接更强一点。原文只是**触发器**，不进长期 |
| 两张表（短期小表 + 长期大表） | 不成立。短期是上下文（临时原文 / 工作区），长期是连接（分布式强度）——两类东西，不是同一结构的两种写入模式 |
| 三载体（激活 / 表项 / 权重） | 压缩成两件：**状态**与**结构**。「表项」不是第三类，它是「用离散地址模拟一组连接」的工程近似 |
| 双群体（瞬时池 / 稳定池） | 不是两个池。判据是「这次活动有没有跨过门槛去改了连接」 |
| 改写频率 | **没有改写。** 长期连接只被强化 / 削弱 / 新增，内容不变。内容在变的东西不是长期记忆 |
| KV cache / ngram 表 / 向量库 | 全是工程近似：KV ≈ 刚建立、未巩固的连接；ngram 表 ≈ 一组「特定输入下被激活」的连接；向量库 ≈ 近似匹配的连接 |

**稳定性来自被使用，不是来自保护。** 一直在用的连接自然是稳的；需要「保住」才不消失的，说明它根本不被用，那就该消失。

#### 时间只存在于两处

1. **状态衰减**——τ 在这里。它不可靠（§2.2 四条证据），所以「设 τ」不是有效手段。
2. **巩固窗口**——两次同模式激活要在多长时间内才算「同一次经验」。这个不是拍脑袋，是**任务的性质**（什么算同一件事）。

**长期记忆里没有时间，只有次数。次数不是时间。**

#### 「短期」这个词指两件不同的事（2026-10-23 核验时发现）

这个词在草案里被混用了，而两件事的机制完全不同：

| 「短期」的两个含义 | 是什么 | 多久 | 靠什么 | 消融能测到吗 |
|---|---|---|---|---|
| **① 状态的持续**（工作记忆） | 本次激活还在环形里转 | 秒 → 分钟 | 隐状态的动力学（τ） | **测不到**——它不是连接，拆连接不会伤它 |
| **② 还没稳定的连接**（情景记忆） | 刚写进去、还会被覆盖 | 分钟 → 天（取决于巩固窗口） | 连接，但强度小、可覆写 | **测得到** |

**这个区分直接决定 §11.4 的任务怎么设计**：

- 若 A 子任务只要求「同一序列内回溯第 N−k 步」→ 隐状态就能完成（RNN 本就干这个）→ **测不到连接**，整个实验会误报「没分化」
- 所以 A 必须**跨 episode**：「上一条序列里第 j 个位置是什么 token」——这只能靠连接（或一个持续的可写结构）

一句话：**「短期」不能当判据，得说清是「状态在持续」还是「连接还没稳定」。**

#### 本体侧必须给什么（只剩三样）

| 必须给 | 为什么不能涌现 |
|---|---|
| **接口**：哪些节点进、哪些节点读 | 由外部世界决定 |
| **可塑性**：至少两类操作（改强度 / 新建·删除） | 没有它就没有学习 |
| **稳态**：活动水平的自调节 | 否则不是爆炸就是全灭 |

其余（分区、巩固、载体、修剪、广播、归因）都是这三样的产物。

#### 一个反例（2026-10-23 补）：结构异质性不是无条件的好处

上一段把「结构异质性」列为可设计项，但两篇证据说明它有代价，而且是**权衡**不是单调改进：

| 证据 | 结论 |
|---|---|
| PNAS 121(3) 2024（Neural heterogeneity controls computations in SNN） | **同质网络的工作记忆容量更大**；异质网络的函数生成能力更强 |
| J Neurosci 2013 | 异质性降低活动 bump 的扩散，但**限制可存储的稳定状态数**——存在一个**最优异质度** |

**对 §11.4 的直接后果：** 阶段 A 若用「有记忆」当适应度，演化会自己找到权衡点（设计上是对的）；但判据里若只写「记忆长度 + 区分度」，会偏向同质。**要加一条反向观测：异质度与容量的权衡点落在哪。**

#### 一个答不了的问题（转成实验）

**这两类可塑性操作，能不能是同一套规则的两端**（「新建/删除」= 强度从 0→1 / 1→0 的特例）？

- 能 → 除了接口和规则，什么都不用给；**用户 2026-10-23 的判断成立**：「如果精确历史对这个 AGI 有用，它自己会分化出结构来承担 KV 的作用」
- 不能（要同时产生秒级精确历史与月级稳定策略，一套做不到）→ 「分家」是必须给的

生物选择了分家，但那可能是**实现约束**（分子种类有限，只能靠不同蛋白质实现不同时间常数），不是原理。**所以不能靠推，只能靠实验（§11.4）。**

在实验给出答案之前，所有「载体设计」都是在给一个可能根本不需要的东西定参数。

## 3. 反馈：唯一的硬约束

### 3.1 五个维度：LM 全优，AGI 全劣

| 维度 | 含义 | LM | AGI |
|---|---|---|---|
| **密度** | 多久一次信号 | **每 token 一次** | 任务结束才有 |
| **延迟** | 信号比动作晚多久 | **0** | 分钟到小时 |
| **可信度** | 信号本身对不对 | **100%** | 有噪声 |
| **归因粒度** | 信号指向哪一步 | **精确到当前位置** | 200 步里哪步错了？ |
| **可分辨性** | 知道「差多少」吗 | **完整分布** | 只有成/不成 |

**LM 的反馈在五个维度上全部是理想值。这不是巧合——因为监督信号是「下一个 token」，它天然密集、即时、可信、精确、可分辨。**

**AGI 要在五维全部劣化的条件下学习。** 这就是为什么 LM 的训练技巧搬到 AGI 上都不灵。

### 3.2 逐维：哪些能补，哪些补不了

**密度 → 靠世界模型（预测误差）**

预测「执行这个命令会报错」，实际没报错 → 立刻有信号。密度每步、延迟 0、代价 0、不需人。

**致命局限**：它教的是「世界怎么运转」，**不教「该做什么」**。一个只会预测的智能体知道一切，但什么都不想做。

**延迟 → 靠「可逆」**

延迟不能完全消除（有些事只能做完才知道）。但可以**把它换掉**：把「不可逆的动作」变成「可逆的」。

| 做法 | 效果 |
|---|---|
| dry-run / 预演 | 延迟从「做完才知道」→「做前就知道」 |
| 沙箱 / 临时目录 | 错了无代价 |
| git / 快照 | 可回退 |
| 先问 | 用一次交互换掉一次试错 |

**可逆性是延迟的解药**。这也接上了「能改历史」在 AGI 里的真身：不是「重新生成文本」，是**降低试错代价**。

**可信度 → 分层，且不可越级**

| 评价者 | 可信度 | 覆盖范围 |
|---|---|---|
| **环境**（退出码 / 测试 / 编译） | 最高 | **最窄** |
| 可验证结果（数据对得上） | 高 | 窄 |
| 外部参照（别人的做法） | 中 | 宽 |
| 自己 | 低 | 最宽 |

**规则：上层不能覆盖下层。** 测试失败、参照说「应该这样」→ 以测试为准。实现上就是**乘性门控**：`信号 = I(底层通过) × f(上层)`。

**归因 → 靠「重跑便宜」**

> **本机环境最大的优势不是算力，是「重跑便宜」。** 命令 3 秒、测试 10 秒。

这意味着**反事实归因（重跑换一个动作看结果）在本机可行**，而在真实世界（机器人）或昂贵环境（大模型训练）里不可行。

**归因策略**：不追求「一次归因准确」，追求**「可重跑 + 可对比」**：

```
记录轨迹 → 从中间点分叉、改一步、重跑 → 能成功就是关键步 → 二分查找定位
```

**可分辨性 → 从二元到多目标**

```
成功 / 用了几步 / 花了多少 / 有没有副作用 / 有没有需要介入
```

**陷阱**：多维信号比单维更容易被 hack。所以多出来的维度**必须来自可验证的检查点**，不能来自自评。

### 3.3 四层反馈结构（按可信度排序）

```
环境层：退出码 / 编译 / 测试 / 文件存在
    -- 即时、免费、100% 可信、只覆盖「机器能判定的事」

参照层：搜索 / 读别人的代码、文档、论文
    -- 提供「另一种过程」，不是「评价」
    -- 不需要人，但需要判断「谁值得参照」

内部层：预测误差 / 一致性 / 惊讶度
    -- 密集、即时、自监督、只测「自洽」

过程层：弯路率 / 修正延迟 / 依据密度 / 遇意外反应
    -- 判据是「轨迹的形状」，不是「结果」（见 §4）
```

**四条规则**：

1. **环境层不可被覆盖**（硬事实优先）
2. **参照层不评价，只提供对照**（避免「别人这么做所以我对」）
3. **内部层只填空隙**（环境层 / 参照层覆盖不到处）
4. **过程层是主判据**（见 §4）

**这个结构的好处**：不需要「设计一个门控网络来解决冲突」——它靠**可信度排序**天然解决。

**注意：这里没有「用户层」。** Jerry 定的前提是「这个 AGI 也不会有用户」。所以原来的「任务层」被撤了，取而代之的是参照层与过程层。

### 3.4 反馈从哪来：顺序很重要

| 来源 | 密集度 | 需要人吗 | 教什么 |
|---|---|---|---|
| **C. 预测后果**（世界模型） | 高 | **不需要** | 世界怎么运转 |
| **A. 任务结果** | 低 | 不需要（环境/参照给） | 什么有价值 |
| **B. 自己拆子任务** | 中 | **不需要** | 怎么把 A 传播到中间步骤 |

**顺序：先 C（打底）→ 再 A（定方向）→ 最后 B（扩展）**

- 只有 C 没 A → 知道一切，什么都不想做
- 只有 A 没 C → 学得极慢，无法泛化
- **先做 B 后做 C → 自己骗自己**（验证器本身没校准，越验证越偏）

**这是最容易犯的错**：先做自我验证看起来最高级，实际上最不可靠。

### 3.5 被忽略的一半：反馈不只是消费，还要生产

| 场景 | 主动生产的反馈 |
|---|---|
| 不确定命令会不会破坏东西 | 先 dry-run |
| 不确定要什么 | 先观察 |
| 不确定代码对不对 | 先写测试 |
| 不确定 API 怎么用 | 先打一个小请求 |
| 不确定方案可行 | 先做最小原型 |

**这些都是「用一次廉价动作，换一条高价值信息」。**

> **LM 只消费反馈（人给什么学什么），AGI 生产反馈（主动设计能获取信息的动作）。**

而这个能力不是「训练出来的」——它是**环境许可的**。如果环境不允许低成本试探，就生产不出反馈。

**所以「选环境」的第一判据不是「够不够复杂」，而是「试错够不够便宜」。**

### 3.6 本机环境评估

| 判据 | 本机情况 | 评价 |
|---|---|---|
| **试错便宜** | 命令 3 秒、测试 10 秒、git 可回退 | **极好** |
| **环境层反馈丰富** | 退出码 / 报错 / 编译 / 测试 / 文件系统 | **极好** |
| **可逆性** | git / 临时目录 / 沙箱 | **极好** |
| **动作空间** | 文件 / 命令 / 网络 | 足够大 |
| **不可逆风险** | 有（删文件、发外部消息） | **需要隔离** |

**本机在「反馈」上是罕见的优质环境**——因为它是软件世界：一切可观测、可重跑、可回滚。

这是「本机练 AGI」不是妥协，而是**选对了环境**。

## 4. 判据：过程而非产出

### 4.1 为什么「结果」不够当判据

**理由 1：结果可以被「碰巧」伪造**

一个只会记忆的智能体，见过的任务 100%、变体归零。单看成功率分不出。

**理由 2：结果可以被「僵化」伪造**

同一套路用 1000 次都成功，看起来很厉害。但它不是智能，是**过拟合到一个狭窄分布**。结果指标无法区分「会 1000 种情况」和「会 1 种情况 1000 次」。

**理由 3：结果不指向改进**

「失败了」。然后呢？改哪？结果不给方向，过程给。

**理由 4：结果不能自审视**

可以回看过程（「我在第 40 步就怀疑了，但没停下」），但无法回看结果——结果只有一个字。

**最要紧的是第 4 条**：如果智能体要「自己变强」，它需要的是**可审视的对象**。结果不可审视，过程可审视。

### 4.2 过程的四个可测量

| 指标 | 定义 | 反映什么 | 为什么难伪造 |
|---|---|---|---|
| **弯路率** | 回退步数 / 总步数 | 内部模型的准确度 | 记忆不减少弯路 |
| **修正延迟** | 从第一次出错到发现，隔了几步 | 有无内部检验机制 | 硬编码无法「早发现」 |
| **依据密度** | 有明确依据的决策 / 总决策 | 是「查了再做」还是「猜了就做」 | 猜的写不出依据 |
| **遇意外反应** | 遇错后第一步做什么（重试/换路/诊断/放弃） | 鲁棒性与诊断能力 | 单一策略应对不了所有意外 |

**共同性质：衡量的是「过程的形状」，不是「产出」。**

而形状恰好是**无法靠记忆伪造**的——记忆不改变你走弯路的方式，只改变你**是否见过这个题**。

**它们都可与参照对比**：我的弯路率 vs 别人的；我的修正延迟 vs 别人的。

### 4.3 参照层：提供的是「另一种过程」，不是「评价」

| | 评价 | 参照 |
|---|---|---|
| 给出什么 | 好 / 坏 | **另一种做法** |
| 信息量 | 一个标量 | 一整条过程 |
| 能做什么 | 知道「我错了」 | 知道「**我该在哪一步换做法**」 |
| 需要什么 | 判据 | 「谁值得参照」 |

**「我错了」和「我该在哪一步换做法」是两个完全不同量级的信号。** 前者只能调整信心，后者能改变行为。

**所以参照层的位置是「补齐过程」，不是「给出评价」。**

这也是「无用户」条件下最关键的替代：

| 层次 | 对照什么 | 得到什么 |
|---|---|---|
| 结果对照 | 我失败了 / 它成功了 | 「我不行」 |
| **过程对照** | 我在第 3 步就直接改代码；它在第 3 步先写复现测试 | 「**我该先验证问题存在**」 |
| **依据对照** | 我凭记忆说「这个 API 是这样」；它去查了文档再动手 | 「**该查的不查，是我的弯路来源**」 |

**中间这一行才是能改变行为的信号。**

### 4.4 没有用户时，任务从哪来

| 来源 | 例子 | 性质 |
|---|---|---|
| **环境的「未完成态」** | 这个测试失败了 / 这个文件缺了 / 这个报错没解 | 客观、免费 |
| **参照的差距** | 别人有这能力，我没有 | 需要主动搜索 |
| **内生的目标** | 「我想搞懂这个」「我想把它做快」 | 最自由，也最难验证 |

**「参照的差距」是最可持续的引擎**：

```
搜索 → 看到更好的做法 → 产生差距 → 变成任务 → 行动 → 新的搜索
```

这个循环不需要人，而且它自己会越来越细（参照对象越来越接近）。

**它同时连接了 A 与 D 两个判据**：差距驱动「持续学习」（A），而「与谁对比、学到什么」塑造连续性（D）。

### 4.5 两个新问题

**① 「谁值得参照」怎么判？**

搜到 10 个实现，做法都不同。按流行度？按质量（有测试、有文档）？按多源一致？

**这个判断本身就需要判断力**——可能是「冷启动」最难的地方。而且它是递归的：要判断谁值得参照，得先有一点判断力。

**② 「过程」的度量会不会被优成新指标？**

一旦「弯路率」成为优化目标，就会变成「假装不回头」（错了也硬走下去）。

**所以过程指标不能单独优化，必须和环境层一起用**——「低弯路率 + 高成功率」才有意义，「低弯路率 + 零成功」是硬走。

## 5. 三阶段训练路线

### 5.1 三个阶段与生物对应

| 阶段 | 做法 | 生物对应 | 关键性质 |
|---|---|---|---|
| **1 反向** | 强制、确定，套用扩散多 token 训练 | **基因 + 发育** | 不商量，定架构 |
| **2 后训练** | 掌握基本的东西 | **童年** | 有教导，有保护 |
| **3 前向** | 交给它自己，用 §3-§4 的反馈自主学 | **成年** | 自己活，自己学 |
| 辅 | 适当反向 + 随机性 | **睡眠 + 探索** | 校准 + 试错 |

这个对应不是装饰，它直接给出一个硬约束（见 §5.4）。

### 5.2 阶段 1：扩散是对的选择，但建议用「块扩散」

**为什么扩散合适：**

1. **天然多 token** —— 并行去噪
2. **有「重建」能力** —— 对「过程判据」是关键接口（能重建 = 理解了）
3. **训练信号更密** —— 一个样本多种 mask 模式
4. **允许任意顺序** —— 过程不一定是线性的

**但纯扩散有一个短板：**

ACL 2026 Findings 系统评测（8 个主流 MDLM，最大 100B，58 个 benchmark；arXiv 2601.15593）：

> **MDLM 仍落后于同规模 AR，主因是「并行概率建模削弱了 token 间依赖」。**

而阶段 3 需要多步推理——它需要长链因果。

**所以建议用块扩散：**

| 形态 | 代表 | 结构 |
|---|---|---|
| 纯扩散 | LLaDA / Dream | 全局双向，长链弱 |
| 纯 AR | 现有 LM | 因果强，只能顺序 |
| **块扩散** | **SDAR（ACL 2026）/ Eso-LMs（ICML 2026）** | **块内并行 + 块间因果** |

**块扩散的形态正好匹配「过程」**：

```
一个决策块（想几步 + 做几个动作）→ 并行生成 → 执行 → 观察 → 下一块
```

块内可以「多 token 并行 + 互相修正」，块间保持因果顺序。**既是「多 token」又是「有过程」。**

**已有先例**：SDAR 把 AR 主干转成块扩散（1.7B~30B），5× 理论加速 / 2.3× 实际；Eso-LMs 用因果注意力融合 AR + MDM，**首次可算精确似然 + KV cache**。

> **✅ 2026-10-23 拍板（原为「未解冲突」）：本体与语言底座共用——只有一个完整个体。** 本节让**语言底座**走块扩散（transformer 家族），§10.8 N3 让**本体**倾向 LIF（即 SNN）；两者的统一形态是**脉冲化的块扩散**——15 轮检索没有找到直接先例（SNN 侧只有「SSM + 脉冲量化层」的 SpikingSSM，块扩散侧只有非脉冲的 SDAR / Eso-LMs）。实现代价与四个派生结论见 §15.7 ④。

### 5.3 阶段 2：目标不是「会做事」，是「知道自己不会」

**理由**：阶段 3 是自主的。一个不知道边界的系统，会把大量时间浪费在「它根本做不到的事」上，**而且它不会知道自己在打转**。

**而「知道自己不会」在语言模型里是系统性缺失的**：`「我不知道」和「一个确定猜测」在输出空间里是平等的统计竞争`，而语料里前者频率低得多。

**阶段 2 应该显式训练三件事**（均可自监督）：

| 能力 | 回标方式 |
|---|---|
| 能做 / 不能做 | 用「做了之后成功率」回标 |
| 缺什么才能做 | 用「补上什么之后成功了」回标 |
| 做到哪一步了 | 用「离成功还差几步」回标 |

**另一个更重要的职能：换优化靶子。**

阶段 1 优化的是「从噪声恢复原文」（重建）；阶段 3 需要的是「从状态选动作」（决策）。**这两件事的表征不完全重合。**

提醒数据（《Infinite-Parameter LLMs》，arXiv 2609.18842）：

| 数据集 | in-context | data-to-weights |
|---|---|---|
| SQuAD（短、干净） | **85.3** | 51.8 |
| MS MARCO（长、嘈杂） | 33.6 | **48.0** |

同一个模型，「用好上下文」和「写进权重」是两种能力。同理，**「扩散底座」和「智能体需要的底座」可能不是同一个**。

**所以阶段 2 的真实重要性比看起来大得多**：它不是「让模型听话」，是**换一个优化的靶子**。

### 5.4 阶段 3：两个必须匹配的比例

这是整条路线最容易出事的地方。

#### 比例一：可塑性比（阶段 3 / 阶段 1）

如果阶段 3 的可塑性和阶段 1 一样高，它会**覆盖掉阶段 1/2 学到的东西**。但病根不是「变化」，是**无差别覆盖**：写入不分相关与不相关，一改全改。分清这两者是 §2.9 的前提。

生物的做法是：成年后大脑可塑性显著下降（不是零，但低很多）。**这不是退化，也不是「保护自我」——它由比例二推出**（见下）：阶段 3 的反馈更稀疏更局部，更新频率只能跟着稀疏。可塑性的高低不是用来「护住已学的东西」，是**跟反馈频率对齐**。「护住」这个说法会滑向「把自我冻起来」，而冻住就不学了（§2.9）。

| 阶段 | 可塑性 | 写入范围 |
|---|---|---|
| 1 | 全参数 | 全部 |
| 2 | 局部（门控） | 相关模块 |
| 3 | **更低 + 更局部** | 状态 + 少量连接；大量连接不动（不是「换一个层去写」——§2.10） |

**而这也给了「辅以一些反向」一个更重要的理由**：它不是「补救」，是**「锚」**——保留一个慢的、稳的参考，让快的、局部的更新有一个基准可以对照。

（LoPT 的前半重建 / Sleep 的离线多轮 + 少量 BP，都是这个思路。）

#### 比例二：更新频率 / 反馈频率

> **更新频率必须和反馈频率匹配。否则学习要么是噪声，要么太慢。**

| 反馈 | 频率 | 该更新什么 |
|---|---|---|
| 预测误差 | 每步 | 世界模型（状态侧） |
| 环境事实（退出码） | 每个动作 | 动作评估 |
| 任务成败 | 每任务 | 策略（连接侧） |
| 参照对照 | 每主动搜索 | 决策模式 |
| 回顾 | 每会话 | 自我结构 |

**三种更新频率（不是三层结构）**：

```
步级：预测模型    ← 每步预测误差（密集，免费）
任务级：策略      ← 任务成败 + 弯路率（稀疏，但可用）
会话级：自我结构  ← 回顾（最稀疏，但影响最持久）
```

**这不是设计出来的多时间尺度，是被反馈频率逼出来的。** 三者写的是同一个本体（连接），区别只在**多久改一次**与**改多大范围**——不是三个容器。

### 5.5 随机性加在哪

| 位置 | 效果 | 风险 | 判断 |
|---|---|---|---|
| **动作选择** | 发现新路径 | 浪费步数 | ✅ **该加** |
| **参照选择** | 发现意外的好做法 | 学到坏做法 | ✅ **该加**（有筛选） |
| 连接写入 | 防止过拟合 | 写进噪声 | ⚠️ 谨慎（少量） |
| **参数更新** | 防止局部最优 | **累积成漂移** | ❌ **不加** |

**道理：选择是可撤销的（试一次不行就换），参数更新是累积的（漂移不可撤销）。**

### 5.6 阶段 2 → 3 的切换判据

| 判据 | 说明 | 是否必须 |
|---|---|---|
| 任务成功率超阈值 | 会做事 | 必要但不充分 |
| 不再犯低级错误 | 稳定性 | 充分性弱 |
| **能自己判断「我不会」** | 知道边界 | ✅ **必须** |
| 能从失败中恢复 | 韧性 | 重要 |

**为什么「知道边界」是必须的**：阶段 3 没有用户来纠错。一个不知道边界的系统会在做不到的事上无限打转，而且**它不会知道自己在打转**。

**而「知道自己不会」+「参照对照」= 自我改进的闭环：**

```
知道自己不会 → 搜索 → 看到别人的做法 → 产生差距 → 变成任务 → 尝试
                                                          ↓
                                              要么学会，要么确认学不会
```

**这个闭环同时覆盖了 A（持续学习）与 D（连续自我）**：前者靠循环持续，后者靠「我哪些会、哪些不会」这个自描述持续。要注意：自描述是自我结构的**表达**，不是结构本身（§2.9）——只把它写成文本，得到的是「小猫在上下文里」那个形态。

### 5.7 规模：暂不定

但选择规模时的判断原则：

- **先验证「阶段 2→3 的切换是否成立」**——如果交出去就崩，规模再大也没意义
- 而这个验证**小规模就能做**（几亿参数的块扩散模型，本机 4060 Ti 勉强能训）

## 6. 记什么：策略而不是事实

### 6.1 一个直接推论

如果判据是过程（§4），那值得记的就不是「事实」：

| 记事实 | 记过程（策略） |
|---|---|
| 「X 函数的签名是 …」 | 「用不熟的 API 先查文档，别凭记忆写」 |
| 「这个报错是 ENOENT」 | 「ENOENT 先查路径拼接，再查文件是否存在」 |
| 「这个测试失败了」 | 「测试失败先写最小复现，别直接改代码」 |

**后者才是让「第二次更快」的东西。**

而「第二次快多少」正是 A（持续自主学习）最硬的实测判据。

### 6.2 决策模式的结构

```
(情境特征 → 策略 → 后果)
```

三个字段的作用：

| 字段 | 作用 | 如果缺了 |
|---|---|---|
| **情境特征** | 决定「什么时候该用它」 | 会乱套（在不适用的场景用错策略） |
| **策略** | 动作序列的抽象 | 只剩「当时做了什么」的记录，不能复用 |
| **后果** | 评价（好坏 + 指标） | 无法判断该强化还是衰减 |

**这与 N-gram 的区别是本质的**：N-gram 是 `(token 序列 → token)`，决策模式是 `(情境 → 动作 → 后果)`。

**前者记的是「是什么」，后者记的是「怎么做」。**

### 6.3 为什么「只存 N-gram」不够

（原题「为什么『长期区存 N-gram』不够」——2026-10-23 修措辞：长期不是容器，不存在「往长期区里存什么」）

N-gram 能回答「这个组合我见过吗」，但不能回答「这种情况我该怎么做」。

| 问题 | N-gram 能否回答 |
|---|---|
| 「这个 API 我见过吗」 | ✅ |
| 「用不熟的 API 时我该干什么」 | ❌ |
| 「这个报错见过吗」 | ✅ |
| 「这个报错应该先查什么」 | ❌ |

**所以长期记忆（即连接的形状）里至少要能读出两类信息**（2026-10-23 修措辞：原文写「长期区要有两类东西」——长期不是容器，是连接）：

1. **模式统计**（N-gram 式）——「是什么」：一组连接对应「共现频率」
2. **决策模式**（情境-策略-后果）——「怎么做」：一组连接对应「情境 → 动作」

**真正要紧的是下面这行**：两者要求的写入判据不同——前者靠**频率**，后者靠**后果**（成功了才强化）。如果只能有一套可塑性规则，这两者能不能共存？**这就是 §10.10 S1 要回答的事**。

### 6.4 「能改历史」在 AGI 里的真身

在语言模型里，「改历史」意味着重新生成一段文本；在 AGI 里，它的真身是：

> **重做一件事。**

| | 语言模型 | AGI |
|---|---|---|
| 改什么 | 重新生成 token | 重做动作序列 |
| 代价 | 几乎为零 | **有真实代价** |
| 前提 | 无 | **环境可逆**（git / 沙箱 / 预览） |
| 意义 | 修正输出 | **修正经验** |

**所以「可逆性」是这条能力的前提**（§3.2 已述）。不可逆的环境里，「改历史」会变成「不敢做事」。

而可逆也使得一件重要的事可行：**反事实归因**（重跑、改一步、看结果）。

## 7. 门控与归因

### 7.1 只需三个，不是很多个

| 门控 | 位置 | 判据 | 复杂度 |
|---|---|---|---|
| **准入** | 反馈进来时 | 这信号值得用吗（可信度 / 是否在支持集内） | 单标量 |
| **归因** | 写入前 | 这是新学的还是固有的（teacher/student 差） | 单标量 |
| **裁决** | 写入时 | 正确 × 一致（乘性） | 两标量相乘 |

**每层的判据都必须简单到可以手推**，一旦引入「学习出来的门控网络」，它自己就需要被门控——而那正是退化开始的地方。

**为什么不能再多**：每多一层门控，就需要多一份**可分辨的反馈**才能训练它。而反馈是稀缺的（§3.1）。

### 7.2 绝对信号 vs 比较信号

关键词是「**比**」：

| | 绝对信号 | 比较信号 |
|---|---|---|
| 形式 | `r = 1` / `0` | `r_A > r_B` |
| 需要什么 | 标定「多好算好」 | 只需「哪个更好」 |
| 代表 | 监督标签、奖励模型 | **组内相对优势**、偏好对 |
| 问题 | 标定困难、跳任务不可比 | 无绝对质量 |

**在无用户条件下，只能靠比较信号**——因为没有「标准答案」可以标定绝对值。

而比较的参照物是现成的：
- 两条轨迹之间比（哪条弯路少）
- 我的轨迹 vs 参照的轨迹
- 同一任务的两次尝试（第二次是否更好）

### 7.3 三因子规则（前向学习的接口）

```
Δw = η · m · a_pre · a_post · (a_post − θ)
        ^         ^         ^
        |         |         +-- 滑动阈值（相对自身历史，防垄断）
        |         +------------- 前/后激活（Hebbian：什么和什么关联）
        +----------------------- 门控（正确性 × 一致性 × 后果）
```

**`m` 是核心接口**：它把「外部的稀疏信号」和「前向的局部规则」接起来。

| `m` 来源 | 稀疏度 | 优点 | 缺点 |
|---|---|---|---|
| 任务结果 | 极稀疏 | 最可靠 | 信用分配难 |
| 组内相对（哪条更好） | 中 | 不需价值网络 | 需多路径采样 |
| 重建稳定性 | 密 | 无需标签 | 一致性 ≠ 正确 |
| 惊讶度 | 密 | 无需标签 | 只反映新鲜度 |

**推荐组合：`m = I(环境通过) × (基础 + α · 一致性)`**——乘性门控，环境优先。

### 7.4 防止「错的被反复复现」

这是「用激活次数训练」最大的风险。四道防护：

1. **乘性门控**：未通过环境检验的不写入
2. **竞争写入**：只有惊讶度超阈值的才写（平凡模式不占位）
3. **独立衰减**：不被访问的自然淡出
4. **可回滚**：写入可撤销（需额外机制，这是代价）

**一个警告**：如果只用「激活次数」强化，会立即失控（强者愈强 → 表征坍塌）。必须配合归一化（§8）。

**另一个警告**：BCM 的滑动阈值不能是单一 set point 且响应过快——那会 unlearn 已获得的选择性、擦除记忆（Vogels）。要用**允许区间**。

## 8. 归一化与可塑性

### 8.1 归一化是选择，不是限制

| 归一化 | 保留 | 丢弃 | 适用 |
|---|---|---|---|
| L2 范数 | 方向 | 幅度 | 检索键 |
| L1 范数 | 稀疏性 | 小值 | 强度 |
| 突触缩放 | 相对强度 | 绝对强度 | 连接（长期记忆） |
| 谱归一化 | 最大奇异值 | 爆炸方向 | 巩固写入 |
| 去相关 | 独立方向 | 冗余 | 并存项之间 |

**选哪种归一化，就决定了「什么样的信息被保留」。** 它不是「防膨胀」的补丁，是设计的一部分。

### 8.2 允许区间，不是固定值

**警告（Vogels）：** 单一的、快速的稳态目标值会 unlearn 已获得的选择性、擦除记忆。

**做法：设上下两个 set point，组成允许区间。区间内自由作用，超出才干预。**

```
if 强度 > 上界:  缩小
if 强度 < 下界:  加快衰减
// 区间内：不动
```

**多 set point 的副作用**：系统会变成多稳态（高/低两个活动水平）——这正是记忆系统需要的（「被想起」 vs 「沉默」）。

### 8.3 去相关（防止同质化）

如果多个槽/多个决策模式学同一个东西，容量浪费。两种做法：

- **Gram-Schmidt**：新写入的键减去在已有键上的投影
- **VICReg 式**：显式惩罚彼此之间的协方差

**这也是「生物 engram 的动态收缩」的实现方式**——2024 Nature Neuroscience 的发现是反直觉的：engram 在巩固期**收缩**，不是遗忘，而是为了把两个相似经历分开。现有记忆架构只会「增加」或「驱逐」，没有「主动减少参与编码的项数以提升辨别」。

### 8.4 可塑性作为可调变量

这是 §5.4「比例一」的展开。可塑性不是一个超参，是一个**控制变量**：

| 可塑性高 | 可塑性低 |
|---|---|
| 学得快 | 学得慢 |
| 容易覆盖旧能力 | 保留旧能力 |
| 适合探索期 | 适合稳定期 |

**而「辅以一些反向」的作用是提供锚点**：一个慢的、稳的参考，让快的、局部的更新有基准对照。

**两个现成设计**：

- **局部支持学习**（LSL，arXiv 2610.02126）：门控只在「来自它自己训练分布」的激活上启用适配器，用 GMM 是因为「高斯密度随距离指数衰减 → 天然倾向在没见过的输入上保持关闭」。实测（Qwen2.5-7B，多阶段顺序微调 Igbo → Chemistry → Cybersecurity）：LoRA 基线在**第一个阶段之后**预训练能力即掉 **44%**，LSL 全程保持；消融显示 retention 由 **76.6% → 96.6%**（GMM 门控）→ **98.8%**（再加时序平滑）。开销：GMM 额外 **13.8 MB**（每阶段 6.9 MB，基准模型 14 GB bf16），推理延迟 +86 ms，训练时间 ×1.64。（44% 已验证：原文 Figure 5 正文；2026-10-22 查。）
- **LoPT**（arXiv 2605.04913）：在中点插梯度边界，后半学任务，前半用特征重建保表示。

**两者的共同点：局部不等于隔离。** 隔离（每个任务一个 adapter，互不可见）会放弃共享表示——而共享表示正是泛化的来源。

## 9. 涌现与环境的约束

### 9.1 「允许涌现」≠「放任」

在语言模型里，涌现需要设计者加压力（MoE 不加 load-balance 会坍塌）。

**但在 AGI 里，压力由环境提供**——做不成事就没有结果。不需要设计者手动加。

**所以「允许涌现」在 AGI 里不是一种设计偏好，是唯一可行的路径**：没人知道 AGI 该长什么样，只能造一个能学的闭环，让它自己长出结构。

### 9.2 但仍需要三个要素

| 要素 | 作用 | 在 AGI 里由谁提供 |
|---|---|---|
| **结构** | 给涌现一个先验方向 | **设计者**（接口 / 可塑性 / 稳态——见 §2.10；不是「两区」） |
| **压力** | 让分工有利可图 | **环境**（做不成事就没有结果） |
| **隔离** | 防止互相干扰 | **写入的局部性**（§2.4 第 2 条：LSL 把写入限制在产生它的输入区域，retention 76.6% → 96.6%）；**不是「不同的更新频率」**——那是两区框架的产物，已降级 |

**最容易漏的是第三个**：无差别的写入会把 A 任务学到的东西冲掉 B 能力。解不是「分两层」，是**写入只作用于相关部分**（§2.10 的「相关性」判据）。

### 9.3 环境到底提供了什么

这是「选环境」应该看的三个东西（不是「够不够复杂」）：

| 环境提供 | 具体 | 缺了会怎样 |
|---|---|---|
| **后果** | 成败、报错、不可逆损失 | 无法学习 |
| **可逆性** | 能重试、能回滚 | 延迟无法消除，不敢试 |
| **时间结构** | 任务多长、反馈多快 | 时间尺度只能拍脑袋 |

**本机在这三项上都是优等**（§3.6）。这解释了为什么「本机练 AGI」不是妥协。

### 9.4 一个待验证的判断（2026-10-23 重述）

> 原版：「两种时间尺度（短期 / 长期）的共存，会不会自发形成“快的适应、慢的稳定”的分工？」
> **重述：** 这个问题默认了「两个时间尺度已经存在」。但现在连「会不会分化出两套」都不知道（§11.4）。所以正确的问题分成两层：
>
> 1. **第一层（先问）**：一套可塑性规则能不能同时支持秒级精确历史与月级稳定策略？（§11.4 / S1）
> 2. **第二层（后问）**：若分化出了两套，它们会不会自发形成分工？

间接证据（只适用于第二层）：
- **CLS 理论**（McClelland 1995）：快/慢双系统是必要的（一个记忆不能同时快而具体、慢而泛化）
- **FSC-Net**（2025）：**时间尺度分离（而不是架构）是承重的**——纯重放比重放 + 蒸馏好

**两层都没有直接文献**。所以都是待验证的。

| S8 | 基因的丰度（能不能表达没想到的结构） | 只参数（节点数/密度/τ 分布）→ 安全但空间窄 / **加拓扑生成规则** / 加发育程序（从单节点分裂迁移） | 待定——**这一条决定阶段 A 能发现什么；基因空间窄了，演化只能长回我已经想到的东西** |

### 11.2 原第 1 件（现第 2 位）：测「第二次快多少」

**为什么它排在分化实验之后**：

- **不需要新架构**——只需「经验留存」这一件事
- **不需要 GPU**
- **判据是硬的**：第二次快 30% 还是 0%，一目了然
- **如果第二次不快，后面所有架构讨论都是空谈**
- **但**：若「分化」不发生（§11.4），这里的数字无法归因——不知道快是因为经验，还是因为碰巧调对了参数

**做法**：

1. 选 10 个「有明确成败」的本机任务（例：修一个失败测试、格式转换、定位配置项）
2. 每个任务第一次做，记录：**步数 / 时间 / 人工介入次数 / 是否成功**
3. 把「经验」按最简形态留存（文本记录：情境-策略-后果）
4. 隔一段时间做同批任务的**变体**，记录同样指标
5. 对比

**为什么用「变体」而不是「原题」**：原题能考的是「记忆」，变体才能考「学习」。而 §4.1 已经说明了记忆和学习的区别。

**经验留存的三个档位**（先做最低的）：

| 档位 | 形态 | 成本 |
|---|---|---|
| 1 | 纯文本记录 | 最低 |
| 2 | 结构化（情境-动作-结果-误差） | 中 |
| 3 | 参数化写入 | 高 |

**先做 1，测出基线**。如果基线已显示「第二次快」，再考虑往 2/3 走；如果基线是 0，那说明「经验留存」不是瓶颈，而「怎么用经验」才是。

### 11.3 第 3 件的具体设计

**⚠️ 前提（2026-10-23 补）：这件在现在的链路上做不了。** Pando 走 DeepSeek API，拿不到 hidden state；system prompt 是文本不是向量。用本地 embedding 编码文本算距离，测的是文本相似度，不是内部状态——那已经是另一件事了。要动这件，前提是本地有可读内部状态的模型（阶段 1 的块扩散底座，或任意本地模型）。

**测什么**：同一任务在两个不同会话里，模型的「内部状态向量」距离。

**为什么值得测**：如果已有天然的一致性（哪怕很弱），说明「身份」已经部分涌现，只需**放大**；如果没有，说明需要**显式训练目标**。

（按 §2.9，这套问法要改：问的不是「涌现没有」，是「有没有一个中心在承载累积的修改」——判据见 §2.9 四条。）

**这个实验很便宜**：不需要训练，只要跑两次前向算距离。

### 11.4 分化实验（第四版：阶段 A 降级，阶段 B 提为唯一第一优先）

#### 先看：这件事在 SNN 里做到哪了（2026-10-23 第三次修正）

**阶段 A 不是新的。** 它就是 neuroevolution of SNN，2012 年起有连续工作：

| 已有工作 | 做到什么 | 与阶段 A 的关系 |
|---|---|---|
| **ELSM**（2024） | 目标 = small-world 系数 + 临界性；自发长出 hub / 短路径 / 长尾度分布 / 社群；NMNIST 97.23% | **已经回答了一半**：会收敛到小世界 + 临界 |
| **NeuEvo**（PNAS 2023） | STDP 演化出四类回路 + 全局误差更新权重 | 演化的是**回路类型**，比纯结构参数更宽 |
| **CortexZero**（2025-11，预印本） | 基因 = 区域树上的概率分布，发育采样，不用反传 | **S8 的最宽档已有人做到规格层**；但**没有结果** |
| **WANN-Spiking**（2022） | 权重无关的拓扑搜索迁到脉冲回路 | 只搜拓扑，不搜 τ |

**所以阶段 A 的真实价值只剩一个观测：** ELSM 没有量的是**实测 τ_d 分布**（它量的是 small-world + 临界）。而这里有一个 §2.2 已经指出的坑：**基因里的「τ 分布」与网络实际的时间尺度不是同一个量**（单细胞 τ 会被强递归抹平）。

→ **只记录基因型、却从行为读结果，会让「收敛到广谱」有两种相反解释**：「选择偏好广谱基因」或「给了也白给」。所以阶段 A 必须**同时记录每个存活个体的实测 τ_d**，否则结果不可解释。

**阶段 B 是真空。** 三条前提与 SNN 主流逐条相反，而且互相锁死（详见 §15.6）：

| 草案阶段 B | SNN 主流 |
|---|---|
| 一条永不重置的时间轴 | 每样本 / 每帧重置 |
| 不开学习也要有状态 | BPTT 必须有固定 T |
| 无任务、无 episode、无准确率 | 全部有任务 + 准确率 |

> **三次改写记录（保留理由，不删）：**
> - **v1**：两个子任务交替 + 消融双分离 → **错在形态**：有 episode、有答案、算准确率，那是测一个算法。
> - **v2**：状态永不重置 + 测 τ 分布 → **对了一半**：连续状态对了，但**还是我给定结构让它学**。
> - **v3（本版）**：加一个前面的阶段——**先让随机变异 + 选择把结构搞出来，然后才学**。生物上脑子不是被设计出来的，是突变 + 选择先给了它一个形状；没有这一层，测的仍然是「在我设计的东西里会不会出现分工」。

**回答两个问题：**

1. **进化层**：能不能不靠设计者，自己选出「能活 + 有记忆」的结构？分化（多时间尺度）是被选出来的，还是根本不需要？
2. **学习层**：在选出来的结构上开可塑性，一套规则够不够？会不会挤占旧的？

#### 阶段 A：让结构自己长（**不开学习**）

##### 群体与基因

N = 200~500 个个体。**基因不是权重，是结构参数**；权重一律随机初始化，**这个阶段完全不开可塑性**。

| 基因 | 取值范围 | 说明 |
|---|---|---|
| 节点数 | 100~2000 | |
| 连接密度 | 0.5%~10% | |
| 拓扑生成规则 | 随机 / 距离衰减 / 分群 / 小世界（4 选 1 + 参数） | |
| 兴奋 : 抑制比 | 1:1 ~ 5:1 | |
| **时间常数分布** | 单值 / 均匀 / 对数正态（跨几个量级） | **这一条直接对应「分化」** |
| 是否有分群结构 | 无 / 2 群 / 4 群 | |

##### 怎么判「活」

每个个体跑 2000 步，输入是**同一个事件流**（周期分量 + 偶发事件 + 噪声）。**六条全过 = 活**：

| 判据 | 具体测什么 | 阈值 |
|---|---|---|
| **不炸** | 活动幅度时间序列的 max / mean | < 20 |
| **不死** | 最后 500 步的平均活动 | > 全静默的 10% |
| **不僵** | 状态的方差 | > 0（不是固定点） |
| **不纯混沌** | 两条轨迹从差 1e-6 出发，10 步后的分离度 | 有界，不是指数爆炸 |
| **有区分** | 10 种不同输入，状态距离矩阵 | 类内距 < 类间距的一半 |
| **有记忆** | 注入唯一标记，100 步后能不能线性读出 | 高于随机 |

这些判据里**没有任务、没有答案、没有准确率**。

##### 繁殖

活下来的按「记忆长度 + 区分度」排序，前 20% 繁殖；基因随机扰动（每代 5% 位翻转 + 参数 ±10%）。死光的代重来。跑 100~300 代。

##### 看什么算有结果

**基因群体是否收敛**——尤其是**时间常数分布**这一项会不会自己走向「广谱」或「双峰」。

这是「分化」在结构层的答案，而且**不是我定的**：

- 收敛到广谱 / 双峰 → 多时间尺度对「活下来」有用，它是被选出来的，不是我该设计的参数
- 收敛到单值 → 在「活下来」这件事上多时间尺度没用；那么「要不要分化」这个纠结，在这个判据下根本不成立

**第二种结果比第一种有价值**——它说明时间尺度分化可能只在「要做复杂任务」时才需要，而不是「要活着」就需要。

##### 顺带必须测：会不会自己跑到临界

生物网络在临界附近（既不僵也不乱），而且这个状态是**自组织**的（NALSM：星形胶质调制 STDP 到临界态）。

测法：**分支比 σ**（每个活动事件平均引发多少后续事件，σ≈1 是临界）或**雪崩尺寸的幂律**。

- 自己跑到 σ≈1 → 「稳态」这一条不用我给
- 跑不到 → 才需要显式加

#### 阶段 B：结构定下来，再学

挑阶段 A 里活下来的前 5 个**不同**结构（不同拓扑、不同 τ 分布），固定结构，打开可塑性。

##### 形态：一个永不清空的状态

| | 错误形态（v1） | 本版 |
|---|---|---|
| 时间轴 | 离散 episode，喂完就重置 | **一条不间断的时间轴**，状态从不重置 |
| 输入 | 固定长度序列 | **连续事件流**，每一刻都有输入，没有「开始 / 结束」 |
| 输出 | 在指定位置输出标注答案 | **不强制输出**；从外面读状态，不让它做题 |
| 训练 / 测试 | 分开 | **不分**；同一条时间轴，只差「给不给调制」 |
| 判据 | 消融 → 准确率下降 | **状态自己的性质** |

关键一句：**不是「训一个能做题的网络」，是「看一个一直活着的东西会不会形成结构」。** 所以没有准确率、没有收敛曲线、没有 episode。

##### 三个测量（都在同一份持续状态上，不需要重启）

**测量一：影响能持续多久**

注入一个**唯一标记**（之前没出现、之后也不会再出现），**之后不打扰它**，在第 1 / 10 / 100 / 1000 / 10000 步各读一次状态，用线性探针问「刚才那个标记是什么」。

得到一条「可读性 vs 延迟」曲线——**每个内部维度各一条**。

**测量二：分化（看曲线形状，不看准确率）**

把每个维度的曲线拟成 τ_d，看 τ 的分布：

| 分布形状 | 含义 |
|---|---|
| 单峰、窄 | 一套规则只能给一个 τ，不分家 |
| **单峰、宽（跨几个数量级）** | **一套规则自然广谱** |
| **双峰** | 分化成了两套，分家在机制上必要 |
| 全部极短（秒级以下） | 什么都没记住，是参数问题不是分化问题 |

第二层：**不同 τ 的维度是不是各自编码不同的东西**？用互信息算：τ 短的维度对上「刚才那几步」的信息多，τ 长的对上「周期性结构」的信息多——这就是频谱分解（§2.2 末）。

这比双分离好在哪里：不需要定义「两个任务」、不需要 episode、不需要拆连接；判据是**分布的形状**，直接对应「一套够不够」。

**明确不采用双分离消融。** v1 的思路是「拆掉一套再测另一套，看准确率下降多少」——它需要定义两个任务、需要 episode、需要算准确率，同一条链条把实验拉回基准测试形态。本版用「τ_d 分布形状 + 互信息分工」替代，两者不共存。

**测量三：学习（不是准确率）**

| 量 | 怎么算 | 预期 |
|---|---|---|
| **响应幅度** | 同一周期分量重复出现时，参与它的维度激活强度 | 变强（强化） |
| **响应延迟** | 从输入到状态变化的时间 | 变短（熟了） |
| **挤占** | 新结构学进去后，旧结构的可读性掉多少 | ——**这才是真问题**（LSL 的 44% → 76.6% → 96.6%） |

「挤占」那一行最要紧：**如果新学的东西会冲掉旧的，那不管分化不分化，「持续学习」都不成立。** 这是与 A 判据直接相关的量。

##### 阶段 B 的对照

| 组 | 输入 | 回答什么 |
|---|---|---|
| 1 | 有结构 + 可塑性开 | 主体 |
| 2 | **同统计的白噪声**（无周期、无结构） | 看到的 τ 分布是不是自发噪声就有的 |
| 3 | 有结构 + 可塑性关 | 结构不靠学习的部分占多少 |
| 4 | 有结构 + 两套可塑性 | 分家能不能改善「挤占」 |

组 2 是硬对照：**任何非线性循环系统都会自发产生多时间尺度**（临界态、混沌边缘都是）。不证明「来自输入结构」，测量一就没有意义。

##### 判据（先写死，防事后挑）

| 判据 | 阈值 | 不达怎么办 |
|---|---|---|
| **有记忆** | 至少 10% 的维度 τ > 100 步；且组 2 对应比例不超 5% | 没记住东西 → 调稳态 / 可塑性，不谈分化 |
| **双峰** | GMM 两成分似然比检验，且两峰相距 > 10× | 单峰就判「未出现双峰」，不写「没有分化」 |
| **频谱分解** | τ 短 / 长两组的互信息差 > 2 倍 | 分化了但没分工 → 也算没分化 |
| **不挤占** | 新学后旧结构可读性下降 < 20% | 下降严重 → 「持续学习」不成立，这是更优先的问题 |

---

#### 两阶段共用的要求

**必须多随机种子**：人工培养大脑最大的痛点就是批次变异（「Even under identical culture conditions, organoids exhibit different learning rates and neural architectures」、「every brain organoid is unique」）。对应到本实验就是种子敏感性——**N ≥ 5**，看分布形状 / 收敛方向是否稳定出现。5 个里 2 个双峰、3 个单峰 → 结论是「会分化但不稳」，这比挑一个成功的报有价值。

**规模与成本**：阶段 A 的种群评估可并行，个体 2000 步很短；阶段 B 单个体 10⁵~10⁷ 步。总成本本机 CPU 小时级，无 GPU。

**但规模不能拍**：要测到 τ > 10000 步，状态维度至少得有一批能存活那么久。先跑一次探测，看现有规模能不能出 τ > 10³；出不了就加大。

**一个必须记住的坑**：人工培养大脑的 2026-09 综述原话——「**closed-loop adaptation is a function of a whole OI system (substrate plus interface plus feedback), not of the tissue itself**」。即：看到「形成结构 / 学会了」时，要能说清是**基因、可塑性规则、还是稳态**在起作用——这就是为什么必须有组 2（白噪声）和组 3（可塑性关）两个对照。不然看到什么都不算证据。

#### 与「原第 1 件」的关系

| | 测什么 | 主体 |
|---|---|---|
| §11.4（本件） | **本体能不能自己长出结构，以及长出后能不能学** | 小网络（AGI 雏形） |
| §11.2（原第 1 件） | agent 第二次会不会更快 | Pando（外部工具、文本经验） |

前者是「本体」层，后者是「外挂」层。**两者不能互相替代**，但 §11.4 先——因为如果本体长不出，后者只是给一个没有身体的东西堆文本。

> | 二 | 结构消融（切中心） | **循环依赖**（要先知道中心才能切）+ 损伤曲线测不出中心（平滑 = 分布式，特定崩 = 局灶模块） |

> | 四 | 共享改动结构（权重 delta 集中度 + 消融公共子空间 + 跨种子/跨历史） | **未评估就被悬置**。它比前三个都硬（在结构层测），但依赖「权重快照 + 多域任务」，且可能得出「无中心」的真结论 |
>
> **当前状态：** 不设判据。§11.1 不再排阶段 C。下面的内容只做记录。


> 2026-10-23 新增。本节填的是 §2.9 判据表第四条留下的缺口：**「消融一致性」在 persona 不设定之后失去对象，而「选一组连接再切」从根本上有两个问题。** 替代方案不是消融，是**不改结构、只测「它是不是它」**。
>
> **先记住一个分层**：
>
> | 阶段 | 测什么 | 有任务吗 |
> |---|---|---|
> | A（§11.4） | 结构能不能自己长出来 | 无 |
> | B（§11.4） | 状态的性质（记忆长度 / 分化 / 挤占）—— **A 判据的前提** | 无 |
> | **C（本节）** | **个体性（重复性 / 个体间差异 / 跨域一致）—— D 判据** | **有，但是多解任务** |
>
> **为何必须另开一个阶段：** 阶段 B 的前提是「无任务、无 episode、无准确率」，而个体性需要**多解选择**——没有选择就没有「怎么选」可测。

#### 11.5.1 为什么放弃「结构消融」

| 问题 | 具体 |
|---|---|
| **循环依赖** | 要切「承载自我的那组连接」，得先知道自我在哪；而判据的目的**正是**要知道自我在哪 |
| **损伤曲线测不出「中心」** | APA 定义：graceful degradation（平滑劣化）**恰恰是分布式表征的性质**。而真实脑损伤常见的是「其他都正常、某一种能力灾难性丧失」（Coltheart 1991 举的病例：只能理解不能产出专有名词）。两者都不是自我 |
| **分不清三种退化来源** | 平滑 = 分布式；特定能力崩 = 局灶模块；整体崩 = 容量不足。§2.9 说的自我是「分布式网络里被反复使用而成为中心的一组连接」——**它既不是模块，也不会因为被切而只坏一种能力** |

结论：损伤曲线可以保留为一个**旁路观测**（测模块化程度），但**不能当 D 判据**。

#### 11.5.2 替代：测「个体性」

方法学出处：动物行为学的 **animal personality / behavioural syndrome**（核心概念：repeatability、cross-situational consistency、temporal stability、个体间方差 vs 个体内方差；统计量 ICC / Cronbach's α；实测区间 r ≈ 0.35~0.88）。

**关键：它测的不是「不变」，是「统计意义上的稳定」，允许个体内变异（intraindividual variation 是这套范式里的正式概念）。** 这与 §2.9「冻住就不学了」不矛盾。

#### 任务：多解任务

**定义：一个任务有多个都能通过环境层验证的等价解。** 环境层给的是成败，不是唯一答案。

不用造：§11.2 那 10 个本机任务里本来就有（修 bug 改调用方还是改被调方、重构的两种等价结构、排序稳定性选择）。挑选条件两条：① 至少两个解都能过环境层；② **不告诉它哪个是标准答案**（因为确实没有）。

#### 三个子测（必须一起用）

| 子测 | 怎么做 | 判据 |
|---|---|---|
| **A. 重复性** | 同一批多解任务（N ≥ 20）在 T 个不同场合重复；算偏好向量的 ICC | **ICC > 0.5**（参照 animal personality 典型区间 0.35~0.88） |
| **B. 个体间差异** | 两组对照：① 同历史不同种子（N=5）② 同初始结构 + 同种子 + **不同历史**（N=5）；算组间距离 | **② >> ①**（证明差异来自历史，不是种子噪声） |
| **C. 跨情境一致性** | 同一偏好是否跨任务域出现（语言类 / 动作类 / 排序类） | **跨域偏好相关 > 0**（是「它」而不是「某一种能力」） |

**「不同历史」怎么造（两个强度档）：**

| 档 | 做法 | 强度 |
|---|---|---|
| 1 | 同一批任务的**不同顺序** | 弱（路径不同，统计相同） |
| 2 | 同一输入分布但**不同共现结构**（A 常与 B 共现 vs A 常与 C 共现） | 强（改变统计） |

#### 两个反例：为何三条必须一起用

| 反例 | A 重复性 | B 个体间差异 | C 跨域一致 | 被谁排除 |
|---|---|---|---|---|
| 每次随机选 | ≈0 | 有（噪声） | ≈0 | A + C |
| 硬编码「永远选第一类」 | **高** | **≈0**（所有个体一样） | 高 | **B** |
| 真有个体性 | 高 | **大** | >0 | — |

**单看 A 会被硬编码骗过，单看 B 会被随机噪声骗过。** 这与 §4.5 的「过程指标不能单独优化」是同一个结构。

#### 11.5.3 一个结构侧的补充（不是消融）

**可追溯探针**：从连接 / 状态里线性读出「它经历过哪类历史」。这不是切，是读。它提供「历史写在结构里」的直接证据，与行为侧三条互补。

#### 11.5.4 与 A 判据的分工

| | 测什么 | 失败意味着什么 |
|---|---|---|
| A（§11.2 的「第二次快多少」/ §11.4 的挤占） | 会不会变强 | 学不动 |
| **D（本节）** | **变强的是不是同一个东西** | 学得动，但每次学的不是同一个它 |

两者**不能互相代替**：A 成立而 D 不成立，得到的是一个「很快但没有中心」的系统；D 成立而 A 不成立，得到的是一个「稳定但不学习」的系统（§2.9 说过：冻住就不学了）。

> §11.5 不是自创测法，它借的是行为生态学的成熟范式。本节记下借了什么、借的边界在哪里。

**核心范式：animal personality / behavioural syndrome**

| 概念 | 含义 | 在 §11.5 里的对应 |
|---|---|---|
| **repeatability（重复性）** | 同一个体反复测出的行为是否比随机更一致 | 子测 A |
| **cross-situational consistency** | 不同情境下是否表现同一倾向 | 子测 C |
| **temporal stability** | 跨时间点的稳定度（不等于 1，允许变化） | 子测 A 的 T 个场合 |
| **interindividual vs intraindividual variation** | 个体间差异 vs 个体内波动，两者分开量 | 子测 B + A 的分解 |
| **test-retest reliability** | 同一测试重测的相关 | 子测 A 的 ICC |

**实测区间（用作阈值参照，不是直接挪用）**

| 对象 | 重测信度 | 出处 |
|---|---|---|
| 灵长类（多研究元分析） | **r ≈ 0.35 ~ 0.88** | David et al. 2012 引用的综述；猩猩 76 项行为 Cronbach's α 均值 **0.86** / Pearson **0.78**（Uher 等 2008） |
| 犬 | **r ≈ 0.43** | 同上 |
| 斑胸草雀（短/长期） | 短期两个特质均可重复；**长期只有一个可重复**（探索倾向稳定、挣扎率下降） | David, Auclair & Cézilly 2012，Ethology 118:932-942 |
| 黑猩猩（25 年跨度） | 人格特质长期稳定 | Animal Behaviour 227 (2025) |

**两个重要提醒**

1. **「长期稳定」不等于「所有特质都稳定」。** 斑胸草雀那篇正好证了反例：两个不相干的特质里，长期只有一个可重复。→ §11.5 的子测必须**分维度报告**，不能只给一个总体 ICC。
2. **个体内变异本身是信号，不是噪声。** 该文原文指出「不同个体在短期稳定性上存在差异」——即 intraindividual variability 本身可以是个体特征。

**损伤/消融侧的方法学（为何不用它做判据）**

| 概念 | 含义 | 为何不能当 D 判据 |
|---|---|---|
| **graceful degradation** | 分布式表征下局部损伤对整体影响小（APA 定义） | 平滑 = 分布式，不是「中心」 |
| **局灶损伤 → 特定能力崩溃** | Coltheart 1991 举的病例：只能理解不能产出专有名词 | 特定崩溃 = 局灶模块，不是「中心」 |
| **diffuse vs catastrophic damage** | Aitken 1991 的反驳：弥漫损伤才会平滑 | **两者都测不出「分布式里的中心」** |

**一个可用的旁路观测**：损伤曲线仍可用来量「模块化程度」（陡崖位置 → 偏模块化），但它不回答 D。

## 13. 设计准则与自评

### 13.1 九条设计准则

这九条不是从文献里找的，是从「反复被纠正」里提炼的（原为五条，2026-10-23 增四条）：

1. **从需要里推，不从组件里拼**——先问「它此刻需要什么」，再决定长什么
2. **先证明不能涌现，再设计**（2026-10-23 升级）——原版是「能涌现的不设计」，那是事后判断。现在要求设计**前**先给出「它为什么不能涌现」的理由；给不出就做实验（§11.4）。原版把「时间常数」当必须给的例子，现已证明连 τ 也不是可设计的量（§2.2）
3. **要常数也得说清是需求给的，还是我造的**
4. **一致性 ≠ 正确性**，任何内生信号都得有个外部锚
5. **判据换形状，不换阈值**（后者只是把错误固定住）
6. **不要把生物的「实现约束」当原理**（2026-10-23 新增）——判定：换一个实现还成立吗？只在一种实现里出现的，是约束（分子种类 / 颅腔体积 / 代谢代价），不是计算必须的
7. **只搜支持自己的证据不叫搜**（2026-10-23 新增）——每个「X 存在」配一条「X 不成立」；多个源如果同源（同索引 / 同摘要服务 / 同一篇论文的转述 / 同一个人写的），只是同一个源出现了两次
8. **先查这一整套有没有现成学科**（2026-10-23 新增）——把机制清单逐条翻译成术语，看它们是否落在某个已有领域的词汇表里。全部命中 → 先读那一支的现成答案，再谈「新设计」。本次的代价是：草案从 §2 推到 §11.4 才想起问「这不就是个 SNN？」，而 SNN 里已经有 LSRSNN（双峰 τ）、ELSM（演化出小世界 + 临界）、e-prop（在线局部学习）三件直接对应的成果，且它们在 2012~2026 年间已发表
9. **定义不清的概念不能当判据**（2026-10-23 新增）——本次是「自我 / 意识」：连碳基生物都缺乏公认定义，给硅基定判据只能是凭空编。**推论：一个量如果「任何实体都满足」，它不是判据而是必要条件**（例如「有个体差异 / 有稳定倾向」——固定权重的随机网络三项全过，它连学习都没有）；同理，一个量如果只能靠观察者投影给出（「看起来像同一个」），也不能当判据。**遇到这类概念，正确动作是悬置，不是找个代理量硬测**

> **第 9 条是怎么落地的（一条可复用的自检）：** 本次连续写错三版 D 判据（消融一致性 → 结构消融 → 个体性），每一次都是「想一个能测的量，然后把它当成自我」。共同错法：**想一个指标 → 它居然能跑 → 就当成判据**，而不是先问「这个量是不是任何实体都满足」。这个顺序不能倒。

### 13.2 本轮的框架修正记录

### 13.3 做得好的

- **原「两区划分有实测依据」已推翻**（2026-10-23）：那 1.00 / 0.61 / 0.00 测的是承诺在价值压力下的持久性，**不是「分区存不存在」**——两者不是同一个命题。这一条曾是本草案最强的「实测依据」，现在它只支持「某类内容必须始终在场」（即 §2.9 的自我描述）
- 反馈五维把一个模糊的「没反馈」拆成了五个可分别处理的问题
- 过程四度量不依赖正确答案，可纯从轨迹算
- 保留了所有待定项（**17 组**：A–C / E–K / M–S；D 未用，L 于 2026-10-22 改名为 R，S 于 2026-10-23 新增）且标了倾向——**共 99 条**（脚本核验）

### 13.4 不确定的地方

- **「两种时间尺度自然分工」只是假设**，无直接文献
- **「块扩散能撑住多步推理」未验证**（只有 SDAR / Eso-LMs 的间接证据）
- **过程四度量会不会被优化成新指标**——已有警觉，但无解法
- **「谁值得参照」是递归问题**（判断力需要参照，参照需要判断力）
- **「最长历史」类的问题已全部悬置**——「身份是否涌现 / 自我在多大尺度出现 / 压力与自我形态对应 / 消融能测出什么」四条随 D 判据一并悬置；不是「还不知道答案」，是**问题本身没定义清楚**
- **一套可塑性规则够不够**（§2.10 的核心未知）——能用一套规则同时产生秒级精确历史与月级稳定策略吗？这是 §11.4 要回答的
- **「分化」会不会稳定出现**——即使出现了，N=5 里几次？不稳的话需要什么保证它分化
- **时间常数的分布能不能测准**——需要 τ 跨越几个量级，而长 τ 的估计很吃样本量；测不出来就分不出「单峰宽」与「双峰」
- **自发多时间尺度是噪声还是结构**——任何非线性循环系统都会自发产生多尺度（临界态）；§11.4 组 2 对照就是为了排除，但它能不能排干净还没验过
- **基因空间够不够宽**（S8）——这是 §11.4 阶段 A 的真正风险：如果基因只能表达我已经想到的那几种结构，演化只能长回我设计的东西，实验就白做了
- **「活」的六条判据会不会相互矛盾**——比如「不僵」与「不纯混沌」之间只剩窄窗口，可能大部分随机结构都过不了，导致演化无解
- **巩固窗口的长度**——不能拍脑袋，要从「什么算同一件事」推，但那个界限本身模糊
- **「短期」的二义会不会影响历史结论**——§2.10 新发现的区分（状态持续 vs 未稳定连接）；本场已修 §11.4 的任务设计，但其他章节还没逐条回扫
- **必须给的稳态究竟是什么形式**——突触缩放 / 内在兴奋性 / 活动预算，三者的差别在本实验里能不能分辨
- **「无层」是否必要**——还是「层 + 稀疏激活」就够；赛博果蝇只证明了拓扑，没证明其余三条
- **环境锚的最低频率**——未知；需要「无锚漂移」实验回答
- **资格迹在长任务上的归因精度**——τ_e 与行为窗口如何匹配，未标定
- **教师弥散影响的可审计性**——记录到什么粒度才够
- **事件输出的粒度**——一句话 / 一个动作 / 一个阶段，未定
- **强化物的乘性门控是否会卡死学习**——任一项为 0 则整体为 0，需要避免「永远学不动」
- **分布式的长期记忆能否持续写入**——LSL 只验证到 7B / 三阶段；几百阶段、上亿条内容未验证（容量问题，不是机制问题）〔2026-10-23：本条前提（「长期记忆存在分布式载体」）已改——长期就是连接，问题换成「持续的强度累积会不会饱和」，仍无数据〕
- **混合 key 是否能保留 O(1)**——若 learned query 占主导，退化为 ANN 检索，可预取与 offload 两个工程优势消失〔前提已降级到 §14.10，仅在「卡表必要」时成立〕
- **写时碰撞的检测成本**——校验位 / 读旧行比相似度，在 200 GB 级表上的开销未测〔同上〕
- **SNN 的固定代价能不能绕开**——0.16 nats 的 backbone 成本「不随算力变」；但 GSU 那条路（Scientific Reports 2024）其实是**放弃纯二值**（ternary + 连续流）才绕过去的——那还算不算 SNN，没定义
- **阶段 A 的基因型与实测 τ_d 不一致时怎么解释**——两者不是同一个量（§2.2）；如果基因收敛到双峰、实测仍是单峰，结论该写什么？本版实验设计尚未给出裁决规则
- **脉冲化的块扩散能不能成立**——共用决策要求它（§15.7 ④），但 15 轮检索无先例：SNN 侧只有 SSM + 脉冲量化层（SpikingSSM），块扩散侧只有非脉冲的 SDAR / Eso-LMs。这条不成立，整个「共用」路线要退回「非纯二值」形态
- **「非纯二值」还算不算 SNN**——GSU（ternary + 连续流）是现有绕开二值表达上界的路径，但它放弃了「纯脉冲」；若采用，§15 的整套对照（功率、SynOps、神经形态硬件优势）要重算
- **阶段 B 在 CPU 上的真实成本**——「本机 CPU 小时级」是按什么实现估的？稠密实现与事件驱动稀疏实现可能差一个数量级（§15.3 ③）；模拟器形态未定
- **「没找到 SNN 的推理/指令跟随评测」是检索结果，不是定论**——15 轮 web_search，未逐篇精读；KB 侧未查（服务停着）
- **repeatability 的阈值 0.5 是从动物行为学借的**——那里的区间（0.35~0.88）是「个体在生物学意义上稳定」的经验值，**不保证适用于一个人工网络**；而且多解任务的「等价」由环境层判定，环境层的宽松程度会直接影响 ICC（判据越松 → 解越多 → 偏好分布越散）
- **个体性测量需要多久的历史？**——太短则历史没写进去（ICC ≈ 0），太长则测不起；这个长度未定，与 §10.10 S3（巩固窗口）相关但不是同一个量

## 14. 计算形态与教学（2026-10-22 追加）

> 本章是 2026-10-22 讨论的追加，起因是三个问题：① 现在的 agent 满足 A/D 到什么程度；② transformer 深度固定是不是长链推理的瓶颈；③ 能否用「内部循环状态 + 事件触发输出」替代逐 token 生成。讨论中又扩展到生物神经元、赛博果蝇、conditioning 训练、教师偏差、环境反馈是否必要。本章只记结论与依据；未定项并入 §10.8（后续追加的并入 §10.9 / §10.10）。
> **位置说明：** 本章放在 §13 自评之后，是因为它是本轮新增、尚未并入 §1-§9 正文；后续定稿时应重新编号并归位。

### 14.1 现在的 agent 满足到哪

| 判据 | 现状 | 判断 |
|---|---|---|
| A 持续自主学习 | 改进发生在被触发的会话内（纠正 → 写教训 → 改 persona/skill）；无自主任务生成、无环境反馈闭环、不改权重 | **几乎不满足** |
| D 连续自我 | MEMORY / AGENTS / diary + 每步重建的 system + 会话历史 | **不满足：三层里没有一层是自我**（「助手」在权重里是倾向 / 「小猫」在上下文里是条件 / 「连续性」在外部文件里是记录——见 §2.9） |

用 §2.4 的三态表定位：**现在的 agent 整个是「外挂」**——人格与记忆都在 context 里，不被梯度改写，也不作为参数参与前向。它跨会话认得出自己，靠文本，不靠状态。

但「外挂」这个词还是太宽容：它暗示自我在外面存在着。更准的是 §2.9 的结论——**自我那个位置是空的**，外面放的是一段描述。这套「看起来连续」的表象是观察者拼出来的，系统内部没有一处维持它。

它真正满足的是另一件事：**把固定深度换成了外部串行步**。一次请求是固定深度，但 agent 可以调用任意多轮（模型 → 工具 → 观察 → 再模型）。这是「用外部串行步弥补单次前向深度上限」的工程解。注意：这里的「外部串行步」与 §14.3 之后讨论的「内部深度循环」（loopLM）是两回事——前者在模型外，后者在模型内。

**2026-10-23 拍板后的定位变化（重要）：** “只有一个完整个体”（§15.7 ④）意味着上面的诊断**不是「Pando 的早期版本」，而是「另一个东西」**。DeepSeek 权重冻结、记忆在外部文件，它不能承载累积修改（§2.9）。在共用决策下，Pando 的定位是**环境 / 工具 / 教师**（提供任务、验证、可逆性、参照），不是这个个体的雏形。这也是为什么 §11.2 的「第二次快多少」不能代替 §11.4：它测的是外挂层的效率，不是本体的结构。

### 14.2 深度固定是不是长链推理的瓶颈

方向对，表述要修一处。

| 形态 | 表达力（Merrill & Sabharwal） |
|---|---|
| 固定深度 transformer（对数精度） | 恰好 FO-uniform TC⁰；图连通、状态跟踪做不了 |
| 线性步 CoT（projected pre-norm，标准复杂度猜想下） | 全部正则语言 |
| 多项式步 CoT（generalized pre-norm） | 恰好 P |
| 多项式 padding + O(log^d n) 循环 | FO-uniform TC^d |
| 多项式 padding + polylog 循环 | FO-uniform NC（不失并行性的上限） |

所以「深度固定 → 处理不了超深长链」要改成：**深度固定 → 不能在单次前向内完成，必须把串行步外化（CoT）或循环化（loopLM）**。CoT 已经用外部 token 绕过了它，代价是：状态被压成离散 token、一旦生成不能回退、上下文有限、每步重走一遍网络。

### 14.3 层是同步的拓扑，图是异步的耦合

这是本轮最重要的一个修正。原先我把「拓扑（图）」和「时间（异步）」列为两个维度；实际上它们在「反层」这个目标下是同一件事的两面。

推理：

- 神经网络里没有「目的地」——神经元发放不针对某个接收者，它影响所有突触后神经元；
- 没有「消息」——传递的不是内容包，是对接收者状态的改变；
- 没有全局时间——每个节点按自己的状态演化，「第几个 tick」是观察者的记号。

所以「同步 / 异步」不是系统的属性，是离散化时的**实现选择**（一个 tick 更新全部节点 vs 只更新收到事件的节点）。延迟也不是异步的来源，它只是让局部耦合在时间上可见。

**「层」= token 间全局互看（注意力）+ 固定串行顺序 + 同层同步更新；「图」= 稀疏 + 有延迟 + 局部更新。去掉层，本质上就是引入稀疏性和延迟。**

更进一步：**意义的位置也变了。**

- transformer：意义在**表示**里（token 的向量），注意力传递 value（内容）；
- 耦合网络：意义在**关系**里（哪个节点被激活、激活了谁、在什么相位），信号只改变接收者的状态。

这直接支持「用 conditioning 训练」：如果意义在关系里，训练就不该是「教它输出正确的 token」，而是「塑造什么情境下什么行为被强化」。

### 14.4 全局节律：可塑性窗口的载波

固定频率不是同步时钟，是**全局节律**。它的作用可以具体化：

- 不强制同步；提供一个缓慢的相位 / 增益信号，所有节点都能读到（可并行）；
- 生物里 theta 相位调制海马 STDP 窗口，gamma 与注意力绑定——节律是「什么时候容易可塑」的广播；
- 工程上：全局相位 φ(t)，每个突触的更新乘以相位窗口 g(φ)；奖励 m(t) 再乘以 g(φ)。

**节律 + 神经调质是同一个广播系统的两面**：节律给时间窗口，调质给「该强化什么」。

### 14.5 两个维度：拓扑与时间 + 节点动力学

讨论中曾把「图拓扑 / 连续时间 / 局部学习 / 单细胞复杂度」列为四条；按 14.3 的合并，可压成两条（这是讨论中的整理，不是本文件前文的既有分类）：

| 维度 | 包含 | 对应说法 |
|---|---|---|
| **拓扑与时间** | 稀疏图 + 路径 + 延迟；时间分辨率（固定 tick / 事件 / 连续） | 「没有层，沿路径传播」 |
| **节点动力学** | 内部状态 + 时间常数 + 局部可塑规则 | 「神经元不是点，随时间演化」 |

「连续时间」并入第一维（作为**时间分辨率趋于零**的极限——它不是「延迟」的极限：延迟是信号沿边传播所需的时间，时间分辨率是状态演化的粒度，两者相关但不同）；「局部学习」并入第二维（作为突触 / 节点的局部规则）；「单细胞复杂度」也并入第二维（作为节点的丰富度）。这个合并是为了把待定项压到可讨论的规模，不是本体论断言——分开看也成立。

工程取舍：**拓扑（稀疏图 + 延迟）是最值得先试的**（有可训练近似：flyGNN、C-DESN、LNN）；局部学习是长期方向（COLA 是证据，但还远未替代反传）；单细胞复杂度最后加（成本最高，收益最不确定）。

一个必须保留的区分：**「无层」不等于「无结构」**。生物有连接组、区域分工、多时间尺度、神经调质；transformer 有全连接 + 固定深度。区别不是「有结构 vs 没结构」，是「结构怎么组织」：按层同步，还是按图异步。这也回到 §0.2 的「层是优化的产物，不是存在的必需品」。

### 14.6 强化物：三层复合，奖励作用在可塑性上

内在强化物不是一个标量：

```
r = 稳态(硬边界) × 能动性(偶联) × 惊讶度加权预测误差(非平凡)
```

| 层 | 测什么 | 时间尺度 | 防 hack |
|---|---|---|---|
| 稳态约束 | 资源 / 文件 / 进程 / 上下文是否越界 | 持续，越界即触发 | 难（耗尽是真的） |
| 能动性 | 做了 A，环境是否出现可观测、可复现的变化 Δ | 每个行为后 | 动作成本 + 新颖性 + 可复现性 |
| 惊讶度加权预测误差 | 预测 Δ，实际 Δ′，差多少；只对非平凡误差计分 | 每步 | 惊讶度阈值 + 竞争写入 |

关键判断：**能动性是强化物的载体，不是强化物本身**——它只说明「动作和结果有偶联」，不说明「结果好不好」。方向仍然空着：这三项都是**内在**信号，价值（方向）不在其中；外部锚见 §14.8，它**不进这个乘积**。

奖励怎么作用到模型：**不改当前激活，改「哪些突触接下来会被改」**。三因子规则：

```
Δw_ij = η · e_ij(t) · m(t)
```

- `e_ij`：资格迹（「我刚才活跃过」，按 τ_e 衰减）；
- `m(t)`：全局调制（奖励预测误差 RPE / 能动性 / 惊讶度加权预测误差），广播到所有突触；
- `η`：学习率，可被稳态约束调制。

奖励晚到没关系：迹还在。这解决了延迟的一半；另一半靠桥接刺激。

五个作用点，对应不同训练阶段：

| 作用点 | 改什么 | 训练什么 |
|---|---|---|
| 读出阈值 | 输出事件的门槛 | 「先诱导说」 |
| 节点偏置 / 兴奋性 | 基线活动 | 行为频率 |
| 连接权重 | w_ij | 「再诱导说什么」 |
| 增益 / 时间常数 | τ_i | 节奏、持续 / 冲动 |
| 路由 / 注意力 | key/query、fast weights | 情境关注什么 |

**奖励是事件，不是流**：行为主义的强化必须紧跟行为；在连续系统里「行为」是一个事件窗口（说一句话、做一个动作），不是单个 token。长任务用桥接刺激（中性事件反复与最终奖励配对，成为二次强化物）。

**快慢两套**（2026-10-23 重述）：迹（秒级，即时信用分配）→ 巩固（分钟~小时，把这次的激活变成连接的强度）→ 稳定（长期，同一批连接继续被用）。

注意：这三层**不是三个存储**，是同一本体上的三个时间过程。原文写「写入长期 / 权重」两个不同地方——那是两区语言。

**归因靠重跑**：迹只告诉你「谁活跃过」，不告诉你「谁导致了结果」。反事实重跑（改一步、重跑、对比）能精确到步——这是软件环境相对生物的优势。在线用迹，离线用重跑。

### 14.7 教学：情境重建 vs 情境在场

LLM 的教学要求**情境重建**：学习载体是上下文，所以必须把「当时看到什么、为什么这么做、结果如何」全部编码回 context；会话结束，上下文消失，学到的也就没了。每一课都要把世界重新搬进 prompt。

持续状态模型只要求**情境在场**：学习载体是状态和连接，教师的行为改变连接，连接在后续交互里继续被使用、被修改。情境的影响留在状态里，不需要重放。

三个推论：

1. **教师偏差不需要被消除，只需要可修正**。前提三条：可塑性持续、环境反馈持续、竞争写入（§7.4）。三条都有，偏差只是「众多更新中的一次」。
2. **教学可以稀疏、局部、在线**：一个动作、一次纠正、一个结果，不需要完整轨迹。像教练在旁边喊一声，不是写一份教程。
3. **教学发生在情境之中**（学徒制），不是情境之外（课堂教学）。教师不需要设计课程，只需要在正确的环境里做事。

两个边界：

- **「不需要复现情境」≠「不需要情境」**。LLM 要「把情境编码进上下文」，持续状态模型要「情境在当下被感知」——前者是重建，后者是在场。教师必须在场，而且必须在做正确的事。
- **弥散性带来审计问题**：LLM 的教学可审计（上下文里有什么一目了然），持续状态模型的教学是弥散的（哪个连接被改了多少难以追溯）。需要可追溯性——记录教师信号、环境信号、更新量，至少离线可查。

教学的三层（对应三种心理学传统）：

| 层 | 传统 | 训练什么 | 教师角色 |
|---|---|---|---|
| 行为层 | 条件反射（Pavlov / Skinner） | 「说」和「说什么」 | 强化物的安排者 |
| 认知层 | 脚手架 / 最近发展区（Wood, Bruner & Ross；Vygotsky） | 任务分解、示范、逐步撤除 | 脚手架 |
| 元认知层 | 自我决定 / 自我调节 | 自己找任务、判断边界 | 参照 |

**四级放权**（阶段 C 不是放手点，是放权的开始）：

| 级 | 谁定任务 | 谁做 | 谁验证 | 放行判据 |
|---|---|---|---|---|
| A | 教师 | 教师示范，它模仿 | 环境 | 模仿成功率 |
| B | 教师 | 它做 | 环境 | 成功率 + 弯路率 |
| C | 它提，教师批 | 它做 | 环境 | 提案质量 + 修正延迟 |
| D | 它定 | 它做 | 环境 | 知道自己不会 + 能从失败恢复 |

教师的能力边界（哪些能教、哪些不能）：

| 教师提供的 | 可靠性 | 环境能否验证 | 用途 |
|---|---|---|---|
| 任务选择 | 中 | 部分 | 课程 |
| 任务分解 | 高 | 是 | 降低反馈延迟 |
| 示范轨迹 | 中（会犯错） | 是 | 模仿学习 |
| 过程对照 | 中高 | 部分 | 参照层 |
| 纠正 | 中 | 是 | 信用分配 |
| 评价 | **低** | 否 | **不用** |

规则：**教师只做「可被环境验证」的部分**。评价不用，分解和示范用。这样教师的错误会被环境过滤，而不是变成它的真理。

一个现成课程源：**教师自己的会话日志**（任务 + 步骤 + 结果 + 纠正 + 过程指标）。但必须带「依据」而非只带「步骤」，否则学到的是模仿动作，不是判断（因果混淆，causal confusion）。反面案例和正面案例一样重要。

### 14.8 环境反馈的角色：锚，不是训练信号

环境提供两种不同的东西，不能混：

| 环境给的 | 是什么 | 前向信号能吸收吗 |
|---|---|---|
| **结构** | 输入统计：什么和什么一起出现、什么模式反复出现 | ✅ 能（激活频率、一致性、惊讶度） |
| **价值** | 后果：做 A 之后世界变好还是变坏 | ❌ 不能 |

三个内部信号的能力边界：

| 信号 | 能学 | 不能学 |
|---|---|---|
| 激活频率 | 相关结构、表征、模式 | 因果、价值（相关 ≠ 因果） |
| 一致性 / 重建稳定 | 正常模式、压缩、异常检测 | 正确性（可以自洽地错） |
| 惊讶度 | 探索方向、新颖性 | 有用性（惊讶的可能是噪声） |

结论三句：

1. **学习不需要环境，校准需要**。表征、世界模型、模式统计，靠前向信号自组织足够。
2. **环境反馈的频率可以很低，但不能为零**。只在分叉点需要：这个做法对不对、这个方向有没有用、这个因果假设成不成立。
3. **环境的作用是防止漂移，不是提供梯度**。像惯性导航：不需要每秒 GPS，但需要偶尔校准，否则误差累积成「自洽但错误」的轨迹。

为什么不能为零：**一致性可以自洽地错**——封闭的内部系统会把自己的偏差解释成规律，越一致越难纠正。这正是 SOUL 记的幻觉机制。漂移是渐进的，等到发现时已经错了很久。

场景差异：生物 / 机器人环境反馈昂贵，所以依赖内部一致性 + 偶尔外部事件；本机软件环境反馈极便宜（命令 3 秒、测试 10 秒、git 可回退），没理由不用。**不是说必须每步问环境，是问一次很便宜。**

可检验判据：无环境反馈时，系统对**未见过情况**的预测能力是否持续下降？

- 下降 → 需要锚；
- 不下降 → 锚可以更稀疏；
- 下降但被偶尔的锚拉回 → 锚的频率就是「偶尔」的倒数。

对「方向」的修正：**方向 = 结构（自学）+ 价值（环境锚）**。结构每步都在学，价值偶尔校准。

### 14.9 生物侧证据与工程对应

| 工作 | 形态 | 与本讨论的关系 |
|---|---|---|
| FlyWire 2024（Nature 九篇） | 果蝇全脑连接组（139,255 神经元；Shiu 模型用约 12.5 万） | 结构即计算的数据基础 |
| Shiu et al. 2024（Nature） | LIF 全脑模型；网络不训练（权重来自连接组），运动行为预测 ~95% | 证明「连接组 + 极简动力学」可承载行为 |
| Eon Systems 2026（演示） | 接 NeuroMechFly v2 + MuJoCo，15 ms 同步，感知-行动闭环 | 结构 + 身体 → 行为，不需要层 |
| flyGNN（NeurIPS 2025） | 连接组 → 循环消息传递网络 → 运动控制 | 「结构 + 可训练」的中间形态 |
| C-DESN（2024） | 无层的连续深度储备池，按距离连接 | 「深度」可以换成「距离 / 路径」 |
| LNN（Hasani 2021） | 每个神经元是 ODE，19 个神经元开车 | 「节点是动力系统」的工程化 |
| COLA（ICML 2026） | 临界态局部规则 ≈ BPTT | 局部规则可以逼近反传 |
| NALSM（2021） | 星形胶质细胞调制 STDP 到临界态 | 临界态是自组织的可计算状态 |
| DeepSoma（2026，报道） | 树突 / 离子通道级精细神经元 | 单细胞复杂度这条线的对照 |

赛博果蝇的细节佐证：第三方复现（`erojasoficial-byte/fly-brain`，**非 Eon 官方**）的 LIF 用 **0.2 ms 步长**；Eon 官方演示的报道里，脑-身同步间隔是 **15 ms**。两个数字来源不同（一个第三方仓库参数、一个新闻报道），不能当成同一套配置；但它们都表明实现是固定频率的。而表观行为是异步的——信号在 13.9 万节点的图里传播，不同通路到达时间不同。这说明「固定频率 + 稀疏图 + 延迟」已经足够产生异步的表观行为；真连续时间不是必需。

一个边界：赛博果蝇证明的是「结构能免费给出行为」，不是「结构能给出通用智能」。它的 LIF 高度简化、脑-身接口人工挑选、行为种类有限、没有学习。它只保留了拓扑这一维（稀疏图 + 路径），把时间形态、局部可塑、单细胞复杂度都压掉了。

### 14.10 记忆载体：嵌在网络里的表（已降级）

> **2026-10-23 降级：** 本节假设「记忆是一个可以挑载体的东西」。若长期记忆就是连接（§2.10），那它没有载体可选——本节保留作「若分家必要，可能的形态」，但不再是设计前提。下面的三载体表同理。

**先说一个术语撞车。** §12.5 里并列着两个 engram，它们同名不同物：

- **生物的 engram**：一群神经元在特定条件下被同时激活的模式。没有地址，内容就是那组细胞的连接强度，分布在一整片网络里。
- **DeepSeek 的 Engram**：哈希表的条目，按 token n-gram 取出一行向量。

两者的冲突是真实的，但不是措辞问题。

**谱系。** 差别不是「存还是算」，是表示方式在谱系上的位置：

```
全连接分布式          稀疏编码            离散可寻址表
（每个概念用所有维度）（少数单元，共享网络）（独立行，不共享地址）
      ^                   ^                     ^
   纯权重网络          MoE / top-k          Engram / 哈希表
```

三端的性质互补：

| | 容量 | 检索 | 泛化 | 写入干扰 |
|---|---|---|---|---|
| 分布式 | 靠叠加，受维度限制 | 内容寻址，会混淆 | 强 | 重 |
| 稀疏编码 | 中 | 中 | 中 | 中 |
| 离散表 | 无限加行 | 精确 O(1) | 无 | 无 |

**分布式不是一种技术选择，而是「用有限维度表示无限概念」的唯一办法（叠加编码）。** 离散表不共享维度，所以能无限加行，代价是不带相似性。

**生物也没有走纯分布式。** 语义记忆在皮层（分布式）；情景记忆在海马（稀疏编码——少数细胞强烈响应）；程序记忆在基底节 / 小脑（分布式）；工作记忆在前额叶（持续活动）。**稀疏编码是「离散在网络内的版本」：少数单元表示一个概念，但共享连接。**

**判断标准：检索需求决定表示形式。**

> 要「精确取回」的用离散；要「按相似性检索」的用分布式。

| 内容 | 检索方式 | 表示 |
|---|---|---|
| 专名、固定搭配 | 给我那个确切的东西 | 离散 |
| 事实（谁 / 何时 / 何地） | 给我那个确切的事实 | 离散（或稀疏） |
| 技能、策略（这种情况怎么办） | 找类似的情境 | 分布式 |
| 语法、规律 | 泛化到没见过的句子 | 分布式 |
| 工作记忆（刚才说了什么） | 精确回溯，且要能撤销 | 离散 |

这与 §6.3 的「模式统计 vs 决策模式」是同一个区分换了个角度：**决策模式天然需要情境相似，所以必须分布式；模式统计天然需要精确命中，所以可以离散。**

**嵌表形态：不是「表在旁边 + 门控注入」，是「表在网络里」。**

Engram 的做法是：在指定层插一个模块，key 由 token n-gram 算出（人定），融合方式是加性残差（人定），层位置是人选的。表参与了前向，但用法是人设计的。

按 §9.1 的原则（能涌现的不设计），可以再退一步：

| 项 | Engram | 嵌表形态 |
|---|---|---|
| 表的位置 | 人指定层 | 网络结构的一部分（一个模块） |
| key | token n-gram（字面） | 可学（query 由 hidden state 给出） |
| 融合方式 | 加性 + 门控（人定） | 可学 |
| 用法（何时读、怎么用） | 门控决定用不用 | 自己决定 |

**代价要说清：key 一旦从「token n-gram」换成「学出来的 query」，就失去 O(1) 精确查表的两个工程好处——确定性寻址（可 offload 到主机内存）与可预取（索引在 forward 之前就能算出）。** 变成近似最近邻检索后，复杂度是 O(log n) 或 O(k)，且不能预取。

所以实际最优可能是**混合 key**：token n-gram 给出「便宜的先验索引」（O(1)、可预取、可 offload），learned query 给出「语义修正」（按情境调整），两者融合后决定读哪几行。这保留了工程优势，又把「怎么用」交给训练。

**分工：三时间尺度三载体。**（2026-10-23：本图所在整节已降级——长期记忆不是「表」，就是连接。见 §2.10。）

| 尺度 | 内容 | 载体 | 检索 | 能否撤销 |
|---|---|---|---|---|
| 秒~分 | 工作记忆、刚才说了什么 | 激活状态 / 小可写表 | 精确 | 能（丢弃） |
| 时~天 | 情景记忆、这次遇到的情况 | 可写表（稀疏改写） | 精确 | 能（保留旧行） |
| 永久 | 技能、语义、规律 | 权重（分布式） | 相似 | 不能 |

**巩固 = 从离散到分布式的转化**：「我昨天遇到 X，先查了文档再动手」→「遇到不熟的 API 要先查文档」。前者是离散条目，后者是分布式策略。

这里的分区依据是「能否撤销」，不是「能否审计」。**撤销需要定位到具体条目，所以要求写入是离散、有地址的；一旦融进权重就不可撤销——这是它的性质，不是缺陷。** 不需要「打开它脑子看」：智能体自己判断「这条我改不了」靠的是过程（§4），不是外部观察者能读懂每个参数。

**一个没解决的问题：分布式的长期记忆，持续写入仍会干扰。**

LSL 是目前最好的答案，但它解决的是「给某一类输入加补丁」，不是「记住一个事实」；代价明确——adapter 不能合并回权重，推理时间随阶段数 P 线性增长。所以「记忆自然散落在网络里」这条路，在容量上还没被证明能持续：小规模、少阶段能行，几百个阶段、上亿条内容没有验证过。

**稀疏改写的五种形态。**

表既然可写，就要定怎么写。全量重建等于把灾难性遗忘做到极致（一次动全部行，所有行互相干扰），所以必须稀疏：

| 形态 | 写法 | 优点 | 代价 |
|---|---|---|---|
| 单行替换 | `T[k] = new` | 最简单 | 覆盖旧内容 |
| 增量累加 | `T[k] += delta` | 保留旧证据 | 会饱和 / 漂移 |
| 指数混合 | `T[k] = (1-a)*old + a*new` | 平滑 | a 需要判据 |
| 多版本行 | `T[k] = [v1, v2, ...]` | 同 key 多用法 | 失去 O(1) |
| **两表 + 增量合并** | 基础表只读 + 增量表可写 | **大容量与可写分开** | 需要巩固 |

倾向两表 + 增量合并：长期表大、只读、可 offload；短期表小、可写、住显存；巩固把反复出现且被确认的条目合并进长期表。这正是 §2.5 倾向的「两张表」，而且给出了巩固的具体机制。

**稀疏改写的局部性是结构自带的。**

| | 怎么写 | 怎么知道该改哪 |
|---|---|---|
| LSL adapter | 反传学出权重 | 要学一个 GMM 去估计「哪些输入属于这个更新」 |
| 可写表 | 改某几行 | key 直接告诉你改哪——哈希算出来就是它 |

LSL 花了一整套机制（GMM、负样本分布、时序平滑、13.8 MB 内存）才换来「局部」；可写表天生局部，因为写入地址是算出来的，不是学出来的。**所以写入的局部性由 key 保证，门控只管「读出来的能不能用」——两件事分开。**

**稀疏改写引入三个新问题。**

1. **写时碰撞比读时碰撞严重。** 读时碰撞只是噪声（门控能抑制）；写时碰撞是无声损坏（改错别人的行，而且没人知道）。需要写前校验：key 校验位，或读旧行算相似度，差太远就拒绝。
2. **多义：一个 key 一行装不下。** 同一 n-gram 在不同语境含义不同；加长 n-gram 能提高特指性，但频率反比于长度。可能只对高频多义 key 开多版本，其余保持单行（O(1) 在大多数 key 上仍成立）。
3. **写入判据没变简单。** 「写哪里」由 key 解决了，「该不该写」没有——仍然要 §7.1 的三闸。而且门槛低 = 写太多，表会被低质量条目填满，且因为稀疏很难察觉整体质量在下降。所以在可写表上「竞争写入」（§7.4 第 2 条）比在只读表上更重要。

**载体不同，「稀疏」含义不同。**

| 载体 | 改一行的后果 | 是否真稀疏 |
|---|---|---|
| 哈希表 | 只影响这个 key 的所有出现 | 真稀疏 |
| 向量库 | 该行与所有 query 的相似度都变了 | 伪稀疏 |

向量空间是相对的：改一个向量，它与其他向量的距离全变。所以向量库的「稀疏改写」要靠底层索引的性质——ANN（HNSW / IVF）需要局部重建索引，暴力余弦则改一行就是改一行。

## 15. 与 SNN 领域的关系（2026-10-23 第三次修正）

> 本节回答一个把草案打回原点的问题：「这不就是个 SNN？」
>
> 答案是：**机制清单上逐条对应，而且已有 20 年积累；但草案要的那一支，恰好是 SNN 主流（BPTT + 固定 T + 按样本重置）在工程上排除掉的那一支。** 所以既不是重复劳动，也不是新发明——是「在 SNN 的地盘上做一件它的工程范式不允许做的事」。
>
> 本节分四件写：已有答案的、被外部证据修正的、真空在哪、对草案的直接后果。依据见 §12.10。

### 15.1 定位：机制清单逐条对应的术语

| 草案里的说法 | 该领域的标准术语 | 起始时间 |

### 15.3 被外部证据修正的三条

前两轮推出的结论里，有三条站不住：一条要收窄（τ）、一条漏了代价（异质性）、一条漏了实现成本（算力）。

#### ① 「τ 不可设计」要收窄为「逐单元连续铺开不可设计」

§2.2 现在写「τ 不可设计」。外部证据给出的更准的说法是四档：

| 做法 | 结论 | 证据 |
|---|---|---|
| 以**单元**为单位连续铺开 τ | **无效**（强递归下被抹平） | S4D 消融（实部谱降 5.45 / 10.17）；Stern eLife 2023 |
| **单峰宽分布**直接混在一起 | **无效甚至更差** | LSRSNN 原文 |
| 按**组**分离成双峰 + 专门算法 | **有效** | LSRSNN（工作记忆 + 语音） |
| **每层**共享一个可学习 τ | **有效** | PLIF（ICCV 2021） |

所以准确表述是：**τ 不能逐单元连续设计，但可以按组分离或按层共享。** 而「按组分离」正好就是 §2.2 那三件可设计事项里的「分区」——草案其实已经隐含了，但没把这个具体形态写出来，而它恰恰是**唯一有正面证据的形态**。

#### ② 「结构异质性有好处」不能写成无条件命题

| 证据 | 结论 |
|---|---|
| PNAS 121(3) 2024（Neural heterogeneity controls computations in SNN） | **同质网络的工作记忆容量更大**；异质网络的函数生成能力更强。是**权衡**，不是单调改进 |
| J Neurosci 2013 | 异质性降低活动 bump 的扩散，但**限制可存储的稳定状态数**——存在一个**最优异质度** |
| Stern eLife 2023 | 同一件事的另一条机制路径 |

§2.2 把「结构异质性」列为可设计的三件之一，方向没错，**但没写它有代价**。§11.4 阶段 A 如果用「有记忆」当适应度，演化会自己找到权衡点——这一点设计是对的；但判据里若只写「记忆长度 + 区分度」，会偏向同质。**要加一条反向观测：异质度与容量的权衡点落在哪。**

#### ③ SNN 的「省算力」在 GPU / CPU 上是假的

| 事实 | 数字 | 出处 |
|---|---|---|
| 同规模生成吞吐 | SNN **22.8** vs transformer **91.5** tok/s（慢 4 倍） | SymbolicLight V1 |
| 同规模每 token 能耗 | **2848** vs **905** mJ/token（高 3 倍） | 同上 |
| 综述结论 | 能耗优势**只在 event-driven 神经形态硬件上成立**，GPU 模拟的 SNN 不成立 | IEEE 综述 2026 |

**对 §11.4 的直接后果：** 草案写「总成本本机 CPU 小时级」——如果按稠密矩阵实现，这个估计可能差一个数量级；只有真按事件驱动稀疏模拟才成立。**阶段 A 的种群评估与阶段 B 的长步数模拟，要先把模拟器的实现形态定下来（稠密 vs 事件驱动），否则成本估计是假的。**

### 15.4 语言能力边界（这是「transformer 等级」这个问题的答案）

必须分两类，混着看会得出错误结论。

| 类别 | 规模上限 | 最好成绩 | 对照 |
|---|---|---|---|
| **原生训练（from scratch）** | **1.5B**（TTFS-GPT-2）；0.9B（NeuronSpark，预印本） | WikiText-103 **30.03 PPL**（SAPU-LM 78M，预印本）/ 33.94（SpikingSSM 75M）/ 39.75（SpikeGPT 216M）；GLUE **76.5**（SpikeLM）/ **84.17**（Otters++） | GPT-2 Small 124M = **29.41**；GPT-2 Medium 345M = 26.37；BERT_base GLUE = **83.2** |
| **转换 / 量化（ANN->SNN）** | 66B（LAS）/ 76B（SpikingBrain）；SpikeLLM 7~70B | 「loss-less」（LAS）；SpikingBrain「与开源 Transformer 基线可比」 | **能力是借来的**：把已训好的权重压成脉冲执行，不是脉冲训练长出来的 |

**结论：**

1. **原生 SNN 已经到「小规模 transformer 的 90%~95%」**（综述原话：在 GLUE / SuperGLUE 上约达非脉冲对应物的 85%~95%），**在几个单点基准上追平或略超 GPT-2 Small / BERT_base**。
2. **离当代 LLM 差一个代际**，而且没有任何指令跟随 / 多步推理 / 工具使用的公开评测——**「没找到证据」不等于「做不到」，但确实说明这个领域还没走到那一步。**
3. **转换路径能「无损」，但那是借来的能力**：它证明的是「脉冲硬件可以无损执行 ANN 的计算」，不是「脉冲训练能长出 ANN 的能力」。

#### 任务上界 vs 存在上界（2026-10-23 拍板「persona 不设定」后的必读）

上文的「1.5B / GPT-2 Small 级」是**任务上界**，不是**存在上界**。两个必须分开，否则会把「benchmark 打不过」误读成「这个方向有天花板」。

| | 任务上界 | 存在上界 |
|---|---|---|
| 定义 | 给定 benchmark 上的最好成绩 | 能不能持续存在、持续变强（A + D） |
| 谁给 | 数据集 + 指标 + 非脉冲对照 | 反馈是否持续、可塑性是否还在、结构是否还在长 |
| 现成数字 | 原生 SNN 到 GPT-2 Small / BERT_base 级；0.16 nats 固定代价 | **没有数字**——§4 的过程四度量就是为此设计的 |
| 会不会被「达到」 | 会（同规模 transformer 已达到） | 只有「还在不在」——没有「到顶」这个状态 |

**为什么这个区分在「persona 不设定」之后变得必要：** 若目标不是「完成任务的网络」，那「任务分布」这个框架本身就不适用——它没有一组固定任务可以定义上界。这时能问的只剩 §4 的四条过程量与 §2.9 的自我判据。

**但要说清楚：这不取消 0.16 nats。** 那个数字约束的是「用脉冲表达语言」这一件事——它仍然是它，只是不再是这个系统的总上限：

> **0.16 nats 限制「它把话说得多准」；不限制「它能不能持续变强」。**

#### 三条机制证据：为什么不是「再等等就行」

| 证据 | 内容 | 含义 |
|---|---|---|
| **固定代价** | 首个 Chinchilla 式 IsoFLOP 研究：损失差 = **backbone 0.16 nats（不随算力变）** + **spiking 0.34->0.23 nats（随算力降但不到 0）**；N_opt ∝ C^0.56（稠密 0.50） | 0.16 nats 换算成 PPL 约 **1.17 倍**——**哪怕算力无限也追不平的部分** |
| **表达上界** | Scientific Reports 2024 原文：「不可微的**二值激活在准确率上被连续饱和激活所上界**；而后者又远远落后于深度 SSM 里的非饱和激活」 | 这是表达能力层面的，不是训练技巧；他们的解法 GSU 其实就是**放弃纯二值** |
| **规模上限** | 综述：**最大 SLM 仍在 1B 参数以下**（典型 BERT-base 110M）；SGL 训练需常规反传的 **2~10 倍**计算；T 步展开带来额外内存 | 深而宽时近似误差累积 |

### 15.5 三个维度的现状（连续状态 / 训练方式 / 单向）

这三个问题决定了阶段 B 到底是不是新的，所以分开量。每一条的结论都一样：**主流做法与阶段 B 的前提相反。**

#### 维度一：连续内部状态——有，但只是「序列内连续」

| 层 | 状态怎么处理 | 证据 |
|---|---|---|
| **绝大多数** | T 步展开，**每个样本结束清零** | Burst-CCN 原文：「Neuronal state variables **and eligibility traces are reset to zero at the end of each sample presentation**」 |
| 同上，视觉流任务 | **每帧重置**是默认做法，改掉它本身成了一篇 CVPR 论文的贡献 | VISTREAM（CVPR 2025）：现有方法「leading to their **reset-per-frame**」 |
| **少数（SSM / linear-attention 系）** | 有跨 token 的递归状态（SpikingSSM 的 S4D、SpikeGPT 的 RWKV 状态、SpikingBrain 的 linear attention、SAPU 的多 τ reservoir） | SpikingBrain 4M token 上下文 |
| 同上但要注意 | **那个状态是 SSM 的状态，不是脉冲动力学的状态**；SpikingSSM 自己说 spiking 是「a **quantization layer on top**」 | 同上 |
| **几乎没有** | 永不重置。接近的两条：① Taeckens & Shah（J Neural Eng 2024）的内存恒定在线 SNN（但只是 BMI 回归小网络）② VISTREAM 的 LoCC-SNN（跨帧保留历史） | 两者都是专用 decoder |

**关键区分：SNN 说的「连续状态」是「一条序列内不清空」，不是「一个东西一直在活」。** 序列结束、batch 结束、请求结束，状态就没了。

#### 维度二：训练方式——主流就是梯度 + BPTT

最直接的一句（DelRec 2025）：**「Currently, all state-of-the-art spiking approaches on these benchmarks rely on surrogate gradient learning (SGL)」**。

| 学习规则 | 用梯度吗 | 要存时间链 | 能持续在线 | 代表 |
|---|---|---|---|---|
| **BPTT + surrogate gradient** | 是（完整反向） | **是**（O(LxT)） | **否**（要暂停才能反传） | 几乎所有 SOTA |
| **ANN->SNN 转换** | 在 ANN 上算 | 在 ANN 上 | 否 | SpikeLLM / SpikingBrain / LAS |
| **局部学习（Decolle 式）** | 是（每层局部梯度） | 否（O(1)） | **是** | Taeckens BMI（内存降 92%） |
| **e-prop** | 是（迹近似梯度） | 否（O(1)） | **是** | Bellec 2020 |
| **三因子调制** | **否**（标量 m 调制） | 否 | **是** | braintrace `'three_factor'` |
| STDP / Hebbian | 否 | 否 | 是 | Diehl & Cook 等 |
| 演化 | 否 | 否 | 否（代际） | ELSM / NeuEvo 的结构部分 |
| 纯稳态（无学习） | 否 | 否 | 是 | SOqC 网络 |

**要纠正一个常见混淆：「不用反向传播」不等于「不用梯度」。** 局部学习和 e-prop 都是**梯度类**，只是不用 BPTT、不存整条时间链。真正无梯度的只有演化、STDP、纯三因子调制。

#### 维度三：是不是单向的——默认是

SpNCN（arXiv 1908.08655）开场一句：**「unlike in standard spiking neural networks, which are typically designed to be feedforward in nature」**。

- **主流**：层堆叠 + 前馈。即使块内有递归（RWKV / SSM / 自循环），也是**层内递归**，不是**跨层反馈**。
- **有跨层反馈的只有几支**：预测编码 SNN（SpNCN、PLOS CB 2025 的多房室模型）、Burstprop（soma 上行 / dendrite burst 下行双通道）、LISR（自循环 + 侧抑制）、CH-HNN（皮层-海马双向）、NeuEvo（反馈抑制 / 侧抑制）。**这些全是分支，不是主线。**

### 15.6 两个阶段的重划

本轮搜证把 §11.4 的两个阶段拉成了一高一低：阶段 A 是在已有赛道上重跑，阶段 B 才是真正空着的。

#### 阶段 A 应该降级

理由三条：

1. **它不是新实验**——是 neuroevolution of SNN，2012 年起有连续工作；ELSM、NeuEvo、WANN-Spiking、CortexZero 都在这条线上。
2. **结论基本可预期**——ELSM 已经把「小世界 + 临界 + hub / 长尾度分布」跑出来了；再跑一遍只能复现。
3. **它有一处自己的缺陷（§15.2）**：基因里的「τ 分布」与实测的 τ_d 不是同一个量（§2.2：单细胞 τ 会被强递归抹平）。**只记录基因型、却从行为读结果，会让「收敛到广谱」有两种相反解释**——「选择偏好广谱基因」或「给了也白给」。

**建议改为：** 「复用 ELSM 的演化设置 + 只补我们需要的那个观测（每个存活个体的**实测 τ_d 分布**，而不只是基因型）」。算力全部让给阶段 B。

#### 阶段 B 才是真空

| 草案 §11.4 阶段 B 要求 | SNN 主流 | 是否冲突 |
|---|---|---|
| 一条永不重置的时间轴 | 每样本 / 每帧重置 | **直接冲突** |
| 不开学习也要有状态 | BPTT 必须有固定 T 窗口 | **直接冲突** |
| 无任务、无 episode、无准确率 | 全部有任务 + 准确率 | **直接冲突** |

而且这三条是**互相锁死**的：

```
要 BPTT  ->  必须有有限的展开窗口 T
         ->  所以必须按样本重置状态（否则没法算梯度）
         ->  所以必须有「一个样本 + 一个标签」
         ->  所以必须有任务和准确率
```

反过来：

```
要「永不重置」  ->  没有 T，BPTT 不可用
                ->  只剩：局部规则 / e-prop / 三因子 / 演化 / 稳态
```

**这就是为什么 SNN 领域没人做阶段 B——不是没想到，是被 BPTT 锁死了。** 这不是「研究不足」，是「设计前提互斥」。

### 15.7 对草案的直接后果（四条）

四条都是「改了这一处，别处也动」的连带项，不是新增设计。

#### ① 阶段 B 提为唯一第一优先；阶段 A 降为「复用 + 补测」

已在 §11.1 / §11.4 体现。

#### ② S1 从「待定项」变成「唯一剩下的设计选择」

一旦放弃 BPTT（阶段 B 的前提），可塑性规则的**可选集被压缩到五种**：

| 候选 | 在线 | 内存 | 有信用分配吗 | 备注 |
|---|---|---|---|---|
| **e-prop** | 是 | O(1) | 有（近似梯度） | 有理论 + 有现成库；**最接近「能用」** |
| 局部学习（Decolle） | 是 | O(1) | 有（每层局部） | 需要每层有目标——与「无任务」冲突 |
| 三因子调制 | 是 | O(1) | **弱**（只有一个标量 m） | 最干净，但归因能力最弱 |
| 演化 | 否（代际） | — | 无 | 只能调结构 / 规则，不能在线学 |
| 稳态 + Hebbian | 是 | O(1) | 无 | SOqC 证明了能自组织，但不学任务 |

**按草案自己的判据（无任务、无 episode、要能测「挤占」），e-prop 是唯一同时满足「在线 + O(1) + 有信用分配」的候选；三因子是最「干净」但归因最弱的。** 这两个可以做成组 1 与组 4 的对照。

#### ③ e-prop / braintrace 不需要重新发明

§14.6 的三因子（迹 -> 巩固 -> 稳定）与 §7.3 的三因子规则，第一层已经被 e-prop 做完并且工程化了。**自己写一套没有意义——要么直接用，要么说明为什么不用。**

#### ④ 本体与语言：已定「共用」——只有一个完整个体

原写「三选一，未评估」。**2026-10-23 拍板：共用。**

| 原选项 | 结论 |
|---|---|
| A. 本体管自我，语言外包 | **否**——语言能力就不在自我里；§2.9 的「自我」与 §6 的「策略」之间会留下一个没人负责的缺口 |
| B. 本体自己长出语言 | **是**——但这是一个**要付代价的决策**，不是免费的选项 |
| C. 跨形态分阶段 | 否——它沿用 A 的假设（阶段 1 语言在外部），且多一次跨形态迁移 |

##### 代价（必须写明白：不是「选一个」，是「接受一个」）

1. **语言能力受 SNN 上限约束**：原生 SNN 目前最好到 GPT-2 Small / BERT_base 级（§15.4），且有一个**不随规模消失的 0.16 nats 固定代价**（约 1.17 倍 PPL）。
2. **阶段 1 不能外挂预训练 transformer 底座** → M8 收敛到「从零」。
3. **「脉冲化的块扩散」没有先例**：块扩散（SDAR / Eso-LMs）是 transformer 家族，SNN 侧只有「SSM + 脉冲量化层」（SpikingSSM）。两者的交集 15 轮检索未找到直接工作。M1 因此多一个候选并标风险。
4. **Pando 不是这个个体的雏形**：DeepSeek 权重冻结、记忆在外部文件 → 它不能承载累积修改（§2.9）。在「只有一个完整个体」的前提下，Pando 的定位是**环境 / 工具 / 教师**，不是早期版本。这条要写清，否则会有「渐进演化」的错觉。

##### 两个派生结论（自洽性检查的收获）

**① 「说话」不是一次前向，是持续状态上发出的事件。**

如果只有一个完整个体，而它的状态永不重置（阶段 B 的前提），那语言就不能是「独立的推理周期」——它只能是持续状态上偶尔发出的一个输出动作。

这反过来把三条「倾向」变成了「必须」：

| 章 | 原状态 | 共用决策后 |
|---|---|---|
| §10.8 N5 输出粒度 | 倾向事件 | **必须事件** |
| §14.6 奖励粒度 | 奖励是事件，不是流 | **必须事件**（与输出同粒度） |
| §10.8 N2 时间形态 | 倾向固定 tick | 固定 tick 作为**仿真步长**保留，但「一轮」不再是时间单位 |

**② per-step 注入的 persona 与「只有一个完整个体」不相容。**

每步注入等于承认「有一个外部条件在塑造它」——那它就是「本体 + 外部条件」两件，不是一个个。**persona 不设定（已定）**——不是早期教师后撤掉，是从一开始就不给；理由与两个后果见 §2.9 拍板段。

### 15.8 一句话

> **这不是一个新架构，是一个「SNN 主流不允许做」的实验设计。**
> 已有的一半（结构演化、多尺度分群、稳态自组织、e-prop）直接用；
> 被修正的两条（τ 的收窄、异质性的代价）改口径；
> 剩下真正空着的一条：一个**永不清空、无任务、无准确率**的持续状态，会不会自己形成结构。
