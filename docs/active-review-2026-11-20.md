# 让连续状态的图主动复习

本轮最清楚的结果出现在短局和长局里。如果提示的含义固定，一个只有四个可训练系数的选路读出，可以从实际走过的路线学会何时值得牺牲眼前收益去了解未知对象。每条生命重新分配提示的含义，旧策略就失效了。让图继续自由写入也会损坏它原本用于辨认候选的运动反应。下面区分跨生命训练习得的策略、单条生命里真正建立的关联，以及每次写入对旧内容造成的影响。

上一轮观察到一个可利用的信号。给外部调度器读取图对每个对象正反摆向的运动反应，让它从四个对象中选择最犹豫的一项真实复习，能提高随后四项都答对的概率。这一轮让身体自己作复习动作，再检查它选中的对象究竟带来什么。原组为 731–736，另一组为独立初始化和训练的 811–816。每个身体内部有 20 个带泄漏的循环节点，真实接触可以改变权重、偏置及有向接线。部署时关闭外层优化器。[上一轮的完整比较](interleaved-learning-2026-11-20.md) · [本轮总方案](evidence/active-review-20261120/plan.json)

## 一次真实复习该记哪一笔账

同一生命学四个对象之后，从其末态给所有选择器相同的感官预览。只允许再真实接触一个对象，先记下选侧后尝到的味觉，再从同一接触后的状态分别问四道题。在两批均匀回访专家上，最低置信比随机复习的实际四项全对率分别高 **2.79 和 4.38 个百分点**。改为八个对象，这一差距都不到 1 点，区间跨零。对四个对象，置信度判断“当前容易答错”的秩相关约为 0.57，和“这次写入有利于四项一起答对”的秩相关仅约 0.08。对象之间会共享被修改的连接。

这两种收益在同一次动作中甚至可以方向相反。如果复习当场取得正味和后面均匀抽一道题答对各计一分，选择最犹豫项的总分比随机分别**低 0.112 和 0.104 分**。复习一个还答不准的对象，可能让后测更好，当下却更容易选错食物。两对象只相差 15° 且价值相反时，一次写入让目标本身提高约 33 点，同时使另一个对象下降约 39 点。后文分别报告当场收益、后测和联合行为。[共同预览、机会配平和距离控制](evidence/active-review-20261120/value.md)

## 原生身体选择复习对象

身体依次学完四个私有气味，环境给出已见过的两个候选。短暂的公共模式提示后，身体用原有左右运动端口选侧，再去所选对象真正采集一次并取得味觉。所有训练收益来自实际取得的终末资源。对照分别使用随机选侧和原始身体在独立只读分叉上的不确定性。几种方法得到相同数量的复习机会；外部不确定性额外读取了候选摆向。每四次外层更新保留一次普通短生命训练。主终点为 16,000 次更新，留出数据每个出生有 384 个几何并交叉互补私有赋值。[训练协议](evidence/active-review-20261120/noon-review-protocol.md)

原生图四道题的平均实际正确率是 83.81% / 83.52%，四项全对为 50.59% / 48.61%。把同一具身体的复习动作换成随机选择，原生减随机的平均正确率差是 +0.03 / −0.33 点，合并两批的配对差为 **−0.15 [−0.51, +0.21] 点**。和接受相同预算但由随机策略分配复习的身体相比，原生组也没有可靠优势。两侧在普通采集语义中恰好一个有利、一个不利时，它约 85% 趋向有利的一侧。两侧气味都翻成相反摆向，约八成这类动作会换侧，而把这样的动作移植回原生命并没有稳定改善后测。过去的味觉确实影响了它选择哪边，直接使用旧采集动作还不足以让选择瞄准有价值的复习。[训练终点、原生决策与真实后果](evidence/active-review-20261120/noon-review-core-results.md)

## 只靠自己走过的路线，能否学会为未来付眼前的代价

每条生命有两个候选，一个以前真正尝到过，另一个看过却没尝到。当场再次采集可以得或失一单位资源。短局到此结束，长局再实际问四题，因此复习未知项可能在以后回本。一个公开感觉脉冲提示当前是哪种局。身体依次真实预览候选，每个五拍。新增四系数读出使用截距、两个候选原生运动反应强弱之差、身体对期限提示的感觉反应、两者的乘积，只用来改变选侧。一个训练生命只按当时的策略走一次，只用这一路后来实际收到的资源更新系数。跨生命训练固定原有身体，生命内的图、活动和写入继续正常工作。

**换掉提示含义是另一道题。** 每生先真实经历一短一长两个校准局，随机规定哪种提示对应长局，然后用相同结构、先前经双路线教学的四系数版本作答。这项换义测试使用它自己封存的检查点。此时两套新世界中，真实长局减短局选择未知项的差为 −0.09 / +0.01 个百分点。给身体接两个显式关联格，由各提示在刚结束的校准局实际出现的后续机会更新，开放正常图写入时，这个差为 +9.98 / +10.67 点。固定当前身体，只把这两格换成反义履历的值，自己的关联格多得 0.173 / 0.182 单位资源。两个格和更新方法由实验提供。校准期开放原生图写入还使候选预览辨认未尝对象的比例从约 84% 降至 54% / 55%，而身体对提示脉冲本身的感觉响应变化很小。这给出了学习新关联与保住已有读数之间的具体冲突。[提示换义及只交换两格的干预](evidence/active-review-20261120/noon-review-cue-association-results.md)

## 估计自己会不会错，与采取有收益的行动

给同一身体增加候选预览和 17 个可训练的选路系数，按单条实际经验训练后移到独立六个身体，四题全对率相对随机复习高 1.05 [0.55, 1.52] 个百分点。当次真正采到正味的概率却低 5.38 点。移到六轮连续复习时，整生净资源比随机低 0.414 / 0.346。把每次复习自己的即时得失加入续训目标，比只算随后得失多收 0.373 [0.255, 0.492] 单位，和随机复习的差为 −0.010 [−0.151, 0.133]。一次后测能观察到的收益，可以被积累的行动成本抵消。[单次收益与预览](evidence/active-review-20261120/learned-readouts.md) · [六轮真实行动与支出](evidence/active-review-20261120/noon-review-repeated-results.md)

另一个五系数读出预测身体已经作出的普通选侧能否成功。用本人这一动作的实际结算训练后，独立六个身体平均报 82.66%，实测 81.98%，Brier 误差 0.110。只用最后复习收益，它们报 26.63%，误差 0.614，两组的四项全对率却同样比随机高约 0.87 个百分点。把全部预测取补数、同时反转选路对预测差的依赖，可逐个保持每次选侧。由此能区分“动作表现不错”和“内部数值确实表达我这次有多可能做对”。把已训练的选择信号注入原生运动节点、随后逐渐撤掉，裸图在两批的四项全对率相对其同体随机仅 +0.15 / +0.09 点，区间都跨零。[校准和等价变换](evidence/active-review-20261120/learned-readouts.md) · [原组六千步](evidence/active-review-20261120/feedback-original-6000.json) · [独立组](evidence/active-review-20261120/feedback-independent-6000.json)

## 补查是否值得花钱，旧经验能保留多久

在只有一次购买机会时，可从六个方向共激活量、公开价格与一个四系数读出学习是否买可靠味觉。只按真正走过的路线收支训练，三次拟合在原身体及六个新身体上，每生净资源比另库校准的纯票价策略分别多 0.0090 [0.0048, 0.0132] / 0.0115 [0.0073, 0.0152]。模型每次仅选择购买或跳过，终局正确和花费均由采集真正结算。六个记忆量及其连接方式是实验提供的接口。[短局、侧向绑定和压力测试](evidence/active-review-20261120/paid-information.md)

同一个读出放进 32 次连续购票和收获的生命，到最后仍能比只看价格多挣资源。延迟味觉时它平均买 6.57 次，即时味觉时买 2.74 次，价格读出两种情况均买 11.97 次。保留每条生命的购票数量、价格和阶段再打乱购买时机，它比重排分别高 0.033 [−0.080, 0.148] / 0.078 [−0.010, 0.162] 单位，和只记录味觉总量的读出也没有稳定差距。这个长生命验证完成了预定首个读出训练种子在两批身体上的部署。另有普通 A/B 回访退步的定位，两批在专门训练原生购票策略后，普通 A、B 全对率均低了约 6.15 个百分点。[32 次真实收支](evidence/active-review-20261120/transfer-resource-readout.md) · [固定旧动作和回执重放](evidence/active-review-20261120/transfer-scorecard-ticket-coverage.md)

## 看见冲突以后，补查与写入是两个动作

**补查。** 让同一个对象真正反馈两次，每次 20% 概率报反，再决定是否付钱取得可靠反馈。每条生命遇见该对象的次数完全相同。给原生图开放一个局部系数，调节“刚收到的味觉与刚才的运动倾向是否相符”对六个感觉痕迹的影响。双侧输入组在另一批全新世界中，前两次反馈矛盾时的购买率比一致时高 **19.80 / 19.89 个百分点**。实际资源减去费用，相对同预算只计次数的组每生多 0.0096 [0.0064, 0.0130] / 0.0059 [0.0009, 0.0103]。保持图的其他部分不动、只在临场移除这项修正，两批都少赚资源。把这个痕迹只接到购票一侧的亲本中，两批在相同接触数下的冲突减一致购买率为 26.94 / 26.11 点，相对各自同起点只计次数的净收益为 +0.0071 / +0.0058。两种接线继承的亲本不同，布局间差距不能单独归于接线位置。局部统计量和读入位置是我们给的，系数通过真实行动收益学得。换成完全相同的可见历史、却相反的隐藏真值，两条购票动作必须一致，评估逐条验证了这一点。[预先登记](evidence/active-review-20261120/receipt-agreement-plan.json) · [原组复测](evidence/active-review-20261120/agreement-bilateral-confirmed-original-12000.json) · [独立组复测](evidence/active-review-20261120/agreement-bilateral-confirmed-independent-12000.json)

**写入。** 实际复习 A 或 B 并尝到味觉后，增加一个提交开关，让相同的图可以运行或跳过这次权重、偏置及接线更新。复习对象在四分之一的世界中刚改变了奖惩，身体没有收到反转标签。用味觉和先前运动倾向驱动开关，在独立世界复测中两批分别写了 59.66% / 50.97% 的机会。只看奖惩确实反转的生命，它们写了 96.86% / 94.44%；奖惩保持时只写了 47.26% / 36.48%。与同一身体按同样比例随机写相比，后续两题连续全对高 **7.16 [3.75, 10.04] / 8.39 [4.62, 11.60] 个百分点**。与等预算从相同起点专门训练的每次都写组相比，只高 **0.54 [−0.43, 1.61] / 0.05 [−0.74, 0.83] 点**。它确实能挑值得写的时机。在这个任务中，始终写入的图也能学出接近的最终成绩。训练写入开关时，训练器实际比较了提交与跳过两条后续，部署时只执行一次。[同一回执的两种真实延续](evidence/active-review-20261120/receipt-and-writing.md)

旧记忆的损失能具体定位。在接入节点状态的写入门组，如果两个对象本来反馈一致、现在刚变相反，强制写入相对跳过，使刚复习对象的正确率高 **78.07 / 75.47 点**，另一个对象同时低 **18.28 / 18.56 点**。相反，如果刚好消除了原有冲突，同一写入让另一个对象也高 **18.33 / 15.50 点**。这些数字来自选择之后固定状态、分别问两个对象的配对读数。共享参数造成的损失有方向，取决于新旧内容的关系。[写入影响按新旧关系拆分](evidence/active-review-20261120/receipt-and-writing.md)

当前能够支持的判断是：这个规模的连续可塑图，配一个明确的读出或反馈通道，可以把近期经验用于选路、补查、控制本次写入。跨任务时有两种不同的失败。其一，先前训练学到固定线索的用法，同一生换义后，原图没有从两次实际例子学回它。其二，新经验虽然写进去了，可能同时改坏原来辨认别的对象所依赖的反应。裸图学习读出或形成自己的关联结构，目前仍缺少行为证据。
