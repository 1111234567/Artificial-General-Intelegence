## 原意与历史的边界

[初稿](archived/design-memory-learning-2026-10-22.md) 已包含 2026-10-23 的七轮修订。仓库最早提交 `bcfbfa0` 纳入的也是修订后的文本。当前材料不足以逐句判定哪些原话出自用户、哪些派生论证由模型补充；文档中的“拍板”不能替后续技术推导提供证明。

保留的研究方向是：经验持续改变系统；感知、行动、反馈和学习形成闭环；语言属于同一个学习系统的能力；尽量少预设功能分工。持续自主学习是当前核心研究目标，不能据此断言跨域迁移、自主设定目标或 AGI 已经成立。

## 撤销或收窄的论断

下表的章节号指向历史原文，不是现行文档的编号。

| 原论断及位置 | 本次处理与理由 |
|---|---|
| 初稿 §15.6：有限 BPTT 窗口必然要求清空状态，继而要求样本标签和准确率 | 撤销。前向状态、梯度历史和损失来源是不同选择。截断 BPTT 可保留隐状态数值，代价是跨窗口梯度被截断。 |
| 初稿 §15.7：一个完整个体要求从零训练、LIF 和脉冲化块扩散 | 恢复为独立候选。共用学习系统不能推出这些实现选择，更不能互相循环论证。 |
| 初稿 §11.4：有任务、episode、准确率的实验就是错误形态 | 撤销一般性禁令。系统的长期目的与研究者用于诊断能力的任务可以不同；测量准确率不要求重置系统状态。 |
| 初稿 §2.2 / §15.3：τ 不能逐单元连续设计，分布形状不能学出 | 撤销普遍结论。存在每神经元膜/突触时间常数可训练的直接研究；膜参数、活动自相关尺度和学习尺度需分别讨论。 |
| 初稿 §2.10：记忆只能是连接，长期没有时间只有次数，跨 episode 只能靠连接 | 收窄为一个候选建模视角。持续状态也可能跨 episode 携带信息；测试需区分状态、权重及其它持久存储的贡献。 |
| 初稿 §7.4：未通过环境检验的经验不写入 | 撤销作为完整学习规则的要求。失败经验也可能需要更新；应区分错误策略被强化与从错误后果中学习。 |
| 初稿 §13.1：先证明不能涌现，再设计 | 改为比较候选机制及其必要性，不要求先完成一个一般无法穷尽的否定证明。 |
| 初稿 §0.3：常数只能来自需求或文献 | 改为说明参数角色、适用条件和敏感性。文献出处不能保证迁移适用，试取值也不能伪装成推导值。 |
| 旧实验卷 §11.4.0：E/I、不应期、硬预算和特定放电率是所有后续研究的必要条件 | 降为特定 LIF 实现的经验工作点。换规模、连接结构或编码后需重新评估，不能据此排除其它架构。 |
| 旧实验卷 §11.6.2：记忆长度与量化误差放大的乘积为常数 | 撤销。原表把两者都写为约 `1/(1−ρ)`，乘积显然不是常数。相关谱半径区间和误差预算不再作为通用门槛。 |
| 旧实验卷 §16.32：最后一次失败是把 32 维 RNN 搬到 1000 维 SNN | 纠正配置事实。当前 `rnn2snn.py` 使用 166 个节点，并覆盖 `NetSpec.N`；其映射尚未建立动力学等价，不能仅凭规模叙述归因。 |
| 201 项逐位对齐证明实验机制成立 | 限定为历史迁移验证。相同结果也可能保留相同缺陷，仍需独立检查任务、对照和测量语义。 |

这不否定 SNN、局部可塑性、拓扑生长、分区、块扩散、预训练或从零训练中的任何一条路线；每条路线都需要说明它要验证的问题以及证据边界。

## 实验结果的使用范围

- 四类输入的教师实验历史读数为 25% → 65.8%。输入在回答期间持续可见，教师提供逐输出误差，学习主要发生在输出接口。该记录支持特定分类装置能学习，不支持语言、长期记忆或持续自主学习已经成立。
- RNN 的 100% 来自特定小任务的训练设置。随机目标、遮蔽目标和迁移评估不能与该读数合并为一个笼统结论。
- 放电率、结构边数、活动差异和响应速度可用于诊断动力学。它们需要与获得、保持和复用能力的证据相联系，才与持续学习目标相关。
- 转换与记忆实验中的撤回记录保留。某种测法不适合当前问题，不等于所有记忆研究都必须追加同一套世界模型、行动或奖励机制。

## 仍存在的实现问题

本次整理没有改变下列实验的数值配置或学习规则。配置说明已纠正，后续若修复行为，应记录新的运行条件并重新建立相应对照。

| 配置 / 实现 | 已确认的问题 | 影响 |
|---|---|---|
| `sig_episode`；[signal.py](../src/signal.py)、[runner.py](../src/runner.py) | `on_action` 在 episode 模式清空 `_last`，末尾补发拿到空信号；沉默提示仍按目标方向更新 bias | 不能用作“只在任务末接收学习信号”的对照 |
| `sig_scalar`；[signal.py](../src/signal.py) | 动作信号设为标量，`on_silence` 仍产生逐输出向量 | 不能用作纯标量与逐神经元学习信号的隔离比较 |
| `ho_frozen`；[experiments.py](../src/experiments.py) | 相比 `ho_grow` 同时改变拓扑可塑性与 `reset_state_per_chunk` | 差异不能只归因于结构学习 |
| world 的 `agency`；[runner.py](../src/runner.py) | 实际量是近期动作的标准差；调制带固定底值 | 动作变化程度不能直接作为可控因果影响或自主学习的证据 |
| 配置可行性检查与指纹；[config.py](../src/config.py) | 可达性检查包含工程余量；指纹排除 `seed`、`n_ep` 等字段，并包含部分 flow 不使用的字段 | 检查未通过不一定证明数学上不可达；指纹也不是完整运行身份或行为等价证明 |

本次对信号出口和配置差异的检查是局部代码核验，没有重跑历史训练，也没有产生新的性能结论。
