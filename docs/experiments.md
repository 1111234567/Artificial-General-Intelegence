| S7 | 进化层给不给 | **给（阶段 A：基因 + 变异 + 选择，不开学习）** / 不给（只测学习） | **倾向给**——不给的话测的只是「在设定好的结构里能不能分工」，测不到「能不能长出没设计的结构」 |
| S8 | 基因的丰度（能不能表达没想到的结构） | 只参数（节点数/密度/τ 分布）→ 安全但空间窄 / **加拓扑生成规则** / 加发育程序（从单节点分裂迁移） | 待定——**这一条决定阶段 A 能发现什么；基因空间窄了，演化只能长回我已经想到的东西** |

### 11.2 原第 1 件（现第 2 位）：测「第二次快多少」

**为什么它排在分化实验之后**：

- **不需要新架构**——只需「经验留存」这一件事
- **不需要 GPU**
- **判据是硬的**：第二次快 30% 还是 0%，一目了然
- **如果第二次不快，后面所有架构讨论都是空谈**
- **但**：若「分化」不发生（§11.4），这里的数字无法归因——不知道快是因为经验，还是因为碰巧调对了参数

**做法**：

1. 选 10 个「有明确成败」的本机任务（例：修一个失败测试、格式转换、定位配置项）
2. 每个任务第一次做，记录：**步数 / 时间 / 人工介入次数 / 是否成功**
3. 把「经验」按最简形态留存（文本记录：情境-策略-后果）
4. 隔一段时间做同批任务的**变体**，记录同样指标
5. 对比

**为什么用「变体」而不是「原题」**：原题能考的是「记忆」，变体才能考「学习」。而 `design.md` §4.1 已经说明了记忆和学习的区别。

**经验留存的三个档位**（先做最低的）：

| 档位 | 形态 | 成本 |
|---|---|---|
| 1 | 纯文本记录 | 最低 |
| 2 | 结构化（情境-动作-结果-误差） | 中 |
| 3 | 参数化写入 | 高 |

**先做 1，测出基线**。如果基线已显示「第二次快」，再考虑往 2/3 走；如果基线是 0，那说明「经验留存」不是瓶颈，而「怎么用经验」才是。

### 11.3 第 3 件的具体设计

**⚠️ 前提（2026-10-23 补）：这件在现在的链路上做不了。** Pando 走 DeepSeek API，拿不到 hidden state；system prompt 是文本不是向量。用本地 embedding 编码文本算距离，测的是文本相似度，不是内部状态——那已经是另一件事了。要动这件，前提是本地有可读内部状态的模型（阶段 1 的块扩散底座，或任意本地模型）。

**测什么**：同一任务在两个不同会话里，模型的「内部状态向量」距离。

**为什么值得测**：如果已有天然的一致性（哪怕很弱），说明「身份」已经部分涌现，只需**放大**；如果没有，说明需要**显式训练目标**。

（按 `design.md` §2.9，这套问法要改：问的不是「涌现没有」，是「有没有一个中心在承载累积的修改」——判据见 `design.md` §2.9 四条。）

**这个实验很便宜**：不需要训练，只要跑两次前向算距离。

### 11.4 分化实验（第五版：生长规则演化 + 稳态标定）

> **第五版与第四版的两处不同（2026-10-24）：** ① 阶段 A 的个体**不是固定结构**——连接在生命期内自己生长与裁剪，演化对象从「结构参数」变成**生长规则**（依据：2026-10-23 拍板，见 `design.md` 来源与修正记录）；② 阶段 A 之前多一道**稳态标定**（§11.4.0）——第四版把稳态当默认成立，实测它是第一道坎。

#### 11.4.0 稳态的实现与标定

**为什么单列一节。** `design.md` §2.10 把「稳态」列为本体侧必须给的三样之一（接口 / 可塑性 / 稳态），但它一直被当成「给了就成立」。2026-10-23 的实测推翻了这个默认：**稳态不是配置项，是一条要标定的曲线**——标不准，后面三样测量（记忆跨度 / τ 分布 / 挤占）全部没有对象。

##### 实测：均质网络只有两种态

固定结构、只扫兴奋突触权重（N=1000、全兴奋、无抑制、无不应期）：

| w | rate |
|---|---|
| 0.02 ~ 0.25 | **0.19%**（= 外部输入率，信号完全不传播） |
| 0.30 ~ 0.70 | **100%**（全部同时放电） |

**从 0.19% 直接跳到 100%，没有中间态。** 这不是参数没调好，是全兴奋网络只有正反馈：要么信号衰减殆尽，要么自我放大到饱和。

##### 三个必须的动力学要素

| 要素 | 缺了会怎样（实测） | 加了之后 |
|---|---|---|
| **E/I 平衡**（约 80% 兴奋 / 20% 抑制） | 只有全或无，rate 不可连续调 | rate 可以连续调 |
| **不应期**（T_REF） | 放电率无上界——抑制比拉到 10 倍仍卡在 20~30% | T_REF=20 时压到 1.99% |
| **硬预算 + 竞争** | 新建边无代价 → 边数从 8000 涨到 28000、淘汰只有个位数 | 结构尺寸有界，生长与裁剪成为同一选择的两面 |

三者的关系不是「三个超参」，是**缺一不可**：E/I 给可调性、不应期给上界、预算给结构约束。

##### 标定结果（2026-10-23，手扫）

| 参数 | 值 | 结果 |
|---|---|---|
| w_E | 0.50 | rate **1.99%** |
| 抑制权重比 | 5.0（w_I = −2.5） | 尾部波动 0.94% |
| T_REF | 20 步 | 稳定 |

**判据（三条全过才算标定完成）：** ① rate 落在 1~3%；② 末 2000 步的波动 < 1%；③ 不出现全静默、也不出现全饱和。三条都满足，才允许开结构可塑性。

##### 文献已有的自组织方案（未试，优先级高于手调）

`reference.md` §15.2 已列：**两个机制就能让网络悬在临界点附近而无需外部调参**——抑制性突触短时抑郁 + 阈值适应（Phys Rev Research 2, 012042, 2020），同时给出 E/I 平衡与异步不规则放电。

上面那张标定表是**手扫**出来的（`calib` 系列五个脚本），每换一次参数都要重扫，且没有理由相信扫出来的点是「对」的。**所以这里有一个明确的替代方案没试过**：用两个自组织机制换掉三个手调常数。它是 §16.3 列的候选之一。

##### 已知失败模式（标定成功之后仍会遇到）

开结构可塑性后 rate 掉到 0.08%。**当时的根因推断是「时间尺度不对齐」（§16.3），事后证明不是——真正原因是五个实现缺陷**（衰减判据 / 衰减尺度 / 世界发散 / 强化只覆盖 0.45% 的边 / 抑制边沙溢，§16.6）；修后同参数 rate = 1.55%。所以「标定完成」不等于「开着可塑性也能稳住」——**标定是必要条件，不是充分条件**；而且**失败时先查实现，不要先解释机制**。

**结构冻结的那一版是旧的；结构能自己生长的那一版才是新的**，两者不能混：

| 个体生命期内 | 结构不变，只跑动力学 | **结构自己加边 / 删边** |
| 演化的对象 | 一个结构 | 一条规则 |
| 测到的是 | 哪组超参能活 | **结构能不能自己形成** |

已有工作填的是左列：

| 已有工作 | 做到什么 |
|---|---|
| **ELSM**（2024） | 目标 = small-world 系数 + 临界性；自发长出 hub / 短路径 / 长尾度分布 / 社群；NMNIST 97.23% |
| **NeuEvo**（PNAS 2023） | STDP 演化出四类回路 + 全局误差更新权重 |
| **CortexZero**（2025-11，预印本） | 基因 = 区域树上的概率分布，发育采样，不用反传；**只有规格，没有结果** |
| **WANN-Spiking**（2022） | 权重无关的拓扑搜索迁到脉冲回路 |

**所以本版阶段 A 不是重复劳动**——上面这些全部以「出生时结构定死」为前提。加了生长 / 裁剪之后，阶段 A 测的是另一件事（`reference.md` §15.6 里「降级复用 ELSM」那段判断因此撤回）。

仍有一个观测是它们没做的：**每个存活个体的实测 τ_d 分布**（ELSM 量的是 small-world + 临界）。而这里有一个 `design.md` §2.2 已指出的坑：**基因里的「τ 分布」与网络实际的时间尺度不是同一个量**（单细胞 τ 在强递归下被抹平）。→ 只记基因型、却从行为读结果，会让「收敛到广谱」有两种相反解释（「选择偏好广谱基因」或「给了也白给」）。所以必须**同时记录实测 τ_d**，否则结果不可解释。

**阶段 B 是真空。** 三条前提与 SNN 主流逐条相反，而且互相锁死（详见 `reference.md` §15.6）：

| 草案阶段 B | SNN 主流 |
|---|---|
| 一条永不重置的时间轴 | 每样本 / 每帧重置 |
| 不开学习也要有状态 | BPTT 必须有固定 T |
| 无任务、无 episode、无准确率 | 全部有任务 + 准确率 |

#### 阶段 A：演化生长规则（结构在生命期内自己变）

##### 前置

§11.4.0 的标定必须已经完成：rate 稳在 1~3%、尾部波动 < 1%。**在这一条之前，阶段 A 的任何结果都不可解释**——网络是死的，所有判据都无从谈起。

##### 与上一版的区别

| | v3 / v4 | v5（本版） |
|---|---|---|
| 基因 | 结构参数 | **生长规则的参数** |
| 个体出生 | 按基因一次性生成结构 | 从一个稀疏初始结构出发 |
| 生命期内 | 结构冻结，只跑动力学 | **强化 / 竞争淘汰 / 随机新建** |
| 判活 | 六条 | 六条 + **首要：结构有没有收敛到稳定形状** |

##### 生长规则（演化的对象是这三条规则的参数）

> **2026-10-24 修订：删去「闲置衰减」。** 原表列四条（强化 / 闲置衰减 / 硬预算 / 随机新建），但同日两次实测把衰减判据否掉了：判据取「本步前后同时放电」时保护 68 条 / 衰减 14932 条（**1:221**）；改成「前神经元 500 步未放电」后仍衰减 2822 条（**1:141**）——持续衰减的时间常数必须匹配「边被使用的间隔」，而活动率 0.5% 时这个间隔远长于结构更新周期（20 步）。**硬预算按强度竞争淘汰本身就是「用进废退」**，不需要额外的持续衰减。（`test/grow_world.py` 头部 v2 缺陷记录；§16.6 缺陷 2；决策见 `decisions/agi项目.md` 2026-10-24。）

规则形式固定，**演化的是参数**：

| 规则项 | 作用 | 要演化的参数 |
|---|---|---|
| **共激活强化** | 资格迹累积「最近活跃过」，按 `Δw = η·e_ij·m` 写回全部边 | 强化率 η、迹衰减 |
| **硬预算 + 竞争** | 边数超预算时按有效强度淘汰——生长与裁剪是同一选择的两面 | 预算 E_max |
| **随机新建** | 小概率新建边（补局部规则够不着的长程连接） | 概率 p_new |

四条实测依据，写在这里防止再犯：

1. **「衰减不要做」**——两版判据都被数据否掉（1:221 / 1:141），而硬预算已经在做同一件事（弱边被淘汰），多加一层只引入一个难标定的常数与一条错配的时间尺度。
2. **「强化必须用资格迹，不能用瞬时共激活」**——瞬时共激活只覆盖「本步同时放电的对」= **0.45% 的边**（68/15000），而配套的衰减作用于剩下的 99.5%，结构必然冻结。资格迹把「最近活跃过」展开到全部边（覆盖率 100%）。替代方案「把闲置窗口调大」只是把同一个错配的时间尺度挪位置。
3. **「生长与裁剪是同一选择的两面」**——MiTA（NeurIPS 2026）的 emergent token pruning：没人设计剪掉哪些 token，共同机制只有竞争 + 稀缺（top-k 硬约束）。生物学同样是「先过度生产 → 按效能竞争 → 弱的出局」。所以只需一个预算参数，不需要「生长率 + 剪除率」两个耦合参数。
4. **「不能一次全开」**——场次八把强化 / 衰减 / 跳跃 / 退火一次全开，rate 掉到 0.08%。正确顺序是逐项加：先只开「强化 + 硬预算」，rate 稳住了再加随机新建。

##### 演化什么、不演化什么

| 演化（基因） | 不演化 |
|---|---|
| 强化率 / 迹衰减 / 窗口长度 | 初始连接的具体位置 |
| 预算 E_max | 单条边的权重值 |
| 随机新建概率 | 实现细节（数据结构 / 并行） |

**基因空间是这一阶段真正的风险（待定项 S8）**：如果规则只能表达我已经想到的那几条，演化只能长回我设计的东西，实验就白做了。

##### 初始结构与规模（沿用第四版的范围，但不再是「基因」）

个体出生时的初始结构由下面几项确定，**它们不进基因、不参与演化**（演化的是上面三条规则的参数）：

| 项 | 取值 | 说明 |
|---|---|---|
| 节点数 | 100~2000 | 与第四版相同；决定单步成本（§16.1） |
| 连接密度 | 0.5%~10% | 跨过稠密 / 稀疏交叉点 5%（§16.1）→ 实现需两条路径按密度选 |
| 初始拓扑 | 随机 / 距离衰减 / 分群 / 小世界（4 选 1 + 参数） | 第四版把它当基因，现降为初始条件 |
| 兴奋 : 抑制比 | 1:1 ~ 5:1（工作点 4:1，见 §11.4.0） | E/I 平衡是稳态的前提 |
| 是否有分群结构 | 无 / 2 群 / 4 群 | 结构异质性的一个维度（与容量有权衡，见下方反向观测） |
| 初始权重 | 强 / 弱两档（强 = w_E，弱 = w_NEW） | 第四版一律随机初始化；本版「过度生产 → 修剪」需要弱初值 |

**为什么这些不再是基因：** 它们决定「出生在哪个结构里」，而这一阶段要测的是「结构能不能在生命期内自己形成」——把初始结构也交给演化，就分不清长出来的形状是演化的功劳还是初始条件给的。

（第四版的基因表里还有一项「**时间常数分布**：单值 / 均匀 / 对数正态（跨几个量级）」，并标注「这一条直接对应分化」。本版改为：τ 不进入基因，它是**结构异质性的输出**（`design.md` §2.2：逐单元 τ 在强递归下被抹平）；要观测的是**实测 τ_d 分布**，不是基因型。）

##### 输入必须带结构（不是纯泊松）

| 必须有的分量 | 为什么 |
|---|---|
| **周期分量** | 给「可预测」提供对象——能预测的活动才谈得上「值得强化」 |
| **偶发事件** | 给结构提供分化压力（不同时间尺度的分量才有不同的响应理由） |
| **噪声** | 防止确定性锁相 |

**这一条不是可选项。** 场次八最根本的一个认识是：纯泊松输入下没有任何东西「值得学」，竞争只能退化成自洽的（没被激活就淘汰）——自洽的规则可以收敛到任何东西，包括退化态，实测收敛到 rate 0.08% 的死网。**给输入加结构，是给竞争提供「方向」的唯一来源**（`design.md` §14.8：环境反馈是锚，不是训练信号）。

##### 怎么判「活」

每个个体跑 2000 步（用 §11.4.0 标定后的动力学）。输入是**同一个事件流**（周期 + 偶发 + 噪声），所有个体共用。**六条全过 = 活**：

| 判据 | 具体测什么 | 阈值 |
|---|---|---|
| **不炸** | 活动幅度时间序列的 max / mean | < 20 |
| **不死** | 最后 500 步的平均活动 | > 全静默的 10% |
| **不僵** | 状态的方差 | > 0（不是固定点） |
| **不纯混沌** | 两条轨迹从差 1e-6 出发，10 步后的分离度 | 有界，不是指数爆炸 |
| **有区分** | 10 种不同输入，状态距离矩阵 | 类内距 < 类间距的一半 |
| **有记忆** | 注入唯一标记，100 步后能不能线性读出 | 高于随机 |

这些判据里**没有任务、没有答案、没有准确率**。

**六条都要测，不能只测前两条。** 场次八只看了 rate 与波动（≈「不死 + 不炸」），其余四条（不僵 / 不纯混沌 / 有区分 / 有记忆）一次没测——所以「实验跑不通」这个判断本身只基于六条里的一条。

##### 加在六条之上：结构有没有收敛到稳定形状

这是 2026-10-23 新增的首要观测。**但「收敛」本身没有区分力**——死网也会收敛：

| 观测 | 怎么看 | 意义 |
|---|---|---|
| **turnover** | 每 N 步的边集合与上一次的重叠率 | 低 = 结构稳定 |
| **边数 / 预算** | 实际边数占 E_max | 长期贴顶 = 竞争在起作用 |
| **度分布 / 权重分布** | 形状随时间是否稳定 | 收敛后应当稳定 |
| **rate 与 turnover 联合** | 只有「低 turnover **且** rate 在 1~3%」才算真收敛 | **这条是关键** |

最后一行是必须的：场次八的数据是「低 turnover（0.003）+ rate 0.08%」——单看 turnover 会误判成「收敛成功」，实际是**收敛到死网**。

##### 繁殖与选择

活下来的按「记忆长度 + 区分度」排序，前 20% 繁殖；基因（即生长规则的参数）随机扰动（每代 5% 位翻转 + 参数 ±10%）。死光的代重来。跑 100~300 代。

**N ≥ 5 个种子**，看分布形状与收敛方向是否稳定出现，不挑一个成功的报（人工培养大脑的批次变异是同一类问题：「Even under identical culture conditions, organoids exhibit different learning rates and neural architectures」）。5 个里 2 个收敛、3 个不收敛 → 结论是「会收敛但不稳」，这比挑一个成功的报有价值。

##### 看什么算有结果

**规则参数是否收敛**，尤其是会不会自己走向某个角：

| 收敛到 | 含义 |
|---|---|
| 宽分布 / 双峰的时间尺度分量 | 多时间尺度对「活下来」有用，且它由结构异质性承载（不是逐单元 τ） |
| 单值 | 在「活下来」这件事上多时间尺度没用——那么「要不要分化」在这个判据下不成立 |
| 衰减率 → 0 | 「不衰减」被选中 = 结构不需要更新，那一整套生长机制是多余的 |
| 强化率 → 0 | 反过来：强化没用，只剩随机新建在维持结构 |

**后两种结果最有价值**——它们直接说这一阶段是空的，比「跑出一个漂亮的小世界」有用。

**第四版的原判断保留：** 「收敛到单值」这一种比「收敛到广谱」有价值——它说明时间尺度分化可能只在「要做复杂任务」时才需要，而不是「要活着」就需要。

##### 反向观测必须一起测：异质度 vs 容量的权衡点

异质性是权衡，不是单调改进（`design.md` §2.10）：同质网络的**工作记忆容量更大**，异质网络的函数生成能力更强；存在一个最优异质度。

所以判据里若只写「记忆长度 + 区分度」，会偏向同质。**必须同时记录异质度与容量，看演化把权衡点放在哪。**

##### 顺带必须测：会不会自己跑到临界

生物网络在临界附近（既不僵也不乱），而且这个状态是**自组织**的（NALSM：星形胶质调制 STDP 到临界态）。

测法：**分支比 σ**（每个活动事件平均引发多少后续事件，σ≈1 是临界）或**雪崩尺寸的幂律**。

- 自己跑到 σ≈1 → 「稳态」这一条不用我给
- 跑不到 → 才需要显式加

#### 阶段 B：结构定下来，再学

挑阶段 A 里活下来的前 5 个**不同**结构（不同拓扑、不同 τ 分布），固定结构，打开可塑性。

##### 形态：一个永不清空的状态

| | 错误形态（v1） | 本版 |
|---|---|---|
| 时间轴 | 离散 episode，喂完就重置 | **一条不间断的时间轴**，状态从不重置 |
| 输入 | 固定长度序列 | **连续事件流**，每一刻都有输入，没有「开始 / 结束」 |
| 输出 | 在指定位置输出标注答案 | **不强制输出**；从外面读状态，不让它做题 |
| 训练 / 测试 | 分开 | **不分**；同一条时间轴，只差「给不给调制」 |
| 判据 | 消融 → 准确率下降 | **状态自己的性质** |

关键一句：**不是「训一个能做题的网络」，是「看一个一直活着的东西会不会形成结构」。** 所以没有准确率、没有收敛曲线、没有 episode。

##### 三个测量（都在同一份持续状态上，不需要重启）

**测量一：影响能持续多久**

注入一个**唯一标记**（之前没出现、之后也不会再出现），**之后不打扰它**，在第 1 / 10 / 100 / 1000 / 10000 步各读一次状态，用线性探针问「刚才那个标记是什么」。

得到一条「可读性 vs 延迟」曲线——**每个内部维度各一条**。

**测量二：分化（看曲线形状，不看准确率）**

把每个维度的曲线拟成 τ_d，看 τ 的分布：

| 分布形状 | 含义 |
|---|---|
| 单峰、窄 | 一套规则只能给一个 τ，不分家 |
| **单峰、宽（跨几个数量级）** | **一套规则自然广谱** |
| **双峰** | 分化成了两套，分家在机制上必要 |
| 全部极短（秒级以下） | 什么都没记住，是参数问题不是分化问题 |

第二层：**不同 τ 的维度是不是各自编码不同的东西**？用互信息算：τ 短的维度对上「刚才那几步」的信息多，τ 长的对上「周期性结构」的信息多——这就是频谱分解（`design.md` §2.2 末）。

这比双分离好在哪里：不需要定义「两个任务」、不需要 episode、不需要拆连接；判据是**分布的形状**，直接对应「一套够不够」。

**明确不采用双分离消融。** v1 的思路是「拆掉一套再测另一套，看准确率下降多少」——它需要定义两个任务、需要 episode、需要算准确率，同一条链条把实验拉回基准测试形态。本版用「τ_d 分布形状 + 互信息分工」替代，两者不共存。

**测量三：学习（不是准确率）**

| 量 | 怎么算 | 预期 |
|---|---|---|
| **响应幅度** | 同一周期分量重复出现时，参与它的维度激活强度 | 变强（强化） |
| **响应延迟** | 从输入到状态变化的时间 | 变短（熟了） |
| **挤占** | 新结构学进去后，旧结构的可读性掉多少 | ——**这才是真问题**（LSL 的 44% → 76.6% → 96.6%） |

「挤占」那一行最要紧：**如果新学的东西会冲掉旧的，那不管分化不分化，「持续学习」都不成立。** 这是与 A 判据直接相关的量。

##### 阶段 B 的对照

| 组 | 输入 | 回答什么 |
|---|---|---|
| 1 | 有结构 + 可塑性开 | 主体 |
| 2 | **同统计的白噪声**（无周期、无结构） | 看到的 τ 分布是不是自发噪声就有的 |
| 3 | 有结构 + 可塑性关 | 结构不靠学习的部分占多少 |
| 4 | 有结构 + 两套可塑性 | 分家能不能改善「挤占」 |

组 2 是硬对照：**任何非线性循环系统都会自发产生多时间尺度**（临界态、混沌边缘都是）。不证明「来自输入结构」，测量一就没有意义。

##### 判据（先写死，防事后挑）

| 判据 | 阈值 | 不达怎么办 |
|---|---|---|
| **有记忆** | 至少 10% 的维度 τ > 100 步；且组 2 对应比例不超 5% | 没记住东西 → 调稳态 / 可塑性，不谈分化 |
| **双峰** | GMM 两成分似然比检验，且两峰相距 > 10× | 单峰就判「未出现双峰」，不写「没有分化」 |
| **频谱分解** | τ 短 / 长两组的互信息差 > 2 倍 | 分化了但没分工 → 也算没分化 |
| **不挤占** | 新学后旧结构可读性下降 < 20% | 下降严重 → 「持续学习」不成立，这是更优先的问题 |

---

#### 两阶段共用的要求

**必须多随机种子**：人工培养大脑最大的痛点就是批次变异（「Even under identical culture conditions, organoids exhibit different learning rates and neural architectures」、「every brain organoid is unique」）。对应到本实验就是种子敏感性——**N ≥ 5**，看分布形状 / 收敛方向是否稳定出现。5 个里 2 个双峰、3 个单峰 → 结论是「会分化但不稳」，这比挑一个成功的报有价值。

**规模与成本**：阶段 A 的种群评估可并行，个体 2000 步很短；阶段 B 单个体 10⁵~10⁷ 步。总成本本机 CPU 小时级，无 GPU。

**但规模不能拍**：要测到 τ > 10000 步，状态维度至少得有一批能存活那么久。先跑一次探测，看现有规模能不能出 τ > 10³；出不了就加大。

**一个必须记住的坑**：人工培养大脑的 2026-09 综述原话——「**closed-loop adaptation is a function of a whole OI system (substrate plus interface plus feedback), not of the tissue itself**」。即：看到「形成结构 / 学会了」时，要能说清是**基因、可塑性规则、还是稳态**在起作用——这就是为什么必须有组 2（白噪声）和组 3（可塑性关）两个对照。不然看到什么都不算证据。

#### 与「原第 1 件」的关系

| | 测什么 | 主体 |
|---|---|---|
| §11.4（本件） | **本体能不能自己长出结构，以及长出后能不能学** | 小网络（AGI 雏形） |
| §11.2（原第 1 件） | agent 第二次会不会更快 | Pando（外部工具、文本经验） |

前者是「本体」层，后者是「外挂」层。**两者不能互相替代**，但 §11.4 先——因为如果本体长不出，后者只是给一个没有身体的东西堆文本。

### 11.5 个体性测量（阶段 C，D 判据）——⏸️ 悬置

> **⏸️ 2026-10-23：本节整节悬置（D 判据悬置）。**
>
> 保留而不删的理由：本书记了**两次失败**，重开时不用从头想。
>
> | 轮流 | 方案 | 被什么推翻 |
> |---|---|---|
> | 一 | 消融一致性（拿掉 persona） | persona 不设定后**失去对象** |
> | 二 | 结构消融（切中心） | **循环依赖**（要先知道中心才能切）+ 损伤曲线测不出中心（平滑 = 分布式，特定崩 = 局灶模块） |
> | 三 | 个体性（本节：重复性 / 个体间差异 / 跨域一致） | **偏好是实体的必要条件**——固定权重的随机网络三项全过，它连学习都没有 |
> | 四 | 共享改动结构（权重 delta 集中度 + 消融公共子空间 + 跨种子/跨历史） | **未评估就被悬置**。它比前三个都硬（在结构层测），但依赖「权重快照 + 多域任务」，且可能得出「无中心」的真结论 |
>
> **当前状态：** 不设判据。§11.1 不再排阶段 C。下面的内容只做记录。


> 2026-10-23 新增。本节填的是 `design.md` §2.9 判据表第四条留下的缺口：**「消融一致性」在 persona 不设定之后失去对象，而「选一组连接再切」从根本上有两个问题。** 替代方案不是消融，是**不改结构、只测「它是不是它」**。
>
> **先记住一个分层**：
>
> | 阶段 | 测什么 | 有任务吗 |
> |---|---|---|
> | A（§11.4） | 结构能不能自己长出来 | 无 |
> | B（§11.4） | 状态的性质（记忆长度 / 分化 / 挤占）—— **A 判据的前提** | 无 |
> | **C（本节）** | **个体性（重复性 / 个体间差异 / 跨域一致）—— D 判据** | **有，但是多解任务** |
>
> **为何必须另开一个阶段：** 阶段 B 的前提是「无任务、无 episode、无准确率」，而个体性需要**多解选择**——没有选择就没有「怎么选」可测。

#### 11.5.1 为什么放弃「结构消融」

| 问题 | 具体 |
|---|---|
| **循环依赖** | 要切「承载自我的那组连接」，得先知道自我在哪；而判据的目的**正是**要知道自我在哪 |
| **损伤曲线测不出「中心」** | APA 定义：graceful degradation（平滑劣化）**恰恰是分布式表征的性质**。而真实脑损伤常见的是「其他都正常、某一种能力灾难性丧失」（Coltheart 1991 举的病例：只能理解不能产出专有名词）。两者都不是自我 |
| **分不清三种退化来源** | 平滑 = 分布式；特定能力崩 = 局灶模块；整体崩 = 容量不足。`design.md` §2.9 说的自我是「分布式网络里被反复使用而成为中心的一组连接」——**它既不是模块，也不会因为被切而只坏一种能力** |

结论：损伤曲线可以保留为一个**旁路观测**（测模块化程度），但**不能当 D 判据**。

#### 11.5.2 替代：测「个体性」

方法学出处：动物行为学的 **animal personality / behavioural syndrome**（核心概念：repeatability、cross-situational consistency、temporal stability、个体间方差 vs 个体内方差；统计量 ICC / Cronbach's α；实测区间 r ≈ 0.35~0.88）。

**关键：它测的不是「不变」，是「统计意义上的稳定」，允许个体内变异（intraindividual variation 是这套范式里的正式概念）。** 这与 `design.md` §2.9「冻住就不学了」不矛盾。

#### 任务：多解任务

**定义：一个任务有多个都能通过环境层验证的等价解。** 环境层给的是成败，不是唯一答案。

不用造：§11.2 那 10 个本机任务里本来就有（修 bug 改调用方还是改被调方、重构的两种等价结构、排序稳定性选择）。挑选条件两条：① 至少两个解都能过环境层；② **不告诉它哪个是标准答案**（因为确实没有）。

#### 三个子测（必须一起用）

| 子测 | 怎么做 | 判据 |
|---|---|---|
| **A. 重复性** | 同一批多解任务（N ≥ 20）在 T 个不同场合重复；算偏好向量的 ICC | **ICC > 0.5**（参照 animal personality 典型区间 0.35~0.88） |
| **B. 个体间差异** | 两组对照：① 同历史不同种子（N=5）② 同初始结构 + 同种子 + **不同历史**（N=5）；算组间距离 | **② >> ①**（证明差异来自历史，不是种子噪声） |
| **C. 跨情境一致性** | 同一偏好是否跨任务域出现（语言类 / 动作类 / 排序类） | **跨域偏好相关 > 0**（是「它」而不是「某一种能力」） |

**「不同历史」怎么造（两个强度档）：**

| 档 | 做法 | 强度 |
|---|---|---|
| 1 | 同一批任务的**不同顺序** | 弱（路径不同，统计相同） |
| 2 | 同一输入分布但**不同共现结构**（A 常与 B 共现 vs A 常与 C 共现） | 强（改变统计） |

#### 两个反例：为何三条必须一起用

| 反例 | A 重复性 | B 个体间差异 | C 跨域一致 | 被谁排除 |
|---|---|---|---|---|
| 每次随机选 | ≈0 | 有（噪声） | ≈0 | A + C |
| 硬编码「永远选第一类」 | **高** | **≈0**（所有个体一样） | 高 | **B** |
| 真有个体性 | 高 | **大** | >0 | — |

**单看 A 会被硬编码骗过，单看 B 会被随机噪声骗过。** 这与 `design.md` §4.5 的「过程指标不能单独优化」是同一个结构。

#### 11.5.3 一个结构侧的补充（不是消融）

**可追溯探针**：从连接 / 状态里线性读出「它经历过哪类历史」。这不是切，是读。它提供「历史写在结构里」的直接证据，与行为侧三条互补。

#### 11.5.4 与 A 判据的分工

| | 测什么 | 失败意味着什么 |
|---|---|---|
| A（§11.2 的「第二次快多少」/ §11.4 的挤占） | 会不会变强 | 学不动 |
| **D（本节）** | **变强的是不是同一个东西** | 学得动，但每次学的不是同一个它 |

两者**不能互相代替**：A 成立而 D 不成立，得到的是一个「很快但没有中心」的系统；D 成立而 A 不成立，得到的是一个「稳定但不学习」的系统（`design.md` §2.9 说过：冻住就不学了）。

## 13. 设计准则与自评

### 13.1 九条设计准则

这九条不是从文献里找的，是从「反复被纠正」里提炼的（原为五条，2026-10-23 增四条）：

1. **从需要里推，不从组件里拼**——先问「它此刻需要什么」，再决定长什么
2. **先证明不能涌现，再设计**（2026-10-23 升级）——原版是「能涌现的不设计」，那是事后判断。现在要求设计**前**先给出「它为什么不能涌现」的理由；给不出就做实验（§11.4）。原版把「时间常数」当必须给的例子，现已证明连 τ 也不是可设计的量（`design.md` §2.2）
3. **要常数也得说清是需求给的，还是我造的**
4. **一致性 ≠ 正确性**，任何内生信号都得有个外部锚
5. **判据换形状，不换阈值**（后者只是把错误固定住）
6. **不要把生物的「实现约束」当原理**（2026-10-23 新增）——判定：换一个实现还成立吗？只在一种实现里出现的，是约束（分子种类 / 颅腔体积 / 代谢代价），不是计算必须的
7. **只搜支持自己的证据不叫搜**（2026-10-23 新增）——每个「X 存在」配一条「X 不成立」；多个源如果同源（同索引 / 同摘要服务 / 同一篇论文的转述 / 同一个人写的），只是同一个源出现了两次
8. **先查这一整套有没有现成学科**（2026-10-23 新增）——把机制清单逐条翻译成术语，看它们是否落在某个已有领域的词汇表里。全部命中 → 先读那一支的现成答案，再谈「新设计」。本次的代价是：草案从 `design.md` §2 推到 §11.4 才想起问「这不就是个 SNN？」，而 SNN 里已经有 LSRSNN（双峰 τ）、ELSM（演化出小世界 + 临界）、e-prop（在线局部学习）三件直接对应的成果，且它们在 2012~2026 年间已发表
9. **定义不清的概念不能当判据**（2026-10-23 新增）——本次是「自我 / 意识」：连碳基生物都缺乏公认定义，给硅基定判据只能是凭空编。**推论：一个量如果「任何实体都满足」，它不是判据而是必要条件**（例如「有个体差异 / 有稳定倾向」——固定权重的随机网络三项全过，它连学习都没有）；同理，一个量如果只能靠观察者投影给出（「看起来像同一个」），也不能当判据。**遇到这类概念，正确动作是悬置，不是找个代理量硬测**

> **第 9 条是怎么落地的（一条可复用的自检）：** 本次连续写错三版 D 判据（消融一致性 → 结构消融 → 个体性），每一次都是「想一个能测的量，然后把它当成自我」。共同错法：**想一个指标 → 它居然能跑 → 就当成判据**，而不是先问「这个量是不是任何实体都满足」。这个顺序不能倒。

### 13.4 不确定的地方

- **「两种时间尺度自然分工」只是假设**，无直接文献
- **「块扩散能撑住多步推理」未验证**（只有 SDAR / Eso-LMs 的间接证据）
- **过程四度量会不会被优化成新指标**——已有警觉，但无解法
- **「谁值得参照」是递归问题**（判断力需要参照，参照需要判断力）
- **「最长历史」类的问题已全部悬置**——「身份是否涌现 / 自我在多大尺度出现 / 压力与自我形态对应 / 消融能测出什么」四条随 D 判据一并悬置；不是「还不知道答案」，是**问题本身没定义清楚**
- **一套可塑性规则够不够**（`design.md` §2.10 的核心未知）——能用一套规则同时产生秒级精确历史与月级稳定策略吗？这是 §11.4 要回答的
- **「分化」会不会稳定出现**——即使出现了，N=5 里几次？不稳的话需要什么保证它分化
- **时间常数的分布能不能测准**——需要 τ 跨越几个量级，而长 τ 的估计很吃样本量；测不出来就分不出「单峰宽」与「双峰」
- **自发多时间尺度是噪声还是结构**——任何非线性循环系统都会自发产生多尺度（临界态）；§11.4 组 2 对照就是为了排除，但它能不能排干净还没验过
- **基因空间够不够宽**（S8）——这是 §11.4 阶段 A 的真正风险：如果基因只能表达我已经想到的那几种结构，演化只能长回我设计的东西，实验就白做了
- **「活」的六条判据会不会相互矛盾**——比如「不僵」与「不纯混沌」之间只剩窄窗口，可能大部分随机结构都过不了，导致演化无解
- **巩固窗口的长度**——不能拍脑袋，要从「什么算同一件事」推，但那个界限本身模糊
- **「短期」的二义会不会影响历史结论**——`design.md` §2.10 新发现的区分（状态持续 vs 未稳定连接）；本场已修 §11.4 的任务设计，但其他章节还没逐条回扫
- **必须给的稳态究竟是什么形式**——突触缩放 / 内在兴奋性 / 活动预算，三者的差别在本实验里能不能分辨
- **「无层」是否必要**——还是「层 + 稀疏激活」就够；赛博果蝇只证明了拓扑，没证明其余三条
- **环境锚的最低频率**——未知；需要「无锚漂移」实验回答
- **资格迹在长任务上的归因精度**——τ_e 与行为窗口如何匹配，未标定
- **教师弥散影响的可审计性**——记录到什么粒度才够
- **事件输出的粒度**——一句话 / 一个动作 / 一个阶段，未定
- **强化物的乘性门控是否会卡死学习**——任一项为 0 则整体为 0，需要避免「永远学不动」
- **分布式的长期记忆能否持续写入**——LSL 只验证到 7B / 三阶段；几百阶段、上亿条内容未验证（容量问题，不是机制问题）〔2026-10-23：本条前提（「长期记忆存在分布式载体」）已改——长期就是连接，问题换成「持续的强度累积会不会饱和」，仍无数据〕
- **混合 key 是否能保留 O(1)**——若 learned query 占主导，退化为 ANN 检索，可预取与 offload 两个工程优势消失〔前提已降级到 `design.md` §14.10，仅在「卡表必要」时成立〕
- **写时碰撞的检测成本**——校验位 / 读旧行比相似度，在 200 GB 级表上的开销未测〔同上〕
- **SNN 的固定代价能不能绕开**——0.16 nats 的 backbone 成本「不随算力变」；但 GSU 那条路（Scientific Reports 2024）其实是**放弃纯二值**（ternary + 连续流）才绕过去的——那还算不算 SNN，没定义
- **阶段 A 的基因型与实测 τ_d 不一致时怎么解释**——两者不是同一个量（`design.md` §2.2）；如果基因收敛到双峰、实测仍是单峰，结论该写什么？本版实验设计尚未给出裁决规则
- **脉冲化的块扩散能不能成立**——共用决策要求它（`reference.md` §15.7 ④），但 15 轮检索无先例：SNN 侧只有 SSM + 脉冲量化层（SpikingSSM），块扩散侧只有非脉冲的 SDAR / Eso-LMs。这条不成立，整个「共用」路线要退回「非纯二值」形态
- **「非纯二值」还算不算 SNN**——GSU（ternary + 连续流）是现有绕开二值表达上界的路径，但它放弃了「纯脉冲」；若采用，`reference.md` §15 的整套对照（功率、SynOps、神经形态硬件优势）要重算
- **阶段 B 在 CPU 上的真实成本**——「本机 CPU 小时级」是按什么实现估的？稠密实现与事件驱动稀疏实现可能差一个数量级（`reference.md` §15.3 ③）；模拟器形态未定
- **「没找到 SNN 的推理/指令跟随评测」是检索结果，不是定论**——15 轮 web_search，未逐篇精读；KB 侧未查（服务停着）
- **repeatability 的阈值 0.5 是从动物行为学借的**——那里的区间（0.35~0.88）是「个体在生物学意义上稳定」的经验值，**不保证适用于一个人工网络**；而且多解任务的「等价」由环境层判定，环境层的宽松程度会直接影响 ICC（判据越松 → 解越多 → 偏好分布越散）
- **个体性测量需要多久的历史？**——太短则历史没写进去（ICC ≈ 0），太长则测不起；这个长度未定，与 §10.10 S3（巩固窗口）相关但不是同一个量

### 16.1 模拟器成本实测（2026-10-23）

> 完整数据在 `test/baseline-2026-10-23-simulator.md`；脚本 `test/bench_lif.py` / `bench_lif2.py` / `bench_lif3.py`。本节只留结论。

**起因：** `reference.md` §15.3 ③ 自疑「本机 CPU 小时级」这个估计可能差一个数量级，模拟器形态（稠密 vs 事件驱动）未定。

**结论五条：**

| # | 结论 | 数字 |
|---|---|---|
| 1 | 草案的「本机 CPU 小时级」**偏悲观约 2 个数量级** | 单个体 N=1000 带可塑性：10⁵ 步 **4.3 s**、10⁷ 步 **7.2 min**；N=2000 分别 16.7 s / 27.8 min |
| 2 | **GPU 单个体比 CPU 慢 6 倍** | 0.1353 vs 0.0226 ms/步（kernel launch 主导） |
| 3 | GPU 只在批量时赢 | B=64 快 9 倍、B=256 快 33 倍（需 B ≥ 16 才抵得过 launch） |
| 4 | **可塑性在 batch 上是瓶颈** | N=2000 / B=256：带资格迹 + 权重更新是无学习的 **10.5 倍**（迹张量 (B,E) 受内存带宽限） |
| 5 | **稠密 / 稀疏交叉点 = 密度 5%** | 0.5% 时稀疏快 5.3 倍；10% 时稠密快 5.5 倍。§11.4 的搜索范围跨过交叉点 → 实现需两条路径按密度选 |

**一个否定结果：** 事件驱动（CSR，只遍历有 spike 的神经元）在纯 numpy 下只值 **1.25~1.92 倍**（活跃边 15~383 / 总边 10000，理论上该省 26~660 倍）。省下的遍历被索引构造开销（`repeat`/`cumsum`/`arange`）吃掉了 → **脚本语言里不值得为事件驱动增加实现复杂度**；要拿这个收益得下手写 kernel。

**一个约束（对阶段 A 的直接后果）：** GPU batch 的前提是所有个体共享同一个权重矩阵。本版阶段 A 的 E 在个体间与时间上都在变（生长/裁剪）→ **GPU 只能用于多种子（同规则不同种子），不能用于多结构**。

### 16.3 结构自生长实验（15 版，未跑通）

#### 最终状态（`grow_v2.py`，8 种子 × 5 万步）

```
mode=C  E0=30000（过度生产） -> 预算=15000  steps=50000  种子=8

seed       E    born   drop   rate%    std%  deg_E/I   n_inh  turnov
0      15000     118  14614    0.08    0.09 15.0/14.8    5945  0.0028
1      15000     115  14640    0.09    0.09 15.1/14.7    5883  0.0029
...（8 个种子同形）

  跨种子: rate 0.08%±0.00  波动 0.09%±0.00   tov 0.00291±0.00024
  耗时 5.1s (总 79179 步/秒)
```

**怎么读这组数：**

| 观测 | 值 | 说明 |
|---|---|---|
| rate | **0.08%** | 目标 1.99%，差 25 倍——网络基本死了 |
| turnover | **0.0029** | 看起来「结构收敛了」，但配合 0.08% 是**收敛到死网** |
| born | 115 / 5 万步 | 新生几乎停了——共激活几乎不触发，没有「值得强化」的东西 |
| n_inh | 5950（占 40%） | 目标是 20%；**抑制边占位漂移**，竞争把它们留住了 |
| E | 15000 = 预算上限 | 预算在起作用（这是唯一按设计工作的机制） |

#### 四个确凿的机制性发现（有数据）

1. **性能：最初的实现是根本性错误**——用稠密 N×N（100 万格）存只有 8000 条边的图，每次衰减/剪除都要碰 100 万格；单线程细粒度 numpy 调用，CPU 只占 1/20 个核。改稀疏边列表 + 8 进程后：**7.6~7.9 万步/秒（快约 60 倍）**。（已沉淀为 AGENTS 教训「用稠密结构存稀疏数据」。）
2. **均质网络只有两种态，没有中间态**——固定结构扫 w：0.02~0.25 全部 **0.19%**，0.30~0.70 全部 **100%**。
3. **缺三个基本动力学要素，而它们都是实现错误**——① E/I 平衡（全兴奋只有全或无）② 不应期（放电率无上界，抑制比拉到 10 倍仍卡 20~30%）③ 硬预算 + 竞争（新建边无代价 → E 从 8000 涨到 28000、淘汰只有个位数）。加了之后 rate 才能稳定在 1.99%。
4. **衰减与强化的平衡是难点**——全局衰减把已强化的边也磨掉（0.50 → 0.145，5 万步衰减到 29%），共激活强化补不回来 → 死亡螺旋。改成「只衰减闲置边」后仍有抑制边占位漂移问题（20% → 40%）。

#### 根因推断（未验证）

**三个时间尺度不对齐：** 结构更新每 20 步、稳态窗口 200 步 → 结构变化比稳态快 10 倍，稳态永远在追移动目标。

#### 当时认为的下一步（当时未做）

把结构更新周期拉到与稳态同尺度（200~2000 步），且**逐项加机制**（先只开「共激活强化 + 闲置衰减 + 硬预算」，验证 rate 能稳住 2%，再加随机新建/退火），而不是一次全开。

### 16.4 一个认识修正：这不是 SA

起因是 Jerry 追问：「刚才说这已经不是 SA 了。你难道不是给定规则然后让它自己长？」——是，所以「SA 形态」这个标签从一开始就是错的。

| 当时说过的 | 错在哪 |
|---|---|
| 「单个体是 SA 形态 + 多次重启」 | SA 必须有目标函数 E(x)；这里没有。竞争是局部的（用得少就死），不是全局适应度 |
| 「温度 = 可塑性」 | SA 温度控制「接受更差解的概率」；这里不计接受/拒绝。只能说「可塑性随时间衰减」 |
| 「多次重启」 | SA 里重启为跳出局部最优；这里是**测种子鲁棒性**（草案要求 N≥5），目的完全不同 |
| 「局部 + 偶尔大跳 = SA」 | 「大跳」在 SA 里为跳出局部最优；这里的随机新建是**补局部规则够不着的部分**（长程连接）。没有最优就谈不上跳出 |

**根因：修正了结论却没回扫前面基于错误前提说的话**——正是 AGENTS 里刚写过的「前提修正要回扫全文」，又犯一次。

**这个修正牵出更深的问题（可能就是实验跑不通的真正原因）：** 没有目标函数，那「竞争」依据什么？实现里是「没被激活就被淘汰」——但**「被激活」本身取决于网络当前状态**，所以它是**自洽的**，不是**有方向的**。自洽的规则可以收敛到任何东西，包括退化状态（实验里收敛到 0.08% 的死网）。再往下：**输入是随机泊松、没有任何结构**，没有东西「值得学」，也没有东西能区分有用与无用的连接。

→ **下一步不是调参，是给输入加结构**（周期分量 + 可预测模式）。有结构后「能预测的活下来」才成立，这才是「用进废退」有意义的前提。这正是 `design.md` §14.8「环境反馈是锚，不是训练信号」——当时一个锚都没有。

### 16.6 闭环实验（2026-10-24）

**起因（Jerry）：** 之前失败有两个根因，只修了一个——① 输入没有意义；② **没有输出、没有反馈，这样在它内部说什么都没有区别**。本实验修 ②。

**形态（按 Jerry 给的）：** 输出不是外挂读出层，而是**回路里的两个普通神经元**（index 500/501）——它们的放电率被解码成动作，动作推进世界，世界状态又作为输入回来。闭环：`s(t) → a(t) → x(t+1) → 输入(t+1) → s(t+1)`。

世界 = 两个继承变量的周期驱动（快 T=20 步 / 慢 T=500 步）+ 动作推动 + 噪声。输入 = 世界状态的两个通道（前 50 个输入神经元看快模态，后 50 个看慢模态）。反馈 m = 稳态门 × 能动性（动作方差代理）。

**脚本：** `test/grow_world.py`（五个版本都在同一个文件里，头部注释保留了逐版修正记录）。

#### 五个机制缺陷（每一个都由数据打出）

| # | 缺陷 | 数据 | 修正 |
|---|---|---|---|
| 1 | 「闲置衰减」判据错：闲置 = 本步前后同时放电 | 每次保护 68 条 / 衰减 14932 条（**1:221**），等价全局衰减；rate 0.11~0.14% | 改为「前神经元 IDLE_WIN 步未放电」 |
| 2 | 就算判据改对，衰减的时间尺度也错 | 每 20 步仍衰减 2822 条（**1:141**）——活动率 0.5% 时绝大多数边在 20 步内不会被用到 | **衰减关闭**：硬预算已经是「用进废退」的实现 |
| 3 | 世界发散 | 纯旋转 + 恒定动作 → 幅度涨到 24.5（open 组 5.8），观测被 clip 成常数 | 改为有界变量 |
| 4 | 结构冻结（turnover 恒为 0） | 强化只覆盖「本步同时放电的对」= **0.45% 的边**；新边权重 0.08 远低于存量 → 新建即被淘汰 | 强化改成**资格迹**（`Δw = η·e_ij·m`），覆盖全部边 |
| 5 | 抑制边沙溢 | n_inh 从 40% 涨到 **73%**，rate 0.36% | 淘汰按**类型上界**归一化 + 新建边固定小权重 + **年龄保护**（25 次更新内不淘汰） |

**缺陷 1 / 2 / 4 同时解释了 `grow_v2` 那 15 版的死网**：它的 rate 0.08% 不是「结构不能自生长」，而是「衰减判据错 + 强化只覆盖 0.45% 的边」。同样参数、同样网络，修掉之后 rate = 1.55%。

#### 结果（5 万步 × 8 种子，同种子集可比）

| 组 | rate% | turnover | n_inh | a-o 相关（最大种子） |
|---|---|---|---|---|
| **closed**（闭环） | **1.55 ± 0.44** | 0.0450 | 6705 | **0.507 / 0.369 / 0.559** |
| open（断开动作） | 1.88 ± 0.11 | 0.0483 | 6813 | 0.082 / 0.100 / 0.041 |
| randact（动作随机化） | 1.80 ± 0.20 | 0.0488 | 6844 | 0.030 |
| noise_in（输入白噪声） | 1.39 ± 0.53 | 0.0424 | 6572 | 0.032 |
| frozen（结构冻结） | 2.09 ± 0.23 | 0 | 5921 | 0.114 |

#### 三条结论

1. **闭环管道建成且可测。** 动作与观测的相关在 closed 组达 0.51，open 组 0.10。**它证明的是「动作进入了观测通道」（回路连通），不是「感知到自己造成的后果」**——后者要求内部形成「我这么做 → 会这样」的预测，本版没有测（2026-10-24 订正：原写「直接证据」，超出数据能支持的范围）。
2. **闭环有动力学效应，但方向不是「变强」。** closed 比 open 的 rate 低 0.33、方差大 4 倍（0.44 vs 0.11）：反馈让部分种子进入低活动吸引子（0.82 / 0.89），部分保持（2.05 / 1.96）。这是**状态依赖增强**，不是学习。

   一个没被讨论的对照细节：**frozen 组 rate 最高（2.09 ± 0.23），closed 最低（1.55）**——结构可塑性把活动率压低，方向与「可塑性让网络更活跃」的直觉相反。含义未查。
3. **没有任何指标显示「学」发生了。** 本版只测了「活」（rate / turnover / 结构）与「闭环是否建立」（a-o 相关），**没有测功能**：预测误差是否下降、动作是否变得有效、内部状态是否对行为有因果作用。

#### 已知的形态问题

- **输出神经元能否被接线是随机的**：8 个种子里有 1~3 个的入度只有 6~8、放电率为 0（闭环实际未建立）。这本身是一个观测（结构没有长出「输出通路」），但会稀释组间比较。
- **世界过于简单**：两个继承变量的周期驱动，动作只能推两个标量。足以测「闭环是否影响结构」，不足以测「有没有学到世界的结构」。
- **能动性用动作方差代理**，不是「动作对世界的实际效果」——后者需要更长窗口的相关估计。
- **一次未成形的假设（保留，供下版参考）**：先把世界做成循环相位，结果 closed 与 open 完全无差异（1.44 vs 1.50）。原因：随机动作只是给世界加随机相位，统计上与 open 组的相位噪声不能区分。改成「带漏的积分变量」后差异才出现（a-o 相关 0.51 vs 0.10）。

### 16.8 功能测量（2026-10-24，首轮：否定）

**起因：** §16.7 第 2 项——§16.6 只证明「管道通了」（rate 正常 + 动作与观测相关 0.51），没有任何指标显示「学」发生了。

**装置：** `test/grow_func.py`（565 行，基于 `grow_world.py`，**动力学一行未改**，只加测量）。三项测量 + 两项诊断：

| 测什么 | 怎么做 |
|---|---|
| ① 预测误差 | 读出层 `Wp·s[t]` 预测 `o[t+1]`；前一半步在线 LMS，后一半**冻结**；**零模型 = 预测「与上一步相同」** |
| ①′ 离线最优读出 | 同一批数据用正规方程解最优 `W*`（前半段训练、后半段测试）——用来区分「没信息」与「在线没学好」 |
| ② 动作增益 | `a[t-1]` 解释 `o[t]-o[t-1]` 的方差比例（分段 R²） |
| ③ 前史因果 | 同 seed / 同输入，只把初始膜电位加 `1e-3`，比较输出放电分段计数 |
| 诊断 A 因果方向 | `a[t]` 与 `o[t+k]` 的互相关（k ∈ [-20,20]）：正侧 > 负侧才是「a 驱动 o」 |

#### 诊断 A：闭环的因果是双向的，真正「a → o」的成分只有 ~0.09

`a[t]` 与 `o[t+k]` 的互相关（8 种子 × 5 万步，最大通道）：

| 组 | 负延迟侧均值（k<0，o 领先） | 正延迟侧均值（k>0，a 领先） | 峰值 |
|---|---|---|---|
| closed | 0.3395 | **0.4265** | k=+18，0.4377 |
| open | 0.041 | 0.034 | 全平（~0.04） |

**读法：** 正侧 > 负侧 → 「a 驱动 o」这一半**确实存在**（open 组两侧全平，证明 closed 的耦合不是假的）。但两侧都高（0.34 vs 0.43），说明 0.51 的相关里**大部分是共同驱动或反方向**（o → 输入 → 网络 → a与慢周期的共同趋势）——真正的因果成分约 **0.09**。

这解释了后面 ② 为什么 R² 只有 1%：**动作对世界的影响被外源周期淹没了。**

#### 主结果：预测判据否定，且不是「读出层没学好」

8 种子 × 5 万步，前 2.5 万训练、后 2.5 万冻结（比值 = 误差 / 零模型误差；<1 才算学到）：

| 组 | pred/base（后 5 段） | 离线最优 ls/base（后 5 段） | 动作增益 R²（前四段 → 后四段） |
|---|---|---|---|
| closed | 1.005（1.002~1.011） | **1.10~1.17** | 0.0058 → 0.0115 |
| open | 1.006（恒定） | **1.08~1.25** | 0.0000 → 0.0002 |
| frozen | 1.013（1.011~1.018） | **1.03** | 0.0161 → 0.0169 |

**三条读法：**

1. **`pred/base > 1` 在所有组、所有段**——预测器比「猜不变」更差，而且**离线最优读出更差（1.03~1.25）**。→ 已排除「在线 LMS 没学好」这个解释：**即使给最优线性权重，也预测不过「猜不变」**。机制：泛化时 `E[d·Ws] ≈ 0` 而 `E[(Ws)²] > 0`，所以过拟合的解必然比零模型差——这正是观察到的。
2. **没有任何一组出现下降趋势**（open 完全平，closed / frozen 只是波动，且 ls/base 随段**上升**）。→ 冻结读出层后，网络状态**没有变得更好预测**。
3. **动作增益 R² 在 closed 上升（0.0058→0.0115），但 frozen 更高（0.0165）且恒定** → 不能归因为「学到动作的效果」；更可能是**结构可塑性让网络前期乱、后期稳**（frozen 结构固定，从第一步就稳）。

#### 前史因果：3/8 种子持续发散，5/8 完全同步

| seed | 偏差（前 1k 段） | 偏差（累计） | base / pert 输出率 |
|---|---|---|---|
| 1 | 13 | **1286** | 0.037 / 0.018 |
| 5 | 39 | 341 | 0.047 / 0.048 |
| 7 | 12 | 418 | 0.000 / 0.000 |
| 0 / 2 / 3 / 4 / 6 | 0 | **0** | 相同（完全同步） |

**读法：** 3 个种子对 `1e-3` 的初始扰动持续放大（正 Lyapunov），5 个种子扰动被完全吸收。**这是「发散 / 收敛」的二分，不是「记住了什么」**——发散可能只是混沌（敏感但不携带内容）。所以判据 ③ 只完成它字面上的作用：**排除「输出仅由当前输入决定」**（3/8 成立），不构成「学到」的证据。

#### 结论

> **⚠️ 2026-10-24 事后限定（重要）：这一轮的否定是 trivial 的。**
> 本实验的系统**没有给任何奖励 / 教师信号**——`m = steady_gate(rate) × (0.2 + 0.8 × 动作方差)`，
> 其中没有任何一项与「结果好坏」有关。按 `design.md` §5.1 的路线，这已经是**阶段 3**
> （自反馈自主学），而阶段 1/2（教）一步没做。**在无学习信号的系统上测「有没有学到」，
> 结果必然是「没有」，且不说明任何关于机制的事。**
> 带着教师信号的版本见 §16.9（+40 个百分点）。本节的数值保留，但结论只能读成
> 「无信号 = 不学」，不是「这套机制学不了」。

**首轮功能判据：三项里两项否定，一项仅作排除。没有证据显示「学」发生了。**

三个层次，从硬到软：

1. **状态里没有可线性读出的「下一步」**（离线最优也差于零模型）——这是最硬的一条。
2. **动作对世界的影响太弱**（R² 1%，因果成分 0.09）——即使有表征也测不出「能动性上升」。
3. **没有下降趋势**——不是「还没学好」，是「没有在变好」。

**但真正的根因是第三个：这个系统本来就没被给过学习信号**（见上方限定）。
前两条只说明「在这个无信号系统里没有自发出现表征」，不能当成机制结论。

#### 已知的形态问题（下一轮的入口）

- **预测目标选得太弱。** 零模型误差只有 3e-4 ~ 9e-4（`o` 每步变化极小，因为 `tanh` 饱和 + 慢周期），改进空间本身就不大；同时 `s` 极稀疏（rate 2%、每步 ~20 个放电），单步线性读出能拿到的信息很少。**换目标（多步 `o[t+k]` / 累积量 / 表征而非预测）比改动力学便宜，应先试。**
- **世界太简单**（§16.6 已记，本轮首次量化）：`K_PHASE=0.05` 对 `AMP=0.10`，动作贡献被压到 1% 方差。
- **「状态有没有表征当前观测」还没测**——这是比「预测未来」更基础的一问；若连同期都读不出，问题在信息容量（rate 太低），不在学习。

### 16.9 阶段 1/2：教它说话（2026-10-24）——学到

**起因（Jerry）：** 「你这奖励信号根本没给啊」+「我之前说过，分阶段，先教说话，思考，再让它去自己探索，进行一个基于自反馈的学习」。

两条合起来是一件事：**§16.6 / §16.8 做的是阶段 3（无任务、无教师、自反馈），而阶段 1/2 一步没做。**
在没给学习信号的系统上测「有没有学到」，否定是必然的（§16.8 已加限定）。

#### 形态（阶段 1/2）

| 项 | 内容 |
|---|---|
| **「说话」** | **4 个词 = 4 个输出神经元**（500–503，one-hot）+ **侧抑制**（−1.5，词与词竞争） |
| **输入** | 4 个词各对应 25 个输入神经元的空间模式（目标区 3%、其余 0.1%） |
| **教师信号** | 每个 trial 结束比对目标词与说出的词，**按神经元分配**：该说没说 → +1；不该说却说了 → −1；已对 → 0 |
| **可塑性** | 只更新「突触后是输出神经元」的接口边（内部边不动）；淘汰时接口边受保护 |
| **判据（先写死）** | **正确率**。4 类随机 = 25% |

#### 六个实现缺陷，每一个都把正确率钉在 25%

这一轮共修 6 处，每处都有诊断数据。它们是**确定性错误**（每次都错在同一处），不是「机制难」——
与 AGENTS 2026-10-24「稳定失败更像确定性错误」那条完全对得上。

| # | 缺陷 | 诊断数据 | 修正 |
|---|---|---|---|
| 1 | **输入率过高** | `IN_HI=0.15` × 25 神经元 ≈ 3.75 脉冲/步（grow_world 是 ~1）→ 网络过雪崩临界点，rate 冲 89%（全饱和） | 降到 `IN_HI=0.03` / `IN_LO=0.001` |
| 2 | **`m_wrong = −1` 全局削弱** | 4 类里 75% 在削 → 输出神经元入度从 25 崩到 **5**、放电 0.01，永远说同一个词 | 改成「只学错的地方」（已对 → 0） |
| 3 | **`m` 是一个标量** | 表达不了「一个该强一个该弱」——网络只能学会「这次整体好不好」 | 改成**按神经元分配** `m[post]` |
| 4 | **自适应阈值（中位数）** | 把高/低定义成「高于自己」→ 四个词永远均匀分布，曲线平在 **0.25** | 改回绝对阈值（后来改成 argmax） |
| 5 | **编码方式（2 神经元 2 bit）** | 要求两个神经元对 4 个输入块各自有区分且组合恰好 4 种——60 条随机接口边学不出来（3000 trial 只 **+3 pp**） | 改成 **4 神经元 one-hot + 侧抑制**（拆成 4 个二分类） |
| 6 | **输出神经元不应期 = 20** | 最大放电率被锁在 **5%**，20 步窗口期望只有 **0.44** 次放电——物理上无法区分高低 | 输出神经元单独 `T_REF_OUT=4`（`design.md` §14.6 作用点一：读出阈值） |

**转折点是一个诊断脚本（`test/probe_out.py`），不是又一轮猜测。** 它量的是「四个词下输出神经元的
放电数有没有差异」，一行输出（`spread=0.33 < 0.5` + `cnt 恒为 0.9`）就把问题钉死了。
前五轮我都在猜（改 m、改阈值、改学习率），每一轮都花了一次完整跑。
**教训：怀疑「学不到」之前，先量「读得出吗」。**

#### 结果（8 种子 × 1 万 trial）

| 组 | 早期（前 400 trial） | 晚期（后 400 trial） | 提升 |
|---|---|---|---|
| **teach**（正常教师） | 25.8% | **65.8%** | **+40.0 pp** |
| rand_m（m 随机 ±1） | 26.4% | 24.5% | −1.8 |
| no_teach（m 恒 +1） | 24.4% | 24.2% | −0.2 |
| frozen（可塑性关） | 25.3% | 26.2% | +0.9 |

**曲线（teach，每 200 trial）：** 0.26 → 0.26 → 0.30 → 0.33 → 0.36 → 0.37 → 0.37 → 0.42 → ……
→ 0.59 → 0.62 → 0.65 → **0.66** ——单调上升，8 个种子晚期落在 **62.0%~73.5%**，无离群。

#### 三条结论

1. **阶段 1/2 成立：给定教师信号，结构可塑性能够学。** 正确率从随机 25% 升到 **65.8%**，且
   三个对照全部平在随机水平——**学的来源是教师信号**，不是可塑性、不是统计巧合。
2. **验证了路线本身：之前测不到「学」，是因为在阶段 3 上测。** 同一个网络、同一套动力学、
   同一套可塑性，加上教师信号就从「0」变成「+40 pp」。
3. **可塑性把网络变稀疏了**：teach 组 rate 0.13~0.51%，frozen 组 1.7~2.5%；输出神经元入度
   从 88 增长到 250~322（学习把接口边抽出来了）。侧面说明它是「用少量活动完成任务」，不是靠整体兴奋度高。

#### 两个尚未解释的观察

- **conf（窗口放电总数）在 teach 组是「错时更多」（2.84 vs 3.05）**。若按「自信时说得多」的直觉，
  应该反过来。它可能只是「说错时选了一个高频词」——但这直接关系到阶段 2「知道自己不会」，
  要单独测。
- **rand_m / no_teach 的 conf 是 ~15（饱和），teach 是 ~2.8（稀疏）**。无方向的强化把输出推到饱和，
  有方向的教师信号反而让它稀疏。机制未查。

#### 与阶段 3 的关系

阶段 1/2 的「教」和阶段 3 的「自反馈」不是两套机制，而是**同一个三因子规则的不同 `m` 来源**：

| 阶段 | `m` 从哪来 | 本项目的实验 |
|---|---|---|
| 1/2 | **教师**（对错 / 该不该说） | **§16.9（本贡）—— 学得到** |
| 3 | **自反馈**（稳态 × 能动性 × 惊讶度，`design.md` §14.6） | §16.6 / §16.8 —— 尚未给全 |

所以 §16.8 的下一步（换预测目标、加强动作影响）仍然是阶段 3 的事，应排在阶段 2 之后。

**可复现：**

```bash
python test/grow_teach.py 10000 8 8 teach,rand_m,no_teach,frozen
python test/probe_out.py     # 诊断：输出神经元能不能区分四个词
```

### 16.10 阶段 1/2 v2：脉冲刺激 + 事件发射 + 连续状态（2026-10-24）

**起因（Jerry 两点连续指出）：**

1. 「你有该说没说、不该说却说了，但是没有给它『晚点说』的机会，这就失去了内部连续状态的意义。」
2. 「教师的输入难道是持续激活的？这玩意不应该是一个脉冲？」

两条指向同一件事：**§16.9 的「教」是个复杂版 RNN**——每 40 步清空状态、固定 20 步窗口取 argmax、输入一直亮着。
三个设计里明确要求的东西一个没做：一条不间断的时间轴（§11.4 阶段 B）、发射是事件（§10.8 N5）、
输入是偶发事件（§11.4.0）。

**装置：** `test/grow_talk.py`（与 `grow_teach.py` **不同文件**，因为形态变了）。

| 项 | grow_teach（v1） | grow_talk（v2） |
|---|---|---|
| 时间轴 | 40 步一个 trial | **一条连续时间轴**（300 步一次呈现） |
| 状态 | 每 trial `trace[:] = 0` | **永不清空**（v / s / ref / trace / theta 全部连续） |
| 输入 | 每步持续 3% 速率 | **脉冲**：20 步内 2 次同步爆发，之后只剩背景 0.1/步 |
| 输出 | 固定窗口 argmax | **事件**：第一个放电的输出神经元就是它说的词（first-spike） |
| 奖励 | 每 trial 一次 +1/−1 | **衰减信号** `m *= exp(-1/TAU_M)`，每 5 步写一次 |
| 偏置 | 固定 0.05 | **可学**（design.md §14.6 作用点二：节点偏置 → 行为频率） |
| 稳态 | 无 | **阈值适应**（放电后 θ+=0.2、按 τ=100 回落）——它自己清理短期 |

#### 九个实现缺陷（每一个都把正确率钉在 25%）

这一轮比上一轮更狠：**九处**，每处都有诊断数据。共同特征与 AGENTS 2026-10-24「稳定失败更像确定性错误」完全一致——
不是机制难，是每次都错在同一处。

| # | 缺陷 | 诊断数据 | 修正 |
|---|---|---|---|
| 1 | **偏置被花式索引复制掉** | `bias[OUT_IDX] += x` 不写回（花式索引返副本）；`clip(out=)` 也不生效 → 偏置无界跌到 **−5.7**，全沉默 | 先算再赋值 |

`probe_in.py` 的 5 行输出（指向输入区的边 658 / 接口边 359 / 块分布 `[66,62,60,60]`）一次拓出缺陷 5-8。

|---|---|---|---|---|
| **teach** | 25.0% | **75.0%** | **+50.0 pp** | **78.6%**（n=1600） |
| frozen（不学） | 25.0% | 50.0% | +25.0 | 46.3% |

#### 最重要的结果：记忆跨度 = τ，没有巩固

同代码只改回答开始时刻（`--delay`）：

| delay | 早期 | 晚期 | 提升 | 延迟桶正确率 |
|---|---|---|---|---|
| **20** | 25.0% | **75.0%** | **+50.0 pp** | **78.6%** |
| 50 | 25.0% | 25.0% | **0.0** | 25.4% |
| 100 | 50.0% | 50.0% | **0.0** | 22.6% |
| 150 | 25.0% | 25.0% | **0.0** | 24.2% |

**跨度在 20 与 50 步之间，而膜电位时间常数 τ = 20 步。** 两者完全对得上。

这与 `design.md` §2.10 的判断逐字对应：

> 时间只存在于两处 —— **状态衰减**（τ 在这里）、**巩固窗口**（两次同模式激活多久内算同一次经验）。

**现在的实现只有前者。** 所以“记忆”就是膜电位在 τ 内没衰减完；一旦超过 τ，信息就彻底没了。
下面是 20 步内能记住、50 步就忘干净的机制解释：**从未发生过“从状态进连接”的转化**。

#### 三条结论

1. **形态改对了。** 脉冲刺激 + 事件发射 + 永不清空的状态，能够学（+50 pp）。而在 v1（持续输入 + 固定窗口）里，
   同样的事只需要“看着刺激做分类”——内部状态毫无用处。
2. **工作记忆已存在，但它是“漏水的桶”。** 跨度 = τ = 20 步，靠的是膜电位残留，不是连接。
3. **缺的那一层是「巩固」，不是更长的 τ。** 把 τ 调大不会产生长期记忆，只会把“漏水”变慢（`design.md` §2.2：单细胞 τ 在强递归下被抹平）。
   需要的是：同一模式反复出现 → 那批连接被强化 → 网络能在没输入时重建活动。

#### 已知形态问题（下一轮的入口）

  要做“真”实验，接口应该给得更少，让学习承担更多。
- **内部边虽然参与学习（全局 m），但没测到效果**：delay=50 时正确率完全不升，说明全局 m 太粗糙，
  或 e_ij 的选择性不够。真正的信用分配（固定随机反馈通路）还没做。
- **输出神经元仍有背景放电**（0.02/步），会污染“什么时候说”这个决策。
- **只跑了 2 种子**（每个 mode 800 呈现 ≈ 48 s）；8 种子结论更硬，但本轮优先把机制打通。

### 16.11 阶段 0：放电率稳态下的结构自生长（2026-10-24）

**起因（Jerry）：**「你根本没有做衰减？」+「自组织稳态还没做，我认为这是保持一个稳定内部状态的前腿」。

两句都指向同一个缺口，而且我之前弄错了对象：

| | 我之前做的 | PLOS CB 2022 的 |
|---|---|---|
| 调什么 | 权重 `w`（按时间衰减） | **连接数量**（有/无这条边） |
| 按什么调 | 时间（多久没用到） | **放电率偏离目标** |
| 方向 | 单向（只减） | **双向**（太高→裁、太低→长） |
| 粒度 | 每条边独立 | **按神经元** |
| 目的 | 清理不用的连接 | **把放电率拉回目标** |

我把这三种机制混成一个词，然后基于两次错误实测（1:221 / 1:141）把整个方向删了。
**「按时间衰减权重是错的」这个结论可能还对；但由此推到「衰减不要做」把正确机制一并否掉了。**

#### 装置：`test/grow_homeo.py`

形态照 PLOS Comput Biol 2022（*Homeostatic control of synaptic rewiring in recurrent
networks induces the formation of stable memory engrams*）：

> ① "We initialize a network with random connections to and from inhibitory neurons
>     and **no excitatory-to-excitatory connections, whatsoever**."
> ② "The controlled variable is the firing rate of excitatory neurons, the target rate
>     is set to ν = 8 Hz"
> ③ "After a long-enough growth time, the network structure has reached its equilibrium
>     and all neurons fire at their target rate"

实现：初始**无 E-E 边**（只有 E→I、I→E、I→I、输入扇出）；每个兴奋神经元一个放电率 EMA
（τ=500 步），每 50 步：超标 → 按偏差概率删它的 E-E 入边；不达标 → **按共激活迹加权**新建入边。

#### 六个实现缺陷（每个都有实测数据）

| # | 缺陷 | 诊断数据 | 修正 |
|---|---|---|---|
| 1 | **输入扇出被当成 E-E 边** | `(pre<N_E)&(post<N_E)` 把 100 条输入扇出中 post<800 的 ~3900 条算进来；而且稳态会去**裁掉感觉输入** | `_ee_mask` 要求 `pre >= N_IN` |
| 2 | **`rate_ema` 每 chunk 被重置** | 每次 `simulate` 重新 `np.full(N, R_TARGET)` → 打印的 0.73% 其实是「0.8% 衰减 50 步」的假象（0.008×0.998⁵⁰=0.0072），不是放电率 | 由调用方传入并返回；初值 0 |
| 3 | **抑制完全主导** | BG 从 0.004 到 0.015（3.75 倍），rate 恒为 0.07%——200 个抑制神经元每个扇出 140 个兴奋，每步 3 个抑制放电 × 140 = 240 个兴奋被 −2.5 打击，而只有 10.5 个兴奋得到 +3.0 | 扫描（`test/scan_base.py`）→ `W_I=-1.0 / D_IE=0.05`：E_rate 0.41%，692/800 活跃 |
| 4 | **背景输入太低起不来** | BG=0.004 时 rate 0.06%：源不活跃 → 边长也没用 → 永远起不来（鸡生蛋） | BG=0.015（rate ≈0.48%，低于目标区间下限 0.64%） |
| 5 | **生长太慢** | P_NEW=0.06、rate 0.51% 时 rel=−0.375，533 个不达标 → 12 条/50 步 → 长到入度 25 需 5.5 万步 | P_DEL/P_NEW → 0.30 |
| 6 | **生长无选择性（最关键）** | 从「所有活跃神经元」均匀随机挑源 → **只保证放电率，不含任何选择性** → 4 个 cue 的模式相似度 **0.996**（单一态） | 改成**按共激活迹加权**选源（`p_src = trace / trace.sum()`）→ 0.885；probe 关掉背景后 **0.405** |

#### 结果

**结构生长（seed 0，25000 步）：**

| 步 | E-E 边数 | E 均值率% | 超标 | 不达标 | 活跃数 |
|---|---|---|---|---|---|
| 50 | 0 | 0.05 | 0 | 800 | 178 |
| 2100 | 1161 | 0.48 | 92 | 567 | 664 |
| 9950 | 16294 | 0.55 | 101 | 519 | 721 |
| 16550 | 21323 | 0.59 | 100 | 490 | 773 |
| 39650 | 23123 | **0.61** | 94 | 479 | 789 |

边数收敛（23000），放电率也稳住了，但**没有到达目标区间的下限 0.64%**——形成两个群体（约 100 个超标的、480 个不达标的、其余在区间内），
而不是 PLOS CB 描述的「所有神经元都在目标率」。原因待查。

**多吸引子（共激活生长 + probe 关背景，30000 步）：**

| seed | E-E 边数 | 4 个 cue 的总放电 | 两两相似度均值 | 判定 |
|---|---|---|---|---|
| 0 | 13756 | 205 / 148 / 162 / 162 | **0.405** | **有区分（多吸引子）** |
| 1 | 14095 | 479 / 514 / 980 / 711 | 0.801 | 部分区分 |

#### 三条结论

1. **「按放电率的双向结构可塑性」跑通了。** 初始无 E-E 边，靠稳态闭环长到上万条边，率稳定、活跃神经元数从 178 涨到 789。
2. **共激活是必要的，不是可有可无的装饰。** 同一套稳态规则，源选取从「随机」改成「按痕迹加权」，相似度从 0.996 → 0.405。这正是 PLOS CB 里 engram 的形成机制：**反复共激活 → 连接长在一起**。
3. **会但不稳。** 2 个种子里 1 个长出多吸引子、1 个没有。按项目一贯的判据（N≥5）这不能算成立。

#### 已知问题（下一轮入口）

- **率没到目标区**（0.61% vs 0.64~0.96%）：形成两个群体而不是全体达标。可能原因是删除按「post 超标就随机删它的入边」（不区分强弱），而生长只给不达标的加边。
- **只跑了 2 个种子**。同样的原因（每种子 16 秒 × 4 cue）。
- **probe 没有「读出」**。PLOS CB 测的是「给 cue → 读出神经元是否放电」（条件反应），我测的是「关掉输入后的活动模式相似度」。后者更直接但不等于条件反应。
- **没测「silent memory」**：PLOS CB 说记忆在自发活动里看不出来（"Due to the homeostatic nature of network remodeling, the ongoing activity after encoding was very similar to the activity before encoding"），要靠 cue 才检索得到。我的 probe 应该加一条「编码前后自发活动的差异」作为反向对照（应该接近 0）。

#### ② probe 的 0.405 混进了「起始态差异」；而真正的问题是活动会归零

**测量面校准（`test/probe_sim_noise.py`）**：一次预热后冻结起始态，同一 cue 重复 3 次（各自独立 rng）。

```
within-cue（同 cue 不同次）  +1.000     ← 逐位相同（probe 期无噪声源）
between-cue（不同 cue）      +0.038     ← 近乎正交
置换对照（打乱神经元标签）     +0.096
```

同 cue 逐位相同、不同 cue 近乎正交 —— 但 **0.038 仍然证明不了多吸引子**：4 个 cue 打的是
4 块**不同的输入神经元**，下游本来就会不同。这是通路差异，不是记忆。

**无输入衰减（`test/probe_decay.py`）**：cue 编码 20 步 → 撤掉全部输入（含背景）→ 观测 1000 步。

| cue | 0–50 步 | 50–100 | 100–150 | … | 总 |
|---|---|---|---|---|---|
| 0 | 59 | **0** | 0 | 0 | 59 |
| 1 | 44 | **0** | 0 | 0 | 44 |
| 2 | 66 | **0** | 0 | 0 | 66 |
| 3 | 54 | **0** | 0 | 0 | 54 |
| 不给 cue | 0 | 0 | 0 | 0 | **0** |

**50 步内归零，之后 950 步一直零。** 连「无 cue 时有自发活动」都做不到。

→ 严格意义上**只有平凡吸引子（全静息）**。0.038 / 0.405 都是「不同 cue 走不同通路后一起熄灭」
的瞬态差异，不是收敛到不同的稳定态。
→ 附带事实：**「吸引子」这个词在三卷 + 主文档里只有 4 处使用、0 处定义**（本场查证）。

#### ③ Hebbian 权重可塑性首轮：阴性，且对照说明它不是「记东西」

`test/grow_hebb.py`：结构冻结（隔离变量），在 E-E 边上加一层慢变量 `A`（论文 PRX 14, 021001 的
`(1+p∂t)A = (k/N)φφ` 的低秩形态），输入两种形态（20 步脉冲 / 400 步振荡），撤输入后观测 1200 步。

| 组 | 尾段放电 | 周期 |
|---|---|---|
| r=0.40 pulse | 34566 | 420 |
| r=0.40 pulse **A 随机重排** | **34077** | 420 |
| r=0.05 osc | 30121 | 380 |
| r=0.05 osc **A 随机重排** | **30042** | 40 |
| r=0.02 osc → r=0.40 osc | 31194 → 34596 | — |

**打乱 A 的空间对应关系 → 效果不变；r 差 20 倍 → 效果几乎一样。** 两条同时成立，说明这个
「持续活动」来自「A 把网络推过了某个分岔点」，不是「A 记住了什么」。周期也不对（输入 100 步，
输出 420 步）。

两个根因（都有算式）：

1. **`A` 是纯偏置，不是涨落。** 实现里 `cn = c / mean(c)` 恒 ≥ 0，所以 `A ∝ cn_i·cn_j` 是一片恒正
   的均匀增益。论文的 φ=tanh 均值≈0，A 可正可负 —— 低秩结构才可能起作用。
2. **网络就压在相变点上。** `g_eff ≈ sqrt(K·w²) = sqrt(17 × 0.25²) ≈ 1.03`，对应论文 g=1
   （g<1 静息 / g>1 混沌）。**而 K=17 是生长过程自己长出来的**，不在参数手里。临界点上的
   特征是任何微扰都推向全灭或全爆 —— 这与「要么 0 要么 30000+」的实测形态一致。

#### 一条方法学结论

`design.md` §2.10 最后一句：

> **在实验给出答案之前，所有「载体设计」都是在给一个可能根本不需要的东西定参数。**

本场做的三件事（probe 校准 / 加 Hebbian 层 / 对齐常数标度）**全部属于这一类**。

`design.md` §0.3 第 5 条写的是「**不发明新参数**——每个常量要么是需求给的，要么有文献出处」。
本场清点两套代码的 46 个常数：有文献值 **1**、本项目实测扫描 **4**、归一化约定 **3**、
**纯拍 30**；另有 3 个「只定义从不使用」的死常数。

**所以下一步不在参数层** —— 见 diary 2026-10-24（场次四）§五，与 `design.md` §9.2（三要素：
结构 / 压力 / 隔离）和 `design.md` §7.3（三因子规则 `Δw = η·m·a_pre·a_post·(a_post−θ)`）的对照。


### 16.13 闭环三步：C 打底 / A 定方向 / 第二次快多少（2026-10-24）

**起因（场次四的判定）：** `design.md` §9.2 三要素里，**压力与隔离均为 0**；`design.md` §7.3 的三因子规则里 `m` 为 0。
本场按 `design.md` §3.4 的顺序（**先 C 预测后果 → 再 A 任务结果**）把两者补上，装置 `test/grow_goal.py`。

#### 形态（与 `grow_world.py` 的差异——所以是新文件）

| 项 | `grow_world` | `grow_goal` |
|---|---|---|
| 世界 | 两个漏积分变量 + 纯周期驱动 | **位置 + 目标 + 扰动**（有成败） |
| 任务 | 无 | **episode**：随机初态 + 随机目标，120 步内到 0.08 内算成功 |
| 动作 | 2 维连续（`tanh`） | **4 个离散**（两个输出的符号对，每 20 步采一次） |
| m | 稳态门 × 动作方差 | **稳态门 × 能动性 × 价值** |
| 判据 | rate / turnover / a-o 相关 | **pred 比 / 成功率 / 第二次快多少** |

三层 m：`m = 稳态门 × (0.2 + 0.8 × 能动性 × 价值)`。能动性 = `corr(a, Δx)`（**不是动作方差**——方差只说明动得多）；价值分两步接。
输入 4 通道各 25 神经元：`x0 / x1 / g0 / g1`（位置与目标都进输入，所以任务**不需要记忆**，它测的是「会不会用当前信息」）。

#### 步 1（C）：预测误差当 m——判据不成立

200 episode × 8 种子。预测目标 = `o[t+20]`（不是 1 步后——§16.8 已记「预测目标选得太弱」）。

| 组 | pred 比（前 1/6 → 后 1/6） | 变化 |
|---|---|---|
| C_full（m = 预测误差） | 0.923 → 0.836 | **−0.087** |
| C_novalue（价值恒 1） | 0.917 → 0.843 | −0.074 |
| C_shuffle（m 打乱） | 0.921 → 0.828 | −0.093 |
| **C_frozen（完全不学）** | 0.907 → 0.842 | **−0.065** |

**判定：不成立。** `pred 比` 在**所有组都下降**，包括完全不学的 `frozen`（−0.065）。
下降来自**线性预测器自己在学**（2×2 的 `Wp` 在线 LMS），网络可塑性没有可测贡献——
`C_full`（−0.087）与 `C_shuffle`（−0.093）的差比和 `frozen` 的差还小。

> 顺带一个事实：`pred 比` 全部 **< 1**（0.83~0.92），而 §16.8 是 **> 1**。差别只在预测距离（1 步 vs 20 步）——
> 零模型「猜不变」在 20 步上弱得多。这确认了 §16.8 把否定归因于「预测目标太弱」是对的。

#### 步 2（A）：任务成败当 m——四组全阴性，且 `align` 全是负的

400 episode × 8 种子。

| 组 | 成功率（早 → 晚） | `align`（动作朝目标） | m 价值项均值 |
|---|---|---|---|
| A_dense（距离桥接） | 9.3% → 8.1%（−1.1） | **−0.431** | 0.25 |
| A_sparse（只成败） | 10.2% → 10.0%（−0.2） | **−0.453** | 0.01 |
| A_noagency（能动性恒 1） | 9.5% → 9.7%（+0.2） | −0.440 | 0.25 |
| A_frozen（不学） | 11.2% → 13.4%（+2.3） | −0.307 | 0.30 |

**没有一组提升成功率；`align` 全部为负（−0.31 ~ −0.45）。** 随机基线 ≈ 8~13%（`frozen` 13.4% 最高——
与 §16.6 的「可塑性把活动率压低」同向：**会学的组反而更差**）。

#### 定位一步：连**固定目标**也学不会

如果只是「泛化难」，固定目标应该能学会。所以把目标固定为 `(0.5, −0.5)`（跨象限，让「恒定动作碰巧命中」的概率最低）：

| 组 | 成功率（早 → 晚） | `align` |
|---|---|---|
| A_fixed（目标固定） | **8.7% → 6.2%（−2.5）** | −0.432 |
| A_dense（随机目标对照） | 12.3% → 10.0%（−2.3） | −0.452 |

**固定目标也学不会 → 不是泛化问题，是「连一个固定策略都学不出来」。**

#### 关键诊断：信息在状态里，接口接不上

先排除「动作饱和」——`|a|` 均值 0.34~0.49（1 = 恒定推力）、切换率 0.20~0.26（每 4~5 个窗口换一次），**没有饱和**。

再用线性探针从网络状态 `s`（1000 维）直接读 `(g − x)`（每 5 步采一次，150 episode × 8 种子）：

| 量 | 值 |
|---|---|
| 线性回归 `s → (g−x)` 的 R² | 0.154 ± 0.008 |
| **符号准确率**（该往哪走） | **0.735 ± 0.074**（0.5 = 无信息） |

**信息在状态里（73.5% 可读出），但动作的 `align` 是 −0.44。** 所以问题不在「网络不知道往哪走」，在**输出接口无法表达它**。

#### 机制解释（为什么接口接不上）

输入编码是 `p = IN_RATE × (1 + GAIN·x)`——`x` 越大，输入越强，网络越兴奋，于是：

```
输出放电率 r_out ≈ f(x)   →   a = sign(r_out − base) ≈ sign(x − 近期均值)
```

**这是「微分」（趋势），而任务要的是「比例」（差）。** 要得到 `sign(g − x)`，需要「g 通道 → 抑制神经元 → 输出」这条**两跳通路**：
新建边若 `pre` 是兴奋神经元则必为正权（`W_NEW_E`），所以「负权」只能经抑制神经元。
而抑制神经元接收的输入与输出目标是随机的——两步同时命中的概率约 `(25/1000) × (2/1000) ≈ 5e-5`，
5 万次投边 × 5e-5 ≈ 2.5 次。**结构上做不到。**

#### 步 3（T）：第二次快多少——不成立（反而更差）

400 episode：`T_seq` 前 200 跑 task A（右上）、后 200 跑 task B（左下）；`T_fresh` 从同一初始结构直接跑 B。

| 组 | phase2（B 段前 1/6）成功率 | 中位数 |
|---|---|---|
| T_seq（跑过 A 再来） | **11.7%** | 9.8% ± 4.5 |
| T_fresh（直接跑 B） | **15.3%** | 13.6% ± 4.6 |

**跑过 A 反而更差（负迁移）。** 这是 A 组学不会的必然结果——没学到任何可迁移的东西。

#### 本场结论

1. **C 打底的判据不成立，但原因是「预测器自己在学」，不是「网络没学到」。** 要分开这两者，需要把预测器冻结（下一版）；本版没法分开，所以 C 的结论只能是「不可判定」。
2. **A 定方向四组全阴性，固定目标也阴性。** 结合探针（73.5% 可读出），**根因是接口可表达性，不是「学不到」**。
3. **`align` 系统性为负**是一个可复现的稳定现象（−0.28 ~ −0.46，跨组跨种子），不是噪声。
4. **「第二次快多少」不成立**（11.7% vs 15.3%）。

#### 下一步（下版的入口，按代价排）

| # | 改什么 | 为什么 |
|---|---|---|
| **1** | **换接口：4 个输出神经元 one-hot + 侧抑制 + 可学偏置**（即 `grow_talk` 的形态，§16.10 它学到了 75%） | one-hot 只需要「相对胜出」，不需要负权：两个神经元各自接不同的输入组合 + 不同阈值就能表达「符号比较」。§16.10 已证明这个形态能学 |
| 2 | 把预测器冻结（或改成离线最优读出）| 分开「预测器在学」与「网络在学」——本场 C 的判据因此不可判定 |
| 3 | 动作改成 5 个（加「不动」）| 现在 4 个必有位移，一旦方向反了就持续走错 |

#### 已知局限（不要把结论放大）

- 环境是**人工世界**，不是 `design.md` §3.6 的「本机命令 3 秒 / 测试 10 秒」。压力是真的（成败由客观判据给），但不是可逆环境。
- 预测器是 **2×2 线性**，能力很弱；R² 0.154 不能当成「状态里只有这点信息」。
- 动作是 4 个离散，测的是「选不选对方向」，不是「控得准」。
- **`n_inh` 36~38%**（目标 20%）——继承自 `grow_world` 的抑制边占位问题（§16.6 缺陷 5 只修了一半）。

**可复现：**

```bash
python test/grow_goal.py 200 8 8 C_full,C_novalue,C_shuffle,C_frozen     # 步 1
python test/grow_goal.py 400 8 8 A_dense,A_sparse,A_noagency,A_frozen     # 步 2
python test/grow_goal.py 300 8 8 A_fixed                                 # 定位：固定目标
python test/grow_goal.py 150 8 8 A_probe                                 # 诊断：状态能否读出 (g-x)
python test/grow_goal.py 400 8 8 T_seq,T_fresh                           # 步 3
```

#### v2（2026-10-24，删 4 个机制 + 补 1 项）：结果仍为阴性，但定位换了

**起因：** 用户追问「参数和机制处理有没有做彻底」。v1 只是把 4 个被证明无用的机制「记账」，代码里一行未动。

**v2 改了三样：**

| 项 | v1 | v2 |
|---|---|---|
| 机制 | 6（强化 / 预算 / 新建 / 全局随机边 / 预测器 / 能动性） | **3**（强化 / 预算 / 新建） |
| 三因子公式 | `dw = η · m · trace[pre] · trace[post]`（恒 ≥ 0，**只增不删**） | `dw = η · m · trace[pre] · (trace[post] − θ)`（**双向**，按 `design.md` §7.3 补上 BCM 项） |
| m 的基底 | `0.2 + 0.8 × 能动性 × 价值`（那 0.2 是拍的） | `m = 稳态门 × 价值`（门控就该是 0 或正） |
| 本地参数 | 37 | **14**（删 PRED_K/PRED_LR，加 TAU_THETA） |

**实现错误两个（都是「稳定失败先查实现」拓出来的）：**

1. **漏传 `P_GLOBAL` / `T_GLOBAL`** —— 消重复时把这两个当「与 `P_NEW` 重叠」略过了，但代码还在用 → `NameError`。
2. **BCM 的 `theta` 算错了对象** —— 先把 `theta` 做成了 `s`（单步放电）的慢平均：实测 `theta` 均值 **0.006**，
   而 `trace` 稳态约 **0.1** → `trace − theta` 几乎恒正，**BCM 项等于没起作用**。
   改成 `trace` 的慢平均后 `theta` 均值 **0.107**（同量级），双向才真正生效。

**结果（200 episode × 8 种子）：**

| 组 | 成功率（早 → 晚） | `align` | m 合成值 | theta 均值 |
|---|---|---|---|---|
| **A**（删完机制 + 补 BCM） | **11.0% → 11.0%（+0.0）** | −0.309 | **0.015** | 0.107 |
| A_frozen（不学） | 8.0% → 13.3%（+5.3） | −0.307 | 0.000 | 0.136 |

第 3 步（400 episode）：`T_seq` 的 phase2 = 14.4%，`T_fresh` = 14.4% —— **平局**（v1 是 seq 更差）。
探针仍为 **0.733**（状态里 `(g−x)` 的符号可读出），而 `align` 仍是 **−0.36**。

**本轮最重要的发现：`m` 的合成值只有 0.015。**

因为 `m = 稳态门 × 价值`，而价值只在「成功后的 T_S 步内」为 1，成功率 ~10% → **m 非零的时间占比约 2%**。
所以就算机制删干净、公式按设计写对，**学习信号本身几乎为零**。

→ **瓶颈不在「机制太多」，在两个更硬的地方：**
① **接口**（探针 0.733 vs `align` −0.31：信息在，表达不出）；
② **m 太稀疏**（只奖励正确 + 成功率低 → 非零时间占比 2%）。

而 ② 正是 `design.md` §14.6 里写了、本实现里**没做**的那一项：**桥接刺激**（中性事件反复与最终奖励配对，成为二次强化物）。
注意它与我试过的「距离桥接」不同——后者是「靠近就奖励」（一个紧的连续信号），前者是「把一个可观测的中性事件与奖励关联」。

**可复现：**

```bash

python test/grow_goal.py 400 8 8 T_seq,T_fresh   # 步 3
python test/grow_goal.py 400 8 8 A_probe         # 探针（慢：107s）
```


### 16.14 `grow_cond` v3（顺手跑）：抢答 50% 与「惩罚即死网」（2026-10-24）

**背景：** `test/grow_cond.py` 是阶段 1/2 的 **v3**（只奖励正确 + VI 课程 + 迹 τ=200），
写在 2026-10-24 03:23，但 **`experiments.md` 里 0 处引用**——写完没跑或跑了没记。本场跑两次把它落定。

#### 运行一：默认（不惩罚）

1200 呈现 × 8 种子，`teach` 组：

| 量 | 值 |
|---|---|
| 正确率（早 → 晚） | 11.9% → 12.2%（+0.3 pp；**随机 = 25%**） |
| **抢答率** | **50.0%（精确：4999~5000/10000，8 个种子全部一样）** |
| 放电率 | 1.66% ± 0.06% |
| 分支比 σ | 0.932 ± 0.024 |
| 分桶正确率（保持 0→399） | 23.6% / 26.1% / 24.9% / 25.9% / 25.8% / 26.8% / 22.2% / 24.1% —— **平的** |

**两个确定性信号：**

1. **抢答率精确 50.0%**——概率性行为不会这么齐。查代码：`n_tot` 是「有事件的呈现数」，抢答与回答各 `+1`。
   所以 50% 的真实含义是**「一半呈现抢答、一半呈现回答」**，而不是「每次都有 50% 概率抢答」。
2. **正确率 11.9% ≈ 25% × 0.5 = 12.5%**——**正好是「抢答的那一半全错」**。

机制：输出在保持期放一次电后，阈值适应（`D_THETA_OUT`）把它压住，回答期不再放电；
该呈现只剩一个抢答事件，且抢答不算正确。**一半的呈现因此被浪费**。

#### 运行二：`--punish`

| 量 | 默认 | `--punish` |
|---|---|---|
| 抢答率 | 50.0% | **0.0%**（压住了） |
| 正确率（早 → 晚） | 11.9% → 12.2% | **4.8% → 0.0%** |
| 放电率 | 1.66% | **0.04%**（网络死了） |
| 分支比 σ | 0.932 | **0.502**（亚临界） |

**惩罚把抢答压住的同时把整个网络打死**——这正是 `grow_cond.py` 文件头记的 v2 教训（「每次都给 ±1，在 75% 错误率下期望 −0.5 → 输出入度从 25 崩到 5」）的复现。

#### 结论：v3 形态不成立

| 配置 | 抢答 | 会说话吗 |
|---|---|---|
| 不惩罚 | 50%（浪费一半呈现） | 正确率被拉到随机的一半 |
| 惩罚 | 0% | 网络死（rate 0.04%） |

**两条路都是死路，需要第三条：结构上禁止抢答**（例如回答窗之前抑制输出，或输出只在提问窗可放电）——
不是靠惩罚去「教它别说」。

> **⚠️ 2026-10-24 撤回「结构上禁止」这个提法：** 「可放电 / 不可放电」不是神经元的属性（膜电位过阈就放），实现上只能是外部注入禁止信号——那正是 `design.md` §2.9 排除的「每步外部条件」；
> 而且它把「何时说」这个**要学**的能力焊死成接线，与判据 A 直接矛盾。见 §16.19「下一轮的入口修正」。

`--punish` 的值保留（它是诊断工具），但 `grow_cond.py` 的默认行为**不应作为阶段 1/2 的结论**。

**可复现：**

```bash
python test/grow_cond.py 1200 8 8 teach,frozen          # 默认：抢答 50%
python test/grow_cond.py 1200 8 8 teach --punish        # 惩罚：抢答 0% 但死网
```

### 16.15 12 条偏离全部处理：本机真实环境 + 三闸 + 隔离（2026-10-24）

**起因：** 用户连续三次追问「上次会话提到的有没有处理干净」。核对结果（见 `test/CONSTANTS.md` 第 6 节）：
场次四列出的 **12 条**偏离里，当时只真正做了 1 条（三因子公式），其余 11 条都是「记账」。
本场全部落实为代码，装置 `test/grow_agent.py`。

#### 逐条落地

| # | 偏离 | 本文件里的实现 |
|---|---|---|
| ① | 不发明新参数 | 全部从 `net.py` 取（带 `[标定]/[约定]/[派生]/[需求]/[拍]`）+ `CONSTANTS.md` 台账 |
| ② | 三因子公式缺 `(a_post−θ)` | `Δw = η · trace[pre] · (trace[post] − θ)`，θ 是 trace 的慢 EMA（τ=200） |
| ③ | 门控只需三个、能手推 | `m_gate(admit, correct, consistent) = admit × (correct × consistent)`——三个 0~1 标量，可手推 |
| ④ | 多吸引子当目标 | 不测它（已是作废项） |
| ⑤ | 更新频率 = 反馈频率 | 结构更新 **每个 episode 一次**（= 每个任务一次反馈）；迹 τ=100 跨过反馈延迟 |
| ⑥ | 三要素：结构/压力/**隔离** | 压力 = 本机真实文件后果；**隔离 = 只写入「本 episode 活跃过」的两端** |
| ⑦ | 环境是锚不是梯度 | 环境层只给「成/不成 + 真实值」，不当梯度；内部层（预测误差）只填空隙 |
| ⑧ | 四层反馈 | 环境层（IO 成败）/ 参照层（**显式未实现**）/ 内部层（一致度）/ 过程层（四度量） |
| ⑨ | 过程四可测量 | 弯路率（仅成功 n）/ 修正延迟 / 依据密度 / 遇意外反应 + 额外 progress |
| ⑩ | 长期记忆只有次数没有时间 | 删掉 `T_S`（每 20 步）——结构更新由 **episode 计数** 触发 |
| ⑪ | 两类可塑性是不是同一规则两端 | `--plast=w / topo / both` 三组对照 |
| ⑫ | 「短期」两个含义 | episode 间插 `T_GAP=200` 步无关输入（逼退隐状态 τ=20）+ 目标持续 5 个 episode |

**环境是真的：** 观测来自 `data/env/<mode>_<seed>/state.txt` 的真实字节；动作是真实写文件（原子写 tmp+replace）；
成败由真实读回的值判定。**IO 成功 1.000，1798 次真实读写**（不是 2D 数学世界）。
接口换成 4 输出 one-hot + 侧抑制（`grow_talk` 形态）。

#### 五个实现错误（**全部是重犯旧错**）

| # | 错 | 数据 | 旧错出处 |
|---|---|---|---|
| 1 | `t_glob` 从未递增 | `u_buf[t_glob % 4096]` 永远同一行 → 输入是固定模式 → **rate 压到 0.00%** | — |
| 2 | 桥接判定用 `ep_detour > −1.0` | `detour` 未成功时是 `nan` → 条件恒假 → **桥接从未生效**（`no_bridge` 与 `base` 逐位相同） | — |
| 3 | `m` 是**标量** | 所有边同等更新 → 学不到「该选哪个动作」 | §16.9 缺陷 3 / §16.10 缺陷 3 **同一个错** |
| 4 | 迹 τ=20 而 episode=120 | 奖励到达时迹已衰减到 e⁻⁵≈0.007 | §16.10（`delay=50` 学不到）**同一个错** |
| 5 | 输出神经元用 `T_REF=20` | 最大放电率 5%，动作窗口 20 步内期望 0.3 次放电 → **argmax 是噪声** | §16.10 缺陷 6 **同一个错** |

**5 个里 3 个是同一个错的第二次**。这不是知识问题，是「上次的教训没进入实现前的检查」。

#### 结果（150 episode × 8 种子）

| 组 | 成功率（早→晚） | 全程 | 依据密度 | m 均值 |
|---|---|---|---|---|
| **base**（全开） | 5.0% → 4.5%（−0.5） | **4.8%** | 0.468 | 0.024 |
| frozen（不学） | 7.5% → 3.5%（−4.0） | **5.3%** | 0.506 | 0.027 |
| no_gate（m≡1） | 6.0% → 6.0%（+0.0） | 4.7% | 0.480 | 1.000 |
| no_bridge | 与 base 逐位相同（桥接未生效，见缺陷 2） | 4.8% | 0.468 | 0.024 |
| no_isolation | 5.5% → 5.5% | 5.0% | 0.469 | 0.011 |

**三组（base / frozen / no_gate）无差异，`依据密度` 均≈ 0.47（随机）。**
过程四度量：修正延迟 87 步、遇意外反应 0.22、弯路率仅 7 个成功样本。

#### 结论：机制对齐不是瓶颈

1. **12 条偏离全部处理后，仍学不到。** 这不是「还差哪个机制」。
2. **对照证明不是 m 的问题**：`no_gate`（m≡1，最强信号）也只有 4.7%；`no_isolation` 无差异。
3. **不是环境的问题**：IO 成功 1.000，`basis` 0.468 说明动作与目标无关——网络根本没利用观测。
4. **真瓶颈候选（未验证）：**
   - **接口拓扑与任务的匹配**：`grow_talk` 能学到 75% 靠的是「out_i 只连块 i」的**拓扑偏置**——
     那是把答案写进结构。本文件用随机接口，同样的一-hot 也学不到。
   - **样本量**：每 episode 只 6 个决策 × 150 episode = 900 次决策、但只 **150 次结构更新**。
     而 `grow_talk` 是 800 个呈现×每次更新。本文件把更新压到「每任务一次」（`design.md` §5.4 的忠实实现），
     **代价是样本量降了两个数量级**。

#### 一条需要提请的判断

「更新频率 = 反馈频率」（`design.md` §5.4）在**任务级反馈**下意味着「每任务一次更新」。
但当任务是「120 步内到达目标」这种短任务时，「每任务一次」= 样本量极小。
**这两个要求在现阶段冲突**，而设计里没有说哪个优先。
两个候选：① 把 episode 拉长（一个任务 = 多次尝试）；② 把桥接做实（中性事件当真二级强化物，而不是一个 0.15 的常数）。

**可复现：**

```bash
python test/grow_agent.py 150 8 8 base,frozen,no_gate
python test/grow_agent.py 150 8 8 no_isolation,no_bridge,plast_w,plast_topo
python test/grow_agent.py 150 8 8 recall      # 跨 episode 回忆（目标不可观测）
```



### 16.16 任务不可完成——一个覆盖全部历史结论的参数错误（2026-10-24）

**这一节是今天最重要的发现。在它之前，`grow_agent` / `grow_goal` 的所有数字都读不出意义。**

#### 错误本身

任务参数是：每一步窗口采一个动作，`T_EP=120`、`T_ACT=20`：

```
动作数 = 120 / 20 = 6
最大移动 = 6 × 1 = 6                （若只用 ±1）
目标差距 = 30 ~ 40                  （FIXED_CASES）
```

**6 < 40。任务在参数上就不可完成。** 无论网络多强、学习规则多对，都到不了目标。

实测坐实：`progress`（走过距离 / 最短需要）恆在 **0.6 ~ 0.75**——
从来到不了 1.0。而这个数字之前被当成「学得不够」，实际是「数学上到不了」。

#### 怎么发现的：先做基线，而不是再改机制

连续 5 轮补丁（first-spike / 不动选项 / 偏置 / 立即反馈 / 沉默信号）
每轮都修了一个真 bug，但 `basis` 始终 0.48~0.50。所以停下求机制，先问一个便宜的问题：

> **这个任务本身可学吗？信息在不在？**

装置 `test/baseline_linear.py`：把脉冲网络全部拿掉，只学一个 2 维线性读出
（`y = Wx + b`，delta rule，**只用与脉冲网络完全相同的反馈**：这个动作朝目标了吗）。

三档（现在参数已修正）：

| 组 | 成功率 | basis | progress |
|---|---|---|---|
| **random**（随机选动作） | **20.9%** | 0.540 | 5.83 |
| **linear**（2 维线性读出） | **99.8%**（8 种子全部） | **1.000** | **1.00** |
| greedy（直接朝目标走，上界） | 100% | 1.000 | 1.00 |

`linear` 学到的权重（seed0）：

```
act  +1 : W = [-0.620, +1.407]   b = +3.221
act  -1 : W = [-0.029, -1.542]   b = +3.041
act +10 : W = [ 0.000,  0.000]   b = 0.000     <-- 完全放弃 ±10
act -10 : W = [ 0.000,  0.000]   b = 0.000
```

**两个结论：**
1. **任务完全可学**（2 个参数、15000 次更新就到 100%）——所以问题 100% 在脉冲网络，不在任务。
2. **±10 是无用动作**（`W` 恒为 0）；它会把差距一步跳过，是纯干扰。

#### 修正后的任务参数

```
T_EP = 240 / T_ACT = 5  ->  47 个动作   （原来 6 个）
最大移动 = 47 × 1 = 47  vs  最大差距 40  -> 17.5% 余量
```

（中间还试过 `T_EP=200` -> 39 个动作：`linear` 的 `basis=1.000`、`progress=0.98`，
但成功率只有 25%——因为 2 个差距为 40 的 case 还差一步。**余量必须 > 0**。）

#### 修正后的脉冲网络结果（200 episode × 8 种子）

| 组 | 成功率（早→晚） | 全程 | 相对 none | basis | 输出放电占比 | bias 均值 |
|---|---|---|---|---|---|---|
| **discrete_none**（什么都不学） | 5.7% → 5.7% | **5.9%** | — | 0.509 | 0.094 | 0.00 |
| random（无网络，每次随机动作） | 19.7% → 22.3% | **20.6%** | +14.7 | 0.535 | — | — |
| **discrete**（bias + 权重 + 拓扑） | 23.9% → 37.1% | **36.2%** | +30.3 | 0.598 | 0.341 | 1.15 |
| **discrete_bias**（只学 bias） | 35.2% → 43.9% | **42.0%** | **+36.1** | 0.604 | 0.338 | 1.12 |
| linear（上界参照，非脉冲） | 98.5% → 100% | 99.8% | — | 1.000 | — | — |

#### 一个被术语掩盖的错误：`frozen` 名不副实

原来的 mode 里，`discrete_frozen` 只关掉了「权重」和「拓扑」两项，而 **`bias` 的更新是无条件的**。
所以它实际是「**只学 bias**」，而**真正的「什么都不学」根本不存在**。后果：

> 「frozen 42.0% > discrete 36.2%」曾被读成「不学更好」——
> 实际是「只学管用的那一层更好」。差了一个完全相反的结论。

修后（三层独立控制）才看清：

| | 成功率 | 相对 none |
|---|---|---|
| 什么都不学 | **5.9%** | — |
| + bias | **42.0%** | **+36.1 pp** |
| + bias + 权重 + 拓扑 | 36.2% | +30.3 pp（**比只学 bias 低 5.8**）|

#### 两个新事实

1. **`none` 比 `random` 还差 3.5 倍（5.9% vs 20.6%）。** 原因：偏置恒 0 时输出基本不说话
   （放电占比 0.094），而「不放电 = 不动」——**不学 = 学会沉默**。
   这意味着：如果没有 `random` 基线，`none` 的 5.9% 会被误读成「网络废了」。
2. **bias 是学习的全部贡献（+36.1 pp）；权重/拓扑是负贡献（−5.8 pp）。**
   这坐实了 `design.md` §14.6「作用点二：节点偏置 → 行为频率」——它就是「先诱导说」那一层。
   而全局 `m` 作用在 15000 条边上，噪声远大于信号：下一步应该是 **per-neuron `m`**
   （TESS 的做法，IJCNN 2025：完全局部规则可做到 ≈ BPTT，只差 1.4 个点），不是继续调全局 `m` 的幅度。

#### 一条写进准则的教训

> **实验前先算「物理上最多能做到多少」，再确认它 ≥ 目标。**
> 本例：`动作数 × 每动作步长` vs `目标差距`。算出来 6 < 40，实验从第一天起就无意义，
> 而我用 5 轮「机制修补」去解释一个算术问题。
>
> **伴随判据：先做基线（random / 可学上界），再改机制。** 没有 random 基线，
> 「12.8%」读不出是「没学到」还是「比什么都不做还差」——而它实际上是后者。

**可复现：**

```bash
python test/baseline_linear.py 400 8 random,linear   # 基线三档
python test/grow_agent.py 200 8 8 random,discrete,discrete_frozen
```

### 16.18 移植旧脚本进框架（2026-10-24）——3 个脚本 / 20 项，全部逐位一致

**起因（用户）：** 「`F:\agi\test` 这里面的一堆你是否全部都移植过来了？」

核对结果：**只对齐了 1 个（`grow_agent` 的 `discrete`）**，而且严格说是「给框架加开关让它能复现」，不是移植。所以本场按「判据 = 行为一致」重做。

#### 判据

移植的唯一判据是**同 seed、同参数下行为逐项相同**，不是「配置抄过去了」：

| 脚本形态 | 判据 |
|---|---|
| 写环境文件 | 动作序列逐项相同（拦截 `state.txt` 的写入值） |
| 内存世界 / 统计量 | 全部字段逐位相同 |

#### 结果

| 脚本 | 行数 | mode | 结果 | 判据 | 耗时 |
|---|---|---|---|---|---|
| `grow_agent.py` | 710 | 13（4 个别名） | **9/9** | 动作序列逐项 | 21 s（8 进程） |
| `grow_goal.py` | 403 | 6 | **6/6** | 16 字段逐位 | 3 s |
| `grow_world.py` | 369 | 5 | **5/5** | 19 字段逐位 | 4 s |

全套 28 秒（`python scripts/align_layers.py verify|goal|world`）。

#### 四层对齐法（每层通过前不碰下一层）

| 层 | 比什么 | 结果 |
|---|---|---|
| construct | 同 seed 的初始 `key` / `pre` / `post` / `w` / `age` + RNG 尾状态 | 3/3 逐位 |
| forward | 同结构 + 同输入串跑 250 步的 `state` / `v` / `trace` / `theta` / `ema` | 3/3 逐位 |
| run | 编排端到端（同 seed、同 episode 数） | 差异量化 |
| seq | 动作序列（拦 `state.txt` 写入） | 逐项相同 |

**前两层先过是关键**——本体不等价的话，后面所有差异都会被它放大成噪声，无法归因。

> **工具说明：** `forward` 层的被测对象是**从 `grow_agent.py` 原文抽取**的 `net_step`（只把 `nonlocal` 换成 `global` 一行语法），不是手抄——手抄等于把「我以为它怎么写」当成被测对象。

#### grow_agent 的九处差异与边际贡献

从已对齐的基准逐项关掉（3 seeds × 200 ep）：

| # | 差异 | 框架原来 | 旧实现 | Δ |
|---|---|---|---|---|
| 1 | **动作集** | ±1（2 个） | ±1, ±10（4 个） | **−29.3 pp** |
| 2 | **ep0 是否更新拓扑** | 更新 | 不更新（`if ep > 0`） | **−14.0 pp** |
| 3 | **`win_i` 跨 ep 是否重置** | 重置 | 不重置 | **−10.0 pp** |
| 4 | **沉默时是否更新权重** | 不更新 | 更新 | **−5.2 pp** |
| 5 | `u_buf` 行数 | 16384 | 65536 | −4.7 pp |
| 6 | 拓扑门槛 `m_ep > 0` | 有 | 无 | 0 pp |
| 7 | 同 tick 决胜 | `first` | `argmax(v)` | 0 pp |
| 8 | bridge | 0 | 0.15 | 0 pp |
| 9 | episode 级 `steady_gate` | 缺 | 有 | 0 pp |
| — | noop 时 `m_glob = −base`（框架独有 bug） | 非零 | 无此分支 | 已修 |

**两个交互，比数字本身重要：**

- **bridge 与 topo_gate 耦合**：`bridge>0` 让 `m_ep` 每 episode 都为正 → 「只在成功时更新拓扑」失效。所以 #6 / #8 单独看是 0，合起来不是。
- **`u_buf_rows` 值 4.7 pp**——它只是随机序列的长度，**没有任何机制含义**。这是这个系统的混沌噪声量级：**3 seed 的差异小于 5 pp 不能当机制结论**。§16.13~16.16 里那些 2~5 pp 的「差异」都要按这把尺子重读。

#### 三个脚本的可塑性规则真的不同

移植时发现它们不是「同一件事的不同写法」：

| 脚本 | 归一化 | BCM 项 | 更新方向 |
|---|---|---|---|
| `grow_agent` | `e = el·m` 后归一（m 被约掉） | 有 | 对称 |
| `grow_goal` | `el` 先归一，再乘 m（m 的大小保留） | 有 | 对称 |
| `grow_world` | `el` 先归一，再乘 m | **无**（恒 ≥0） | **非对称**（兴奋向 +1 / 抑制向 −2.5） |

硬合并成一套，任何一个方向都会移植失败。所以 `core.py` 现在是三个原子操作（`apply_weight(norm=)` / `apply_weight_asym`）。

#### 初始化也不同

`grow_world` **不过滤 `post >= N_IN`**（`grow_agent` 过滤）→ 初始边数 **29501 vs 26594**。`frozen` 组的 `E` 直接对不上就是这个原因。已参数化（`block_input_edges`）。

#### 一个新发现：§16.15 的四个对照组是同一配置

#### 两处口径发现（都不是移植缺陷，但会影响引用）

**① 接口权重的偏移：`uniform(0.15~0.60)` 从未落到接口边上。**

旧实现先算 `n_rand = pre.size − nlink − nfan − nside`，但 `nfan` 用的是 `N_IN * N_IN_FANOUT`（= 5000），
而扇出实际插入的是 `(N_IN + N_Q) * N_IN_FANOUT`（= 5500）——**少算 500 条**，
所以 `w[n_rand : n_rand+nlink]` 整体后移 500 条，落进了扇出段内部。

实测（seed 0）：接口边 **197 条**（应为 200，3 条在排序去重时被同 key 合并），
`face_w: min = max = mean = 0.5000`——**全部是 `w_e`，不是 uniform**。而扇出段中段的 500 条被随机化了。

**框架照搬了这个偏移**（否则 construct 层过不去），`maxdiff = 0` 验证了这一点。
要不要修是另一个决定：修了就不再逐位一致，§16.10 的那个 75% 需要重跑。**待拍板。**

**② `--delay` 只改「何时允许回答」，不改「何时提问」。**

`DELAY = 120` 是模块常数（提问脉冲时刻），`--delay=` 只设 `ANSWER_FROM`。所以：

| `answer_from` | 回答窗 | 抢答窗（`burst .. answer_from`） | seed 0 实测（800 呈现） |
|---|---|---|---|
| 20 | 20~200 | **空** | acc **0.50**、early 0 |
| 50 | 50~200 | 30 步 | acc 0、early **1.00**（全抢答） |
| 150 | 150~200 | 130 步 | acc 0、early **1.00** |

含义：§16.10 的「75%」出自 `answer_from=20`——那时回答窗紧接刺激末尾（保持期 0 步），
**不需要跨保持期**；而「跨度 = τ」那组（50 / 100 / 150）在单 seed 下表现为**全抢答**（不是「答错」），
所以「25%」是 8 种子的均值口径。两件事要分开引用：

- **「学到了」**（`answer_from=20`）——成立。
- **「跨度只有 τ」**（`answer_from ≥ 50`）——成立，但表现形式是「抢答」，不是「答错」。

这与 §16.14 的发现同源（抢答浪费一半呈现），但 §16.14 是 `grow_cond` 的另一份实现。

#### 两个口径问题的处理（2026-10-24 晚）

**① 接口权重偏移：加开关修，不删旧行为。**

`NetSpec.talk_legacy_offset`（默认 `False` = 修正）：

| 值 | `nfan` | 接口权重实测（seed 0） | 用途 |
|---|---|---|---|
| `True` | `n_in × n_in_fanout`（旧） | **0.500 恒定**（std 0） | `ta_*` 四个配置 —— 逐位可复现、与 §16.10 历史读数可比 |
| `False` | `(n_in+n_q) × n_in_fanout` | **0.151 ~ 0.599**（mean 0.374 / std 0.135） | `tk_*` 四个配置 — 接口边真正随机 |

边数不变（两组都是 31848）——变的只是那 500 条的归位。
`align_layers.py talk` 始终跑 `ta_*`，所以对齐验证仍然 4/4。

**② 两个时刻拆成两个参数。**

旧名 `delay` 是个错名：它只设**提问时刻**，而旧脚本 `--delay=` 改的是**回答起点**。现在：

| 参数 | 含义 | 默认 |
|---|---|---|
| `TaskSpec.query_at` | **何时提问**（提问脉冲的时刻） | 120 |
| `TaskSpec.answer_from` | **何时允许回答**（回答窗起点） | 120 |
| `hold_steps`（派生）| `query_at − burst` = 真正要扫的保持期 | 100 |
| `early_steps`（派生）| `answer_from − burst` = 抢答窗长度 | 100 |
| `answer_before_query`（派生）| `answer_from < query_at`（回答窗早于提问） | False |

`validate` 新增：`query_at >= burst`（提问不能在编码期内）。
派生量不进 `to_dict()`，所以不会让同一件事有两种写法。

#### 拆开之后暴露出的结构矛盾（重要）

两个参数独立后既可以「扫跨度」也可以「保留抢答窗」，于是可以做之前做不了的实验设计。
实测（`tk_teach`，800 呈现 × 3 seeds，12 任务 / 8 进程 / 251.8 s）：

| `query_at`（= `answer_from`）| 保持期 | acc 早 → 晚（3 seeds） | 抢答（晚） | rate% |
|---|---|---|---|---|
| 20（= `burst`）| 0 步 | 0.00→0.50 / 0.50→0.50 / 1.00→0.00 | 0.00 | **1.57 ~ 1.68** |
| 50 | 30 步 | 0 → 0 / 0 → 0 / 0 → 0 | **1.00** | 0.39 ~ 0.48 |
| 100 | 80 步 | 0 → 0 / 0 → 0 / 0 → 0 | **1.00** | 0.40 ~ 0.44 |
| 120 | 100 步 | 0 → 0 / 0 → 0 / 0 → 0 | **1.00** | 0.36 ~ 0.44 |

**三个读数：**

1. **`answer_from = query_at` 并不能消除抢答。** 抢答窗仍然有 `hold_steps` 那么长（`burst .. query_at`），
   而编码期的刺激余波在这个窗口内仍然很强 → 输出被直接驱动 → 全部在窗内开口。
2. **真正的三选一（结构矛盾）：**

   | 选择 | 抢答窗 | 跨保持期 | 测到的是什么 |
   |---|---|---|---|
   | `answer_from = burst` | 无 | **不跨** | 即时反应（靠刺激余波），不是记忆 |
   | `answer_from = query_at` | `hold_steps` 长 | 跨 | 抢答 vs 沉默 vs 答对，不是纯跨度 |
   **不要用「结构上禁止输出放电」去凑第三行**（我 2026-10-24 一度这样写，已撤回）：
   那会把「何时说」这个要学的能力焊成接线（与判据 A 直接矛盾），且实现上只能是外部注入禁止信号
   （抑制输入 / 抬高阈值 / 钳制膜电位三者等价）——那正是 design.md §2.9 排除的「每步外部条件」形态。
   正解不在门控，而在：「何时说」与「记住多久」是两个问题，**测量面已经能分开**
   （`buck_acc` 只统计落在回答窗内的样本，`buck_n = 0` 本身就是「何时说」没学会的读数）。

   前两种都无法隔离出「靠内部状态撑过保持期」这件事。这与 §16.14 的结论完全一致：
   抢答拉不靠惩罚去教，得**结构上禁止**（回答窗之前抑制输出，或输出只在提问窗可放电）。
3. **抢答把网络活动压低了 4 倍**（1.6% → 0.4%）。机制：抢答后同现进入阈值适应 + 冷却，
   整个呈现的活动被压死。这条是新的——之前只知道「抢答浪费呈现」，不知道它同时把网络推向低活动态。

**修正接口权重没有带来明显改善：** `q=20` 时 acc 仍然在 0.33~0.5 量级，且三个种子分散（其中一个从 1.00 掉到 0.00）。
在「输出能被刺激直接驱动」这个前提下，接口权重是不是随机化改变不了本质——**瓶颈在输出接口的可表达性，不在那几个权重值**（与 §16.13 的诊断同向）。

**下一轮的入口修正（2026-10-24 晚，取代本节原本写的「结构约束」）：**

1. **先不要动输出接口。** 「何时说」是接口选择性问题（输出同时接提问区与内部，谁主导应当由学习分出），
   不是用一个门把它禁掉。
2. **把两个问题分开报：** 「记住多久」看 `buck_acc`（只看落在回答窗的样本）；
   「何时说」看 `early_rate` 与 `buck_n`。混在一起读会把「不敢/不会等到回答窗」误读成「忘了」。
3. **真正的缺口仍是巩固**（§16.10 结论三）——不是抢答。

#### 拓出的旧实现缺陷：每个 chunk 把网络状态清空

`grow_homeo.grow()` 调 `simulate()` 时**从不传 `start=`**：

```python

```

所以每 50 步（`T_STRUCT`）都把 `v / s / ref / theta / x_rec` 清回零，**只保留 `rate_ema` 与结构**。

**这与 `experiments.md` §11.4 阶段 B 的核心前提「一条永不重置的时间轴」直接矛盾**，也与 homeo 自己的机制矛盾：STD（`x_rec`）和阈值适应（`theta`）都是**短时**过程，每 50 步清零等于把两个自组织机制的短时记忆反复抹掉。

**发现方式（不是猜的）：** 50 步纯模拟七个状态量 maxdiff 全为 0，而 `steps=6000` 时从 chunk 1 开始分叉——说明分叉只能在「chunk 之间发生了什么」。

**处理（按 `talk_legacy_offset` 的先例）：** 加 `Plasticity.reset_state_per_chunk`。

| 值 | 行为 | 用途 |
|---|---|---|
| `True` | 每 chunk 清空（旧） | `ho_*` 四个配置——逐位可复现 |
| `False` | 状态连续（设计要的） | 待跑，见下方「下一步」 |
