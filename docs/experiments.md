| S7 | 进化层给不给 | **给（阶段 A：基因 + 变异 + 选择，不开学习）** / 不给（只测学习） | **倾向给**——不给的话测的只是「在设定好的结构里能不能分工」，测不到「能不能长出没设计的结构」 |
| S8 | 基因的丰度（能不能表达没想到的结构） | 只参数（节点数/密度/τ 分布）→ 安全但空间窄 / **加拓扑生成规则** / 加发育程序（从单节点分裂迁移） | 待定——**这一条决定阶段 A 能发现什么；基因空间窄了，演化只能长回我已经想到的东西** |

### 11.2 原第 1 件（现第 2 位）：测「第二次快多少」

**为什么它排在分化实验之后**：

- **不需要新架构**——只需「经验留存」这一件事
- **不需要 GPU**
- **判据是硬的**：第二次快 30% 还是 0%，一目了然
- **如果第二次不快，后面所有架构讨论都是空谈**
- **但**：若「分化」不发生（§11.4），这里的数字无法归因——不知道快是因为经验，还是因为碰巧调对了参数

**做法**：

1. 选 10 个「有明确成败」的本机任务（例：修一个失败测试、格式转换、定位配置项）
2. 每个任务第一次做，记录：**步数 / 时间 / 人工介入次数 / 是否成功**
3. 把「经验」按最简形态留存（文本记录：情境-策略-后果）
4. 隔一段时间做同批任务的**变体**，记录同样指标
5. 对比

**为什么用「变体」而不是「原题」**：原题能考的是「记忆」，变体才能考「学习」。而 `design.md` §4.1 已经说明了记忆和学习的区别。

**经验留存的三个档位**（先做最低的）：

| 档位 | 形态 | 成本 |
|---|---|---|
| 1 | 纯文本记录 | 最低 |
| 2 | 结构化（情境-动作-结果-误差） | 中 |
| 3 | 参数化写入 | 高 |

**先做 1，测出基线**。如果基线已显示「第二次快」，再考虑往 2/3 走；如果基线是 0，那说明「经验留存」不是瓶颈，而「怎么用经验」才是。

### 11.3 第 3 件的具体设计

**⚠️ 前提（2026-10-23 补）：这件在现在的链路上做不了。** Pando 走 DeepSeek API，拿不到 hidden state；system prompt 是文本不是向量。用本地 embedding 编码文本算距离，测的是文本相似度，不是内部状态——那已经是另一件事了。要动这件，前提是本地有可读内部状态的模型（阶段 1 的块扩散底座，或任意本地模型）。

**测什么**：同一任务在两个不同会话里，模型的「内部状态向量」距离。

**为什么值得测**：如果已有天然的一致性（哪怕很弱），说明「身份」已经部分涌现，只需**放大**；如果没有，说明需要**显式训练目标**。

（按 `design.md` §2.9，这套问法要改：问的不是「涌现没有」，是「有没有一个中心在承载累积的修改」——判据见 `design.md` §2.9 四条。）

**这个实验很便宜**：不需要训练，只要跑两次前向算距离。

### 11.4 分化实验（第五版：生长规则演化 + 稳态标定）

> **第五版与第四版的两处不同（2026-10-24）：** ① 阶段 A 的个体**不是固定结构**——连接在生命期内自己生长与裁剪，演化对象从「结构参数」变成**生长规则**（依据：2026-10-23 拍板，见 `design.md` 来源与修正记录）；② 阶段 A 之前多一道**稳态标定**（§11.4.0）——第四版把稳态当默认成立，实测它是第一道坎。

#### 11.4.0 稳态的实现与标定

**为什么单列一节。** `design.md` §2.10 把「稳态」列为本体侧必须给的三样之一（接口 / 可塑性 / 稳态），但它一直被当成「给了就成立」。2026-10-23 的实测推翻了这个默认：**稳态不是配置项，是一条要标定的曲线**——标不准，后面三样测量（记忆跨度 / τ 分布 / 挤占）全部没有对象。

##### 实测：均质网络只有两种态

固定结构、只扫兴奋突触权重（N=1000、全兴奋、无抑制、无不应期）：

| w | rate |
|---|---|
| 0.02 ~ 0.25 | **0.19%**（= 外部输入率，信号完全不传播） |
| 0.30 ~ 0.70 | **100%**（全部同时放电） |

**从 0.19% 直接跳到 100%，没有中间态。** 这不是参数没调好，是全兴奋网络只有正反馈：要么信号衰减殆尽，要么自我放大到饱和。

##### 三个必须的动力学要素

| 要素 | 缺了会怎样（实测） | 加了之后 |
|---|---|---|
| **E/I 平衡**（约 80% 兴奋 / 20% 抑制） | 只有全或无，rate 不可连续调 | rate 可以连续调 |
| **不应期**（T_REF） | 放电率无上界——抑制比拉到 10 倍仍卡在 20~30% | T_REF=20 时压到 1.99% |
| **硬预算 + 竞争** | 新建边无代价 → 边数从 8000 涨到 28000、淘汰只有个位数 | 结构尺寸有界，生长与裁剪成为同一选择的两面 |

三者的关系不是「三个超参」，是**缺一不可**：E/I 给可调性、不应期给上界、预算给结构约束。

##### 标定结果（2026-10-23，手扫）

| 参数 | 值 | 结果 |
|---|---|---|
| w_E | 0.50 | rate **1.99%** |
| 抑制权重比 | 5.0（w_I = −2.5） | 尾部波动 0.94% |
| T_REF | 20 步 | 稳定 |

**判据（三条全过才算标定完成）：** ① rate 落在 1~3%；② 末 2000 步的波动 < 1%；③ 不出现全静默、也不出现全饱和。三条都满足，才允许开结构可塑性。

##### 文献已有的自组织方案（未试，优先级高于手调）

`reference.md` §15.2 已列：**两个机制就能让网络悬在临界点附近而无需外部调参**——抑制性突触短时抑郁 + 阈值适应（Phys Rev Research 2, 012042, 2020），同时给出 E/I 平衡与异步不规则放电。

上面那张标定表是**手扫**出来的（`calib` 系列五个脚本），每换一次参数都要重扫，且没有理由相信扫出来的点是「对」的。**所以这里有一个明确的替代方案没试过**：用两个自组织机制换掉三个手调常数。它是 §16.3 列的候选之一。

##### 已知失败模式（标定成功之后仍会遇到）

开结构可塑性后 rate 掉到 0.08%。**当时的根因推断是「时间尺度不对齐」（§16.3），事后证明不是——真正原因是五个实现缺陷**（衰减判据 / 衰减尺度 / 世界发散 / 强化只覆盖 0.45% 的边 / 抑制边沙溢，§16.6）；修后同参数 rate = 1.55%。所以「标定完成」不等于「开着可塑性也能稳住」——**标定是必要条件，不是充分条件**；而且**失败时先查实现，不要先解释机制**。

**结构冻结的那一版是旧的；结构能自己生长的那一版才是新的**，两者不能混：

| 个体生命期内 | 结构不变，只跑动力学 | **结构自己加边 / 删边** |
| 演化的对象 | 一个结构 | 一条规则 |
| 测到的是 | 哪组超参能活 | **结构能不能自己形成** |

已有工作填的是左列：

| 已有工作 | 做到什么 |
|---|---|
| **ELSM**（2024） | 目标 = small-world 系数 + 临界性；自发长出 hub / 短路径 / 长尾度分布 / 社群；NMNIST 97.23% |
| **NeuEvo**（PNAS 2023） | STDP 演化出四类回路 + 全局误差更新权重 |
| **CortexZero**（2025-11，预印本） | 基因 = 区域树上的概率分布，发育采样，不用反传；**只有规格，没有结果** |
| **WANN-Spiking**（2022） | 权重无关的拓扑搜索迁到脉冲回路 |

**所以本版阶段 A 不是重复劳动**——上面这些全部以「出生时结构定死」为前提。加了生长 / 裁剪之后，阶段 A 测的是另一件事（`reference.md` §15.6 里「降级复用 ELSM」那段判断因此撤回）。

仍有一个观测是它们没做的：**每个存活个体的实测 τ_d 分布**（ELSM 量的是 small-world + 临界）。而这里有一个 `design.md` §2.2 已指出的坑：**基因里的「τ 分布」与网络实际的时间尺度不是同一个量**（单细胞 τ 在强递归下被抹平）。→ 只记基因型、却从行为读结果，会让「收敛到广谱」有两种相反解释（「选择偏好广谱基因」或「给了也白给」）。所以必须**同时记录实测 τ_d**，否则结果不可解释。

**阶段 B 是真空。** 三条前提与 SNN 主流逐条相反，而且互相锁死（详见 `reference.md` §15.6）：

| 草案阶段 B | SNN 主流 |
|---|---|
| 一条永不重置的时间轴 | 每样本 / 每帧重置 |
| 不开学习也要有状态 | BPTT 必须有固定 T |
| 无任务、无 episode、无准确率 | 全部有任务 + 准确率 |

#### 阶段 A：演化生长规则（结构在生命期内自己变）

##### 前置

§11.4.0 的标定必须已经完成：rate 稳在 1~3%、尾部波动 < 1%。**在这一条之前，阶段 A 的任何结果都不可解释**——网络是死的，所有判据都无从谈起。

##### 与上一版的区别

| | v3 / v4 | v5（本版） |
|---|---|---|
| 基因 | 结构参数 | **生长规则的参数** |
| 个体出生 | 按基因一次性生成结构 | 从一个稀疏初始结构出发 |
| 生命期内 | 结构冻结，只跑动力学 | **强化 / 竞争淘汰 / 随机新建** |
| 判活 | 六条 | 六条 + **首要：结构有没有收敛到稳定形状** |

##### 生长规则（演化的对象是这三条规则的参数）

> **2026-10-24 修订：删去「闲置衰减」。** 原表列四条（强化 / 闲置衰减 / 硬预算 / 随机新建），但同日两次实测把衰减判据否掉了：判据取「本步前后同时放电」时保护 68 条 / 衰减 14932 条（**1:221**）；改成「前神经元 500 步未放电」后仍衰减 2822 条（**1:141**）——持续衰减的时间常数必须匹配「边被使用的间隔」，而活动率 0.5% 时这个间隔远长于结构更新周期（20 步）。**硬预算按强度竞争淘汰本身就是「用进废退」**，不需要额外的持续衰减。（`test/grow_world.py` 头部 v2 缺陷记录；§16.6 缺陷 2；决策见 `decisions/agi项目.md` 2026-10-24。）

规则形式固定，**演化的是参数**：

| 规则项 | 作用 | 要演化的参数 |
|---|---|---|
| **共激活强化** | 资格迹累积「最近活跃过」，按 `Δw = η·e_ij·m` 写回全部边 | 强化率 η、迹衰减 |
| **硬预算 + 竞争** | 边数超预算时按有效强度淘汰——生长与裁剪是同一选择的两面 | 预算 E_max |
| **随机新建** | 小概率新建边（补局部规则够不着的长程连接） | 概率 p_new |

四条实测依据，写在这里防止再犯：

1. **「衰减不要做」**——两版判据都被数据否掉（1:221 / 1:141），而硬预算已经在做同一件事（弱边被淘汰），多加一层只引入一个难标定的常数与一条错配的时间尺度。
2. **「强化必须用资格迹，不能用瞬时共激活」**——瞬时共激活只覆盖「本步同时放电的对」= **0.45% 的边**（68/15000），而配套的衰减作用于剩下的 99.5%，结构必然冻结。资格迹把「最近活跃过」展开到全部边（覆盖率 100%）。替代方案「把闲置窗口调大」只是把同一个错配的时间尺度挪位置。
3. **「生长与裁剪是同一选择的两面」**——MiTA（NeurIPS 2026）的 emergent token pruning：没人设计剪掉哪些 token，共同机制只有竞争 + 稀缺（top-k 硬约束）。生物学同样是「先过度生产 → 按效能竞争 → 弱的出局」。所以只需一个预算参数，不需要「生长率 + 剪除率」两个耦合参数。
4. **「不能一次全开」**——场次八把强化 / 衰减 / 跳跃 / 退火一次全开，rate 掉到 0.08%。正确顺序是逐项加：先只开「强化 + 硬预算」，rate 稳住了再加随机新建。

##### 演化什么、不演化什么

| 演化（基因） | 不演化 |
|---|---|
| 强化率 / 迹衰减 / 窗口长度 | 初始连接的具体位置 |
| 预算 E_max | 单条边的权重值 |
| 随机新建概率 | 实现细节（数据结构 / 并行） |

**基因空间是这一阶段真正的风险（待定项 S8）**：如果规则只能表达我已经想到的那几条，演化只能长回我设计的东西，实验就白做了。

##### 初始结构与规模（沿用第四版的范围，但不再是「基因」）

个体出生时的初始结构由下面几项确定，**它们不进基因、不参与演化**（演化的是上面三条规则的参数）：

| 项 | 取值 | 说明 |
|---|---|---|
| 节点数 | 100~2000 | 与第四版相同；决定单步成本（§16.1） |
| 连接密度 | 0.5%~10% | 跨过稠密 / 稀疏交叉点 5%（§16.1）→ 实现需两条路径按密度选 |
| 初始拓扑 | 随机 / 距离衰减 / 分群 / 小世界（4 选 1 + 参数） | 第四版把它当基因，现降为初始条件 |
| 兴奋 : 抑制比 | 1:1 ~ 5:1（工作点 4:1，见 §11.4.0） | E/I 平衡是稳态的前提 |
| 是否有分群结构 | 无 / 2 群 / 4 群 | 结构异质性的一个维度（与容量有权衡，见下方反向观测） |
| 初始权重 | 强 / 弱两档（强 = w_E，弱 = w_NEW） | 第四版一律随机初始化；本版「过度生产 → 修剪」需要弱初值 |

**为什么这些不再是基因：** 它们决定「出生在哪个结构里」，而这一阶段要测的是「结构能不能在生命期内自己形成」——把初始结构也交给演化，就分不清长出来的形状是演化的功劳还是初始条件给的。

（第四版的基因表里还有一项「**时间常数分布**：单值 / 均匀 / 对数正态（跨几个量级）」，并标注「这一条直接对应分化」。本版改为：τ 不进入基因，它是**结构异质性的输出**（`design.md` §2.2：逐单元 τ 在强递归下被抹平）；要观测的是**实测 τ_d 分布**，不是基因型。）

##### 输入必须带结构（不是纯泊松）

| 必须有的分量 | 为什么 |
|---|---|
| **周期分量** | 给「可预测」提供对象——能预测的活动才谈得上「值得强化」 |
| **偶发事件** | 给结构提供分化压力（不同时间尺度的分量才有不同的响应理由） |
| **噪声** | 防止确定性锁相 |

**这一条不是可选项。** 场次八最根本的一个认识是：纯泊松输入下没有任何东西「值得学」，竞争只能退化成自洽的（没被激活就淘汰）——自洽的规则可以收敛到任何东西，包括退化态，实测收敛到 rate 0.08% 的死网。**给输入加结构，是给竞争提供「方向」的唯一来源**（`design.md` §14.8：环境反馈是锚，不是训练信号）。

##### 怎么判「活」

每个个体跑 2000 步（用 §11.4.0 标定后的动力学）。输入是**同一个事件流**（周期 + 偶发 + 噪声），所有个体共用。**六条全过 = 活**：

| 判据 | 具体测什么 | 阈值 |
|---|---|---|
| **不炸** | 活动幅度时间序列的 max / mean | < 20 |
| **不死** | 最后 500 步的平均活动 | > 全静默的 10% |
| **不僵** | 状态的方差 | > 0（不是固定点） |
| **不纯混沌** | 两条轨迹从差 1e-6 出发，10 步后的分离度 | 有界，不是指数爆炸 |
| **有区分** | 10 种不同输入，状态距离矩阵 | 类内距 < 类间距的一半 |
| **有记忆** | 注入唯一标记，100 步后能不能线性读出 | 高于随机 |

这些判据里**没有任务、没有答案、没有准确率**。

**六条都要测，不能只测前两条。** 场次八只看了 rate 与波动（≈「不死 + 不炸」），其余四条（不僵 / 不纯混沌 / 有区分 / 有记忆）一次没测——所以「实验跑不通」这个判断本身只基于六条里的一条。

##### 加在六条之上：结构有没有收敛到稳定形状

这是 2026-10-23 新增的首要观测。**但「收敛」本身没有区分力**——死网也会收敛：

| 观测 | 怎么看 | 意义 |
|---|---|---|
| **turnover** | 每 N 步的边集合与上一次的重叠率 | 低 = 结构稳定 |
| **边数 / 预算** | 实际边数占 E_max | 长期贴顶 = 竞争在起作用 |
| **度分布 / 权重分布** | 形状随时间是否稳定 | 收敛后应当稳定 |
| **rate 与 turnover 联合** | 只有「低 turnover **且** rate 在 1~3%」才算真收敛 | **这条是关键** |

最后一行是必须的：场次八的数据是「低 turnover（0.003）+ rate 0.08%」——单看 turnover 会误判成「收敛成功」，实际是**收敛到死网**。

##### 繁殖与选择

活下来的按「记忆长度 + 区分度」排序，前 20% 繁殖；基因（即生长规则的参数）随机扰动（每代 5% 位翻转 + 参数 ±10%）。死光的代重来。跑 100~300 代。

**N ≥ 5 个种子**，看分布形状与收敛方向是否稳定出现，不挑一个成功的报（人工培养大脑的批次变异是同一类问题：「Even under identical culture conditions, organoids exhibit different learning rates and neural architectures」）。5 个里 2 个收敛、3 个不收敛 → 结论是「会收敛但不稳」，这比挑一个成功的报有价值。

##### 看什么算有结果

**规则参数是否收敛**，尤其是会不会自己走向某个角：

| 收敛到 | 含义 |
|---|---|
| 宽分布 / 双峰的时间尺度分量 | 多时间尺度对「活下来」有用，且它由结构异质性承载（不是逐单元 τ） |
| 单值 | 在「活下来」这件事上多时间尺度没用——那么「要不要分化」在这个判据下不成立 |
| 衰减率 → 0 | 「不衰减」被选中 = 结构不需要更新，那一整套生长机制是多余的 |
| 强化率 → 0 | 反过来：强化没用，只剩随机新建在维持结构 |

**后两种结果最有价值**——它们直接说这一阶段是空的，比「跑出一个漂亮的小世界」有用。

**第四版的原判断保留：** 「收敛到单值」这一种比「收敛到广谱」有价值——它说明时间尺度分化可能只在「要做复杂任务」时才需要，而不是「要活着」就需要。

##### 反向观测必须一起测：异质度 vs 容量的权衡点

异质性是权衡，不是单调改进（`design.md` §2.10）：同质网络的**工作记忆容量更大**，异质网络的函数生成能力更强；存在一个最优异质度。

所以判据里若只写「记忆长度 + 区分度」，会偏向同质。**必须同时记录异质度与容量，看演化把权衡点放在哪。**

##### 顺带必须测：会不会自己跑到临界

生物网络在临界附近（既不僵也不乱），而且这个状态是**自组织**的（NALSM：星形胶质调制 STDP 到临界态）。

测法：**分支比 σ**（每个活动事件平均引发多少后续事件，σ≈1 是临界）或**雪崩尺寸的幂律**。

- 自己跑到 σ≈1 → 「稳态」这一条不用我给
- 跑不到 → 才需要显式加

#### 阶段 B：结构定下来，再学

挑阶段 A 里活下来的前 5 个**不同**结构（不同拓扑、不同 τ 分布），固定结构，打开可塑性。

##### 形态：一个永不清空的状态

| | 错误形态（v1） | 本版 |
|---|---|---|
| 时间轴 | 离散 episode，喂完就重置 | **一条不间断的时间轴**，状态从不重置 |
| 输入 | 固定长度序列 | **连续事件流**，每一刻都有输入，没有「开始 / 结束」 |
| 输出 | 在指定位置输出标注答案 | **不强制输出**；从外面读状态，不让它做题 |
| 训练 / 测试 | 分开 | **不分**；同一条时间轴，只差「给不给调制」 |
| 判据 | 消融 → 准确率下降 | **状态自己的性质** |

关键一句：**不是「训一个能做题的网络」，是「看一个一直活着的东西会不会形成结构」。** 所以没有准确率、没有收敛曲线、没有 episode。

##### 三个测量（都在同一份持续状态上，不需要重启）

**测量一：影响能持续多久**

注入一个**唯一标记**（之前没出现、之后也不会再出现），**之后不打扰它**，在第 1 / 10 / 100 / 1000 / 10000 步各读一次状态，用线性探针问「刚才那个标记是什么」。

得到一条「可读性 vs 延迟」曲线——**每个内部维度各一条**。

**测量二：分化（看曲线形状，不看准确率）**

把每个维度的曲线拟成 τ_d，看 τ 的分布：

| 分布形状 | 含义 |
|---|---|
| 单峰、窄 | 一套规则只能给一个 τ，不分家 |
| **单峰、宽（跨几个数量级）** | **一套规则自然广谱** |
| **双峰** | 分化成了两套，分家在机制上必要 |
| 全部极短（秒级以下） | 什么都没记住，是参数问题不是分化问题 |

第二层：**不同 τ 的维度是不是各自编码不同的东西**？用互信息算：τ 短的维度对上「刚才那几步」的信息多，τ 长的对上「周期性结构」的信息多——这就是频谱分解（`design.md` §2.2 末）。

这比双分离好在哪里：不需要定义「两个任务」、不需要 episode、不需要拆连接；判据是**分布的形状**，直接对应「一套够不够」。

**明确不采用双分离消融。** v1 的思路是「拆掉一套再测另一套，看准确率下降多少」——它需要定义两个任务、需要 episode、需要算准确率，同一条链条把实验拉回基准测试形态。本版用「τ_d 分布形状 + 互信息分工」替代，两者不共存。

**测量三：学习（不是准确率）**

| 量 | 怎么算 | 预期 |
|---|---|---|
| **响应幅度** | 同一周期分量重复出现时，参与它的维度激活强度 | 变强（强化） |
| **响应延迟** | 从输入到状态变化的时间 | 变短（熟了） |
| **挤占** | 新结构学进去后，旧结构的可读性掉多少 | ——**这才是真问题**（LSL 的 44% → 76.6% → 96.6%） |

「挤占」那一行最要紧：**如果新学的东西会冲掉旧的，那不管分化不分化，「持续学习」都不成立。** 这是与 A 判据直接相关的量。

##### 阶段 B 的对照

| 组 | 输入 | 回答什么 |
|---|---|---|
| 1 | 有结构 + 可塑性开 | 主体 |
| 2 | **同统计的白噪声**（无周期、无结构） | 看到的 τ 分布是不是自发噪声就有的 |
| 3 | 有结构 + 可塑性关 | 结构不靠学习的部分占多少 |
| 4 | 有结构 + 两套可塑性 | 分家能不能改善「挤占」 |

组 2 是硬对照：**任何非线性循环系统都会自发产生多时间尺度**（临界态、混沌边缘都是）。不证明「来自输入结构」，测量一就没有意义。

##### 判据（先写死，防事后挑）

| 判据 | 阈值 | 不达怎么办 |
|---|---|---|
| **有记忆** | 至少 10% 的维度 τ > 100 步；且组 2 对应比例不超 5% | 没记住东西 → 调稳态 / 可塑性，不谈分化 |
| **双峰** | GMM 两成分似然比检验，且两峰相距 > 10× | 单峰就判「未出现双峰」，不写「没有分化」 |
| **频谱分解** | τ 短 / 长两组的互信息差 > 2 倍 | 分化了但没分工 → 也算没分化 |
| **不挤占** | 新学后旧结构可读性下降 < 20% | 下降严重 → 「持续学习」不成立，这是更优先的问题 |

---

#### 两阶段共用的要求

**必须多随机种子**：人工培养大脑最大的痛点就是批次变异（「Even under identical culture conditions, organoids exhibit different learning rates and neural architectures」、「every brain organoid is unique」）。对应到本实验就是种子敏感性——**N ≥ 5**，看分布形状 / 收敛方向是否稳定出现。5 个里 2 个双峰、3 个单峰 → 结论是「会分化但不稳」，这比挑一个成功的报有价值。

**规模与成本**：阶段 A 的种群评估可并行，个体 2000 步很短；阶段 B 单个体 10⁵~10⁷ 步。总成本本机 CPU 小时级，无 GPU。

**但规模不能拍**：要测到 τ > 10000 步，状态维度至少得有一批能存活那么久。先跑一次探测，看现有规模能不能出 τ > 10³；出不了就加大。

**一个必须记住的坑**：人工培养大脑的 2026-09 综述原话——「**closed-loop adaptation is a function of a whole OI system (substrate plus interface plus feedback), not of the tissue itself**」。即：看到「形成结构 / 学会了」时，要能说清是**基因、可塑性规则、还是稳态**在起作用——这就是为什么必须有组 2（白噪声）和组 3（可塑性关）两个对照。不然看到什么都不算证据。

#### 与「原第 1 件」的关系

| | 测什么 | 主体 |
|---|---|---|
| §11.4（本件） | **本体能不能自己长出结构，以及长出后能不能学** | 小网络（AGI 雏形） |
| §11.2（原第 1 件） | agent 第二次会不会更快 | Pando（外部工具、文本经验） |

前者是「本体」层，后者是「外挂」层。**两者不能互相替代**，但 §11.4 先——因为如果本体长不出，后者只是给一个没有身体的东西堆文本。

### 11.5 个体性测量（阶段 C，D 判据）——⏸️ 悬置

> **⏸️ 2026-10-23：本节整节悬置（D 判据悬置）。**
>
> 保留而不删的理由：本书记了**两次失败**，重开时不用从头想。
>
> | 轮流 | 方案 | 被什么推翻 |
> |---|---|---|
> | 一 | 消融一致性（拿掉 persona） | persona 不设定后**失去对象** |
> | 二 | 结构消融（切中心） | **循环依赖**（要先知道中心才能切）+ 损伤曲线测不出中心（平滑 = 分布式，特定崩 = 局灶模块） |
> | 三 | 个体性（本节：重复性 / 个体间差异 / 跨域一致） | **偏好是实体的必要条件**——固定权重的随机网络三项全过，它连学习都没有 |
> | 四 | 共享改动结构（权重 delta 集中度 + 消融公共子空间 + 跨种子/跨历史） | **未评估就被悬置**。它比前三个都硬（在结构层测），但依赖「权重快照 + 多域任务」，且可能得出「无中心」的真结论 |
>
> **当前状态：** 不设判据。§11.1 不再排阶段 C。下面的内容只做记录。


> 2026-10-23 新增。本节填的是 `design.md` §2.9 判据表第四条留下的缺口：**「消融一致性」在 persona 不设定之后失去对象，而「选一组连接再切」从根本上有两个问题。** 替代方案不是消融，是**不改结构、只测「它是不是它」**。
>
> **先记住一个分层**：
>
> | 阶段 | 测什么 | 有任务吗 |
> |---|---|---|
> | A（§11.4） | 结构能不能自己长出来 | 无 |
> | B（§11.4） | 状态的性质（记忆长度 / 分化 / 挤占）—— **A 判据的前提** | 无 |
> | **C（本节）** | **个体性（重复性 / 个体间差异 / 跨域一致）—— D 判据** | **有，但是多解任务** |
>
> **为何必须另开一个阶段：** 阶段 B 的前提是「无任务、无 episode、无准确率」，而个体性需要**多解选择**——没有选择就没有「怎么选」可测。

#### 11.5.1 为什么放弃「结构消融」

| 问题 | 具体 |
|---|---|
| **循环依赖** | 要切「承载自我的那组连接」，得先知道自我在哪；而判据的目的**正是**要知道自我在哪 |
| **损伤曲线测不出「中心」** | APA 定义：graceful degradation（平滑劣化）**恰恰是分布式表征的性质**。而真实脑损伤常见的是「其他都正常、某一种能力灾难性丧失」（Coltheart 1991 举的病例：只能理解不能产出专有名词）。两者都不是自我 |
| **分不清三种退化来源** | 平滑 = 分布式；特定能力崩 = 局灶模块；整体崩 = 容量不足。`design.md` §2.9 说的自我是「分布式网络里被反复使用而成为中心的一组连接」——**它既不是模块，也不会因为被切而只坏一种能力** |

结论：损伤曲线可以保留为一个**旁路观测**（测模块化程度），但**不能当 D 判据**。

#### 11.5.2 替代：测「个体性」

方法学出处：动物行为学的 **animal personality / behavioural syndrome**（核心概念：repeatability、cross-situational consistency、temporal stability、个体间方差 vs 个体内方差；统计量 ICC / Cronbach's α；实测区间 r ≈ 0.35~0.88）。

**关键：它测的不是「不变」，是「统计意义上的稳定」，允许个体内变异（intraindividual variation 是这套范式里的正式概念）。** 这与 `design.md` §2.9「冻住就不学了」不矛盾。

#### 任务：多解任务

**定义：一个任务有多个都能通过环境层验证的等价解。** 环境层给的是成败，不是唯一答案。

不用造：§11.2 那 10 个本机任务里本来就有（修 bug 改调用方还是改被调方、重构的两种等价结构、排序稳定性选择）。挑选条件两条：① 至少两个解都能过环境层；② **不告诉它哪个是标准答案**（因为确实没有）。

#### 三个子测（必须一起用）

| 子测 | 怎么做 | 判据 |
|---|---|---|
| **A. 重复性** | 同一批多解任务（N ≥ 20）在 T 个不同场合重复；算偏好向量的 ICC | **ICC > 0.5**（参照 animal personality 典型区间 0.35~0.88） |
| **B. 个体间差异** | 两组对照：① 同历史不同种子（N=5）② 同初始结构 + 同种子 + **不同历史**（N=5）；算组间距离 | **② >> ①**（证明差异来自历史，不是种子噪声） |
| **C. 跨情境一致性** | 同一偏好是否跨任务域出现（语言类 / 动作类 / 排序类） | **跨域偏好相关 > 0**（是「它」而不是「某一种能力」） |

**「不同历史」怎么造（两个强度档）：**

| 档 | 做法 | 强度 |
|---|---|---|
| 1 | 同一批任务的**不同顺序** | 弱（路径不同，统计相同） |
| 2 | 同一输入分布但**不同共现结构**（A 常与 B 共现 vs A 常与 C 共现） | 强（改变统计） |

#### 两个反例：为何三条必须一起用

| 反例 | A 重复性 | B 个体间差异 | C 跨域一致 | 被谁排除 |
|---|---|---|---|---|
| 每次随机选 | ≈0 | 有（噪声） | ≈0 | A + C |
| 硬编码「永远选第一类」 | **高** | **≈0**（所有个体一样） | 高 | **B** |
| 真有个体性 | 高 | **大** | >0 | — |

**单看 A 会被硬编码骗过，单看 B 会被随机噪声骗过。** 这与 `design.md` §4.5 的「过程指标不能单独优化」是同一个结构。

#### 11.5.3 一个结构侧的补充（不是消融）

**可追溯探针**：从连接 / 状态里线性读出「它经历过哪类历史」。这不是切，是读。它提供「历史写在结构里」的直接证据，与行为侧三条互补。

#### 11.5.4 与 A 判据的分工

| | 测什么 | 失败意味着什么 |
|---|---|---|
| A（§11.2 的「第二次快多少」/ §11.4 的挤占） | 会不会变强 | 学不动 |
| **D（本节）** | **变强的是不是同一个东西** | 学得动，但每次学的不是同一个它 |

两者**不能互相代替**：A 成立而 D 不成立，得到的是一个「很快但没有中心」的系统；D 成立而 A 不成立，得到的是一个「稳定但不学习」的系统（`design.md` §2.9 说过：冻住就不学了）。

## 13. 设计准则与自评

### 13.1 九条设计准则

这九条不是从文献里找的，是从「反复被纠正」里提炼的（原为五条，2026-10-23 增四条）：

1. **从需要里推，不从组件里拼**——先问「它此刻需要什么」，再决定长什么
2. **先证明不能涌现，再设计**（2026-10-23 升级）——原版是「能涌现的不设计」，那是事后判断。现在要求设计**前**先给出「它为什么不能涌现」的理由；给不出就做实验（§11.4）。原版把「时间常数」当必须给的例子，现已证明连 τ 也不是可设计的量（`design.md` §2.2）
3. **要常数也得说清是需求给的，还是我造的**
4. **一致性 ≠ 正确性**，任何内生信号都得有个外部锚
5. **判据换形状，不换阈值**（后者只是把错误固定住）
6. **不要把生物的「实现约束」当原理**（2026-10-23 新增）——判定：换一个实现还成立吗？只在一种实现里出现的，是约束（分子种类 / 颅腔体积 / 代谢代价），不是计算必须的
7. **只搜支持自己的证据不叫搜**（2026-10-23 新增）——每个「X 存在」配一条「X 不成立」；多个源如果同源（同索引 / 同摘要服务 / 同一篇论文的转述 / 同一个人写的），只是同一个源出现了两次
8. **先查这一整套有没有现成学科**（2026-10-23 新增）——把机制清单逐条翻译成术语，看它们是否落在某个已有领域的词汇表里。全部命中 → 先读那一支的现成答案，再谈「新设计」。本次的代价是：草案从 `design.md` §2 推到 §11.4 才想起问「这不就是个 SNN？」，而 SNN 里已经有 LSRSNN（双峰 τ）、ELSM（演化出小世界 + 临界）、e-prop（在线局部学习）三件直接对应的成果，且它们在 2012~2026 年间已发表
9. **定义不清的概念不能当判据**（2026-10-23 新增）——本次是「自我 / 意识」：连碳基生物都缺乏公认定义，给硅基定判据只能是凭空编。**推论：一个量如果「任何实体都满足」，它不是判据而是必要条件**（例如「有个体差异 / 有稳定倾向」——固定权重的随机网络三项全过，它连学习都没有）；同理，一个量如果只能靠观察者投影给出（「看起来像同一个」），也不能当判据。**遇到这类概念，正确动作是悬置，不是找个代理量硬测**

> **第 9 条是怎么落地的（一条可复用的自检）：** 本次连续写错三版 D 判据（消融一致性 → 结构消融 → 个体性），每一次都是「想一个能测的量，然后把它当成自我」。共同错法：**想一个指标 → 它居然能跑 → 就当成判据**，而不是先问「这个量是不是任何实体都满足」。这个顺序不能倒。

### 13.4 不确定的地方

- **「两种时间尺度自然分工」只是假设**，无直接文献
- **「块扩散能撑住多步推理」未验证**（只有 SDAR / Eso-LMs 的间接证据）
- **过程四度量会不会被优化成新指标**——已有警觉，但无解法
- **「谁值得参照」是递归问题**（判断力需要参照，参照需要判断力）
- **「最长历史」类的问题已全部悬置**——「身份是否涌现 / 自我在多大尺度出现 / 压力与自我形态对应 / 消融能测出什么」四条随 D 判据一并悬置；不是「还不知道答案」，是**问题本身没定义清楚**
- **一套可塑性规则够不够**（`design.md` §2.10 的核心未知）——能用一套规则同时产生秒级精确历史与月级稳定策略吗？这是 §11.4 要回答的
- **「分化」会不会稳定出现**——即使出现了，N=5 里几次？不稳的话需要什么保证它分化
- **时间常数的分布能不能测准**——需要 τ 跨越几个量级，而长 τ 的估计很吃样本量；测不出来就分不出「单峰宽」与「双峰」
- **自发多时间尺度是噪声还是结构**——任何非线性循环系统都会自发产生多尺度（临界态）；§11.4 组 2 对照就是为了排除，但它能不能排干净还没验过
- **基因空间够不够宽**（S8）——这是 §11.4 阶段 A 的真正风险：如果基因只能表达我已经想到的那几种结构，演化只能长回我设计的东西，实验就白做了
- **「活」的六条判据会不会相互矛盾**——比如「不僵」与「不纯混沌」之间只剩窄窗口，可能大部分随机结构都过不了，导致演化无解
- **巩固窗口的长度**——不能拍脑袋，要从「什么算同一件事」推，但那个界限本身模糊
- **「短期」的二义会不会影响历史结论**——`design.md` §2.10 新发现的区分（状态持续 vs 未稳定连接）；本场已修 §11.4 的任务设计，但其他章节还没逐条回扫
- **必须给的稳态究竟是什么形式**——突触缩放 / 内在兴奋性 / 活动预算，三者的差别在本实验里能不能分辨
- **「无层」是否必要**——还是「层 + 稀疏激活」就够；赛博果蝇只证明了拓扑，没证明其余三条
- **环境锚的最低频率**——未知；需要「无锚漂移」实验回答
- **资格迹在长任务上的归因精度**——τ_e 与行为窗口如何匹配，未标定
- **教师弥散影响的可审计性**——记录到什么粒度才够
- **事件输出的粒度**——一句话 / 一个动作 / 一个阶段，未定
- **强化物的乘性门控是否会卡死学习**——任一项为 0 则整体为 0，需要避免「永远学不动」
- **分布式的长期记忆能否持续写入**——LSL 只验证到 7B / 三阶段；几百阶段、上亿条内容未验证（容量问题，不是机制问题）〔2026-10-23：本条前提（「长期记忆存在分布式载体」）已改——长期就是连接，问题换成「持续的强度累积会不会饱和」，仍无数据〕
- **混合 key 是否能保留 O(1)**——若 learned query 占主导，退化为 ANN 检索，可预取与 offload 两个工程优势消失〔前提已降级到 `design.md` §14.10，仅在「卡表必要」时成立〕
- **写时碰撞的检测成本**——校验位 / 读旧行比相似度，在 200 GB 级表上的开销未测〔同上〕
- **SNN 的固定代价能不能绕开**——0.16 nats 的 backbone 成本「不随算力变」；但 GSU 那条路（Scientific Reports 2024）其实是**放弃纯二值**（ternary + 连续流）才绕过去的——那还算不算 SNN，没定义
- **阶段 A 的基因型与实测 τ_d 不一致时怎么解释**——两者不是同一个量（`design.md` §2.2）；如果基因收敛到双峰、实测仍是单峰，结论该写什么？本版实验设计尚未给出裁决规则
- **脉冲化的块扩散能不能成立**——共用决策要求它（`reference.md` §15.7 ④），但 15 轮检索无先例：SNN 侧只有 SSM + 脉冲量化层（SpikingSSM），块扩散侧只有非脉冲的 SDAR / Eso-LMs。这条不成立，整个「共用」路线要退回「非纯二值」形态
- **「非纯二值」还算不算 SNN**——GSU（ternary + 连续流）是现有绕开二值表达上界的路径，但它放弃了「纯脉冲」；若采用，`reference.md` §15 的整套对照（功率、SynOps、神经形态硬件优势）要重算
- **阶段 B 在 CPU 上的真实成本**——「本机 CPU 小时级」是按什么实现估的？稠密实现与事件驱动稀疏实现可能差一个数量级（`reference.md` §15.3 ③）；模拟器形态未定
- **「没找到 SNN 的推理/指令跟随评测」是检索结果，不是定论**——15 轮 web_search，未逐篇精读；KB 侧未查（服务停着）
- **repeatability 的阈值 0.5 是从动物行为学借的**——那里的区间（0.35~0.88）是「个体在生物学意义上稳定」的经验值，**不保证适用于一个人工网络**；而且多解任务的「等价」由环境层判定，环境层的宽松程度会直接影响 ICC（判据越松 → 解越多 → 偏好分布越散）
- **个体性测量需要多久的历史？**——太短则历史没写进去（ICC ≈ 0），太长则测不起；这个长度未定，与 §10.10 S3（巩固窗口）相关但不是同一个量

### 16.1 模拟器成本实测（2026-10-23）

> 完整数据在 `test/baseline-2026-10-23-simulator.md`；脚本 `test/bench_lif.py` / `bench_lif2.py` / `bench_lif3.py`。本节只留结论。

**起因：** `reference.md` §15.3 ③ 自疑「本机 CPU 小时级」这个估计可能差一个数量级，模拟器形态（稠密 vs 事件驱动）未定。

**结论五条：**

| # | 结论 | 数字 |
|---|---|---|
| 1 | 草案的「本机 CPU 小时级」**偏悲观约 2 个数量级** | 单个体 N=1000 带可塑性：10⁵ 步 **4.3 s**、10⁷ 步 **7.2 min**；N=2000 分别 16.7 s / 27.8 min |
| 2 | **GPU 单个体比 CPU 慢 6 倍** | 0.1353 vs 0.0226 ms/步（kernel launch 主导） |
| 3 | GPU 只在批量时赢 | B=64 快 9 倍、B=256 快 33 倍（需 B ≥ 16 才抵得过 launch） |
| 4 | **可塑性在 batch 上是瓶颈** | N=2000 / B=256：带资格迹 + 权重更新是无学习的 **10.5 倍**（迹张量 (B,E) 受内存带宽限） |
| 5 | **稠密 / 稀疏交叉点 = 密度 5%** | 0.5% 时稀疏快 5.3 倍；10% 时稠密快 5.5 倍。§11.4 的搜索范围跨过交叉点 → 实现需两条路径按密度选 |

**一个否定结果：** 事件驱动（CSR，只遍历有 spike 的神经元）在纯 numpy 下只值 **1.25~1.92 倍**（活跃边 15~383 / 总边 10000，理论上该省 26~660 倍）。省下的遍历被索引构造开销（`repeat`/`cumsum`/`arange`）吃掉了 → **脚本语言里不值得为事件驱动增加实现复杂度**；要拿这个收益得下手写 kernel。

**一个约束（对阶段 A 的直接后果）：** GPU batch 的前提是所有个体共享同一个权重矩阵。本版阶段 A 的 E 在个体间与时间上都在变（生长/裁剪）→ **GPU 只能用于多种子（同规则不同种子），不能用于多结构**。

#### 最终状态（`grow_v2.py`，8 种子 × 5 万步）

```
mode=C  E0=30000（过度生产） -> 预算=15000  steps=50000  种子=8

seed       E    born   drop   rate%    std%  deg_E/I   n_inh  turnov
```

**怎么读这组数：**

| 观测 | 值 | 说明 |
|---|---|---|
| rate | **0.08%** | 目标 1.99%，差 25 倍——网络基本死了 |
| turnover | **0.0029** | 看起来「结构收敛了」，但配合 0.08% 是**收敛到死网** |
| born | 115 / 5 万步 | 新生几乎停了——共激活几乎不触发，没有「值得强化」的东西 |
| n_inh | 5950（占 40%） | 目标是 20%；**抑制边占位漂移**，竞争把它们留住了 |
| E | 15000 = 预算上限 | 预算在起作用（这是唯一按设计工作的机制） |

#### 四个确凿的机制性发现（有数据）

1. **性能：最初的实现是根本性错误**——用稠密 N×N（100 万格）存只有 8000 条边的图，每次衰减/剪除都要碰 100 万格；单线程细粒度 numpy 调用，CPU 只占 1/20 个核。改稀疏边列表 + 8 进程后：**7.6~7.9 万步/秒（快约 60 倍）**。（已沉淀为 AGENTS 教训「用稠密结构存稀疏数据」。）
2. **均质网络只有两种态，没有中间态**——固定结构扫 w：0.02~0.25 全部 **0.19%**，0.30~0.70 全部 **100%**。
3. **缺三个基本动力学要素，而它们都是实现错误**——① E/I 平衡（全兴奋只有全或无）② 不应期（放电率无上界，抑制比拉到 10 倍仍卡 20~30%）③ 硬预算 + 竞争（新建边无代价 → E 从 8000 涨到 28000、淘汰只有个位数）。加了之后 rate 才能稳定在 1.99%。
4. **衰减与强化的平衡是难点**——全局衰减把已强化的边也磨掉（0.50 → 0.145，5 万步衰减到 29%），共激活强化补不回来 → 死亡螺旋。改成「只衰减闲置边」后仍有抑制边占位漂移问题（20% → 40%）。

#### 根因推断（未验证）

**三个时间尺度不对齐：** 结构更新每 20 步、稳态窗口 200 步 → 结构变化比稳态快 10 倍，稳态永远在追移动目标。

#### 当时认为的下一步（当时未做）

把结构更新周期拉到与稳态同尺度（200~2000 步），且**逐项加机制**（先只开「共激活强化 + 闲置衰减 + 硬预算」，验证 rate 能稳住 2%，再加随机新建/退火），而不是一次全开。

### 16.4 一个认识修正：这不是 SA

起因是 Jerry 追问：「刚才说这已经不是 SA 了。你难道不是给定规则然后让它自己长？」——是，所以「SA 形态」这个标签从一开始就是错的。

| 当时说过的 | 错在哪 |
|---|---|
| 「单个体是 SA 形态 + 多次重启」 | SA 必须有目标函数 E(x)；这里没有。竞争是局部的（用得少就死），不是全局适应度 |
| 「温度 = 可塑性」 | SA 温度控制「接受更差解的概率」；这里不计接受/拒绝。只能说「可塑性随时间衰减」 |
| 「多次重启」 | SA 里重启为跳出局部最优；这里是**测种子鲁棒性**（草案要求 N≥5），目的完全不同 |
| 「局部 + 偶尔大跳 = SA」 | 「大跳」在 SA 里为跳出局部最优；这里的随机新建是**补局部规则够不着的部分**（长程连接）。没有最优就谈不上跳出 |

**根因：修正了结论却没回扫前面基于错误前提说的话**——正是 AGENTS 里刚写过的「前提修正要回扫全文」，又犯一次。

**这个修正牵出更深的问题（可能就是实验跑不通的真正原因）：** 没有目标函数，那「竞争」依据什么？实现里是「没被激活就被淘汰」——但**「被激活」本身取决于网络当前状态**，所以它是**自洽的**，不是**有方向的**。自洽的规则可以收敛到任何东西，包括退化状态（实验里收敛到 0.08% 的死网）。再往下：**输入是随机泊松、没有任何结构**，没有东西「值得学」，也没有东西能区分有用与无用的连接。

→ **下一步不是调参，是给输入加结构**（周期分量 + 可预测模式）。有结构后「能预测的活下来」才成立，这才是「用进废退」有意义的前提。这正是 `design.md` §14.8「环境反馈是锚，不是训练信号」——当时一个锚都没有。

### 16.6 闭环实验（2026-10-24）

**起因（Jerry）：** 之前失败有两个根因，只修了一个——① 输入没有意义；② **没有输出、没有反馈，这样在它内部说什么都没有区别**。本实验修 ②。

**形态（按 Jerry 给的）：** 输出不是外挂读出层，而是**回路里的两个普通神经元**（index 500/501）——它们的放电率被解码成动作，动作推进世界，世界状态又作为输入回来。闭环：`s(t) → a(t) → x(t+1) → 输入(t+1) → s(t+1)`。

世界 = 两个继承变量的周期驱动（快 T=20 步 / 慢 T=500 步）+ 动作推动 + 噪声。输入 = 世界状态的两个通道（前 50 个输入神经元看快模态，后 50 个看慢模态）。反馈 m = 稳态门 × 能动性（动作方差代理）。

**脚本：** `test/grow_world.py`（五个版本都在同一个文件里，头部注释保留了逐版修正记录）。

#### 五个机制缺陷（每一个都由数据打出）

| # | 缺陷 | 数据 | 修正 |
|---|---|---|---|
| 1 | 「闲置衰减」判据错：闲置 = 本步前后同时放电 | 每次保护 68 条 / 衰减 14932 条（**1:221**），等价全局衰减；rate 0.11~0.14% | 改为「前神经元 IDLE_WIN 步未放电」 |
| 2 | 就算判据改对，衰减的时间尺度也错 | 每 20 步仍衰减 2822 条（**1:141**）——活动率 0.5% 时绝大多数边在 20 步内不会被用到 | **衰减关闭**：硬预算已经是「用进废退」的实现 |
| 3 | 世界发散 | 纯旋转 + 恒定动作 → 幅度涨到 24.5（open 组 5.8），观测被 clip 成常数 | 改为有界变量 |
| 4 | 结构冻结（turnover 恒为 0） | 强化只覆盖「本步同时放电的对」= **0.45% 的边**；新边权重 0.08 远低于存量 → 新建即被淘汰 | 强化改成**资格迹**（`Δw = η·e_ij·m`），覆盖全部边 |
| 5 | 抑制边沙溢 | n_inh 从 40% 涨到 **73%**，rate 0.36% | 淘汰按**类型上界**归一化 + 新建边固定小权重 + **年龄保护**（25 次更新内不淘汰） |

**缺陷 1 / 2 / 4 同时解释了 `grow_v2` 那 15 版的死网**：它的 rate 0.08% 不是「结构不能自生长」，而是「衰减判据错 + 强化只覆盖 0.45% 的边」。同样参数、同样网络，修掉之后 rate = 1.55%。

#### 结果（5 万步 × 8 种子，同种子集可比）

| 组 | rate% | turnover | n_inh | a-o 相关（最大种子） |
|---|---|---|---|---|
| **closed**（闭环） | **1.55 ± 0.44** | 0.0450 | 6705 | **0.507 / 0.369 / 0.559** |
| open（断开动作） | 1.88 ± 0.11 | 0.0483 | 6813 | 0.082 / 0.100 / 0.041 |
| randact（动作随机化） | 1.80 ± 0.20 | 0.0488 | 6844 | 0.030 |
| noise_in（输入白噪声） | 1.39 ± 0.53 | 0.0424 | 6572 | 0.032 |
| frozen（结构冻结） | 2.09 ± 0.23 | 0 | 5921 | 0.114 |

#### 三条结论

1. **闭环管道建成且可测。** 动作与观测的相关在 closed 组达 0.51，open 组 0.10。**它证明的是「动作进入了观测通道」（回路连通），不是「感知到自己造成的后果」**——后者要求内部形成「我这么做 → 会这样」的预测，本版没有测（2026-10-24 订正：原写「直接证据」，超出数据能支持的范围）。
2. **闭环有动力学效应，但方向不是「变强」。** closed 比 open 的 rate 低 0.33、方差大 4 倍（0.44 vs 0.11）：反馈让部分种子进入低活动吸引子（0.82 / 0.89），部分保持（2.05 / 1.96）。这是**状态依赖增强**，不是学习。

   一个没被讨论的对照细节：**frozen 组 rate 最高（2.09 ± 0.23），closed 最低（1.55）**——结构可塑性把活动率压低，方向与「可塑性让网络更活跃」的直觉相反。含义未查。
3. **没有任何指标显示「学」发生了。** 本版只测了「活」（rate / turnover / 结构）与「闭环是否建立」（a-o 相关），**没有测功能**：预测误差是否下降、动作是否变得有效、内部状态是否对行为有因果作用。

#### 已知的形态问题

- **输出神经元能否被接线是随机的**：8 个种子里有 1~3 个的入度只有 6~8、放电率为 0（闭环实际未建立）。这本身是一个观测（结构没有长出「输出通路」），但会稀释组间比较。
- **世界过于简单**：两个继承变量的周期驱动，动作只能推两个标量。足以测「闭环是否影响结构」，不足以测「有没有学到世界的结构」。
- **能动性用动作方差代理**，不是「动作对世界的实际效果」——后者需要更长窗口的相关估计。
- **一次未成形的假设（保留，供下版参考）**：先把世界做成循环相位，结果 closed 与 open 完全无差异（1.44 vs 1.50）。原因：随机动作只是给世界加随机相位，统计上与 open 组的相位噪声不能区分。改成「带漏的积分变量」后差异才出现（a-o 相关 0.51 vs 0.10）。

|---|---|
| ① 预测误差 | 读出层 `Wp·s[t]` 预测 `o[t+1]`；前一半步在线 LMS，后一半**冻结**；**零模型 = 预测「与上一步相同」** |
| ①′ 离线最优读出 | 同一批数据用正规方程解最优 `W*`（前半段训练、后半段测试）——用来区分「没信息」与「在线没学好」 |
| ② 动作增益 | `a[t-1]` 解释 `o[t]-o[t-1]` 的方差比例（分段 R²） |
| ③ 前史因果 | 同 seed / 同输入，只把初始膜电位加 `1e-3`，比较输出放电分段计数 |
| 诊断 A 因果方向 | `a[t]` 与 `o[t+k]` 的互相关（k ∈ [-20,20]）：正侧 > 负侧才是「a 驱动 o」 |

#### 诊断 A：闭环的因果是双向的，真正「a → o」的成分只有 ~0.09

`a[t]` 与 `o[t+k]` 的互相关（8 种子 × 5 万步，最大通道）：

| 组 | 负延迟侧均值（k<0，o 领先） | 正延迟侧均值（k>0，a 领先） | 峰值 |
|---|---|---|---|
| closed | 0.3395 | **0.4265** | k=+18，0.4377 |
| open | 0.041 | 0.034 | 全平（~0.04） |

**读法：** 正侧 > 负侧 → 「a 驱动 o」这一半**确实存在**（open 组两侧全平，证明 closed 的耦合不是假的）。但两侧都高（0.34 vs 0.43），说明 0.51 的相关里**大部分是共同驱动或反方向**（o → 输入 → 网络 → a与慢周期的共同趋势）——真正的因果成分约 **0.09**。

这解释了后面 ② 为什么 R² 只有 1%：**动作对世界的影响被外源周期淹没了。**

#### 主结果：预测判据否定，且不是「读出层没学好」

8 种子 × 5 万步，前 2.5 万训练、后 2.5 万冻结（比值 = 误差 / 零模型误差；<1 才算学到）：

| 组 | pred/base（后 5 段） | 离线最优 ls/base（后 5 段） | 动作增益 R²（前四段 → 后四段） |
|---|---|---|---|
| closed | 1.005（1.002~1.011） | **1.10~1.17** | 0.0058 → 0.0115 |
| open | 1.006（恒定） | **1.08~1.25** | 0.0000 → 0.0002 |
| frozen | 1.013（1.011~1.018） | **1.03** | 0.0161 → 0.0169 |

**三条读法：**

1. **`pred/base > 1` 在所有组、所有段**——预测器比「猜不变」更差，而且**离线最优读出更差（1.03~1.25）**。→ 已排除「在线 LMS 没学好」这个解释：**即使给最优线性权重，也预测不过「猜不变」**。机制：泛化时 `E[d·Ws] ≈ 0` 而 `E[(Ws)²] > 0`，所以过拟合的解必然比零模型差——这正是观察到的。
2. **没有任何一组出现下降趋势**（open 完全平，closed / frozen 只是波动，且 ls/base 随段**上升**）。→ 冻结读出层后，网络状态**没有变得更好预测**。
3. **动作增益 R² 在 closed 上升（0.0058→0.0115），但 frozen 更高（0.0165）且恒定** → 不能归因为「学到动作的效果」；更可能是**结构可塑性让网络前期乱、后期稳**（frozen 结构固定，从第一步就稳）。

#### 前史因果：3/8 种子持续发散，5/8 完全同步

| seed | 偏差（前 1k 段） | 偏差（累计） | base / pert 输出率 |
|---|---|---|---|
| 1 | 13 | **1286** | 0.037 / 0.018 |
| 5 | 39 | 341 | 0.047 / 0.048 |
| 7 | 12 | 418 | 0.000 / 0.000 |
| 0 / 2 / 3 / 4 / 6 | 0 | **0** | 相同（完全同步） |

**读法：** 3 个种子对 `1e-3` 的初始扰动持续放大（正 Lyapunov），5 个种子扰动被完全吸收。**这是「发散 / 收敛」的二分，不是「记住了什么」**——发散可能只是混沌（敏感但不携带内容）。所以判据 ③ 只完成它字面上的作用：**排除「输出仅由当前输入决定」**（3/8 成立），不构成「学到」的证据。

#### 结论

**首轮功能判据：三项里两项否定，一项仅作排除。没有证据显示「学」发生了。**

三个层次，从硬到软：

1. **状态里没有可线性读出的「下一步」**（离线最优也差于零模型）——这是最硬的一条。
2. **动作对世界的影响太弱**（R² 1%，因果成分 0.09）——即使有表征也测不出「能动性上升」。
3. **没有下降趋势**——不是「还没学好」，是「没有在变好」。

#### 已知的形态问题（下一轮的入口）

- **预测目标选得太弱。** 零模型误差只有 3e-4 ~ 9e-4（`o` 每步变化极小，因为 `tanh` 饱和 + 慢周期），改进空间本身就不大；同时 `s` 极稀疏（rate 2%、每步 ~20 个放电），单步线性读出能拿到的信息很少。**换目标（多步 `o[t+k]` / 累积量 / 表征而非预测）比改动力学便宜，应先试。**
- **世界太简单**（§16.6 已记，本轮首次量化）：`K_PHASE=0.05` 对 `AMP=0.10`，动作贡献被压到 1% 方差。
- **「状态有没有表征当前观测」还没测**——这是比「预测未来」更基础的一问；若连同期都读不出，问题在信息容量（rate 太低），不在学习。
