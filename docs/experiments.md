## 现有证据能支持什么

等预算初始化搜索含 64 候选×32 代、三个配对重复及独立测试世界。胜者重训 512 步后，自身经历条件下进化组严格完成率为 25.31%，随机搜索组为 24.97%，三个配对差值分别为 +0.40、+1.98 和 −1.36 个百分点。观察到的差异随配对重复变化。[完整留出结果](evidence/seed-evolution-2026-11-11-large/report.md) · [搜索协议与恢复入口](reports/initialization/seed-evolution-experiment-2026-11-11.md)

11/10的[固定循环特征对照](reports/memory/frozen-trace-experiment-2026-11-10.md)只改变encoder是否更新，保留先读后写、状态容量、数据与训练预算。正确教师经历后总体严格完成19.75%，原先读后写版19.60%，手写soft参照84.37%；内容翻译仍约24%。固定特征仍不足以学会可靠绑定，不能据低分宣称旧记忆保持成功。

取消手写绑定后，第一版学习者在正确教师经历下严格完成19.5%，手写soft为84.4%；自身PG有少量回报改善，内容翻译仍近随机。z中可线性恢复请求身份不等于现有读写头已会使用它，旧A还没可靠学会，不能直接讨论保持成功。[学习绑定、实际回报与读写顺序后续](reports/memory/learned-binding-experiment-2026-11-07.md)

冻结原执行器后，64 标量关联适配器可将新公开示例用于实际行动。第一版 delta 在大量 B 后旧 A 冲突严格为 85.9%，累加为 76.6%、同状态递归为 55.4%；改写 A 后分别为 83.4%/60.2%/54.8%。绑定器是手写的，第一版地址参数独立，不能据其 theta_only 分支证明共享表示稳定。[关联状态实验及共享地址后续](associative-state-experiment-2026-11-07.md)

定向复习旧 A 减轻了有限范围的遗忘：A 冲突严格为 61.7%，不复习/等量旧 B 为 48.4%/46.8%，但 B 成绩有代价。再统一学习 64 次 B、停止复习后，A 组为 52.4%，对不复习的优势缩至约 3.7 个百分点。两个阶段都冻结后评分，原世界和 h 连续返回也有同方向结果。额外前史重建成本单列，不能称同 FLOPs。[旧经验复习与后缀保持](reports/memory/episodic-review-experiment-2026-11-07.md)

连续状态下扩大时长覆盖使 16–32 的严格完成从同预算对照 7.6% 提高到 33.3%，旧 8–16 从 90.8% 降到 72.9%。撤出 A 后，A 冲突严格从 79.4% 降至 50.3%，B 提高到 96.2%；不重置原世界与 h 的返回测试也有同方向损失。更常答成 B 是旧 A 错误的主要签名之一，不等于证明旧信息完全消失。[时长覆盖与规则撤出](coverage-retention-experiment-2026-11-07.md)

实际中点示范使同预算动作组在 4,057 个新请求上的严格完成从 50.8% 提高到 87.0%，三个种子均改善；抢答首错从 1,715 减到 10。联合组为 87.5%，没有一致的额外严格优势。示范同时改变标签和回执历史，更长等待仍然失败。[教师时机与真实行为](teacher-timing-experiment-2026-11-06.md)

完整保留原策略后，只训练辅助时间读出的对照与原策略逐步一致。时间目标更新循环能把共同教师历史的时间 MAE 从 0.633 降到 0.154，实际严格完成却从 64.5% 降到 5.0%；联合训练也未稳定优于只练动作。更精确的时间读出未转成可靠行动，旧动作头的内容排序还可能受干扰。[保留原策略的时间学习](remaining-time-experiment-2026-11-06.md)

相同 256 次更新、零初始化新动作头的对照中，原模式损失下全训练组完全不结束。把模式损失改成三类各自平均后，冻结/全训练在新请求上的普通完成为 65.1%/46.4%，严格完成仅 3.7%/2.9%，抢答首错接近全部请求。损失归一化会改变出手倾向，尚未解决时机可靠性。本轮未证明分头结构优于原策略。[同预算训练与单个补测](reports/actions/action-split-experiment-2026-11-05.md)

在 4,040 对新的相邻就绪时刻上，训练后 GRU 的线性时间读出有约 88%–91% 的成对方向正确，但两步都判对只有 28%–31%；一个固定小型非线性读出为 33%–37%。同一状态的版本与内容在首次合法时可读到约 89%–90%。模型已有可读的时间信息，精细边界尚不稳定；本轮读出未控制动作。[时间边界与内容诊断](reports/actions/timing-boundary-experiment-2026-11-04.md)

固定旧 A 的末步 WAIT，把其 FINISH 标签提前到首次合法时刻，混合测试的新 B 合法窗口漏发由 33/117 降至 0/117，但旧 A 首错抢答从 9/118 升至 84/118，同槽冲突对两次全程无错从 95/317 降至 42/317。另有两种正例时刻之间的单点补测。[结束监督时间与自由行动](finish-position-experiment-2026-11-03.md)

保持相同旧请求和训练预算，把唯一的 WAIT 从处理中点移到最高风险处，旧 A 冲突请求的首次错误为过早 FINISH 的计数从 106/118 降到 19/118，静态末步为 9/118。静态末步将两次均无错的冲突切换对从 12/317 增至 95/317，新 B 合法窗口未出手的请求则增加。[等待监督时机与实际行为](reports/actions/wait-position-experiment-2026-11-03.md)

等预算比较三种旧请求复习方法后，普通 GRU 更常最终做成旧 A，但无错切换仍很弱。在 317 对同槽同符号、情境改变且正确答案不同的长请求中，两次都严格完成的数量为均匀组 12、只选冲突组 0、按误差组 2。不复习参照为 1 对。交错测试的首次错误常出现在合法窗口以前。[复习选择、B 速度和切换结果](reports/memory/review-selection-experiment-2026-11-03.md)

2026 年 11 月 3 日的前史迁移实验又区分了起点与后续增益。A 组还没学 B 时，答案重合部分的严格完成率为 30.0%，需要改答案的部分为零。在相同难点上交换相关前史，前四轮曲线平均优势三个种子分别为 +24.72、−0.12、+0.24 个百分点。另在完全相同的公开输入与回执下，部分双向共享模型的状态和行动倾向仍长期分离。[新规则学习与相同输入释放实验](reports/memory/experience-transfer-experiment-2026-11-03.md)

- 显式事实存储、学习写入策略、旧经历参与更新，在各自小任务中有可核对的收益；尚未合成一个能自主选择经验、长期更新全部部件且稳定保持能力的系统。
- 完整连续状态保护跨边界任务，但不自动解决长等待。原动作头失败、独立线性探针失败和实际任务失败是不同证据。
- 结构确实可以出生、减弱和退出；边数、回路数量、平均损失下降均不足以证明功能分工或长期记忆。若撤出前没有学会，撤出后的零分不能测出遗忘。
- 2026-11-03 的普通 GRU 在独立长任务中获得有限的全程无错完成，同更新预算的历史复习改善了旧规则及其独有符号的保持。这是有教师、四种规则、三个种子的结果。
- 双向共享循环模型对进入运行时的 h 明显敏感：一次移入训练端点状态改善同一批新请求的表现。这不等于系统能从任意起点自行恢复，也不计入主评估自主保持成绩。

各轮任务、模型、训练起点和分母不同。已观察到的跨游戏结果来自规定的游戏、感觉条件与实验者提供的候选比较关系，适用范围见[迁移报告](pulse-game-transfer-boundaries-2026-11-19.md)。

## 读表口径

| 需要区分的量 | 本页采用的含义与限制 |
|---|---|
| 普通／严格完成 | 普通完成允许请求中途出错；严格完成要求最终成功且全程无错。请求指标只计各协议规定的成熟、合格请求，继承／未成熟请求另列。 |
| 空闲误动作 | 按策略实际遇到的空闲机会计数，通常报告每千次机会；策略改变后分母也可能改变。低误动可同时意味着始终等待。 |
| 内容可读性／真实行动 | 在 FINISH 子集内选对、外部探针读对、教师要求 FINISH，以及模型真的合法出手完成，不能互相替代。 |
| 连续状态／时间信用 | h、世界、时钟、回执和优化器连续，不表示计算图或梯度无限延续；完整 RTRL 的求导边界也单独限定。 |
| 规则保持／单请求记忆 | 撤出某家族后仍会其映射，和一次命令消失后 h 影响输出，是不同问题；“未来不再发旧请求”也不等于历史库不再复习。 |
| 重复数／工程核验 | 各轮多数为三个独立训练种子；actor、请求、分叉和数百万一致性检查不增加独立训练重复。测试通过验证实现，不能单独证明科学机制。 |

<a id="rnnsnn尚未形成可比较的转换"></a>

### RNN→SNN 仍未形成可比较的转换

[rnn2snn.py](../experiments/prototypes/rnn2snn.py) 对两层 32 维 RNN 做正负分解，实际 N=166、N_E=130；旧“32→1000”混淆了已有基线默认规模。源／目标状态、符号、时间、输入输出和更新协议尚未通过等价性与标定对照。不能将下降唯一归因于抑制比例、编码或某个参数；步长、积分窗、发放率和 E/I 均可作为待检选择，不由历史默认值固定。这段是历史问题定位，不是批准或完成新路线。

<a id="撤销的公式与门槛"></a>

### 撤销的公式与统一门槛

旧 §11.6.2 同称记忆时间和稳态误差均近似 1/(1−ρ)，却称乘积为常数，第三句与前两句矛盾，已撤销。标量稳定线性递归的衰减时间可写 −1/ln|ρ|；反复扰动的界另依赖范数与收缩条件。矩阵非正规性、非线性、输入、读出和脉冲机制都会改变结果，不能只凭谱半径推出通用记忆时间或误差界。

旧 ρ∈[0.95,0.99]、固定掉点比例和固定 probe_decay 不再作为全项目统一通过标准。初始图的环数、边数、平均活动、低空闲误动、检查数量也均不能替代任务能力及适当因果对照。

<a id="当前仍存在的代码限制"></a>

### 历史框架仍保留的执行限制

这些路径保留旧运行语义，新原型不使用对应流程；整理并未修复它们。来源为[审查](review-2026-10-26.md)、[实验声明](../src/experiments.py)、[信号实现](../src/signal.py)和[配置](../src/config.py)。

| 配置／路径 | 实际行为及结论限制 |
|---|---|
| sig_episode | Signal.on_action 的 episode 分支清空 _last，任务末没有可补发动作权重信号；不能作正常的延迟权重学习。 |
| sig_episode 沉默路径 | Signal.on_silence 仍生成目标方向向量，允许时 runner 据此更新 bias；该组仍有在线目标信息。 |
| sig_scalar | 动作信号可为标量，沉默分支仍给目标方向向量，不能称全程纯全局标量反馈。 |
| ho_frozen 对 ho_grow | 关闭 topology 时也使 reset_state_per_chunk 回默认 false，而 grow 为 true；结构可塑性与状态连续性同时改变。 |
| 部分 homeo／hebb | 为对齐旧行为启用 reset_state_per_chunk=True，不能作从不重置的连续系统。 |

201 项历史对齐不消除上述限制，也不证明后加配置接受过相同检查。[局部学习补充](streaming-local-notes-2026-10-26.md)另说明旧 after_m 对统一非零标量幅度的归一化抵消，以及 frozen／bias 的历史口径问题。
