## 研究目标

研究一个智能体能否在持续交互中主动获取经验、更新自身，并在后续情境中取得可验证的改进。“不问也会变强”是希望验证的能力，不能靠持续运行或参数一直变化来判定。

持续自主学习是项目重点，单独满足它不足以定义 AGI。自主设定子目标、跨域迁移、已有能力的保留都需要独立评估，不能假定会随在线学习自动出现。“自我 / 意识”没有在本项目中形成可操作定义，继续悬置，不作为架构依据或成功判据。

“一个完整个体”表达的是系统层面的连续性与整合目标。它不决定必须采用哪种神经元、是否从零训练、是否共享全部参数或是否允许外部存储。

旧稿关于“记忆只能是连接”“只能从零训练”“不能 BPTT”“先证明不能涌现才允许设计”的说法均不能升级成现行约束。保留历史是为了追踪问题如何形成与被修正。

## 先分清状态、记忆与学习

| 对象 | 本文中的含义 | 需要回答的问题 |
|---|---|---|
| 运行状态 | 隐状态、膜电位、缓存、活动迹等随运行变化的量 | 哪些边界保留，哪些边界重置？ |
| 持久记忆 | 能在指定间隔与干扰之后影响后续行为的信息 | 信息存在哪里，如何读写，保持多久？ |
| 学习 | 经验引起可测的后续能力变化 | 改变来自状态、接口、权重、结构还是外部存储？ |

这些是功能与测量上的区分，不预设必须分成几个物理区域。连接权重、拓扑、快权重、持续状态和外部记忆都可以成为候选载体；载体有更新不等于已经学会。

跨 episode 的保留取决于实验实际重置了什么，不能预先规定“只能靠权重”。长期记忆也不只与使用次数有关：时间、干扰、衰减、巩固和检索条件都可能影响表现，应由具体模型与实验检验。

持续状态与反向传播是可分的设计维度。TBPTT 截断计算图可以保留隐状态数值；PyTorch 官方例程使用 `detach()` 后继续传递 `hidden`，不是清空状态。来源与适用范围见[参考资料](reference.md#持续状态与训练边界)。

## 实现选择仍然开放

现有 [src/core.py](../src/core.py) 的脉冲网络、统一实验框架，以及 [RNN 原型](../experiments/prototypes/grow_rnn.py)是可复用的实验资产。历史行为对齐保证它们能用于回看旧结果，不赋予其中的参数或机制不可修改的地位。

| 选择维度 | 当前可比较的候选 |
|---|---|
| 动力学与计算形态 | 连续值循环网络、SNN / LIF、状态空间模型及混合系统 |
| 训练起点 | 从零训练、预训练初始化、转换、蒸馏或混合训练 |
| 信用分配 | BPTT / TBPTT、资格迹、带神经元特异反馈的局部规则及其组合 |
| 记忆载体 | 持续状态、快权重、慢权重、拓扑、可检索的外部存储及组合 |
| 结构与时间尺度 | 固定或可塑结构，显式、共享或逐单元可训练的时间常数 |
| 生成与动作接口 | 自回归、扩散及其他接口，按任务需求比较 |

这些候选不是已批准的新架构。下表把逐轮记录收回到其实际检验的问题；具体数字、运行状态和复现入口由[实验索引](experiments.md)维护。

| 设计问题与假说 | 已试机制、结果边界与来源 |
|---|---|
| 学习接口和反馈，能否改善记忆的使用？ | [显式存档与读取](persistent-experiment-2026-10-26.md)比较了共享读取循环、补足预算的简单循环、联合梯度、自评与真实二值奖励；补足预算后简单循环也能全对，联合梯度和自评未显示额外收益。[持续流](streaming-experiment-2026-10-26.md)把写入、读取、停止作为训练对象，但回到冲突旧规则仍失败。可训练接口有用，不等于自主判断经验价值已成立。 |
| 反复计算与持续状态分别提供什么？ | [消耗式规划](planning-experiment-2026-10-26.md)让完整规则可见、每动作前清状态，比较共享循环、独立深层和外部搜索；共享参数不保证额外迭代有效。[动力学](dynamics-experiment-2026-10-26.md)改为跨动作保留状态，以实际时间增量积分，并将数值子步与行动机会分开；学习循环改善指定任务，长等待仍失败。该同步监督实现不构成硬件异步或通用推理优势。 |
| 连续性本身能否形成长记忆？ | [完整连续状态](continuity-experiment-2026-10-27.md)延续世界、待发生事件、回执、时钟、h 和优化器；截断梯度与重放分支不覆盖实时状态。清状态损害跨边界任务，但连续训练未自动改善未见长等待。完整暂停恢复是同一模拟过程的恢复，不是程序暂停时仍在演化。 |
| 旧经历参与更新，能否保持能力并学会修订？ | [交错与巩固](reports/memory/consolidation-experiment-2026-10-26.md)在显式情境/版本条件下测到均匀重放的保持收益。[整合](integration-experiment-2026-10-27.md)与[前向信用](credit-experiment-2026-10-27.md)显示收益依赖误差信号和更新规则；本地无任务信用共激活没有成功，持续对角资格迹也未自动保留远期影响。固定表征、线性平方损失的充分统计量可替代相应样本目标；动态表征压缩仍未验证。 |
| 交错、缺席与返回，能否区分一次记住和长期会做？ | [从随机出生的交错实验](lifelong-experiment-2026-10-29.md)匹配历史复习与近期重复的辅助计算，分别记请求保持、规则缺席和参数复习；等 tick 不等于等事件或等经验。[学会与记住](reports/memory/learn-remember-experiment-2026-11-03.md)中普通 GRU 在有教师、有限复习条件下已有自主长任务完成与旧规则保持，状态交换也改变内容选择；尚无自主重要性选择或无限期保持证据。 |
| 更复杂的瞬时场、回路和功能分工是否有益？ | [回路实验](loops-experiment-2026-10-28.md)先确认原稠密图已有不同长度回路，再用零初始化、等增量参数的来源平方项和接收者/来源乘积项扩展，保留状态与旧优化器；并未新增层、出生或路由。[组织实验](organization-experiment-2026-10-30.md)实际比较普通、独立非线性支路和嵌套耦合，具体形式未整体胜出。图的支持、有效影响、瞬时表达与跨时计算须区分，当前没有稳定功能分工的证据；历史[深转移等参数方案](evidence/credit-2026-10-27/topology-design-v1.json)仍是未运行的独立方案。 |
| 生长或退出，是否比收缩和固定支撑更好？ | [持续流](streaming-experiment-2026-10-26.md)测到固定预算硬剪冲击，共存减少即时损害却仍遗忘。[渐进增删](rewiring-experiment-2026-10-28.md)用候选 BPTT 导数生长、旧边到零退出，两种强度再生长未优于同收缩只退出。[因素对照](factors-experiment-2026-10-29.md)分开允许集合、软收缩与永久退出，主要保持表现接近；固定允许位置的零权重仍可恢复。边数、实际非零恢复、初始图外首次使用和累计更替都不等于知识累积。 |
| 能否按功能复核结构，而不把删边规则当结论？ | [组织实验](organization-experiment-2026-10-30.md)用旧窗口导数提案，再在下一块近期/历史轨迹复核；混合损失改善可伤旧经历，半幅可接受不保证全删。休眠导数影响裁剪，有限候选限制速度；候选数、窗口、半幅均是配置。[覆盖与退出](reports/structure/coverage-exit-experiment-2026-11-02.md)后来才在指定弱边规则下产生真实退出，[缺席与返回](reports/actions/action-return-experiment-2026-11-03.md#退过弱边的模型经受旧任务缺席和返回)在保留复习条件下测到部分短任务保持；未证明一般功能性自组织。 |
| 无向连接与完整时间信用能否解决失败？ | [无向图方法](undirected-experiment-2026-10-30.md)为无序节点对共享一个参数，对照可学习接口与统一端口，并用记录轨迹上的完整 block-RTRL 跨块传敏感度。[正式结果](undirected-results-2026-10-30.md)中统一端口全等待、零完成，生长与渐退也未实际删边。[共享循环 GRU](reports/memory/learn-remember-experiment-2026-11-03.md#双向共享循环连接的对照)使用另一种带门动力学，有较低且不稳定的完成；其参数量、接口和行动经历不同，不能仅归因于无向性。 |
| 信息可读，是否就能正确行动？ | [独立读出](credit-experiment-2026-10-27.md)分开状态信息与动作头；[启动覆盖](reports/structure/coverage-exit-experiment-2026-11-02.md)带来成功 BEGIN 经历仍未让原生端口出手。[外部 BEGIN 头](reports/actions/action-return-readout-2026-11-03.md)可启动但伴随误动，接入结束头或[自主轨迹复拟合](reports/actions/action-return-experiment-2026-11-03.md)仍无可靠长任务完成。[内容与时机](reports/actions/content-timing-experiment-2026-11-03.md)发现提示须经下一步传播，长等待的内容与时长区分均有问题；[等待期内容监督](reports/actions/wait-content-experiment-2026-11-03.md)仅小幅改善内容排序，实际长任务仍零完成。 |

额外 idle 损失曾减少误动作，也减少部分允许途中出错的最终完成；它只在训练时使用动作前的真实空闲掩码，推理仍自由选择。始终 WAIT、较高探针分数、更多连接或单项严格指标都不足以代表整体成功。共享循环 GRU 的[起始状态干预](reports/memory/learn-remember-experiment-2026-11-03.md#同一组权重为何有时能工作有时会一直乱动)还表明，同一权重的工作表现可以依赖进入运行时的 h；移入状态改善表现，未说明它能从任意起点自行恢复。

以下旧推论已撤销：

- 持续状态不能推出“必须 SNN / LIF、从零训练、脉冲化块扩散、禁止 BPTT、无任务或无准确率”。
- “τ 不能逐单元设计或训练”不成立；已有逐神经元膜与突触时间常数可训练的反例。S4D 的初始化实验也不能推出普遍禁令。
- e-prop 具有神经元特异学习信号，不能用它为任意“全局标量 × Hebbian 规则”的有效性背书。
- “记忆就是连接”“失败经验不得写入”“必须先证明不能涌现才允许设计”都不再作为公理。失败轨迹可以提供学习信号；显式机制与自组织机制都可以接受比较。
- 特定规模、E/I 比例、1.99% 放电率及旧谱半径窗口只是特定装置的取值或标定，不能作为通用目标或门槛。

以上来源见[参考资料](reference.md)，详细审查见[本次复核](review-2026-10-26.md)。

## 反馈与评价

反馈需要说明来源、密度、延迟、噪声、可用信息量和归因粒度。下一 token 监督、环境成败、教师提示、预测误差和内部一致性测量的是不同对象，不能一概排成固定可信度顺序。退出码、测试或环境奖励也只覆盖它们实际检查的内容。

预测与控制可以在同一系统中结合。内部一致、低预测误差、稳定放电或结构收敛都可以作诊断，不能单独证明任务正确或持续学习。结果表现与过程证据应一起记录；过程更短也需要确认没有牺牲正确性。

比较学习方法时，必须同时说明它们收到的信息与更新的部位。例如，“只有任务末奖励”若仍收到朝目标方向的沉默提示，就不是纯延迟标量反馈；“冻结”若偏置仍在学习，就不是完全冻结。

## 开放的研究问题

| 问题 | 需要区分的证据 |
|---|---|
| 是否发生经验驱动的改进？ | 与未学习、随机和简单可学习基线比较，排除输入泄漏与接口变化 |
| 信息由什么保留？ | 分别检查状态保留、状态重置、参数冻结与记忆读写条件 |
| 是否持续学习而不挤占？ | 新经验后的获得、旧能力保留、干扰与恢复 |
| 长期训练后是否仍能学新东西？ | 在可比难度和学习预算下，分别测新任务学习速度、旧任务保持与返回后的重学速度；活动多样性只作辅助证据 |
| 是否发生迁移？ | 与训练情境分开的任务或分布，报告迁移收益与代价 |
| 是否能自主获得有用经验？ | 获取信息的动作、经验选择、子目标及其实际后果 |
| 是否值得采用脉冲或局部规则？ | 同等信息、任务与资源下的功能表现、计算成本与实现限制 |
| 结构是否有利于复杂计算？ | 区分状态转移内部深度、循环层数、状态容量与连接拓扑；匹配参数、计算和训练后，分别检验保持、计时与组合任务 |

这里不规定新的数字门槛或固定实验路线。每项研究先定义可证伪假设、数据与状态边界、对照和判定方式，再记录结果。当前有限证据及仍未修复的实验限制见 [experiments.md](experiments.md)。
