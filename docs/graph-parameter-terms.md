# 图模型的参数与写入术语

本文档采用项目约定：**参数指全部偏置、接线和权重**。对本轮固定节点集合的图，记为 P = (b, M, W)。

| 名称 | 在本项目中的含义 |
|---|---|
| 偏置 bᵢ | 节点 i 自身的带符号偏置。写入节点也各有偏置。 |
| 接线 Mᵢⱼ | 从发送节点 j 到接收节点 i 的连接是否存在。这是独立的布尔状态。 |
| 权重 Wᵢⱼ | 已存在连接传递信号的带符号数值。存在且权重为零，与连接不存在可以由读回区分。新版对不存在的连接读回为零，去掉连接时也清除其权重。 |
| 参数地址 | 一条有向连接的地址可操作其存在位和权重，偏置有自己的地址。对允许自环的 N 节点图，地址数为 N²＋N，最多有 N² 个连接位、N² 个活跃权重和 N 个偏置。报告“活跃数值数”时仅计实际存在的边权和偏置。 |
| 写入器 | 图中产生写入决策的部分。它的入边、出边和节点偏置也属于图参数。移植实验只取预登记的写入节点入边、对应权重和偏置，读数覆盖这部分可移植的改变。 |
| 活动 h | 节点在某一拍的激活。连续生命中，活动和图参数都能影响下一拍。清活动是需注明的实验干预。 |
| 执行规则与实验设置 | 端口的物理含义、更新时钟、地址解码、采样器、执行器、节点数及实验中的优化器设置单列。当前图参数的写入权限不包含改写这些程序和增删节点。 |

**完整寻址**指所有偏置和全部有序节点对（包括自身）都可以选到。**完整操作**还要求已有边能独立调权或退出、缺边能连入并给定初值，且写入器自身没有保护行。写入是否受额外约束另行记录，如数值限幅、强连通保护、单次命令数。一次写入能执行、模型曾经自主发出该操作、该操作改善未来学习，是三个不同的验证问题。[执行器及逐地址验收](evidence/self-edit-dose-2026-11-19/permissions/README.md)
