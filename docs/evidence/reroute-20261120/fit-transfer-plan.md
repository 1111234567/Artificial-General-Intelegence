# 留出整份房间地图的训练复验

沿用主训练的六个配对出生、原生回路、取样规则、阶段预算和优化器。比较终点教学与加真实房间教学。为复验分配另一个独立随机域，训练的预先划分只依赖实际前史里房间到终点的绝对物理地图。

按房间 0 的原终点、房间 1 的原终点、余下终点构造三元组。训练只接收偶置换 (0,1,2)、(1,2,0)、(2,0,1)。严格留出奇置换 (0,2,1)、(1,0,2)、(2,1,0)。两个支持域内，每种终点都分别可以是任一房间的原终点或未用终点。门分配、复查位置、顺序、改道和目标仍独立随机。交换左右门时，先前房间到终点的地图和划分不变。若单独交换房编号，绝对地图及划分随之改变。

生成器保留按次序出现的前 64 条符合训练地图划分的生命。正式固定终点每条件每个出生 1,792 次更新，其中 256 次为启蒙。对每一批匀速核验真实走门、到账、房间教学和地图划分。主训练与本复验分别封存，主训练的世界划分保持原定范围。
