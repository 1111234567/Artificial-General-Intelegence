# 同一份先前经验，只改变房内看到的出口

补充诊断复用严格地图复验已冻结的策略。把原来两次过门、受复查房间、探查顺序和最终目标完全相同的生命配成对；一条复查时看见旧出口，另一条看见通往第三终点的新出口。两份生命周期均在复查后第一次回到起点作真实选择。让两条生命的内部试探与最终运动均使用同一对均匀抽样值，记录当正确优门翻转时，模型在两条历史都选对的比例、两条均选错的比例、保持原选侧的比例；在优门不变时计算错误换边。另从每支路的真实运动概率精确积分共享动作带，给出在这套有限地图上的期望。

区分记错房间与记错房间的出口：从同一真实历史询问左门或右门，遍历六个后来才出现的目标。对固定试探，算哪一个终点的六个真实效用最接近主区的六个预报（均方距离）。这是冻结后的功能性读数，不等于图里有显式终点槽。只在被复查且真的改道到第三终点的那扇门上报告新出口、旧出口和另一终点各自被选中的比例，等距平分。三候选等概率基线为三分之一。与第 3 拍对房间本身的预报联合阅读。所有数字在两种教学、未见与见过的先验图内各自给出。
