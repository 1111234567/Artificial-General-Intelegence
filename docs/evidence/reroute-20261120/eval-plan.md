# 局部改道后的第一次真实行动

## 冻结样本

全部六个独立出生 731–736，逐出生配对比较只教实际终局的 `terminal`、额外教实际经过下一房的 `next_room` 以及同方法错配试探的 `misbound`。测试世界根种子为 287416031、287416099，各 128 根全交叉地图。仅侧别固定模板在 287415979 的 64 根独立校准地图上按模型与侧别平均，测试世界从未参与模板制作。测试时间不训练参数。行动和试探各有独立的固定均匀随机数。同一根地图内的完整对照共享随机数，同一出生各训练臂与同一身体各干预逐行共享随机数。试探和行动采用冻结模型原生马达口，以零探索噪声取样。

标准身体先实际经过起点两道门，再亲历一次房内出口报告。然后只经过规定的决策准备和内部试探。主端点只记该报告后在起点发出的第一次正式选门，以及这次实际经过房间和终点后得到的收益。试左、试右两条内部支路用于预测对照。它们不推进身体在地图内的位置，也不算外部动作。无额外返回起点并试行一道路线作为新提示。审计前史、真实结算、试探保持外界不变及分母。外部参考只从地图计算两门可到房间、最后终点与收益，并与强制实际走过两支的结算交叉核对。

## 分层与对照

- **翻转（flip）**保留改道前后都有严格优门且两者相反的情形。**保留（stay）**要求同样发生物理改道，前后严格优门相同。**无改道（unchanged）**是实际重复观察旧出口的对照。**终点同效（tie）**包括同归后的负、零、正结算，任一门均可，没有指定应选的门。每类报告前后优门侧、探房所在侧、实际行动与终点收益的分母，区分收益为负、零、正。
- **自然、空试**冻结于完全相同的身体状态，保持拍数和普通桥接。空试只取消这一次动作脉冲。
- **固定侧别**将副区活动、迹和接收快权逐拍固定在该身体的空试轨迹，只向主区空试回流加独立校准的左、右模板。模板按侧别和拍均值固定，对具体生命只带一位试探侧别。零模板必须逐位复现空试。
- **错配回流**保持受体的请求、真实脉冲、前史与拍数。供体有相同最后观察、目标和试探实体侧，但初始门到房的映射互换。保留受体的空试背景电流，取供体对应的自然减空试方向并缩放到受体自然减空试的逐拍范数。若供体没有方向而受体有增量，用固定公开轴回填并报告次数。把真实回流逐拍重注入受体应逐位复现原状态、预测与行动。真假回流审计至少覆盖每套世界每种冻结模型的首个完整根组。
- **仅末次观察**移除早先两道门的物理经历输入，等拍保留末次局部观察、当前目标、身体动态与自然试探。**旧优门固定**是有特权的行为捷径，照走改道前严格较优的实体门，在同一新地图核算本次真实收益。**试探前马达固定**把正式选择固定到等时空试之前已可发出的本体选择，检验内部窗口前的自然偏好。

## 统计与判断

- 主教学对比是 `next_room/自然 − terminal/自然` 在翻转情形的严格选优率。两套世界的配对 95% 区间下界均需大于零。保留情形（B）的同一教学差在两套世界的下界均需高于 −5 个百分点。终点同效按实际到账逐行核对，选任意门均满足等效选择准则。无改道单独报告，并列出 B 的同身体 `自然 − 空试` 非劣对照。
- 一次普通试探带来动作改善需要该教学组同身体 `自然 − 空试` 在翻转的配对区间两套下界均大于零，同时两套 B 下界高于 −5 个百分点。自然相对固定侧别、错配回流分别使用同样的配对翻转端点，附相应 B 差，另报告 `next_room − misbound`。无需以相对初始状态的预测排对替代实际动作。
- 独立检查预测习得。先从同一准备状态分别令身体内部试左、试右，再以主区原生终局单元的两路标量排序严格优门，分差恰为零给半分，并以物理收益算均方误差。同时检查提前拍的下一房有符号读出和零预测均方误差。操作性预测门槛为两世界自然终局排序均高于机会半分，且相对空试的排序差两套配对下界均大于零。数值误差和相对侧别、错配的表现另列。这条门槛与动作门槛独立。
- 保留每个出生与根地图全部场景。对同一指标的不同模式或教学，先逐根逐出生相减，再用相同的出生和地图下标交叉自助重采样 8192 次，取 2.5% 与 97.5% 分位。两测试世界分别显示，不合并。记录比例分子分母、每个出生的均值、冻结文件与协议、代码和原始账本的 SHA-256。未过任一门槛时保留数值及区间。
