# 副区中途换房，主区是否按新房间的后果选择

两条供体生命的每个门在改道前后都通向相同的终点、收到相同的收益，供体当前两房同归、到账为零。仅交换其物理房间身份，使两条供体对同一门作试探时会经过不同房。接收者有自己的目标和实走地图；第 3 拍只把副区 20 个活动值换成其中一份。保留受体主区、快权重、慢迹和待采用增量，随后四拍完全按原图运行。自身同拍活动重注逐位复现。正式选择只在受体的真实世界结算。[完整预定设计](midpoint-plan.md)

主要读数取「换入房 0 相对换入房 1 的差」在两种相反目标下的半差。若房 0 比房 1 更有利时模型更倾向于走所试的门，调换目标后该倾向也反转，则为正。对照再使两房实际通往同一终点。各出生遍历六种终点角色、两扇受检门与其它成对条件，另抽两套正式动作随机带。两套比较使用同样的六个训练出生。

换房对实际动作的交互在分流时比同归高 5.52 [0.47, 11.26] / 6.12 [1.30, 11.46] 点，马达概率也同向。分流中相对保留同中点、同范数的逐坐标错配，实际动作差为 +4.50 [−0.21, 9.33] / +4.93 [1.56, 9.27] 点，其中一次区间跨零。同归的两个区间也都超出预置的 ±3 点等效范围，不能称其确定无影响。主区终局预告的分流交互区间均跨零，只教终局的分流动作交互接近零。

所以，有助于表示房身份的副区活动确实能把马达倾向朝接收图中的相应后果移动，幅度随路线是否同归而有所不同。尚未通过“中途换房同时稳定改变终局预测、实际动作，并超过等量扰动”的整套机制判据。试探选择的总体增益必须依据正常身体的真动作另算。更换全部副区活动，也会转移与房间一起出现的其它状态。[原始数据指纹与配对效应](midpoint-results.json) · [逐个体分叉](../../../experiments/pulse_game/reroute_midpoint.py)
