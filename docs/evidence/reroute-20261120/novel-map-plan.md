# 留出完整房间出口映射

现有离散地图只有两扇门、两间房和三个终点。即使换了几何种子或动作随机带，不同地图组合也会重复。为单独检验跨未见组合的第一次选门，另训同精度、同预算的两组：只校准终点的规则和同时校准下一房的规则。初始「房0出口、房1出口、剩余终点」作三项排列，开发期间仅出现偶排列；全体奇排列只用于检验。所有单个终点、房与门、可得收益、目标、保留/改选/同归情形须在两侧有覆盖。训练日志的每个先验映射与正式检验的整张先验映射交集必须为空。此划分不能排除有限游戏内的快捷运算。

独立构造全部 6 种原出口排列、两门映射、被查房、首次探查次序、三种出口事件和 6 种后到目标。测试将训练见过和未见过的排列分别完整列出（每侧 3 种房间先验图），再对物理动作抽样使用两个新根种子 5469301 / 5469361，各 32 份随机带。结果按出生和三种基础先验图分别给出，并报告完整有限地图集合的精确策略期望，不能把同一地图的多份抽样当作新地图。分别检查真实改道且旧优门翻转、真实改道但优门保持、未改道、两门同归下的首次实际收益，另测同身体、同钟的空试、同一自然试探前的直接选择和只依据旧地图的显式策略。

用与主研究相同的标准评估在未见先验图上的行为效益：两个世界带的翻转情形均有正的配对区间（双教学减终点单教学，以及同体自然减空试，两项分开判断），在需保留原优门时差的下界高于 −5 个百分点。准确预测房间与终点另行计分，不代替真实行动。每个对照给出按当前身体的自选试探做真实选择的收益；冻结检验才另外执行两条内部试探以积分其选择分布，不将未选路线标签传给本体。全部分支用原受体图真实结算。
