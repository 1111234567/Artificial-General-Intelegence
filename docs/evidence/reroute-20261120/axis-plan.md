# 冻结副区的房间方向

使用旧地图奇偶留出复验的六个配对出生，比较只校准终点和额外校准下一房的两个固定训练终点。枚举全部旧地图组合，固定同一个内部试探侧，同时交换两房的物理身份、旧出口表和复查位置。每个门的旧、新终点与旧、新目标得失在这一对中完全相同，实际下一房身份翻转。冻结后的外部分析只读副区 20 个节点。

按两个旧出口身份的无序对分三折。在其余两折按「房 1 减房 0」定向后取两组自然活动之差的均值，单位化作一条线性方向，配对中点的平均投影作阈值。测试折的两张互为交换的旧图都不进入该折的校准，同一折只把奇排列作为正式测试受体。每对供体仍包含相反奇偶的自然对应轨迹。校准覆盖三种复查、六种目标和两个问题。分别报告在准备末、注入后第一拍、第三拍、第五拍和第七拍的单样本与成对房间准确率。同一状态的两个问题在准备末对应两间相反房，构成计半的诊断底线。该线性方向只在冻结后用于测量。

仅对第三拍做活动替换。真实供体选择两条当前路线同归到零收益的配对，两个供体拥有相同 q、每门的旧终点与旧得失、当前终点和当前零得失。取其自然房间活动差的半个投影，沿冻结方向对原受体副区第三拍作等幅正负改变，其余副区分量、主区、迹、快权和候选保持在受体值。正交对照沿同一供体差的正交分量改变并配平每条生命的能量。受体用未见旧图，配对比较实际分流和改到同一终点，再交换目标使两房回报顺序翻转。只动副区活动后照常运行后续递归、原生预测和真实马达。

首轮核验发现直接加法会使部分活动超过原生的绝对值 1。保留初版作为敏感性结果，同时增加区间内的复验。每条生命对两个方向、两种符号共用一个最大允许缩放因子，使所有节点都在原生范围内，并保持方向与能量匹配。

主统计量是房 0 方向减房 1 方向的终点预测与询问门选择概率，再乘以分流下房 0 的真实目标符号，与同归、正交和另一训练条件比较。真实走门分别用独立预先固定的两个动作抽样带，同一配对共享随机数，身体实际穿门后才记录房间对应的真实到账。同方向下还配对比较代入符合真实房的信号、代入另一房信号所获得的实际与期望收益。每张旧图去重汇总，区间按六个出生与三份留出旧图交叉抽样。可读性与这次定向干预是否影响后续行为分别报告。
