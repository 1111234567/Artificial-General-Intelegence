# 中途换入另一间房的自然副区状态

问题是在同一个接收身体、同一试探门和真实地图内，只改变中间时刻副区的活动，后面四拍的预报和真动作能否遵循「换入的房间究竟通往哪里」。这里干预的是原生节点活动；供体的房间语义由其真实物理经过确定，图不收到房间标签。

- 取终点教学与增加下一房教学的六个匹配出生。冻结后在两套固定随机带（93156371、93156413）分别检验。世界只有三个终点的六种角色排列，全部枚举，每个排列另取八份新动作带。每根另外交叉被探查的房、门到房映射、初次访问顺序和固定内部试探左或右。统计时先在每个角色排列、成对条件中平均，共六个有限地图角色；两套测试是同一有限集合上的不同真实选侧抽样。避免将重复画出的相同离散地图计为新的结构。
- 来源身体的两个房间在复查后都通往同一个终点，且供体目标固定为令这个共同终点得零。另一供体仅对调两房的实体标记，同时对调门→房、原房→出口和被复查的房。两供体对每个门在变更前、变更后的真实终点、收益和初次过门次序完全相同；但固定试探同一扇门会经过不同房。取两供体在同一个自试脉冲下第 3 拍的副区 20 维活动。供体没有看到受体的目标或其未来正式动作。
- 同一供体对用于两类接收体。分流接收体把探查房改到第三个终点、另一房保持；同归接收体把探查房改到另一房的终点。两类都向本体给出相同的两个目标设置：按分流图房 0 和房 1 可得 +1/−1，或 −1/+1。同归时两个选择的真实收益相同。受体自己的实际地图、经历、输入、主区活动、全部快权和痕迹均保留，只插入一份自然的副区活动。主区自己在后续无新感觉的拍数中行动，真实结算始终由受体地图决定。固定试探方向、目标和正式动作抽样在干预间配对。
- 主要交互为「蓝房活动减黄房活动的差」在两种相反目标下的半差。对终点预告、选择试探门的运动概率及真正是否走试探门分别计；正值说明受体的表现朝其自己的房间后果移动。要求分流组预告和实际行动交互在两套随机带下都高于零，且显著超过同归和等量扰动。色名只对应两个看得见的实体房。对照从同一对自然供体逐坐标交换成分，保持两个向量的中点、差量 L2、范围及拍数；每个随机带和地图角色预定平衡交换 10/20 个位置。另记同归组效应是否落入 ±3 个百分点，而不是把跨零解释为等效。
- 额外检查同一身体自身中拍活动重注的逐位一致性，同时核对除副区活动以外所有状态字段保持不变。若正常训练只学到一个可读取的中间标签，而它在这条路径上不能驱动正确的后续决策，就报告是哪项通过。这个定向干预是诊断用的反事实；不会把供体的答案或重复试门送进训练。
