# 自环、单向环与多闭环的表达力证书

三种 [电路](../../../experiments/pulse_game/ring_logic_model.py) 都沿用逐元 `tanh`、可训练的泄漏、稠密输入和线性读出。自环学习每个单元的自耦合，单向环学习每个单元来自唯一前驱的耦合。多闭环使用相同的单向主环，再加一个固定的发送者置换 `p(i)`，每个节点有两个不同的来边和两个去边。目的节点 `i` 的主环与弦边系数同为 `gᵢ/√2`。对于五维输入、单一读出和 32 个单元，三组都有 449 个独立参数，包含 32 个可取正负实数的增益。

## 固定端口的一拍布尔任务

把测试位直接放在指定单元内，真值编码为 `+1/2`、`−1/2`，其他初始状态固定为零。再次输入为常数，更新一拍后，比较指定目标单元的状态与固定阈值，正向读出。构造取合法置换 `p(i)=i+16 (mod 32)`，即各节点的弦边连接环上的对向节点。

| 任务 | 能实现的结构 | 另外两种结构的限制 |
|---|---|---|
| 把节点 0 的位一拍复制给节点 16 | 多闭环可沿弦边传递 | 自环和单向环在该拍都读不到节点 0 的状态 |
| 节点 1 复制节点 0 的位，同时容许节点 17 的位独立变化 | 单向环只从前驱 0 接收 | 自环读不到节点 0。多闭环对 `(+1/2,−1/2)` 和 `(−1/2,+1/2)` 得到同一个和，后续 `tanh` 与泄漏保留项的输出也相同 |
| 一拍反转节点 3 自己的位 | 自环取保留系数 `1/2` 和增益 `−2`。正输入的输出为 `1/4−tanh(1)/2<0`，负输入的输出为其相反数 | 当其余节点为零时，另外两组的候选值与节点 3 的初态无关，泄漏保留项则严格随初态递增 |

前两项的端口可针对任意合法置换选定，取同一目标的弦边源和主环前驱即可。中间一项的碰撞来自两条入边共享增益。释放为独立弦边和主环增益后，总参数为 481。节点 1 可将主环增益取正、弦边增益调小至幅值低于主环增益，弦边输入就无法翻转输出符号，两条边仍可保持非零。最后一项依赖读出方向固定。[布尔回归测试](../../../experiments/pulse_game/tests/test_ring_witness.py) 在实际前向中验算这三张完整真值表。证明的条件是固定端口和一拍时限。训练实验有全局输入和读出，且允许传播多个 tick，不能用上表预测训练成绩。

## 稠密输入与读出下的平衡点响应

固定基础输入，各模型从各自的平衡状态出发。记 `K=diag(kᵢ)`，其中 `kᵢ=σ(leakᵢ)∈(0,1)`，`zᵢ` 为平衡状态进入 `tanh` 的值。状态 Jacobian 为 `A=K+DW`，其中 `D=diag((1−kᵢ)tanh′(zᵢ))` 为正对角矩阵，`W` 为候选状态的耦合矩阵。零候选偏置和零基础输入给出零平衡状态，可用稠密驱动把输入的一阶方向 `B` 设为任意实列向量。读出 `C` 也是自由的。以脉冲进入状态后的当拍为第 0 拍，标量的一阶响应为 `hₜ=CAᵗB`。

- **自环**的 `A` 为实对角矩阵。统一取泄漏保留系数 `1/2`，任意对角值 `λᵢ` 由增益 `gᵢ=2λᵢ−1` 实现。取 32 个不同的负值，并用全 1 的标量输入方向和读出，使全部极点可见。同宽的单向环或多闭环若复现这组极点，迹必须为负，与零耦合对角和 `trace(A)=∑ᵢkᵢ>0` 冲突。
- **单向环**的特征多项式为 `∏ᵢ(λ−kᵢ)−∏ᵢaᵢ`，`aᵢ` 是进入单元 `i` 的有效耦合系数。因为 `∏ᵢ(λ−kᵢ)` 在 `λ<0` 时严格单调，单向环至多有一个负实极点。另一方面，取 `A=I/2+P/4`，其中 `P` 是把状态沿主环移一格的矩阵，可得到非实极点。沿节点 0 输入和读出时，每个循环移位的模态都有非零权重。这一响应超出任意宽度自环的一阶表达范围。
- **多闭环**取合法置换 `p(i)=i+16 (mod 32)`。只在节点 0、2、16、18 设置非零增益，输入方向和读出都取 `e₀+e₂`。四个活跃节点收取的主环输入均来自始终为零的奇数节点，余下两对节点各形成一个互相反馈的二元块。保留系数取 `1/8`，两对在 `A` 中的有效弦边系数分别取 `1/4` 和 `3/8`，四个可见极点为 `3/8, −1/8, 1/2, −1/4`。两个不同的负实极点超出任意宽度单向环的一阶表达范围。保持相同置换并改为统一非零增益，则可取 `A=I/2+(P+P¹⁶)/8`，沿节点 0 输入和读出可见非实极点，因此也有自环无法复现的一阶响应。

这些构造给出自环与另外两组之间的双向区分，以及多闭环能实现单向环无法实现的响应。结论针对精确响应，弦边例子取的是拓扑族中一个明确允许的置换。将二元块例子中零增益改为充分小的正增益时，两个不同的负实极点仍为单根，极点及其非零留数连续变化，因此整个多闭环也能在所有边都有效的条件下保有这一区分。图没有源点或汇点的条件只约束连接的存在，碰撞、迹、极点和 Hankel 秩还依赖具体连边、增益和读写端口。单向环与多闭环之间的完整包含关系、有限振幅和非平衡轨迹的表达力，仍需各自验证。

代码另含一个严格互易的对照组。其 `W` 为对称矩阵，`D⁻¹ᐟ²AD¹ᐟ²=K+D¹ᐟ²WD¹ᐟ²` 实对称，所以给出实对角化 `A=VΛV⁻¹`。在稠密端口下，等宽自环可改用 `Λ,V⁻¹B,CV` 来复现其整个一阶响应。互易组与多闭环组的拓扑约束不同。

## 复算

[脚本](../../../experiments/pulse_game/ring_witness.py) 使用 `Fraction` 计算脉冲响应，并从 Hankel 矩阵恢复可见极点的首一多项式。对响应阶数 `r`，矩阵由 `Hᵢⱼ=hᵢ₊ⱼ` 定义。自环、单向环和均匀增益多闭环的 32 阶矩阵满秩，两个二元块的例子使用满秩的 4 阶矩阵。满秩证明有 `r` 个可控且可观测的维度。单向环或自环的 32 阶响应，前 64 拍就唯一确定任意等宽候选可使用的首一递推。多闭环的四极点响应若与一个 32 状态候选的前 36 拍相同，两者的差由至多 36 状态的直和实现，Cayley–Hamilton 定理使它们之后也必须相同。

```powershell
.venv\Scripts\python.exe -m experiments.pulse_game.ring_witness
.venv\Scripts\python.exe -m pytest -q experiments/pulse_game/tests/test_ring_witness.py
```
