# 分离感觉脉冲的顺序辨别

每个请求给出三种气味中两种不同的气味。第二种是第一种在 `0→1→2→0` 中的后继时，右端食物为正，逆向顺序则左端为正。保留任意一枚目标的身份，或保留两枚目标气味组成的无序集合，都会剩下两种等概率的方向。两枚目标脉冲都带有同一种可辨认的载波，伴随同端口的气味干扰。标准条件的两枚目标间隔 6–12 tick，并有 6 枚干扰脉冲。长间隔条件间隔 18–26 tick，并有 12 枚干扰脉冲。两种条件也有不同的等待长度。

每一对网络从相同随机权重出发，有 32 个感觉状态、449 个可训练系数。每个单元容许当前输入调整自身保留比例，再计算包含一个状态输入的非线性更新。有向臂把这个状态输入接到环上前一单元，自环臂接回同一个单元。两臂共享权重形状、初始化分布、线性读出和训练算法。感觉口提供三个气味坐标、载波幅度和运动门。运动门打开后，线性读出的正负号每拍强制产生向左或向右的脉冲。动作以开环方式驱动原 PulseWorld 身体，身体按阻尼、加速度、端点与阵风改变位置，首次碰到端点才计分。所有请求计入分母，感觉状态穿过接触、超时和下一请求连续演化。

训练先由随机探索策略对两臂的同一批感觉历史发运动脉冲，记录实际接触侧和收到的正负味觉。离线 Adam 按实际接触侧预测该动作的味觉结果。在这道二选一题中，相当于用接触侧和正负味觉合成方向监督。每步先经历前一次请求以形成连续感觉状态，再用当前请求的真实接触回执更新参数。开发世界中按两种拓扑和两种时序的平均物理正确率选中学习率 0.016、900 次更新，每步 48 个生命。冻结评分时权重固定，感觉网络的输入来自外部感觉时间序列。结果适用于相同探索经历与计算预算下的一个有向环和自环单元。[原始登记](order-registered.json) · [反事实修订](order-amendments.json) · [开发选择与参数计数](order-recipe.json)

## 原登记试验

12 个配对出生、192 个留出世界根，每根 12 个连续请求。区间分别重采样配对出生和世界根，先在每个世界内平均请求。

| 条件 | 有向循环 | 自环 | 配对差及 95% 区间 |
|---|---:|---:|---:|
| 长间隔，预登记主指标 | 84.57% | 76.17% | +8.40 [−6.58, 23.15] 个百分点 |
| 标准间隔 | 84.76% | 76.51% | +8.25 [−6.88, 23.17] 个百分点 |

主区间包含零，也超出预先设定的 ±3 个百分点等效范围。长间隔有向臂 8 个出生超过 95%，自环臂 6 个出生超过 95%。长间隔共为每臂保留 27,648 次机会，有向臂超时 12 次，自环臂 0 次。[出生、区间与逐条件统计](order-summary.json)

### 长间隔的行为对照

| 操作 | 有向循环 | 自环 |
|---|---:|---:|
| 同一 11 请求前缀，交换最后一请求的两枚气味，原版和交换版均正确 | 70.14% | 53.60% |
| 只去掉候选状态输入，保留可变自留项 | 58.67% | 54.88% |
| 第二枚目标脉冲前清空状态 | 49.40% | 49.69% |
| 去掉感觉状态的所有跨拍延续 | 50.23% | 50.12% |
| 只留第一枚气味身份，隐藏身份可反转 | 49.93% | 50.00% |
| 只留第二枚气味身份，隐藏身份可反转 | 49.98% | 50.00% |
| 只留载波与时刻，隐藏身份可反转 | 50.00% | 50.00% |

交换时对调两个完整气味向量，载波和其他观测逐拍相同。单气味和只留时序的双生分支有逐位相同的公开历史以及相反的计分方向。有向臂去掉交叉状态输入后的损失为 25.89 [14.81, 36.57] 个百分点。自环臂去掉额外自环输入也有损失，为 21.29 [8.69, 33.78] 个百分点。知道顺序规则的诊断策略只读公开脉冲信号，走同一物理身体，长间隔原版与交换版均为 100%。随机探索策略在长间隔为 50.22%。[逐世界结果和冻结权重](order-original-raw.zip)

单线程 Intel Core i5-14600KF CPU 吞吐约为每秒 63,208 和 63,864 个完整请求。12 个交替顺序的配对计时中，有向与自环的耗时比为 1.014 [0.953, 1.077]。计时包含感觉状态演化和物理动作评分，使用预生成世界，先预热并核对相同行为。[逐批计时](order-summary.json)

## 独立复测

首轮区间较宽，所以在查看任何复测结果之前固定了 64 个新配对出生和 192 个新留出世界根，每根仍有 12 个连续请求。训练世界池、网络、感官时间表、控制和分析沿用原配方。所有 128 份权重在复测评分前冻结。[复测登记](order-replication-registered.json) · [冻结检查点清单](order-replication-frozen.json)

| 条件 | 有向循环 | 自环 | 配对差及 95% 区间 |
|---|---:|---:|---:|
| 长间隔，预登记主指标 | 90.15% | 69.76% | +20.39 [15.04, 25.97] 个百分点 |
| 标准间隔 | 90.50% | 69.77% | +20.74 [15.32, 26.33] 个百分点 |

长间隔有向臂 46 个出生超过 95%，自环臂 21 个出生超过 95%。相同训练预算下，一个有向环更常学到可用的顺序策略，自环单元也能够学会。在长间隔中，交换两个目标气味后两种顺序均答对的比例为 80.35% 和 39.71%。有向臂去掉交叉状态输入后从 90.15% 降至 64.61%，配对下降 25.54 [21.88, 29.15] 个百分点。第二枚目标前清空状态后，两臂降至 49.96% 和 50.18%。三种只有部分信息的双生对照均为 50.00%，可读目标顺序的诊断策略为 100%。长间隔每臂 147,456 次物理机会，有向臂超时 1 次，自环臂 0 次。[复测统计](order-replication-summary.json) · [逐世界结果、训练日志及权重](order-replication-raw.zip)

两轮的逐请求结果与检查点分别归档。事后复核重建两种时序的训练池，核对每个训练日志中的实际回执计数，以及全部检查点的 SHA-256。每轮抽取登记中的首个出生，对两种时序、两臂、完整运行和各项干预的逐请求数组做了精确重放。[事后来源与重放复核](order-provenance.json) · [原登记归档校验](order-original-raw-sha256.json) · [复测归档校验](order-replication-raw-sha256.json)

## 复现

下列命令在仓库根运行，使用 Python 3.15.2、CPU PyTorch 2.15.0 和 NumPy 2.5.4 的本机环境。实际版本记录在冻结配方内。解压后的目录可作为 `--out` 或 `--results`。`confirm` 会补齐目录中缺失的结果，完整重新评分可在新目录中复制 `registered.json`、`recipe.json`、`frozen.json` 和 `births` 内的权重及训练日志。`order_verify` 用完整解压目录与已封存结果逐值对比。数组的最后一轴依次为是否正确、实际接触侧、接触 tick 和符号回执，超时接触侧与 tick 都是 `-1`。

```powershell
python -m pytest -q experiments/pulse_game/tests/test_order_study.py
python -m experiments.pulse_game.order_study confirm --out F:\order-replay
python -m experiments.pulse_game.order_analysis --out F:\order-replay
python -m experiments.pulse_game.order_replication confirm --out F:\order-replication-replay
python -m experiments.pulse_game.order_replication summarize --out F:\order-replication-replay
python -m experiments.pulse_game.order_verify --results F:\order-replay F:\order-replication-replay --output F:\order-provenance-replay.json
```
