# 相关经历能否加快新规律的学习？

在 192 个留出世界、六个独立出生中，与新规律有共同结构的旧经历，使个体在前 2、4 次教学机会上的平均学习增益多出 **8.52 个百分点**，配对 95% 区间为 **[6.69, 10.41]**。完全相同的读写结构使用默认系数时，这项优势已有 8.76 点。外层训练对这项优势的增量为 −0.24 点，区间 [−0.86, 0.37]。[预先登记的判据](relation-protocol.json) · [留出统计](relation-summary.json)

## 个体经历了什么

同一出生分到两种前史。两者都先在 A 学 12 对新气味，实际碰到食物才尝到正负味道。A 的变换会翻转四维气味空间中某个二维平面内的分量。相关前史与 B 共用这个平面，无关前史在一个独立抽取的平面中学同样难度的规律。两组随后面对完全一样的 B。开发时 B 沿一条直线反射；正式留出时 B 在平面内向一个未知方向旋转 90°。这些 B 变换在开发时从未出现。各世界的 A 和 B 有独立的味觉规则，四种正反组合全部测试。两组即使见过全部 A，在 B 第一次真正教学前都只有约一半机会选对。

每个出生沿用独立训练过的连续感觉图和脉冲动作器，并在开发世界单独训练新读写规则。每个气味对之间插入一题没有味觉的请求，使相邻真实回执能提供配对信息；各端口含义、背景地址和这种时间安排都是提供给系统的结构。新旧规则各自测试三个此前未见的气味对。每次从同一个教学后状态复制个体，给一次能尝味的锚题，再由身体自行走向两个端点之一，选择题的味觉静默。锚味单列，超时计错。所谓“两项都对”是同一生命状态分到两条未来后，配对的新旧探针都选对。[世界与诊断参照](../../../experiments/pulse_game/relation_world.py)

相关组和无关组的早期绝对增益分别为 17.63 和 9.10 点。回 A 从教学前到第 16 次机会变化 +1.04 点，区间 [−0.72, 2.79]，满足预设的最多下降 5 点界限。无关组在 B 教学前回 A 也有 80.80%。六个出生在同样的 192 个世界上接受测试，先在物理世界内平均四个正反组合，再同时重采样出生和世界。三个探针和四种组合都不单独当作独立世界。[逐世界数据](relation-worlds.json.gz) · [学习曲线](relation-learning.png)

相关组每生在 A 的 24 个味觉机会中平均实收 23.984 次，B 的 16 个机会中实收 15.986 次。两种前史在主学习器上的物理接触侧逐题相同。只比较两种前史中 A 教学收全、B 前 2、4 次收全且接触侧相同的生命，早期优势仍为 +8.55 点。使用公开气味和真实味觉、另获知变换类别和题目节奏的几何参照，在零剂量时也是 50%；两次机会后相关组为 100%，无关组为 74.31%。诊断时直接给身体正确方向，两组皆可达 100%。

## 哪一部分带来了优势

新学习器依据前后两次实际尝到的气味、回执和之前的预测，改写当前情境的连续映射。其他情境的映射以协方差形式引导本次改动。更新和读出共有 32 个外层参数。每生有六个背景地址，每个地址可改一个 4×4 的映射及一个味觉系数，共 102 个实际参与更新的快参数。提取气味脉冲的方式、背景原型分配、跨情境协方差的计算和按地址隔离写入都由实现给定。训练和留出时身体持续逐拍演化。[学习器实现](../../../experiments/pulse_game/relation_learner.py)

| 同一组相关前史和物理世界 | 16 次机会后 B 正确率 | 所检验的机制 |
|---|---:|---|
| 完整学习器 | 84.12% | 冻结外层参数，保留生内更新 |
| 保留局部更新，关闭其他情境的协方差贡献 | 79.54% | 两种前史的 B 曲线逐点重合 |
| 默认外层参数，生内仍可写 | 83.45% | 完整外层拟合在该剂量增加 0.67 点，区间 [0.16, 1.34] |
| B 教学后，仅把快矩阵恢复到教 B 前 | 49.99% | 原有运动、感觉、最近一次接触及随机数状态保留 |
| 打乱 B 教学回执 | 50.59% | 按真实接触时机从其他物理世界取得打乱的教学味觉 |
| 出生起冻结快矩阵 | 49.99% | 仍接触并保留短期气味痕迹 |
| 之前发布的手写同物／变换选择器 | 52.25% | 在原身体上原样运行 |

矩阵回滚使 B 下降 34.14 点，区间 [31.87, 36.37]，回 A 的成绩与完整矩阵相同。打乱回执损失 33.53 点，按置乱发生的 32 世界整块重采样，区间 [30.88, 36.06]。

把早期优势与关闭共享的同一个体再比较，可以拆出两个方向。开启共享使相关前史多学 **6.59 点 [5.35, 7.91]**，也使无关前史少学 **1.93 点 [0.57, 3.32]**。两者共同产生完整模型的 8.52 点差距。到第 16 次机会，关闭共享仍能使无关组从 75.02% 提高到 79.54%。另外，B 写入自己的地址，保护 A 的一部分能力由结构承担。

## 训练与复验

六个出生都从原独立出生登记的前六项取得，无二次择优。每个出生在三批开发世界尝试中心参数和三对正负扰动，再在 40 个独立验证世界比较四个入围参数。教师与评价都通过身体接触获得。首次留出运行因分批结果的元数据键不一致中止，未生成任何候选结果文件。修正汇总代码后，用同样的训练种子再拟合，核验六组参数与首次封存逐项相同。[初次封存](relation-original-seal.json) · [修订和最终封存](relation-seal.json) · [外层候选与验证成绩](relation-fits.json.gz)

在仓库根目录依次运行以下命令，建议将 BLAS 每进程线程数设为 1。准备阶段使用[六个冻结身体及读出配置](relation-births.zip)，完整旧训练档案可以作为另一条导出来源。正式测试原始数组位于 `data/pulse-game/learning-transfer-20261119/relation/test/`。另起进程复跑了参考出生首批 32 个留出世界的四种符号组合，1,170 个逐生命指标数组与原批次逐项一致。[执行环境、源文件与产物指纹](relation-artifacts.json)

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
python -m experiments.pulse_game.relation_study prepare
python -m experiments.pulse_game.relation_study fit
python -m experiments.pulse_game.relation_study seal
python -m experiments.pulse_game.relation_study test
python -m experiments.pulse_game.relation_study report
```
