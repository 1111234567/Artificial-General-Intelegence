# 一张图持续经历 512 道新题后，写入规则是否更容易迁移

固定原先一次接触启蒙保存的 8 个出生图和运行步。每个出生图与 12 个世界根交叉，运行 96 条完整开放生命及 96 条保护写入端的配对生命。每条生命依次遇到 512 道题，每题 4 次实际接触。每题更换一对反向气味并独立随机哪种是好的，左右位置在每次接触前随机。两种生态各占一半，反馈翻转概率为 2% 和 35%，气味浓度为两种可靠性提供共同的感官线索。题与题之间连续保留图和神经活动。生命阶段只运行归档的 NumPy 动力学与编辑提交，没有优化器。

在 0、8、32、128、512 题后取同一生命的快照。受体从同一出生图和零活动开始，精确移植供体四个写入节点的入边、权重、存在位和偏置。保护供体写入端的移植物逐位等同于出生参数，作为原始写入端对照。另一个对照保留开放供体的接线与数值增量总范数，在能保持限幅的同类输入间打乱数值增量。所有受体都开放生命写入。12 个新世界根与出生根和供体世界根完全交叉，每根提供两种生态和互补的偏好。每臂每剂量 4,608 个受体，实际自主动作在此前拿到 0、1、2、4 次真实反馈时计分。每组的互补偏好使反馈前正确率恰为 50%；移植仍能改变选择侧。分析对三个根因子独立重采样，保留臂、剂量和同世界的配对。方案在运行前固定。[预登记](preregistered.json) · [配对单元及完整结果](summary.json)

收益定义为 1、2、4 次反馈后的平均正确率减去反馈前正确率。512 题相对 8 题的收益差变化为 **+0.63** 点 [−3.21, +4.20]，512 题相对数值打乱为 **+1.89** 点 [−0.12, +4.27]。原始写入端的收益为 +7.69 点。预登记的三项条件均要求区间下界大于零，本次未达成。512 题时，77 个保持强连通的移植物收益差为 −7.08 点，19 个失去强连通的为 −7.60 点。所有移植物都进入主要分析。限幅后可行的打乱受到约束，终点 96 个移植物中有 26 个的权重增量被打乱并改变，54 个的偏置增量被打乱并改变，接线相同。[分析和单元数据](summary.json) · [配对正确率](paired-action-cells.npz)

512 题时分生态的次要分析，可靠反馈的移植收益差为 −16.25 点 [−27.10, −5.71]，带噪反馈为 +1.88 点 [−6.45, +10.66]。合并后的下降主要由可靠生态贡献。

## 实际改写和下一笔写入

终点 96 条开放生命写入端累计执行 404,169 次现存入边的调权、54,932 次偏置变化，长出 376 条入边、移除 1,292 条入边。对应的身体为 584,525 次调权、205,462 次偏置变化、3,612 条新增和 1,540 条移除。供体本身始终由原始提交器保护强连通。终点 11,524 条活跃边有 11,511 条达到限幅，1,536 个偏置有 1,533 个达到限幅。移植后反馈前的实际选择侧有 58.03% 与出生图不同。饱和与衰退同时发生，本实验未操纵写幅来独立识别饱和的因果作用。

下一笔写入的重放从共同的冷启动活动出发，复用同一个实际接触侧、味觉、气味和结构抽签。每个移植物内比较收到实际味觉与把味觉清零的提交结果，再减出生对照的同样差值。512 题时，身体边权和偏置差值的平均 L2 范数分别为 0.713、0.086，写入端分别为 0.551、0.029。身体和写入端的净存在位响应分别在 265 和 110 个受体分叉中不同。这个重放确认新味觉到下一笔实际写入的映射变了。

## 扩展权限图的单独复验

对允许包括自环在内的任意边地址和任意节点偏置写入的另一种图重复同一生态和剂量。保留 4、8 个写入节点各自的全部 3 个出生根。使用修正读回后的冻结检查点，活跃位独立于矩阵数字，未启用边的保存值逐位核对为零。接触时用原有地址与操作抽样和提交器，保持默认 ±2.5 数值限幅，并将真实接触后的活动保留到下一道题。每臂每剂量每个宽度 1,728 个受体。移植仍只复制写入节点的入边及偏置，写入节点指向身体的边留在出生状态。所有移植图保持强连通。[单独预登记](expanded-preregistered.json) · [扩展权限结果](expanded-summary.json)
