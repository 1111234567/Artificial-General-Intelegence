# 旧版单次启蒙的结构梯度审计

旧版梯度确实会沿已执行的连续边权、偏置和被选中新边的首值反传。它没有计入参数改变后生退命令出现概率的变化。三组图、九个输入方向的全枚举显示，该概率项在这些方向均非零，大小和符号随图与接触改变。

## 一次接触怎样枚举

沿用[历史启蒙损失](../../../../experiments/pulse_game/self_write_core_bootstrap.py)与[原生执行器](../../../../experiments/pulse_game/self_write_core.py)。图先选择一侧并实际收到味觉，之后各发出一次可弃权的生边、退边命令。写完后从静息活动重测气味的两个朝向，目标为平均 softplus 损失。审计在第 101 个出生图、同根历史一步启蒙检查点及[等预算长信用](../bootstrap/README.md)检查点各固定一个气味对。读取状态为本图，连续写入规则与历史稠密版本一致。

每个结构命令共有 241 种抽样结果。概率先由写入活动经截断决定是否发命令，再由独立 Gumbel 扰动取最大值。后者的地址概率等于未扰动分数的 softmax。对生与退的两个概率向量取外积，精确边际化每例 (241^2=58,081) 种原始命令组合。原生执行器先检查占用并生边，再检查退边及强连通。因弃权、地址无效、强连通保护或同一新边立即删掉而得到同一提交的概率合并。三例分别得到 13,407、13,407、13,532 种不同的提交，其中有正概率的为 13,407、99、133 种。命令发生率为零的情况也保留在联合支持里。

对每个结构结果 (e)，后续损失有连续函数 (L_e(	heta))，其发生概率为 (p_e(	heta))。在动作、门控截断、写入阈值和限幅所在区间不变的局部，期望损失梯度为

\[
\nabla_\theta \operatorname{E}[L]
= \sum_e p_e \nabla_\theta L_e
+ \sum_e L_e \nabla_\theta p_e .
\]

第一项是历史抽中路径导数的期望。逐路径冻结被抽中的地址、离散写入和实际动作，保留对执行后连续数值的导数。第二项来自策略概率。它既有命令有没有发出的门控贡献，也有选择哪个地址的贡献。历史训练中的结构抽样、地址和收据均在梯度图之外。后一项会影响参数应怎样通过改变未来写入分布来降低损失。

最小步长下，整项约等于两项之和的最大绝对残差为 (1.33\times10^{-10})。固定各分支的损失，独立用 Torch 对门控与地址概率求导，和数值概率项的最大差为 (1.60\times10^{-9})。给原版 `training_trial` 输入独立选定的原生随机种子，覆盖无结构动作、实际生边和实际退边，原版浮点导数与对应固定分支的双精度差分最大差为 (1.90\times10^{-8})。等预算长信用例的退边门控已关，偏置 15 仍可通过图内活动改变生边地址概率，此方向的概率项主要来自地址分布。历史一步例的生边门控已关，剩余的退边概率仍有贡献。

这是三个单次接触的局部审计。它没有测量跨多次结构变化的梯度，未给出训练总体偏差，也未跨过硬动作、硬阈值、限幅或门控截断边界。两条已训练的样例仍使用旧版单次接触目标做诊断。完整方向与算子取值见[设置](protocol.json)和[结果](results.json)。
