## 在线学习规则

同一连续状态经过 120 道请求。身体自行移动，实际接触时才收到带正负的味觉。把左侧编码为 −1、右侧编码为 +1，接触侧乘味觉便得到这一道应选择的侧。回执到达后，快速回归调节自身动作预测的乘数。乘数从正值起步，可以通过预测误差改符号。上下文项根据两次有标记脉冲引起的循环状态变化，从过去实际回执学习相近请求的预测残差。使用公开标记阈值和两次脉冲的先后顺序属于架构先验。个体接触之前无法读取正确侧，运行时也不提供规则、气味对编号、切换点或所在阶段。

本次回执损失沿感知、循环状态、动作读出和感知键回传。所有活跃边各自调权，感知权重、门控、偏置和动作读出同时可写。每 9 次回执尝试从任意非自连缺边中出生，把该弧的带符号敏感度作为首笔权重更新。每 6 次回执尝试退休，要求正的回执收益估计足以抵偿与系数平方成比例的代价，并保留整图强连通。新增和退出均保持其余边的有效系数尺度。唯一的图约束是强连通和禁止自连。

完全反转的 480 个生命共出生 **6,240** 条不同代次的边，全部收到后续回执并实际修改自己的系数。**4,920** 条后续退休，**1,320** 条存活，终图有 **57–68** 条边。所有边的生长、调权和退出与性能结果在同一批生命里发生。性能对照分离了快速标量和上下文程序带来的净效果。单独操纵改线以估计它的行为贡献属于另一项实验。

## 分区与复现
