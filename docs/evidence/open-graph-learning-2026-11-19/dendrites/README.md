# 原生端口图中的可塑二阶树突输入

同一张 16 节点强连通图接收两侧各 4 路原始浓度、实际接触和味觉，并由两个动作节点的状态直接驱动行进。每个接收节点把其现存入边中每对源活动先相乘，再用独立的树突系数加权，合并进该节点原有的一阶入边电流。源活动是上一拍的神经状态。每个节点都使用相同形式的有界更新，初始树突系数为零。没有向端口预先输入浓度乘积，也没有指定任何气味坐标之间的组合。[节点实现](../../../../experiments/pulse_game/dendrite_ports_graph.py)

实际接触回执触发试次内截断反传。一阶权值和二阶系数共同接受当前动作梯度。二阶边权更新为接收端信用乘上两条发送活动的乘积，多拍贡献相加。尚缺一条入边的组合可以通过信用提出长边。退边优先考虑一阶和二阶作用都较弱的边，保持强连通，并去掉依赖已退入边的二阶系数。选择规则、试次界限和跨节点信用传播由实验程序给定。[试验协议](registered.json) · [物理运行器](../../../../experiments/pulse_game/dendrite_ports_study.py)

三种图用同一批加密度的随机出生图和同一份初始一阶权重、更新速率、偏置。对照“加法”给每一对入边分配同样数目的参数，将源活动相乘改为求和后乘固定尺度。加法项可并入有效一阶权值，分配的参数槽数相同，独立函数维度不同。所有确认图臂共享乘法图在开发出生和世界上选出的配方。训练过程保留在线增边和退边，各臂的最终接线随各自经验而变。[匹配及配方](development.json)

## 纯交互世界的物理结果

沿用纯交互世界的味觉生成。每个生命的两侧物体均从 4 个独立的连续浓度分布采样，私有的 4 个交叉项系数决定期望，单个气味分量没有边际味觉信息。实际味觉仍有随机性，只有身体抵达一侧时才能尝到该侧。反转隐藏在生命中点附近，同时改变所有私有交互项的符号。确认独立交叉 8 个出生根与 12 个世界，每臂、每种情境各 96 个连续生命，每个生命 1,280 次请求。表中末段为 112 个无公开味觉、无探索电流的新物体对，按身体首次接触期望较高物体计分。[原始分段及配对区间](summary.json)

| 模型 | 稳定末段 | 反转末段 |
|---|---:|---:|
| 乘法树突图 | 75.04% | 73.68% |
| 同参数槽加法树突图 | 49.53% | 48.90% |
| 原有 tanh 图 | 50.55% | 50.12% |
| 乘法树突图，独立随机回执 | 50.61% | 49.36% |
| 图外公共浓度多项式参考 | 93.97% | 91.37% |

乘法图稳定情境比加法图高 25.51 个百分点，反转情境高 24.78 点。按出生和世界做配对交叉重抽，95% 同时区间分别为 [21.39, 28.84] 和 [20.73, 29.32] 点。相对于 tanh 和随机回执的四项同族区间也都严格高于零。隐藏反转后前 64 次，乘法图从反转前的 65.72% 降到 39.42%，末段恢复至 73.68%。公共多项式参考单独示范了该物理回执足以学到的能力，结构对照只使用共用图内信号。[结果与区间](summary.json)

每个乘法图平均有 61 次增边、68 次退边，从约 759 个二阶系数槽起步，末段约 819–824 个。单生命平均约 32.4 万次二阶系数的实际梯度改写涉及至少一条在生命内新增的入边。该量按请求与二阶系数组合计数。独立核验覆盖 1,228,800 条物理请求记录、变点前两环境的一致性、无回执时无权重改写、无效二阶系数为零，以及每次退边后的强连通。[轨迹与参数核验](checked.json)

## 成熟图的二阶系数切断

确认结束后，给每个训练好的乘法图再提供 128 个新物体对。两条分支具有完全相同的已学一阶权重、接线和零初始活动，保持静默且停止学习。一条保留已学二阶系数，另一条只把二阶系数置零。保留二阶系数的稳定准确率为 74.51%，置零为 50.91%，差 23.60 点，95% 同时区间 [20.23, 26.54]。反转世界中为 74.33% 与 50.24%，差 24.09 点，区间 [21.05, 27.19]。两分支接触率均接近 100%。该干预测量学成后的能力对二阶系数的依赖。[切断登记](pair-ablation-registered.json) · [物理切断结果](checked.json)
