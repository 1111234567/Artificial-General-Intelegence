# 统一端口图学习非线性气味偏好

左右两份食物各有四个连续气味分量，由相互独立的均匀分布生成，中心为零。每个世界有一组新抽取的私有系数，只乘在第 1、2 个分量与第 3、4 个分量之间的四个交互项上。这个加权和决定真实接触后收到正味觉的概率。任选单个分量并固定其值，翻转另一组分量的符号就会反转效用，保持输入的联合分布，因此单个分量的边际期望味觉为 50%。反转环境在生命中点附近暗中翻转全部私有系数，气味、地形和探索驱动保持配对。每个生命共 960 道，末 128 道的食物全新，关闭味觉回执和对学习器动作的探索驱动。[登记和源文件指纹](registered.json)

两种图均有 16 个节点，保持感觉、动作、味觉和接触端口同属一张强连通循环图。原始版使用 `tanh`。平方版在 8 个气味节点和 2 个内部节点中令 `u = tanh(z)`，输出 `(u + βᵢu²) / (1 + |βᵢ|)`，相邻节点使用相反号的 βᵢ。动作、接触和味觉端口的节点函数保持原样。平方版采用新函数的解析导数，两臂使用同样的在线边权和增退规则，图的输入仍是原始浓度。独立开发中同时选学习率、探索尺度、权重衰减、初始权重幅度和平方尺度。两臂最终学习率为 0.32，探索幅度 0.28，衰减 0.999。平方版选中 `|β| = 0.85` 和原始初始幅度，原始版选中 1.75 倍初始幅度。另保留一臂使用与平方版相同的初始幅度和学习参数，仅换回原始节点。[独立开发选择](development.json)

## 新混合物上的真实首次接触

确认使用 8 个未参与开发的图出生与 16 个未见过的私有偏好世界，每种环境每臂共 128 个配对生命。正确率按是否真实接触了期望味觉更好的食物计算，超时计错。

| 末 128 道的正确率 | 规律稳定 | 隐蔽反转 |
|---|---:|---:|
| 原始图，独立选参 | 50.26% | 49.73% |
| 平方节点图 | 50.62% | 49.89% |
| 原始图，匹配平方组的参数 | 49.26% | 49.38% |
| 原始图，接触时给予独立随机味觉符号 | 49.84% | 50.15% |
| 平方图，接触时给予独立随机味觉符号 | 49.95% | 50.05% |
| 随机侧 | 51.81% | 48.19% |
| 只用实际接触回执的线性模型 | 53.56% | 48.49% |
| 只用实际接触回执的二次模型 | 92.58% | 93.65% |
| 直接知道潜在偏好的物理上界 | 100% | 100% |

平方节点图相对匹配原始图的差异为稳定 **+1.37** 个百分点 [−1.14, +3.95]、反转 **+0.51** 点 [−1.98, +3.14]。两种图各自与独立随机味觉对照的四项比较区间也全部跨零。六项区间采用 20,000 次出生和世界根交叉配对重抽样，按同一组比较控制 95% 同时覆盖。图组末段实际接触率高于 99.97%，每个生命均新增 43 条、退出 48 条边。在稳定和反转环境，平方组平均分别有 42.98、43.00 个新生边世代获得了自己的回执梯度更新，每个生命合计约 60,566、60,568 次独立边权改值。[完整配对统计](summary.json)

二次模型在接触前看到相同的四项浓度，自行计算六种两两乘积，只用本身体实际接触一侧的味觉更新系数。反转前 64 道该模型为 87.40%，反转后首 64 道跌至 40.82%，最终静默段恢复至 93.65%。确认后另做了同回执检验。将两种图自己实际收集的气味、接触侧和味觉原样交给二次模型训练，再让模型在同一静默测段亲自操作身体。使用原始图回执时，稳定和反转正确率为 92.86%、92.81%，使用平方图回执时为 92.88%、92.16%。同回执的线性模型为 49.05%–49.92%。[同一批回执的描述性重放](same-receipts-replay.json)

两种图实际收集的回执包含足够的非线性偏好信息。原始节点和固定平方响应连同本次调权、接线规则，均未在新混合物上显示学到这种偏好。实验没有单独测定纯表示能力与回执如何分配到相应边权的影响。[稳定原始数组](stable-raw.zip) · [反转原始数组](reverse-raw.zip)

## 核验和重放
