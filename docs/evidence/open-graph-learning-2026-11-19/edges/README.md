# 用后续回执决定边是否退出

三组从同一张 32 节点强连通图开始生活。每个个体处理 120 道请求，状态跨请求保留，行动后仅收到自身实际接触的侧和味觉。每道请求从真实首次接触计分，超时计错。8 个出生组各有 3 条已训练的规则，在 16 个新世界根上成对运行，每种环境每臂共 384 个生命。沿用上一轮开发选定的学习率 0.015、出生更新倍率 4 和回执时钟。稳定环境一直沿用规律 A，隐蔽反转在第 41 或 61 道改为 B，返回条件在经历 40 道 B 后恢复 A。切换时刻未提供给电路。[登记和初始模型哈希](registered.json) · [先前共同配置](../../free-graph-2026-11-19/coupled/recipe.json)

每次有符号回执到达后，三臂用相同规则更新每条活跃循环边的独立有效权重，以及输入、门控和动作读出。每九次回执可生长一条边，生长点与首笔更新由本次回执的梯度决定。每六次回执有一次退出时机，候选边须有正退出评分，删除后全图须仍然强连通。退出可跳过，也没有固定边数。

- **即时组**沿用原规则，使用包含本次回执梯度的指数移动平均估计删边收益，新边至少经历两次后续回执。
- **延迟组**在每六笔中的第 4、5 笔回执到达后，于调权前固定真实请求的已观察输入、起始状态、动作活动掩码和其他权重，分别重放每条活跃边单独静默时的损失。用完整电路的损失减去静默时的损失，更新能退出的方向。历史指数移动平均衰减取 0.5，边须已收到至少两个这样的样本。新边的出生回执不能贡献给它自己的退出评分。第 6 笔回执只给这个评分提供盲测标签，并照常更新所有权重。
- **打乱组**使用同样的历史评分、样本成熟条件及退出时钟。每次考虑退出时，在同一生命的初始边或新生边各自的集合内打乱评分，把评分的正负和大小分布保留下来。强连通约束可能让打乱后的实际候选集合与延迟组不同。

## 候选边的后续效用

第 6 笔回执上的单边重放独立于延迟和打乱组的退出评分。逐生命、逐退出时机计算先前累计分数和当次单边静默损失差的 Pearson 相关，再平均这些相关系数。在延迟组中，全体成熟边在稳定、反转和返回条件的平均相关为 **+0.128、+0.039、+0.060**，初始边为 **+0.126、+0.038、+0.059**，后生边为 **−0.028、−0.026、−0.029**。打乱组采用的评分在总体上的相关分别为 +0.004、+0.000、+0.001。延迟组最终选中的退出边在这笔盲测回执上静默时，分别有 44.9%、47.8%、47.8% 降低损失。即时组选中边在本次静默重放上降损比例为 73.9%、79.0%、77.4%，其退出决策本来就使用了同一笔回执，因此该比例反映同次拟合。

各臂各环境都长出 4,992 条边，所有实测退出时机都找到一条可退边。延迟组实际退出 505、423、477 条后来长出的边，打乱组退出 92、22、80 条。三臂终图均为 57–58 条边。延迟组三种环境中所有新边都在至少两笔后续真实回执中实际改过权重。每笔回执的日志分开记录初始边、此前长出的边和刚长出的边，含参与更新数、实际改值数和绝对变化量；输入、门控和输出也记录每笔的最大步长。分析重建了每次编辑后的接线并校验强连通，从动作记录检查回执时钟和调权资格。[稳定原始数组](stable-raw.zip) · [反转原始数组](reversal-raw.zip) · [返回原始数组](return-raw.zip)

延迟组在稳定条件下优于即时退役，在反转条件下优于打乱评分，恢复旧规律时低于打乱评分。这里的延迟评分没有在新生边上预测到下一笔回执的边际效用。单边静默复算固定身体已走出的动作时段和请求起始状态，衡量的是同一已观察请求的损失变化。经过真实物理请求的配对差异衡量的是整条退役策略的结果。
