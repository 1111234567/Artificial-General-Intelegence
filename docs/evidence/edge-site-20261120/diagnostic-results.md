# 一次真实反馈写到哪里

在现有二十节点图上，把同一份 B 反馈的原生数值步长移到其他已有边，会改变之后的实际行动。15° 反规律时，按条件联合正确率事后选一边，相对同方向同剂量的随机重定位，两项实际都答对提高 **0.84 和 0.61 个百分点**，选四边提高 **7.77 和 6.63 点**。两组的四边方案均牺牲了一部分旧 A。把每条生命的 A 条件概率损失限制在 2 点以内后，15° 下只剩约 2 点的 B 实际增益。30° 和 90° 则能在同样限制下保住更多 B 的学习收益。两批均用出生前已封存的均匀回访图，各六个出生。[登记方案](diagnostic-plan.md)

生命先接触 A，完整提交原生写入，等待四拍，再接触新 B。B 是一次按真实动作取得的味觉。同一 B 味觉和写前活动、痕迹分叉出所有干预。主对照保留 B 写前的偏置和接线，只提交原生收据中前后均存在的部分边的数值。全原生写入另行计分，保留本次偏置与生退边。各分支等待相同拍数，再从各自同一末状态分别实际执行 A 和 B 两次选侧。两项都对指这两个无新反馈的独立动作都正确。

## 给旧 A 留下多少空间

用真实答对方向和两种末测菜单摆向，对每个候选积分掉动作随机数。事后联合策略按两项条件概率的乘积排名。保 A 的策略要求每条生命的 A 条件正确率相对无写下降最多 2 点，再找期望 B 最好的四边。两个策略选完，才在封存的末测菜单和独立随机带上执行实际动作。分数借用了真实答案和额外反事实。四边上限只覆盖登记的候选组，其中包括来自同一接收或发送节点的组合，以及按三种单边分数形成的组合。

| 反规律夹角 | 保 A 四边减无写，A 实际 | 保 A 四边减无写，B 实际 | 保 A 四边减无写，B 条件概率 |
| --- | --- | --- | --- |
| 15° | −1.50 [−2.38, −0.78] / −0.85 [−1.56, −0.29] | +1.82 [+1.01, +2.83] / +2.05 [+1.24, +2.99] | +2.23 / +2.48 |
| 30° | −1.20 [−1.95, −0.59] / −0.75 [−1.40, −0.26] | +10.68 [+7.68, +13.77] / +9.51 [+7.49, +11.49] | +10.29 / +9.29 |
| 90° | 0.00 [−0.29, +0.29] / 0.00 [−0.20, +0.20] | +38.83 [+34.18, +43.62] / +33.59 [+28.87, +38.18] | +38.55 / +33.22 |

15° 反规律在登记的四边组里，仅 0.26% / 0.26% 的状态存在让 A 和 B 各自的条件正确概率都提高至少 1 点的组合。在这一极近反规律条件下，从数值收据中挑地址可以改变 B 学习与 A 保持的代价，但两者在被测的少量更新下很少同时改善。30° 同一比例为 1.20% / 1.40%，90° 为 4.79% / 7.00%。旧 A 的无写表现本身接近上限，各组双改进比例均受这一基线约束。

## 分母和剂量回放

每批六个出生和 256 个共享几何，各几何带同值与反值各两种赋值，三个夹角共 18,432 份实际 B 收据。每个位置组合使用八份随机重定位。两个出生组共 10,321,520 次有效重定位均改变了地址，同时保住实际步长的符号，且目的地自己在同收据中的原生更新方向也一致。99.89% 的单步绝对误差不超过 10⁻⁷。最大单步误差为 2.38×10⁻⁷，最大一组总绝对剂量误差为 3.58×10⁻⁷。事后评分的快速回放与相应操作的原生完整回放，所选动作的条件正确概率最大偏差为 3.88×10⁻⁷。
