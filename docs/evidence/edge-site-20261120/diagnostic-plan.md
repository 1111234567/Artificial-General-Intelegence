# 一次真实反馈中的边写入位置

在现成均匀回访二十节点图中做冻结诊断。原组出生 731–736，独立组出生 811–816，各取气味任务第 8,000 步的检查点。两批世界根为 346112031 和 346112087，每批 256 个新几何。每个世界交叉同值和反值各两种赋值。各出生和 15°、30°、90° 共用本批的世界基向量、反馈前行动带、末测菜单摆向及动作随机数。每条生命先真实接触旧 A 并完全写入，等待 4 拍，随后真实接触新 B。B 行动与味觉发生一次，后续各分支共享这份观察和提交前的活动与痕迹。

主对照固定 B 写前的偏置和接线。在 B 原生提交的实际收据中取前后均存在的边，使用原生提交给该位置的浮点数值。无写、单边、少数边和全部已有边分支都从相同写前活动开始，推进两拍写后等待和四拍中立等待。全原生提交另外保留 B 的实际偏置和接线变化，独立计分。后测从每个分支的同一末状态分别执行一次 A 和一次 B 的实际采样动作，两题均不给新反馈。联合成功指这两次动作都正确。

每次 B 收据遍历所有有效单边。二边候选包括全图剂量最高的两边，以及下列三套单边前四名的并集中的所有两边组合，排名依据分别为 A、B 及联合的条件正确率。四边候选包括全图剂量最高的四边、每个接收节点入边中剂量最高的四边、每个发送节点出边中剂量最高的四边，以及按各单边概率指标的前四名。相同分数按原生边地址顺序处理。固定策略按 `|Δw|` 取一、二或四边。事后策略分别选条件联合正确率最高的一组，和 A 的条件正确率相对无写下降不超过 2 点时 B 条件正确率最高的一组。允许不写的事后上限单列。小组中的事后最优限于已登记候选。

事后分数用真实答对方向和正反两种物理菜单，积分掉末测随机动作和公平摆向。联合分数相乘，因为两题从同一末状态分别行动且随机带独立。真实成绩另外用封存的新末测摆向和动作随机带直接采样，选址规则不读取它们。报告分数及实际 A、B 和双对，各自相对不写、全写、以及下述剂量匹配对照的配对差。另记有限候选中是否存在让 A 和 B 分别提升至少 1 个条件概率点的位置组合。

每次选址有八次匹配随机重定位。对照把同一有符号 FP32 步长逐条放到不同的其他幸存边。新位置需能按原生数值边界承接步长，且它自己的原生 B 更新与该步长同号。随机结果可核对每一条实际变动的幅度、符号、地址和是否变动。若没有足够的同向其他地址，优先放宽目的地原生方向，再允许保留原地址。每级回退单独计数。报告每步以及每组的实现误差和真正重定位比例。

每批分别按出生和共有几何交叉重抽样 4,000 次。每个世界保留规律、动作和随机对照间的配对。报告逐项 95% 区间、逐出生点估计和两批结果。所有区间为探索诊断的逐项区间。
