# 冻结门的留出评估协议

此协议在读取任何已训练门的结果前固定。训练的两个门共享边规则，评估期间冻结门和出生参数，只有正常生内写入。训练门使用出生 731–736，主评估使用 811–816，两组身体就各自的已有检查点而言是独立出生；评估不将这些身体称作从未进行过任何预训练。

## 试验与主判据

- 每个角度使用相同的 256 个基础几何根（种子 93780531，几何流出生号参数固定为 0），在全部评估出生、模型步数及试验臂复用。固定根的 A 与切线生成 15°、30°、90° 的 B；评估只使用独立生成的新绝对方向，15°、30° 是训练用过的夹角，90° 是未训练夹角。每根穷举独立的 A、B 正负规律，共四格，根内共享菜单方向和动作随机数，候选随机对照另用独立的固定随机带。
- 主情形是 15° 与 30° 冲突等权池：实际接触 A 一次，实际接触 B 一次，B 写入后等待 4 个中性 tick，连续各作一次真实 A、B 复访选择。A 回访推动身体状态后由同一身体作 B 回访选择，复访无味觉和新写入。在同一生对两个实际动作分别计 A、B 命中，只有二者均命中才计联合分。门在每次 B 接触时只作一次原生随机选址动作，测试时不改成取最大概率，不用概率乘积替代实际命中。
- 主估计是最后预定训练步的成对准确率差。门相对同体原生全写须同时满足联合和 A 的两侧 95% 区间下界均大于 0，以及 B 的同类区间下界大于 −0.05（预先容许损失最多 5 个百分点）。联合分相对等量随机地址的区间下界须大于 0，才把正收益归到地址选择。区间跨零只表示差值未定。非劣仅由预定下界判定。全套主判据是交集；无论是否通过，都报告分子、分母、点估计与区间。
- 对比均用同一出生 × 同一几何根相减。角度和规律先在根内等权平均，再独立有放回重采样出生与几何根，各保持样本数，以 8192 次重采样的 2.5% 和 97.5% 分位给区间。出生范围与逐出生结果同时保留。六个出生是这个区间对出生变动的有效根数。
- 报告每个角度、冲突与一致、B 后 32 tick 和多次接触的分层结果，以及可用保存步的同带评估；全部为次要或诊断。分层区间为逐项区间。最终预定步缺档时明确标记；已保存步的结果不会改称最终主检验。

## 对照及剂量核验

- 原生全写使用同一身体、B 味觉和原生拟写。空数值写在同一时序保留原生 bias 及结构事件，清除对存续边的 B 数值改写；另比对同样接触但整笔禁写。
- 等量随机地址只随机化训练门可选的地址，沿用同一局部候选组、同一实际 B 拟写、每组选一、同一延期量和正负构成。当固定候选组的物理浮点实现允许时，等约束适用于撤掉的写量及最终存续边的净写量。记录每生实际写地址数及正、负绝对写量，核对的是作用在图上的差值。公布写量绝对偏差的均值、最大值，地址计数相等比例，以及组内随机与门选择重合率。若实际剂量无法精确一致，标明差距来源和哪项硬保证成立；匹配到的样本或动作数完整保留。
- 无旧痕门与完整门使用同样训练预算、规则和对照带，移除来自 A 的输入；另冻结完整门并关闭其旧痕输入，以区分重训补偿与运行时依赖。没有经过实证比较的旧痕依赖不计入主通过条件。
