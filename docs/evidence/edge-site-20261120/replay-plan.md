# 用自己已经尝过的反馈，能否在同剂量候选中找到写入地址

本试验给推理过程增加一份显式旧回执和临时前向计算，测量原生身体在已有边上能达到的选择效果。用于区分「这些地址造成不同结果」和「给身体可取得的信息后能否实际选出有用地址」。不增加训练步数。

- 亲本分别是 731–736、811–816 的均匀回访 8000 步图。全部个体都保留。每个身体使用同一组 128 个新几何，每个几何交叉四份私有赋值，A 与 B 相隔 15°、30°、90°。生成种子 49017073。先真实学 A，再真实遇到 B，每次都由该身体自己选择一侧，尝到确定性的有符号味觉。此处两对象在本生命中各有稳定奖惩。
- 地址层沿用选边训练的现有权重候选，限 B 写入前后均存在的边。按原生更新的符号与幅度分成四条一组，各组从一个地址扣回同一份带符号的份额，所有地址方案在组内具有相同预算。保留原生的偏置变化和结构操作。额外花费是缓存 A 当时实际出现的三维菜单及「自己的动作 × 得到的味觉」，当前 B 的同类记录，以及下面的临时前向计算。
- 先从同一份 B 味觉后的状态取得一个随机分组方案。在每组分别试遍四个地址，其他组仍用该随机方案。临时副本中按同一个中性时长再次展示已经亲历的菜单和反向摆放，读原生运动概率；不发生新写入、实际动作或额外奖惩。以两种摆向平均的已知目标选侧概率，构造四种固定权衡：只考虑 B、或给 A 权重 0.5、1、2。各组分别挑地址并合并，重新前向检查这四种整体方案以及原随机方案，避免把相互作用误当成可加。用同时有 A、B 回执的版本时，只接受预计 B 相对随机对照下降不超过 0.01 的整体方案，再从可行方案中选预计两项全对概率最高者。所有 tie 走固定顺序。
- 对照为同剂量随机地址、只用 B（不读取 A）、只调换 A 记下的味觉符号但保留相同身体与同一组机会、原生全写和等剂量均摊衰减。错记 A 行为只由干预后的回执决定，在未改动真值的接收者身体上实际结算。均摊组用于对照整体衰减，动到的地址数更多。只用 B 时沿同一候选组做单因素搜索并验证只看 B 产生的整体方案和随机起点。
- 正式行为检验重新走所选整体编辑，等 4 或 32 拍，以独立的随机摆向、动作抽样和均衡随机顺序连续实际回答 A、B。两题间只推进相同的动作回显和中性时间，不提示正确答案。每个体每条件每次只作一次选择。主要端点为 15° 与 30° 的相反规律、4 拍、两真动作全对；同时列出 A 和 B，以及真实算法相对同额随机的配对差。B 非劣界为 −5 个百分点，和原生全写及同额随机分别比较。95% 区间按出生和几何交叉配对重抽样，四项私有赋值、两种角度或任一同世界条件不伪作独立个体。其它角度、同向规律及长等待单独列出。
- 报告实际改动量差、实用前向次数和旧支持的外加存储。所有涉及旧 A 的追忆只用于决定落点，正式回答直接使用选定图的原生运动端口。最终动作的采样、朝向、顺序、私有正确答案或未来真实资源均不进入地址评分。任何优势仅说明这套明确提供的回执回放能选址。
