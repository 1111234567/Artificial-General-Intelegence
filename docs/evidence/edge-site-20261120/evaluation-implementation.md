# 留出评估的实现细节

[主协议](evaluation-protocol.md)固定后、读取任何训练结果前，训练与评估接口明确如下。

- 两份独立随机种子训练的完整门和无旧痕门分别执行。主表在同一出生×几何根内给两个已训练门等权，各门另列。区间条件于这两次训练，重采样评估的身体和几何。两份门共享控制带，重复出现的原生控制动作并不构成新的独立样本。
- 两次复访按 A→B 顺序。第一次动作之后进行无反馈接触，味觉端口为零，经过原生等待时钟，期间图不写入。相反顺序单列为诊断时点。独立舌尝接触按分支自身选侧生成实际奖励；第三次 B 后回访是各臂延续自己的图和动作，第二次以后的拟写量可随分支状态变化。等量约束及写量审核应用在同拟写的第一个 B 接触。
- 每个有效候选组从四个真实地址中选一个延期固定数值，延期量为同组最小正向幅度的 75%，使用拟写符号。门与随机地址进入图前都移除相同符号和数值的延期量。只凭此规则无法保证物理浮点加法后剂量逐位相等；实际计数和差异将从施加后的图重新计算。
- 训练方预定末步 1024，两份训练分别使用独立种子和同样步数。默认评估读取最后产物中保存的 `final_step` 并标明其与预定末步的关系。完整留出几何种子与主统计阈值均沿用主协议。
