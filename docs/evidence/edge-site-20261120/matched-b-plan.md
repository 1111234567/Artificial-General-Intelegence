# 新对象正确率相同时，重演旧反馈还能否保住旧内容

前一个已登记的 128 几何回放检验发现，仅用 B 搜索偏向 B，随机落点偏向 A，完整回放的工作点位于两者之间。此处在全新世界实际部署一个不引用旧回执的混合对照，并检查减少临时前向次数后的结果。本协议在生成新世界之前落盘。

只取前一检验原六出生、冲突 15°/30°、4 拍的平均 B 正确率，用线性插值预定「只优化 B」与「随机落点」的混合概率，使其 B 正确率与重演 A、B 相近。套用同一个混合概率到所有 12 个出生的新世界，单生命以独立公平随机带选出一种实际使用的策略，再由那条路线真实作答。两种分配使用相同分组和正负剂量。每批 256 个新几何，种子 258391，固定针对冲突 15° 和 30° 等权池，另外列同规律。同一生命实际执行 A 和 B 两次、没有中途正确答案。重演所取的 A 来源仅限自己先前收到的感官线索、动作和实得味觉，终测几何、顺序及抽样不供它使用。

主比较为完整回放减上述混合对照，按两批分别报告 A、B、两项全对的配对 95% 区间。若 B 差的整个区间在 ±5 个百分点内，才称这项对照在规定容差内配平，A 与联合提高还分别要求区间下界大于 0。若独立部署后 B 未配平则如实报告。另以原生全写、随机写和只用 B 为参照。

次要问题是把候选数直接限制为 4 或 8 个完整地址集合。直接从各组独立均匀取一个地址，不做逐边有限差分和组合重排。每个完整候选做 4 次已尝菜单的运动查询（A、B 的两种摆向）。按原方案的「B 相对首个随机候选预测下降最多 0.01，候选中预计两题全对最高」选择。4/8 候选共享前缀，首个候选就是同剂量随机对照。对照仍经过同样接触、时钟和写量。本次是冻结身体和显式回放的前向部署，模型不接受训练。
