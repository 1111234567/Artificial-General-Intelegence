# 三角形困难映射的接收行移植

从同一个出生图经历相反私有价值，学习期间共享几何、六顺序、行动与编辑随机数。接收者只换指定接收节点的整行入边权重、偏置与支撑位，保留其自身活动及迹。三次查询均由同一末状态独立分叉，不再观察味觉或提交编辑。

每个出生用 96 个校准几何按单行移植导致的实际三项全对降幅排名。128 个新几何上仅依干预前总边权差、偏置差和支撑变更数匹配其他行。集合级结果报告实际改变剂量及部分移植后有无破坏强连通。三类节点整组移植的行数各异。
