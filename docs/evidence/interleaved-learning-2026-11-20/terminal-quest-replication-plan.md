# 三项终局奖励的独立复验

出生 811–816 从独立 full-direct 联合续训的固定 8,000 步端点开始。联合与平均两个回报定义、四世界每步、完整规律交叉、等待、六次经验加三次静默接触、Adam 预算和超参数均沿用原试验。两臂各更新 8,000 步，顺序在同一个计算进程中执行。新阶段固定世界种子 971723，依次用 `0x7EA230` 至 `0x7EA234` 作为训练、开发、原生确认、物理确认和供体域。[原协议](terminal-quest-plan.md) · [复验入口](../../../experiments/pulse_game/interleave_quest_replication.py)

确认保留 96 个原生序列世界和另一组 96 个物理世界。物理核心是熟悉气味、独立非对径气味和新体位，分别测试 A 前史、无关 C 前史和 A 反味前史。沿用均匀选侧、固定选左和公开感觉查找参考。从同一个静默探测快照给出冲突规律的 A、B、标记、A∧B 和三项联合实际接触率，并与整条连续静默序列和相同规律分别报告。
