# 三项终局奖励训练

两臂从同一个 full-direct 联合续训 8,000 步检查点的六个出生图出发，各进行 8,000 次 Adam 更新。每个出生每次更新采四个世界，各世界交叉 A、B 和标记的八种私有二元规律。学习率 0.0015，按出生裁剪梯度范数到 2。随机世界、运动、编辑、等待和训练时钟逐条配对。终局选择按实际物理接触计分。两臂使用相同身体、原生局部写入器和图学习参数。[训练源码](../../../experiments/pulse_game/interleave_quest_train.py)

每个生命头六次接触随机穿插一次 A、一次 B、两种标记示范及两个额外请求。每个额外请求半数机会是一次已有知识复习，另半数机会是独立 C 菜单。A 和 B 使用同一对气味及随机置换的可见双侧环境气味，私有味觉分别抽取。六次接触提供实际味觉。

终局的 A、B、标记各出现一次，顺序独立随机置换。三次选择之间保持同一图、活动及局部迹，身体到达后提供真实触侧，对应味觉始终保持零。图仍可凭本地接触活动发出改动。计分器收集三次实际选侧的资源。联合臂仅在三项均成功时得到 1，其余得到 0。平均臂收到三份 ±1 资源的算术平均。两臂用相同的独立世界留一基线为实际采样动作和前置编辑分配终局信用。

开发与确认使用独立域，8,000 步端点预先锁定。原生序列确认使用 96 个共享世界，开局前两次均为标记示范且体位变化更大。训练阶段保留其他开局顺序。物理确认使用另一组 96 个世界根，以独立原有脉冲身体从同一快照分出 A、B 和标记三条静默试次，另保留完整三次静默序列。物理确认含熟悉线索、非对径气味、新体位及新标记，比较完整历史、无关 C 前史、提前反味、屏蔽 A 味觉和独立供体前史。比较同配方均值训练臂、固定选左、均匀选侧和公开感觉查找策略。[独立评估源码](../../../experiments/pulse_game/interleave_quest_eval.py)

主指标为冲突规律下三项实际接触同时成功的比例。报告不同和相同规律、每个出生的最弱规律、A/B/标记分项和 A、B 联合成功以及相同初始化时的整条动作与改动轨迹一致性。两臂差值用配对的逐出生与世界重采样给出逐项 95% 区间。
