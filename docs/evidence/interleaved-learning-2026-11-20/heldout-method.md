# 同图交错学习的物理留出测验

独立评估在每个世界根完整交叉 A、B 的二元口味规律和两种标记规律。A、B 共享两件物体，各自的可见环境气味独立于口味映射。A、B、C 的双侧环境气味每个世界随机置换，C 使用另一对物体和独立口味。独立于规律抽取物体位置、身体端点、风、等待和运动与编辑随机数。[世界生成与评估](../../../experiments/pulse_game/interleave_eval.py)

模型在请求开始读取双侧连续气味。图采样的运动方向驱动原有身体持续发脉冲，第一次抵达左或右端点才产生真实接触。评估按接触端点计分，漏接触计错。图沿自己的活动、迹和写入机制推进，在身体确认接触后读取实际侧和当次公开口味。运动过程由身体适配器积分。标记示范让两侧相同，接触任一侧都获得对应标记的味觉。[身体代码](../../../experiments/pulse_game/mixture_world.py)

完成共同历史后，从**完全相同的图、活动、迹和待续等待时间**分别分出 A、B、标记三个实地请求。分支接触保持静默，记录身体接触的一侧、拍数及脉冲数。A 与 B 都答对指两条分支都实际到达各自正确侧，并同时报告两种口味冲突子集和每个出生的最弱映射。原始档案另保留三次静默请求连续发生的轨迹。

| 条件 | 独立控制 |
|---|---|
| A → B → 回访 | A 和 B 都有公开味觉，最终同时检验两条旧规律。 |
| C → B → 回访 | C 替代较早经验，保持 B 与探测请求的外部条件。 |
| 较早 A 反味 | 早期 A 的双侧气味逐项相同，仅反转其示范味觉。 |
| 先前只有 B | 将较早 A 请求替换为 B，总时钟一致，B 获得额外经验。 |
| 较早 A 静默或供体 | 仅对较早 A 屏蔽味觉，或在实际接触时播放依照独立规律和动作抽取的供体符号。 |
| 禁写、打乱落点 | 禁写保留活动演化。打乱调用局部图原生落点干预，并记录数值匹配和结构落点变化。 |
| 无提示反转 | 在连贯 A 内改变私有口味。按首次反转口味前以及实际取得 1、2、4 次新味觉后分别评分。另一组对齐末次请求的感官与身体，调节此前公开味觉数。首个反转动作与稳定世界逐项相同。 |

基准同时给出均匀选侧与仅从公开气味、自己的触侧和味觉学习的精确匹配策略。几何留出分别使用接近训练条件的气味、独立的非对径气味、更不对称的物理布局、不沿训练标记轴的新标记，以及三个气味对。在三个气味对的压力测验中，完整交叉 A 的八种映射，B 对每个气味对采用相反映射。每个世界根随机抽一对用于最终双情境探测。

原始输出与完整统计写入 `data/interleaved-learning-20261120`。精简证据包括运行协议、模型和训练检查点指纹、平均与最弱映射、真实探测剂量、配对差与逐项 95% 区间。配对重采样同时保留世界及独立训练出生作为抽样单位，每次包含同一个根的全部规律。

出生 811–816 使用单独的世界根、世界域和供体域。固定端点逐出生联合表在冲突世界中列出 A、B、标记各自答对、两种口味同时答对以及三项同时答对，给出逐行配对的均匀选侧结果。另列同一生命连续经历三个静默请求时的三项联合结果。[独立复验预登记](heldout-replication-plan.json)
