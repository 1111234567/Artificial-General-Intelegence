# 允许 B 草稿原样提交的检验

在两套独立新世界的 15°、30° 冲突条件，读取试写后 A/B 重演的开关分别原样提交了 81.97% 和 83.04% 的草稿。相比总接受，两套的 A 正确率分别高 1.66、1.73 个百分点，B 分别低 1.99、1.79 点，联合率近乎相同。两套世界中，三种重演开关相对同接受率随机对照的联合差区间均跨零。当前验证证实了原样提交的实际路径，数据没有显示开关通过内部重演选中了更值得修订的生命。

补充拟合累计 737,280 条单路线训练，每个开关在每条生命只从其实际提交图收一次真回访收益。两套留出累计记录 184,320 次配对路线读数。独立复核了 24 个留出原始文件和两个训练文件的哈希，逐项确认了同接受率随机的分层接受计数、原样接受的零延期改量，以及同路线选择下两次真实动作的逐位一致性。分层配平的剂量随实际候选份额仍有差别。试写后开关在两套冲突世界平均每生分别延期 8.981、8.424 条边，同接受率随机为 8.984、8.420 条。
