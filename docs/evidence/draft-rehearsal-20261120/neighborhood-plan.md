# 草稿附近的可行修订

在相同 C→A→B 真实经历、相同 B 原生试写及活体中性等待时钟下，检查预算内是否存在同时对两个对象有利的落点。诊断限定同一批候选组、每组同符号与同剂量，不拟合共享系数。完整组合的搜索需要额外计算，不能据此估计单次重演规则的部署表现。

- 新几何域 `80721127`。两批各六生（731–736、811–816），与拟合域及主评估域独立。每批 96 个新几何根，交叉 15° 和 30°、两种相反奖惩符号与实际回访 A→B/B→A。先完成 C、A、B 的真实选择和实际味觉，再给 B 形成一次试写。
- 从逐组均匀随机落点开始，每组试四个地址。每个候选使用实际活图在选定修改后本应具有的状态，再中性等 4 拍。由本人已尝到的 A、B 回执恢复两个方向，读取每个已尝菜单两种摆向的原生运动概率。单次候选查询的 A、B 分数来自各自的单独前向，最终指标由另一次实际串行回访得到。
- 按 `log(P(B)) + w·log(P(A))`，使用 `w=0,0.5,1,2` 各组选点后合并，再计算每个整套组合和最初随机组合的分数。联合搜索在预测 B 较随机最多下降 1 点的候选中选预测 A/B 联合最高者。只优化 B 仅在随机方案与 `w=0` 组合里比较预测 B。独立的真实复测摆向、运动随机数以及两种回访顺序不参与搜索。
- 实际执行联合搜索、只优化 B、同额随机或原生全写，等待 4 拍后按实际顺序回访。首题之后为无新写入接触。按两批分别汇总旧 A、新 B、联合正确的真实动作，并按出生与几何根配对自助估计差值 95% 区间。验证改动数量、实际正负剂量、结构和时钟。
