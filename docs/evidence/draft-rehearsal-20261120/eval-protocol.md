# 单草稿选址的独立评测方案

冻结训练末步的两个复本，在 `odor/uniform` 第 8000 步的独立身体 811–816 上评测。评测几何域为 `63190477`，每个角度保留 256 个几何根，所有身体和条件共用这些根。训练几何域为 `73111943`。每个几何根交叉 A/B 的四种二值奖惩配置，角度、训练复本、奖惩和两种实际作答顺序在各自报告池内等权。所有条件体验同一笔真实旧 C、真实 A 与眼前 B。C 发生在 A 以前，即使选址规则读取 A，C 的真实经历仍保留。评价中的主要比较禁止用 C 的经历重新写实际图。

主池为 A/B 相反奖惩的 15° 与 30°，真实 A、B 各取得一回味觉，完成 B 提交后等 4 拍。并行的两条只读评测从同一末态分别按 A→B、B→A 真实采样动作。先回答的对象只经历中性味觉，评测期间不发生学习写入。以实际 A、实际 B 和两题都答对为端点。正确方向从真实环境取出，仅用于评分。报告 15°、30°、90° 的一致/冲突分面，15°/30° 冲突的 32 拍与真实 B 三次作为次项。

| 条件 | 地址选择规则 |
|---|---|
| `post` | 冻结的草稿后训练头，读取真实 A 和 B |
| `pre` | 冻结的草稿前训练头，读取真实 A 和 B |
| `wrong` | 同预算单独训练于旧 C 的草稿后头 |
| `post_wrong` | 同一个 `post` 头当场用同身体的旧 C 代替 A，保留其余输入及企图写入的候选 |
| `pre_wrong` | 同一个 `pre` 头当场用同身体的旧 C 代替 A，在写前图重演 |
| `random` | 使用相同候选组与签名剂量，在组内用均匀概率随机选择一个真实延期地址 |
| `native` | 经过同一草稿阶段与等长中性等待，完整执行 B 的原生更新 |

各条件共用同一第一次 B 实际经历和同一原生提议。随机和五种选址方式保持同每生命的正负剂量、边数、偏置和原生接线，物理审计按逐生命账本检查。有选址的臂和随机臂共用每组的抽样数。三次 B 的后续路线允许因先前真实更新而自然分化，当回施加同一种选址规则及固定分组剂量，并共用外界随机数。后续逐次剂量随实际提议变化，三次 B 属于持续表现检验。

主端点再做一次固定起点的图读出。保存各组的最终权重、接线和偏置，将各自整张图装入原生全写臂的同一中性末态，再使用相同的读出等待、方向、动作抽样数与顺序回答。逐元素检查提交末点的活动、发送痕迹和接收痕迹，并比较现场与固定起点的逐动作结果。选择阶段携带的中间回放活动因此无法决定固定起点的组间差。

## 配对差与通过条件

在每个出生×几何单元内计算所有成绩并作差，对出生和几何根分别独立、有放回地等数量重抽，共 8192 次，使用种子 `5814903` 和 2.5%／97.5% 分位数。训练复本和同一几何的上下文均保留在这个单元内。区间同时报告原始计数、分出生点估计及范围，覆盖这两个冻结训练复本的平均表现。检验采用预设交集门槛，不从次项挑选通过结果。下界必须严格越过所列边界。

- `post` 事前首选。适合推进到三个保留对象的两对象门槛要求现场和固定起点上均达到以下四项。相对 `native`，A 与双对的区间下界大于 0，B 的区间下界大于 −5 个百分点。相对 `random`，双对的区间下界大于 0。还要求同冻结头 `post − post_wrong` 的双对区间下界大于 0。`pre` 用完全相同的五项门槛和 `pre_wrong`，独立报告。在两臂都有证据时仍保留事前主次。
- 真实 A 的内容效应看同一个冻结头的当场错配。除联合差外，单列 A 差下界是否大于 0、B 差下界是否大于 −5 点。`post − wrong` 给出训练组对照。只有共同通过实际选择和物理条件，才将主池联合差归于真实 A 内容的地址选择增益。
- 草稿修改后的回放是否额外改善地址辨别由 `post − pre` 检验。要求现场和固定起点双对区间下界大于 0，同时记录 A 改善与 B 非劣判据。即使 `post − pre` 未越过边界，满足自身门槛的臂仍可给出两对象效果。没有达到超越门槛也不证明两臂等效。
- `post − post_wrong` 与 `pre − pre_wrong` 的差中之差单独估计，联合差下界以 0 为正向效应界线，若上界低于 0 报告负向，其他结果报告区间跨 0。它检验草稿变化是否放大同头使用真实 A 的收益。

评测前保存本文件。主终点与次项均使用冻结末步。同步验证输入哈希、实际动作评分和可重建的逐生命记录。
