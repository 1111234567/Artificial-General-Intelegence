# 从空二阶支路开始的在线双窗口确认

稀疏图出生时有一阶入边，二阶乘积系数为空。身体接触产生已公开的味觉回执时，每个接收节点为其空闲观测槽从当时已有的入边中随机抽两条，同一个节点受检组合互不重复。确认配方每个节点最多保留 8 个槽，跨两个连续的 5 回执窗口收集该组合的有符号更新量。更新量来自试次内各拍的接收端信用乘以两条入边发送活动的乘积。[模型实现](../../../../experiments/pulse_game/sparse_alt_model.py)

两个窗口各自的更新总量须同号，合计绝对值须达到所有观测的平方和开方的 1.45 倍，平均更新量的绝对值须至少为 0.0003。通过检验才分配一个实际影响节点电流的二阶系数。结束后释放观测槽。活跃系数按真实回执更新，并做 L1 近端收缩。收缩至零或任一来源入边被移除时删除该系数。活跃系数没有数量上限，未抽到的组合没有持久记录。一阶权值学习、增边与保强连通退边全程开放。[确认前登记](registered.json) · [开发选择](development.json)

## 确认结果

使用与主实验相同的 8 个新出生根和 12 个新世界根，均独立于开发集。每臂每种情境有 96 个交叉生命。每个生命经历 1,280 次物理请求，其中最后 112 次屏蔽味觉和探索电流。正确指身体首次接触期望味觉较高的一侧。各臂共享一阶初始接线、权值、速率、探索和增退边规则。完整树突臂为每个合法入边组合保留一个二阶系数。随机回执臂保有相同稀疏规则，在实际接触时接收独立随机正负信号。[逐臂指标及区间](summary.json)

| 模型 | 稳定末段 | 隐藏反转末段 |
|---|---:|---:|
| 在线二次确认 | 77.19% | 78.42% |
| 完整二阶系数 | 73.20% | 75.42% |
| 同规则随机回执 | 51.09% | 48.90% |
| 普通 tanh 图 | 49.58% | 49.80% |

按出生和世界配对交叉重抽，八项比较的 95% 同时区间中，稀疏图相对于完整二阶图的差分别为 **+3.99** 个百分点 [1.45, 6.46] 和 **+3.00** 点 [−0.27, 6.37]。相对于随机回执为 **+26.10** [22.69, 29.70] 和 **+29.52** [23.09, 34.87]，相对于普通 tanh 图为 **+27.60** [23.29, 32.47] 和 **+28.63** [23.55, 33.12]。反转情境中，稀疏图准确率从反转前 64 次的 59.62% 降到反转后首 64 次的 44.66%，最终恢复至 78.42%。[确认摘要](summary.json)

另一组 128 个新物体对用于冻结测验。两条分支从零活动开始并共享相同已学一阶权值及接线，仅有一条删除学习得到的二阶系数。稳定情境由 78.96% 降至 50.34%，差 **28.62** 点 [24.67, 32.23]。反转由 78.24% 降至 49.35%，差 **28.89** 点 [24.87, 32.45]。两种情境中各分支接触率都超过 99.98%。[切断轨迹及区间](summary.json)

## 分配和计算量

| 指标 | 稳定 | 隐藏反转 |
|---|---:|---:|
| 出生时活跃系数 | 0 | 0 |
| 生命平均活跃系数 | 51.34 | 49.62 |
| 最终活跃系数与当时的合法组合数 | 86.17 / 740.18 | 82.93 / 743.00 |
| 全部生命及试次的最高活跃比例 | 17.93% | 18.21% |
| 平均被占用的临时观测槽 | 110.91 | 110.84 |
| 活跃与受检组合的合计最高比例 | 34.23% | 34.36% |
| 梯度求值量占合法组合机会的比例，跨生命平均 | 23.39% | 23.17% |
| 梯度求值比例，所有生命中的最高值 | 27.37% | 26.37% |

确认集中每个生命都从零二阶系数开始，且每一试次的活跃二阶系数均少于当时合法组合的四分之一。平均每个生命增加 61 条一阶边，移除 68 条，约 3.6 万至 3.8 万次真正的二阶更新涉及出生后增加的入边。每个生命约分配 632 次二阶系数，约 530 至 534 次收缩至零，约 15 至 16 次因来源入边退役被移除。一次分配代表一个新生系数，原来的两条入边仍然合法时，同一组合可以被重新抽中。临时观测槽也存有索引和统计量，表中梯度求值比例将临时观测与活跃系数都计入，分母为每个有回执试次开始时的全部合法组合数。该比例只计二阶梯度求值，实际内存、墙钟时间与信用传播的整体成本未用该比值衡量。[原始轨迹核算](accounting.json)

## 核验与复现
