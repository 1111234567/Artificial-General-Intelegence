# 成熟二元系数的功能定位

在新的食物探测中，仅保留「两个感官节点发送、运动节点接收」的二元系数，稳定和反转环境中的接触准确率分别为 **78.51% 和 77.27%**，原样策略为 **78.30% 和 77.13%**。仅移除这组系数，准确率降至 **50.08% 和 50.19%**。固定已学习的普通边与成熟起始状态时，二元系数带来的准确率增益集中在这个子集。

## 实验

从已封存的位置实验档案恢复 8 个初始图种子与 12 个世界种子交叉得到的成熟策略。保留普通边的拓扑和权重、节点时间常数、偏置与递归状态。在原世界随机流的索引 2,048–2,175 取 128 个新物理试次，使用同一私有偏好及其最终符号。每种环境核对了 3,072 个不同的食物浓度向量，且与历史前 1,280 次试次中的向量无重叠。同一生命的六个分支共享食物和物理轨迹，关闭学习、外加运动探索和公开味觉。二元系数掩蔽把选中的系数置为零，保留对应的地址和普通边。

评分使用身体第一次实际接触的食物，选到期望味觉较好的食物得一分，超时得零。每个条件每种环境有 12,288 次试次。用 20,000 次交叉抽样初始图与世界种子的成对 bootstrap，对两种环境合计 20 个预注册对比做 95% 同时覆盖校正。 [预注册](roles-registered.json)

| 味觉、接触、内部节点接收 | 0 | 0 | 0 | 0 |
| 全部 | 5,225 | 741.24 | 5,100 | 733.13 |

所有装配系数在快照中均非零。双感官输入的运动接收组占总系数约 60%–61%，占权重绝对值之和约 86%。感官发送端使用从本体观测和递归普通边更新的节点状态。干预定位了成熟策略中带来准确率增益的二元项，固定普通边后的结果也允许其他节点和边参与生成感官状态和运动输出。训练过程中各组系数的作用仍由训练干预单独检验。

逐接收节点的计数、正负权重与绝对权重总量，及各条件左接触、右接触、超时数均保存在摘要中。核对了封存快照和探测档案的哈希、二元系数和掩蔽地址，重新计算了全部 20 个区间。 [统计摘要](roles-summary.json) · [原始探测档案](roles-probes.zip)
