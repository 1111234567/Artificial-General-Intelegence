# 成熟稀疏树突的位置置换

在独立留出种子上，保持原样的成熟策略在稳定和反转环境中的物理接触准确率分别为 77.62% 和 76.29%。清零全部二元系数，或在同一接收节点内打乱系数与输入对的对应关系，均使准确率下降约 26–27 个百分点。保留已选位置并随机分配权重，与在合法位置中另取等量位置并随机分配权重，差值区间均跨过零。这个对照支持成熟策略依赖学出的系数与位置的具体对应关系，也限定了对已选位置集合本身的结论。

## 对照设计

两种环境各交叉 8 个初始图种子与 12 个世界种子。这些种子和主实验的开发与确认种子均无重叠。每个生命运行 1,280 次，取前 1,168 次之后的同一成熟快照。在随后 112 次从未遇过的食物上，四个条件共享快照中的状态、普通边拓扑与权重、偏置、节点时间常数和世界轨迹。所有分叉冻结学习和拓扑编辑，关闭外加运动探索，屏蔽公开味觉。每个分叉独立驱动身体，以实际首次接触的食物评分。超时计为错误。

固定条件包括原样、只在已选位置上置换权重、在全部合法输入对中随机选择等量位置并置换权重、二元系数清零。两个置换条件在每个接收节点内保留系数个数和带符号权重的多重集，并共用当次的权重排列。随机选择地址可抽回原地址。每个置换条件用四次预注册随机抽取，先在生命内平均，再计算成对差。主实验开发阶段选定配方，位置检验没有再次选择。 [位置检验预注册](registered.json) · [主实验开发记录](../main/development.json)

## 结果

| 条件 | 稳定准确率 | 反转准确率 | 每种环境尝试次数 |
|---|---:|---:|---:|
| 原样 | 77.62% | 76.29% | 10,752 |
| 已选位置内置换 | 50.41% | 50.37% | 43,008 |
| 合法位置重抽并置换 | 50.35% | 49.85% | 43,008 |
| 二元系数清零 | 51.56% | 50.73% | 10,752 |

| 成对差，百分点 | 稳定 | 反转 |
|---|---:|---:|
| 原样减合法位置重抽 | +27.27 [24.54, 30.16] | +26.44 [22.62, 30.41] |
| 已选位置内置换减合法位置重抽 | +0.06 [−2.68, 2.74] | +0.52 [−1.99, 3.05] |
| 原样减已选位置内置换 | +27.21 [23.48, 31.06] | +25.92 [21.77, 29.69] |
| 原样减清零 | +26.06 [22.09, 30.36] | +25.57 [21.29, 29.29] |

区间采用 20,000 次初始图与世界的交叉成对 bootstrap，两种环境共八个对比做 95% 同时覆盖校正。每种环境的 96 个生命都存在可调换权重、可重选位置的二元系数。稳定和反转快照分别有 5,225 和 5,100 个非零系数。合法地址重抽平均将 80.95% 和 79.67% 的系数放到了原先未选的位置，已选位置内的置换实际改变了 85.93% 和 85.79% 的系数。八个条件的接触率均超过 99.98%。原样分叉逐次复现原训练回放末段的接触侧、接触时刻和实际味觉。 [精确计数和摘要](summary.json)

这组成熟干预估计给定学习后普通边与状态时的行为影响。置换比较的地址效应保留各接收节点的系数个数，因此不估计接收节点选择带来的影响。已选位置集合在随机权重下的两个区间仍允许约 2–3 个百分点的差异。生长策略在训练期间相对随机或固定位置的优劣需要各自训练到成熟的对照。
