# 等长经历后的旧规则再学习

同一个稀疏图配方分别经历 **A → B → A** 和 **C → B → A**。A 和 C 在相同四个气味交叉项上使用正交权重。C 的权重通过对一组独立对称的浓度坐标作带符号置换得到，因此 A 和 C 的期望效用分布相同。B 换用完全不重复的两个交叉项。两条历史的出生图、物体、身体环境和探索电流逐生命配对，每段持续 640 次真实接触机会。学习过程中保留神经活动、接线和权值。回到 A 后，在四个时点复制当前图，用同一组 80 对新物体测量静默选择。[确认前登记](reacquire-registered.json)

| 静默测验 | A → B → A 的历史 | C → B → A 的历史 |
|---|---:|---:|
| 第一段结束，测试各自的规则 | 74.88% | 77.99% |
| 第一段结束，统一测试 A | 74.88% | 50.72% |
| B 开始前，测试 B | 47.27% | 50.43% |
| B 结束后，测试 B | 84.18% | 82.44% |
| 回到 A，公开新回执前 | 50.68% | 50.92% |
| 回到 A 后 80 次请求 | 61.84% | 61.45% |
| 回到 A 后 240 次请求 | 74.55% | 74.02% |
| 回到 A 后 640 次请求 | 80.20% | 78.71% |

八个新出生根与八个新世界根交叉为每条历史 64 个生命，各测验的实际接触率至少 99.98%。分别重抽出生与世界并保留历史配对，得到以下差值和 95% 同时区间。回到 A 后，0 次时的历史差为 **−0.23** 个百分点 [−3.48, 2.77]，80 次时为 **+0.39** 点 [−2.73, 3.28]，240 次时为 **+0.53** 点 [−3.36, 4.34]。零回执时 A 历史组超过 50% 的差值为 **+0.68** 点 [−2.50, 3.93]，与前三项同属一个区间族。[确认摘要](reacquire-summary.json)

两组在重新获得 A 的真实回执后都学会按 A 选择。这个试验没有检测到先前 A 经历带来的即时保持或早期再学习优势。两组在 B 中使用共同的试次，但各自的动作可以接触不同物体，因此差值度量的是经过各自实际经历后的行为结果。[逐生命轨迹](reacquire-raw.zip)
