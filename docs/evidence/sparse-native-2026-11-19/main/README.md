# 16 节点端口图从零生长稀疏二阶连接

稀疏图出生时只有普通有向边。每次身体接触食物并收到实际味觉后，图从可能的接收节点和无序发送节点对中私下抽取少量地址。两个发送节点都必须已有入边通向接收节点。本试次内将动作目标的信用截断回传，再在接收节点上乘两路源活动。二阶梯度过阈值的候选以带符号的第一次更新成为独立系数。存活的二阶系数继续按每次回执更新。二阶系数在一条支撑边退役或达到收据年龄后仍然较弱时退出。普通边权更新和增退边全程开启。所有图收到同样的原始浓度观测，由同样的动作节点驱动身体。 [实现](../../../../experiments/pulse_game/sparse_pairs_model.py) · [预登记](registered.json)

开发网格交叉了 3 个出生根和 6 个世界根。先用逐生命、逐请求峰值占比筛选候选，再最大化稳定与隐藏反转两种情况下的等权末段准确率。选定配方每次抽 48 个地址，二阶梯度绝对值至少 0.022 才出生，存活满 96 次回执后若二阶系数绝对值小于 0.075 则退役。普通学习率为 0.045，二阶学习率为 0.65。二阶系数的数量由当地回执和存活证据决定，运行中没有固定容量或替换配额。 [开发选型](development.json)

## 独立确认

每种条件和图臂各交叉 8 个独立出生根和 12 个独立世界根，共 96 个连续生命，每个生命经历 1,280 次物理请求。末段 112 次均为新物体对，关闭公开味觉和探索电流，以身体首次接触期望味觉较好的一侧计正确。两类密集图使用相同的乘积和端口。匹配密集图与稀疏图共享普通边增退规则。旧密集图保留原有二阶信用参与普通边增退的机制。 [确认摘要](summary.json)

稀疏图与匹配密集图相比，稳定情境提高 4.07 个百分点，95% 同时区间为 [2.05, 6.19]。反转情境提高 2.46 点，区间为 [−0.64, 5.73]。相对原密集图的区间为 [1.95, 6.44] 和 [−0.91, 4.85]。四个下界均高于预登记的 −3 点。隐藏反转后前 64 次从反转前的 63.13% 降至 42.97%，末段恢复至 77.87%。末段接触率分别为 99.97% 和 100%。区间按配对出生根和世界根做交叉重抽。 [配对结果](summary.json)

同次数随机臂逐生命逐请求的二阶出生次数与引导臂完全相同。随机臂自己的普通边可能退役并带走更多二阶系数，逐请求退役次数有约 98.8% 相同，平均占用差约 10 个，末段平均比引导臂少 19.56 个和 18.24 个。该对照同时改变二阶出生地址与证据退役。 [随机臂统计](summary.json)

## 逐接收节点的在线占用匹配

另取 8 个出生根和 12 个世界根，固定原开发配方。随机臂只接收本次引导图在每个接收节点的目标占用和出生次数。随机臂保留自己的身体轨迹、实际味觉、普通增退边及带符号的后续二阶更新。普通支撑边退役后，随机臂在该接收节点均匀补入或移除系数，尽量匹配占用，能够匹配时沿用引导臂的本次出生次数。稳定和反转两种情境中，逐接收节点、逐生命、逐请求占用分别有 99.99791% 和 99.99995% 完全匹配，静默末段均为 100%。稳定条件有 41 个接收节点和请求的计数低于目标，反转条件有 1 个。随机臂为弥补独立支撑损失，累计二阶出生略多。 [补试预登记](stock-match-registered.json) · [补试核验](stock-match-checked.json)

引导臂稳定末段为 77.62%，接收节点占用匹配的随机臂为 61.79%，差 15.83 个百分点，95% 同时区间为 [11.69, 20.58]。隐藏反转为 76.29% 对 60.28%，差 16.02 点，区间为 [10.60, 20.94]。效应是在相同的接收节点槽数下比较由回执引导的组合出生和证据退役与随机选择的联合差异。 [配对补试结果](stock-match-summary.json) · [补试原始轨迹](stock-records.zip)

稀疏实现使用一维记录存放已安装系数和出生信息。前向和反向计算只聚合活跃记录，出生候选单独抽样并立即丢弃，未安装地址没有持久分数。二阶存储及索引和抽样数组的批次峰值折算到单生命分别为 3,196 和 3,032 字节，密集图为 33,664 字节。在独立的 96 生命 Windows 进程中，稀疏图的整进程峰值工作集分别为 71.84 MB 和 70.52 MB，匹配密集图为 70.36 MB 和 70.81 MB。进程工作集包括共同的物理世界、试次输出和 Python/NumPy 运行时，这次测量未观察到整体工作集随二阶存储大幅下降。 [内存测量](process-memory.json)
