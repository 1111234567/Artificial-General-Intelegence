# 解除逐节点等度限制的固定闭合图

本试验在同一五气味世界中比较三种固定状态图。每种图均有 32 个状态单元、64 条无自环有向弧，且整图强连通。三条规则分别判断两枚气味的环序、邻接和混合查表。网络获得随机探索的公开味觉回执，权重冻结后，由 PulseWorld 身体实际发出动作并按首次接触计分。每个世界根包含同一前缀和地形下全部二十种有序气味对，超时计错。[预登记](registered.json) · [原始闭合图试验](../../ring-logic-2026-11-19/README.md)

| 图族 | 抽样规则 | 32 个出生图的入度范围 | 出度范围 | 图数 |
|---|---|---:|---:|---:|
| 规则多环 `regular` | 固定有向骨架环，叠加不重合的随机置换弦 | 2 | 2 | 32 |
| 骨架加自由弦 `free_chords` | 同一有向骨架环，从剩余 960 条合法弧等概率无放回抽取 32 条 | 1–6 | 1–6 | 32 |
| 自由强连通 `fully_free` | 在满足固定弧数、无自环、无重边、强连通的标号有向图中均匀抽样 | 1–7 | 1–7 | 32 |

自由强连通图的两列端点序列各自按覆盖全部节点的条件均匀生成。抽样程序用整数动态规划计数每种前缀可接的序列数，再拒绝有自环、重边或非强连通的配对序列。每个合法图恰对应 `64!` 种弧顺序。32 张自由图包含 0–7 条原骨架的弧。每次重启抽出的图供三条规则共同使用，集合在训练前锁定。[全部逐弧列表、度数、最短回返与哈希](graphs.json)

主试验每个接收节点学习一个增益，来自所有入弧的状态都乘以该增益再除以实际入度平方根。候选矩阵每行的初始欧氏范数因此等于同一个配对增益的绝对值。每个模型共 449 个参数。补充比较使用每条弧各自可训练的 481 参数版本，只比较规则多环和自由强连通图。每条弧的初始系数等于同图的绑定版，解除绑定后仍按接收端入度平方根归一。同一代码路径计算所有图的递归更新。

每种规则和图使用 16 个配对出生组，每组两次重启。各组共享模型初值、训练数据、探索轨迹、训练抽样和 Adam 学习率 `.024`。每个检查点使用另 48 个校准根独立选出每组、每条规则、每个图族的重启，平手选重启 0。240 与 1200 步均保留全部权重。校准选择冻结之后，才打开各 128 个新世界的标准和长间隔确认集。逐格准确率及单根全二十格正确率分别对主试验的 9 个计划对比给出同时 95% 区间。抽样单位分别是配对出生组与世界根，根内二十格一起重抽。补充比较分别以每项结果的 3 个规则对比作同时区间。[冻结检查点和校准选择](frozen.json)

## 复现

在仓库根运行以下命令。用新目录从头运行三阶段。使用归档时，解压 `raw.zip` 后把后三条命令的 `--out` 指向解压目录。已存在的确认评分可直接用于汇总和逐步回放核验。

```powershell
.venv/Scripts/python.exe -m pytest -q experiments/pulse_game/tests/test_free_graph.py
.venv/Scripts/python.exe -m experiments.pulse_game.free_graph_study register
.venv/Scripts/python.exe -m experiments.pulse_game.free_graph_study train
.venv/Scripts/python.exe -m experiments.pulse_game.free_graph_study confirm
.venv/Scripts/python.exe -m experiments.pulse_game.free_graph_analysis summarize
.venv/Scripts/python.exe -m experiments.pulse_game.free_graph_analysis verify
```

每条原始评分记录的末轴是接触侧、接触拍与公开回执。超时表示 `[-1, -1, 0]`。全部 4,915,200 条记录另行核对了接触侧、拍与回执，两个时序的公开气味诊断策略均为 100%。GPU 对每个检查点的第一个出生组、两次重启及两个时序的评分逐值回放一致。归档还包含全部冻结权重、出生与世界根、图列表、规则真值表和校准选择。[回放核对](verification.json) · [原始数据和权重](raw.zip) · [逐文件 SHA-256](provenance.json)
