# 多个分离环出生，随后开放增退边

出生时把 32 个单元划入互不重叠的有向环。各单元在所属环内恰有一入一出。再抽 32 条跨环弧，保证每个环至少有一条跨环入弧和一条跨环出弧。16 张实际出生图各有 2–6 个环，环长 2–30，全部强连通。固定比较和本实验使用同一出生采样器。[出生图、原环成员和跨环弧](registered.json) · [采样器](../../../../experiments/pulse_game/module_graphs.py)

每个出生及规则，三组从同一张图与相同参数开始，先冻结接线进行 120 次 Adam 更新。随后冻结组沿用出生图至第 1,200 步。回执引导组从第 120 步起，每隔 120 步在保留、增一、增二、退一、退二间择优，使用随机探索实际送达的有符号味觉来计算回执预测交叉熵。同步随机组按照相同时间和增退数量从可行位置中独立选择。所有非自连接都可加入，任意原环内弧和跨环弧都可退出。每次编辑后要求全图强连通，因此每个原环的节点集合仍有通往其补集的入弧和出弧。初始模块标签只用于事后统计。候选生成、参数化、训练集和统计沿用自由出生图协议。[自由出生图协议](../plastic/README.md) · [冻结清单](frozen.json) · [模块实验实现](../../../../experiments/pulse_game/plastic_topology_modules.py)

八组出生各保留两个重启，128 个确认世界各覆盖 20 个气味对。区间为 20,000 次配对自助抽样的六项 Bonferroni 95% 同时区间，全部包含零。可观测的邻接平均提高仍伴随较大组间不确定性。[逐规则、逐重启成绩及区间](summary.json)

## 原环与跨环弧的去留

引导在 432 次机会中接受 410 次编辑，其中 214 次增长、196 次退边。编辑过程中弧数为 51–74，终图为 51–73。两个编辑组各有 48/48 个终图改变了出生接线，144 个终图均强连通。引导组保留 1,440/1,536 条原环内弧和 1,352/1,536 条原跨环弧。165 个原环实例中，91 个完整保留。同步随机保留 101 个完整原环。两组均出现原环均已断开的终图。引导组在原环的节点集合内还长出 157 条原先没有的非自连接，随机组长出 149 条。这里原环实例按出生、规则累加。[接线统计](summary.json) · [掩码及编辑日志](raw.zip)

8 个 CPU 线程的两个训练片共用时 288.4 秒。候选构造、7,776 次候选图打分、选择与掩码安装合计 7.65 秒。该次运行与其他实验共享 CPU，耗时用于记录本次执行情况。[完整时序](summary.json)
