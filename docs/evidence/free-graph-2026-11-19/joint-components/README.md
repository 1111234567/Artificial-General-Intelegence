# 已经共同学习的内部权重与动作读出

每个个体先做完完整联合学习的 120 次请求。用同一份终点状态和同一张最终接线图分叉，在 20 项全新物理探针上，分别恢复动作读出、恢复感觉及循环参数，或恢复两者。对于生命中新长出的边，“恢复”取当前这次生长时该边自己的系数。新生后退出又长回的连接，按其最近一次出生计。所有分叉都有同一段完整的联合学习经历。探针延续所存神经状态，每种气味对单独测试，味觉静默，计实际首次接触。[预登记与探针根](protocol.json) · [实现](../../../../experiments/pulse_game/joint_component_probe.py)

| 生命周期经历 | 保留全部学习值 | 只恢复动作读出 | 只恢复感觉和循环参数 | 两部分都恢复 |
|---|---:|---:|---:|---:|
| 稳定 | 73.26% | 71.08% | 71.02% | 68.23% |
| 规律反转 | 43.62% | 44.17% | 36.99% | 37.15% |
| 反转后回到旧规律 | 66.38% | 63.98% | 67.59% | 64.79% |

反转后的生命在新探针上，恢复感觉和循环系数使正确率下降 **6.63 个百分点**，六项比较的同时 95% 区间为 **[3.28, 10.57]**。说明整体内部权重改变已经影响行为。此处一起替换了感觉权、门控参数、突触系数与相应偏置，无法单独归因给新生边。终点的动作读出和内部表征也可能已互相适应。新生边自身数值的贡献见[逐代连接回滚](../joint-edges/README.md)。新探针在 120 次学习后才出现，所以其正确率与训练生命最后 20 次的正确率有不同分母。[全部区间](summary.json) · [逐生命动作](probes.zip)
