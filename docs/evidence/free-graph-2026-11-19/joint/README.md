# 生命内的独立边权学习与拓扑编辑

每个生命从同一已拟合的 32 节点、64 弧的模块环出发，连续经历 120 个物理请求。神经状态、参数和图在请求之间延续。每组克隆共享出生和世界，每臂驱动自己的身体，只有实际首次接触产生带正负号的味觉。变点、规则名称和正确侧保持隐藏，超时没有回执。三种情境分别维持规律 A、在第 40 或 60 次请求后切为逐题反向的规律 B、在经历 40 次 B 后恢复 A。每个 20 请求区块含全部有序气味对。每个条件有 8 个拟合出生组、3 条规则及 16 个未参与开发的世界，即每臂 384 个生命。三条真值表沿用出生模型的任务设置。[登记](registered.json) · [继承权重](confirmed-heads.json)

出生时把同一接收节点的拟合增益赋给其每一条入边的独立原始系数，实际传递系数为原始系数除以接收端当前入度的平方根。新增边也从接收节点出生时的带符号增益起步，从之后实际收到的第一份回执起就能更新。退边删去该代系数。拓扑规则仍按各自的回执周期检查独立的增边和退边机会，保留正分数条件和全图强连通检查，候选范围和边数开放。入度变化会同时改变该节点现有入边的有效系数。

权重学习由可见接触侧与味觉提供当前二选一动作的误差信号。收到回执后，对接触前行动时段的平均输出计算逻辑损失，从该时段反传到当前请求起点和气味出现时刻，沿用请求初始状态但在此处停止求导。更新对象包括每条有效弧的独立原始系数，以及输入到候选和门控的矩阵与偏置、动作读出和偏置。学习发生在请求完成之后，先更新现有参数，再实施已评分的编辑。旧的无学习与只改拓扑路径在三个确认条件的接触侧、接触拍、回执、编辑地址及终图上与参考实现一致。[模型](../../../../experiments/pulse_game/joint_live_model.py) · [物理运行](../../../../experiments/pulse_game/joint_live_study.py)

在独立出生和世界上用联合臂选择共同学习率。开发目标按末窗计算反转收益，对稳定损失做两倍扣分。最佳主动学习率为 0.06，联合臂相对全冻结的开发得分是 −5.97 个百分点，低于全冻结的零分。确认仍测试主动联合臂，所有含权重学习的确认臂共享同一学习率和权重更新规则。先启动的另一套预登记由只学权重臂选共同学习率，也选中 0.06，使用另一批确认世界和相同拟合组。[联合开发](development.json) · [冻结配方](recipe.json) · [另一批世界](weight-dev/summary.json)

## 新边的实际权重更新

反转确认追踪了联合臂的全部 4,992 个新增世代，包括同一位置退边后的重新生长。4,991 个世代从出生到退边或生命结束之间又收到了实际回执，全部发生了至少一次可测的原始系数更新。发生更新的世代有 1,559 个保留到终图，3,432 个后来退出。中位出生原始系数绝对值为 3.0855，中位起止绝对改变量为 0.01319，中位逐次绝对改变量之和为 0.03758。首个权重改写的出生后等待中位数为 1 个请求。出生至退出或终点的起止符号均相同。归一化由各事件的接收端入度另行计算，终值变化可以由入度或原始系数变化引起。[完整原始和有效系数统计](summary.json)

确认中，联合臂对气味三个输入通道、标记通道、行动通道均产生了实际更新。在反转臂，至少一个原始边权发生变化的回执有 45,990 次，更新任一候选或门控输入系数的有 46,038 次。锁住新边的对照只锁每个新世代的原始系数，其他参数仍学习，接收端归一化仍随编辑而变化。锁住新边的准确率差区间覆盖零。反转确认的新增边出生原始系数绝对值中位数约为起止改变量中位数的 234 倍。上述结果覆盖沿用旧初始化和旧选边规则、进行单请求信用分配的 120 请求生命周期。
