# 同一终点下，新边独立权重的检验

每条在生命中生成的边持有一个有符号系数。接收节点收到的边消息还要除以该节点入度的平方根。这里直接读取前者。逐个回放生长和退场事件，把始终在场的出生边、在新地址首次生长的边、在新地址再次生长的边、在出生地址再次生长的边分开。同一地址的边退场后再次出现时，以这次生成的初始数值和时刻为准。[冻结探针登记](registered.json) · [权重回执登记](receipt-replay-protocol.json)

两批试验都使用 8 组拟合模型、三条规则、16 个生命世界根。第一批用只更新数值的开发臂选择公共步长，第二批用允许同时改线和更新数值的开发臂选择公共步长。两批复用起始模型组，生活世界根和静默查询世界根均不同。对稳定和持续反转两种情境，分别从每个联合学习生命的终点分出 20 个物理查询，覆盖全部有序气味对。每个查询使用同一个终点神经状态、实际图、输入和动作读出，查询期间不呈现味觉。身体实际首次抵达正确一侧时得分。[第二批冻结探针登记](integrated/registered.json)

主要对照只把生命中新增且仍在场的边重置为各自生成时的系数。其他对照分别重置仍在场的原始出生边、同时重置两类边，或仅重置新地址上的第一代边。每个对照沿用同一终图，因此度数归一化一致。配对区间对模型组及生命和查询世界根的配对单位分别重抽样；三条规则和 20 个有序气味对保持固定。每批对稳定与反转两个主要差同时给出 95% 区间。相同终点的重置检验衡量已学系数对冻结表现的作用；一生内固定新增边权重的对照检验学习过程中的作用，包括后续自选体验和图变化。

另外按事前指定的根下标 0、5、10、15 回放真实回执。在每次数值更新前后直接读取系数，统计每条边在生命周期中的更新次数、绝对变化总和和变号。生成请求的味觉发生在生成之前，该次味觉不计入这条边的年龄。回放也记录途中退出的边及最终回到初值的边。[回执回放登记](receipt-replay-protocol.json) · [第二批回放登记](integrated/receipt-replay-protocol.json)

## 数值更新

## 静默物理查询

每批每种情境共 7,680 个查询，各分支从同一批生命终点开始。下表的差为已学系数减去重置新边系数，单位为百分点。

| 步长选择及情境 | 已学系数 | 重置新边 | 差及同时 95% 区间 | 首次接触侧或超时状态变化 |

| 仅权重，反转 | 44.84% | 45.03% | −0.18 [−0.42, +0.04] | 0.44% |
| 联合，稳定 | 73.67% | 73.67% | 0.00 [−0.14, +0.13] | 0.13% |

重置会改变少数物理决定，四个配对准确率区间均包含零。重置原始边、重置所有边和只重置首次新增的边，配对准确率区间也均包含零。对这两批联合生命和这套静默查询，观察到独立数值学习以及个别动作变化，尚未观察到可可靠复现的正确率收益。[第一批对照和逐规则得分](summary.json) · [第二批对照和逐规则得分](integrated/summary.json)
