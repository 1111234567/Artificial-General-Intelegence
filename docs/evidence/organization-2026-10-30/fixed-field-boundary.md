## 数学结论

在实际 live/aux 学习前向和保存边界，`functional_fixed` 不接受出生或退出，允许集合始终为出生块对角 mask，故 `B=C=0`。对任意允许的 A、D 和任意 h=(x,y)，plain 与 coupled 都限制为：

```text
f(x,y) = (-x + A tanh(x), -y + D tanh(y))
```

两者在受约束参数子空间上的函数族相同，且活动 A/D、编码器、动作头的目标导数相同。然而，在该子空间之外的 B 方向，

```text
plain:   d f_x_i / d B_jk = delta_ij tanh(y_k)
coupled: d f_x_i / d B_jk | B=0 = A_ij (1-tanh(x_j)^2) tanh(y_k)
```

C 方向同理。因此，前向限制相同不代表完整分配参数空间的梯度相同。`FunctionalOperator.before_gradient` 原样返回全部梯度，`NativeTrainer._apply_gradients` 对所有模型参数联合裁剪，Adam 更新全部坐标与矩，之后才将未允许权重清零。休眠 B/C 的梯度能进入全局范数并影响裁剪系数、Adam 矩和后续更新。

“B=C 始终为零”须限定为真实控制/辅助学习及保存边界：固定组的无梯度候选损失探测仍会暂时插入候选，然后强制拒绝并恢复；这些探测不驱动世界、不覆盖 live h，也不接受结构改变。

## 单块 CPU 机械例

两模型使用同一 seed=0、相同参数/h/世界/Adam/出生 mask；宽度 8、batch 2、live chunk 4，原 startup 辅助梯度。预先把 toy clip 设为 `.01`，使一块内显式发生裁剪；正式方法的 clip=1 未改。两者的 field、Heun 状态/动作输出、真实观察/标签/行动摘要、块末 h/世界均逐位相同。

| 量 | plain | coupled |
|---|---:|---:|
| 活动循环梯度 L2 | 0.0234382753504 | 0.0234382753504 |
| 休眠跨 bank 梯度 L2 | 0.0346734060382 | 0.034865491566 |
| 全参数梯度 L2 | 1.59324312395 | 1.59324731583 |
| 实际联合裁剪系数 | 0.00627650205093 | 0.00627648561432 |
| 保存后跨 bank 非零数 | 0 | 0 |

休眠跨 bank 梯度差 L2 为 `0.0508792026715`；活动循环梯度最大差为 `0`。首次更新后活动循环 Adam 一阶矩差 L2 为 `3.73741048223e-11`；活动循环权重差 L2 为 `0`。

Adam 首步归一化可能抵消大部分统一缩放，不能把范数差直接当成同比例的权重或行为差。这个例子证明路径存在，不估计正式 clip=1 的触发频率、效应大小或正式分数差。

## 报告话语限制

- `coupled_fixed` 对 `plain_fixed` 是同一受约束真实前向函数族内，完整参数化及更新实现的比较。不能把其分数差归因于实际已启用的跨 bank 非线性计算。
- `[(coupled_task-coupled_fixed)-(plain_task-plain_fixed)]` 只能称“完整参数化 × 结构学习策略的交互”或等价表述；不能声称已分离跨 bank 联合非线性的净收益。
- `coupled_task` 是否实际启用跨 bank 作用，还须结合其真实桥坐标与行为，且这些关联仍不自动排除候选梯度、裁剪、Adam 和容量轨迹等共同改变。
- 当前已执行方法保持不变。若将来需要识别纯前向机制，应另立具有匹配活动更新/裁剪规则的对照，不能回写本轮冻结实验。
