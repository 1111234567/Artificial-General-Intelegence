# 单神经元试探预报中的固定侧别回声

三个冻结成体都用原主区 14 号单元预测、10 和 11 号单元实际选门。替代条件把副区活动、慢迹及副区接收的快权逐拍固定在它自己的空试轨迹上。主区依原方程更新，收到该受体本来的空试回流和一个由试探侧索引的固定模板。模板来自独立的 96 个校准几何根，两个留出各有 96 个新根，每根 64 个平衡单元。零模板逐拍、逐位恢复了完整原生空试。[事前方案](native-relay-plan.md) · [数据和配对区间](native-relay-results.json)

| 冻结运行方式 | 反向到账时排对两门 | 双门 MSE | 真实动作口走到优门 |
|---|---:|---:|---:|
| 原生试探 | 74.94% / 75.20% | 0.523 / 0.523 | 95.62% / 96.66% |
| 空试副区加固定侧别模板 | 51.49% / 51.39% | 0.722 / 0.724 | 95.59% / 96.65% |
| 原生空试 | 50.00% / 50.00% | 0.708 / 0.710 | 95.55% / 96.56% |

原生比固定模板排序高 23.45 [−3.60, 40.33] 和 23.81 [−2.73, 40.53] 个百分点。按出生 731、733、735，这两个差分别为 +33.79、+40.40、−3.82 点及 +33.79、+40.59、−2.96 点。原生的双门 MSE 比模板低 0.200 [0.002, 0.334] 和 0.201 [0.002, 0.335]，三个出生同向。两套留出的实际选优差为 +0.02 [−0.13, 0.15] 和 +0.01 [−0.10, 0.13] 个百分点。

在这三个严格 40 节点成体上，固定侧别只恢复了约 6% 的原生排序提升。更精确的预测依赖完整试探回路，具体差距仍可由状态依赖的传输、递归耦合或副区对后果的计算产生。三种模式的实际选优率接近，区间支持的区别是预测误差，而实际选路收益的增量仍未建立。
