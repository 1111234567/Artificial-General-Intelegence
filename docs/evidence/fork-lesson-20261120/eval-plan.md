# 冻结副本试算与延迟选择的预定检验

以下种子、指标及判据在首次读取正式终点行为或预测之前固定。样本由评估脚本独立生成。世界种子为 `98633071` 与 `98633107`，每个世界 144 个几何根。根按两条提示向量夹角分层，`[55°,85°)`、`[85°,125°)`、`[125°,180°]` 各 48 个。每个几何根完整交叉两个私有值、旧接触次序、左右门的物体分配与各门乘子，共 64 种。每条配对复用随机动作抽样值。两个门的当步收益必须实测为零。先冻结网络再逐环境强制走左和走右至实际到账，仅以结算的两条支路定义目标。正式报表分列两组独立世界、各出生种子、几何近角且两门到账相反，以及私有值相反且两门到账相反的近角子集。决策位置左右交换以门分配和乘子一并交换为准。

## 先检验主图的预测

只有主图的原生预测口计作预测。比对行动前两个值和其后真实走两门的到账。自然随机行动没有走的门在另一条冻结环境分叉强制兑换，另报预测均方误差和符号正确率。只把训练看到的已选门当教学样本。回报以 ±1 记，预测的常量对照为零，符号相等时按半分处理。两门到账相反时，预测值的大小关系另报排序正确率。两个留出世界中，未选门的均方误差相对零常量和打乱目标组均须改善，且所有出生种子同向，才记为通过预测学习判据。已选和未选门的计分同时给出实际计数和样本分母。

## 再检验双向连接是否用于预测及选择

固定同一行门线索结束后的主图与副区状态、快权、迹、环境、动作抽样值与时间。静默窗始终给零外界输入。在其各拍分别切断、替换主图→副区与副区→主图的电流，其余路径按原动力学。双向重放同一世界自身注入序列必须逐位恢复自然活动、状态、预测与行动。异历史供体复用几何、旧接触次序与眼前门线索，翻转两个旧私有值，由此反转后续结算。等量对照只置换同一行、同一方向、同一拍的流入地址，验证每拍 L2 平方和保持。主图预测只能读主区原生端口。行为验证从每个干预自己的临场状态真实走选中的门并结算。

双向参与预测的严格判据要求在最小角度的反向到账子集，两套世界均满足以下条件。正常训练组的预测排序优于相同容量且训练期断开联络的同目标组。自身回传与自然条件保真。去程和回程各自切断及异史替换都应使预测排序下降，其中异史替换还应使按真实左右优势编码的预测差朝供体方向变化。主图确实借此改善选择的严格判据要求在相同子集，两套世界的自然结算准确率均高于去、回各单独切断和异史替换，以及等量置换。支持一条方向、只改变数值而未改变行动、只能发现一般性扰动，分别作为较弱证据报告。统计比较使用按出生和几何根交叉重采样的 95% 配对区间，正式通过需下界超过零且所有出生种子差同向。三出生条件下同时列出逐出生差和范围。

另在行动前两拍的主预测读出时交换主图两个评分单元的活动，保持其平方和、快权、迹、待写入值和其他单元不变，再走两拍自然递归。未改动活动的分段执行必须精确复现自然执行。报告换位前后差在真值方向的动作 logit、实际选门和实际到账是否下降。这对评分单元参与行动提供额外检验，两个单元可能还有其它功能。

旧接触序列被保留但用同拍长空输入替代现门线索，以及保留门线索但用未经历的初态走等拍流程，两者只作为诊断。自然结果与这些缺失输入的基线比较，及私有值或左右门镜像时的配对，检查单独旧经历或单独当前输入能解释多少。有历史且有当前信息的主图直接推断仍有可能。是否真正逐步在副区试算，每个预测数值或动作基线本身都无法判定。
