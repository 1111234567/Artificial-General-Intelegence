# 双门环境与身体接口

每条生命有两件物体。各物体的私有味觉值独立取 −1 或 +1，方向从相反的两个角帽内均匀取样。物体方向的 x 分量绝对值至少为 0.45，方向长度乘以 1.35 后成为感觉脉冲。方向区分物体身份，私有值、遇见顺序、调查轨道侧、门左右配对和门乘数分别抽样。默认方向夹角的理论范围约为 53.49° 到 180°。

调查一件物体时，身体沿唯一可通行的轨道移动。视野先出现物体方向，身体抵达物体位置后才出现所在侧的接触，接触后的下一拍才出现正味或负味。每件物体的过程为 2 拍空白、3 拍看见、2 拍沿轨道移动、2 拍味觉。连续 18 拍调查脉冲传入同一个身体。两次调查都由轨道引导，自主动作发生在随后必须选边的岔路。

岔路两门各展示一件见过的物体的方向和一个公开的 −1 或 +1 乘数，共 3 拍。输入 0–2 和 3–5 是左、右门方向，输入 6、7 是同一顺序的乘数。之后有 6 拍全零外部输入。主区已有的 10、11 号动作神经元给出侧选择，比分为 `2.5 * (h[11] - h[10])`。自然生命只能跨过一道门，第一拍的味觉收益恒为零，之后再空等 6 拍，所选门才给出两拍终末味觉。兑现值为所选门的公开乘数乘以对应物体的私有值。两个兑现值有时相同，评估选边正确率时使用严格偏好场景。

## 双区神经流

图继承既有 20+20 节点的 `TrialGraph`。复制区每拍共享主区的活跃递归权重，可见试写增量，同时保有自己的活动。两个区通过各自的稀疏边和生命期快权重双向传输神经电流。整张图以主区的 12、13 号神经元作为左右门价值拟合的读数，主区仍由原来的动作端移动。复制区没有指定的预测输出。外界不将身体活动、已见轨迹或未走门的结果重新输入模型。

空白期的审计可逐拍替换任一方向实际进入接收区的 20 维电流，或者把它置零。两个方向用同一初态的自然电流完整注回时，活动、快权重、慢迹和待接纳增量应逐位复现。这项操作针对普通跨区神经电流。共享权重和复制区活动参与的试写接纳机制仍在运行，单独截桥衡量的是该桥电流的作用。

## 取样与物理核验

固定种子 5192026 的 4,096 个场景有 1,027 个左优、1,021 个右优和 2,048 个平局。按三个未拟合出生体各抽 256 个场景。每个场景用原门和互换门两种布局分别实际强制走左右各一次，共 3,072 次走门。即时收益全部为零，所选门的终止味觉均与离线算式一致，三个出生体的双桥自身替换均逐位复现。[核验数据](world-smoke.json)

世界单元测试还逐拍核对味觉次序、隐藏的未来门配置以及桥电流进入接收区的时序。只运行本环境与其继承结构的回归测试：

```powershell
.\.venv\Scripts\python.exe -m pytest -q experiments/pulse_game/tests/test_fork_lesson_world.py experiments/pulse_game/tests/test_native_rehearsal_trial.py
```

这些测试核验环境和干预实现。学习结果由另行冻结的拟合与留出评估给出。
