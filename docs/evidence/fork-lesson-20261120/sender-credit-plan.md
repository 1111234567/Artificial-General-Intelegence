# 发送轴突的信用跨度对照

方案在读取完整信用组的任何结果之前固定。对整体教学与训练期切去程两个母组，分别使用出生 `731`、`733`、`735` 的同一冻结起点。只开放主区→副区的 80 条原有发送轴突，沿用原训练的 Adam、学习率 0.006、768 步、每步 64 条路线、混合探索率 0.25 与梯度范数上限 2。训练场景均从 `[6238511, birth, step]` 生成。每条训练路线只实际走一扇门，唯一教学信号为该门真实延迟到账的 ±1 回报，目标为行动前两拍的主区同侧估计。两个训练组的前向流程均在全部接触、门线索与静默期间使用当时的发送轴突。完整信用组的唯一变化是允许这项预测误差沿全部前史回到同一组发送轴突。对照为原静默窗内信用训练终点与未续训起点。训练不访问任何留出世界。用正式第 768 步检查点与已有同流对照评估。

保留每步每条路线的原字段，复查随机数、动作抽样、实走收益及教学信号。每个完整信用终点逐位检查其余参数、发送矩阵的非连接元素及掩码。第 1 步从共同起点复算原静默窗的前向、实际到账与梯度，对照旧账本，要求两信用跨度的同起点前向相同并显示不同的梯度。后续动作可随已训练轴突变化，因此使用公共抽样随机数，允许真实所走路线不同。

保持原发送试验的完整因子结构，使用额外独立的留出世界 `69253111`、`69253189`，各 128 个几何根，每根交叉 64 个私有值、门顺序、乘子与接触顺序组合。冻结后从临场状态分别真实走左右门至延迟到账，并用相同随机数选择自然动作。主要指标为两门等权均方误差、自然未走门均方误差、两门到账相反时实际选优率。以共同未续训策略未走的门为锚另报误差，排查各臂动作改变造成的未走门组成变化。两套世界分别按出生与几何根配对做交叉自举，报告区间、逐出生差、总计数与收益。完整信用降低相对静默窗组的双门误差，才支持截断是原退化的贡献因素。即使改善，仍须与未续训起点比较才能判定是否追回原来的预测和选优。
