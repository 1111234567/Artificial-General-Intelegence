# 延迟预测误差沿完整经历回传到发送轴突

只开放主区发往克隆区的 80 条原有发送轴突。沿用相同起点、优化器、场景和动作抽样种子。两组生命都从接触物体、读取门线索到选择实跑当前发送轴突，每条只走一扇门。唯一区别是预测误差能否沿较早的接触与门线索阶段返回这些发送轴突。开发期间没有反向传播实际选门收益到马达策略。副区、回程、主区读出和共享递归的慢参数保持位级不变。

| 起点 | 续训条件 | 两门等权 MSE，世界 A / B | 未走门 MSE，世界 A / B | 实际严格选优，世界 A / B |
| --- | --- | ---: | ---: | ---: |
| 整体教学 | 未续训 | 0.0869 / 0.0853 | 0.1497 / 0.1481 | 96.27% / 96.19% |
| 整体教学 | 只给静默窗信用 | 0.8187 / 0.8315 | 0.8905 / 0.9029 | 66.67% / 65.78% |
| 整体教学 | 完整经历信用 | 0.0571 / 0.0555 | 0.1045 / 0.1021 | 96.49% / 96.47% |
| 曾切去程，续训重开 | 未续训 | 0.4554 / 0.4634 | 0.5036 / 0.5146 | 79.96% / 79.92% |
| 曾切去程，续训重开 | 只给静默窗信用 | 1.1783 / 1.1716 | 1.2842 / 1.2797 | 59.05% / 58.50% |
| 曾切去程，续训重开 | 完整经历信用 | 0.1404 / 0.1374 | 0.2226 / 0.2183 | 87.10% / 86.14% |

完整经历信用相对静默窗信用，在两个母组、两世界及每个出生中都降低两门误差和未走门误差，提升真实选优。相对未续训起点，整体教学组的两门误差分别降低 0.0298 和 0.0298，配对 95% 区间为 [0.0174, 0.0483] 和 [0.0175, 0.0474]。实际选优恢复到起点水平，差的区间为 [−0.11, +0.60] 和 [−0.05, +0.73] 个百分点。曾切去程组相对未续训起点的实际选优分别提高 7.14 和 6.23 个百分点，区间为 [+6.10, +8.11] 和 [+5.14, +7.23]，三出生同向。以共同未续训策略的未走门为固定评价对象，完整经历信用的误差仍然较低。每个表格单元覆盖三个独立出生，严格选优的每世界分母为 12,288。

六条新训练账本各有 49,152 次真实行程。首步从同一起点复算并精确复现旧静默窗的账本，完整信用的预测、选门和实际结果在首步保持相同，梯度向量在六条训练中都发生改变。学习结束时，只发现 80 条已有发送轴突改变。留出世界在冻结后实际走完左右两条路作为预测真值，没有用于挑选终点。

同一设置下，截掉较早阶段的预测误差信用足以造成先前看到的退化。允许完整经历信用后，只调整本体的去程便足以提升主区预测，并在曾切去程的身体上提升实际选优。信用在早期形成接触记忆和随后查询之间可能都有贡献。此比较只共同改变了接触和门线索阶段的梯度，尚未定位哪一阶段的梯度贡献更大。

## 前史与六拍静默窗各自使用学后发送权重

对六个完整信用终点做冻结权重互换。将接触和门线索合为前史，保留该段形成的全部活动和快权，再独立设置静默窗使用未续训或学后的发送权重。在世界 `69253111`，两段都用起点或都用学后权重时，逐位复现原先的预测、马达和真实到账。另一套几何 `69253917` 是新留出。

| 起点 | 学后权重用于 | 未走门 MSE，配对世界 / 新世界 | 真实严格选优，配对世界 / 新世界 |
| --- | --- | ---: | ---: |
| 整体教学 | 无 | 0.1497 / 0.1470 | 96.27% / 96.25% |
| 整体教学 | 仅静默窗 | 0.1351 / 0.1312 | 96.45% / 96.35% |
| 整体教学 | 仅前史 | 0.1185 / 0.1157 | 96.32% / 96.22% |
| 整体教学 | 两段 | 0.1045 / 0.1010 | 96.49% / 96.43% |
| 曾切去程 | 无 | 0.5036 / 0.5081 | 79.96% / 80.07% |
| 曾切去程 | 仅静默窗 | 0.4587 / 0.4658 | 82.73% / 82.60% |
| 曾切去程 | 仅前史 | 0.2625 / 0.2624 | 85.69% / 85.48% |
| 曾切去程 | 两段 | 0.2226 / 0.2205 | 87.10% / 87.18% |

未走门误差的下降以前史阶段为主。只在静默窗换入学后权重，也在两母组、两世界及两种固定前史下进一步降低误差，所有这些配对区间均低于零。前史与静默作用的误差交互区间均跨零。前史包含门线索，故其收益可来自接触记忆，也可来自呈现门时的初始处理。

曾切去程的身体使用父体前史时，只在静默窗用学后发送就使实际选优加 2.77 和 2.53 个百分点，95% 区间为 [+1.73, +3.93] 和 [+1.64, +3.57]。当前史已用学后发送时，静默换入再增 1.41 和 1.70 个百分点，区间为 [+0.88, +1.95] 和 [+1.10, +2.35]。两段各自有用，学后前史使静默窗的边际收益缩小。整体教学组起点已在 96% 左右，四格行为差的区间均跨零。该互换定位的是部署期权重的作用时间，训练时各阶段的梯度贡献仍是开放问题。
