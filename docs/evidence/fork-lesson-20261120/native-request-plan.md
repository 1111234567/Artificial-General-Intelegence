# 40 个既有节点中的单神经元试探预报

从三个整体教学终点出发，原身体的全部慢参数和两条内部试动作输入的增益参加端到端训练。模型在感受两物和门线索后，只由原主区 10、11 两个运动神经元选择试探侧。试探侧唯一的物理注入是副区 30、31 的一拍相对侧向脉冲。允许两个活动侧的增益学习，非活动侧抑制固定。主区在第三个静默试探拍只读既有节点 14 的活动作试探收益估计，再走原图两拍，由原主运动端实际选一扇门。没有新增节点、读出网络、外部选择器或直接向主区送试探侧的通道。所有副区活动由原本的递归、内部试探脉冲和完整个体目标产生。

同样的起点按出生配对训练。绑定组向副区送真实自选试探；打乱组把同一批自选侧向循环移动一行再送入副区。训练场景 `[69278203, birth, step]`，相同的独立试探和执行抽样带。各 1,536 步 × 64 条真实单路线。策略梯度以实际延迟到账和前批收益基线更新原运动端，预测误差只在真动作等于本体原试探侧时用这一实际到账校准，其样本按实际侧的探索概率逆权重。两臂预测信用都穿过全生命。世界从未结算训练中的另一条路线。统一 Adam 0.005，评估只用固定终点。

独立世界 `69278519` 和 `69278653` 各 96 几何根与每根 64 全因子配对，按三个角度档各 32 根。冻结后从同一门线索与准备状态强制内试左或右，读取同一主区节点，再分别真实执行左右门至延迟结算，预测标注仅来自实际终点。两门到账反向时，计算成对强制内试预测排序，预测相等计半。另统计自然自选内试再实际择路的严格选优率，以及自然未走门的强制内试估计误差。分别比较自然、空试动作、切副区至主区实时电流，以及同时关闭草稿采用的副区返回隔离。主体测试沿用原静默准备与询问时间，选择和真实推演保持各自后续状态。主要判据要求两世界的绑定组排序超过随机与打乱组，并受空试或切回程影响，单列三个出生和近角场景。若回路干预显著改变估计但行动未稳定改变，分别报告。证据适用于此原生复现，直接与有外部非线性读出的实验相比还同时改变了学习信号可到达的参数、直接回流结构与优化过程。
