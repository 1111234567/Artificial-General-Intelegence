# 固定侧别回声的冻结检验

三个绑定成体各在独立的 96 个校准几何根上计算三条冻结轨迹。分别向副区送入左、右内部脉冲，或保持空试。各根完整交叉两个已尝过的私有值、接触顺序、门位置以及两个门乘子，共 64 个单元。逐出生逐边计算真实试探回传减同史空试回传，然后在所有校准单元取算术均值，得到固定的左、右两份 5 拍 × 20 接收口模板。校准种子 `2130712610`，留出分别为 `2130712749` 的 144 根和 `2130712893` 的 96 根。三套几何均独立于正式训练、现有留出以及其他诊断。模板及其用法在读出这两套留出之前锁定。

每次留出只用真实受体一次无试探的副区轨迹。主区收到这条空试轨迹本来的回传，加上仅由给定侧索引的固定模板。逐拍固定副区活动、慢迹和以副区为接收端的快权，主区候选采用与快权调制读取的是同时刻的空试副区活动。副区的活动演变来自独立空试副本，也始终读取空试自己的进程状态。主区保有真实受体旧经历和当前门线索，主区、预测口和运动口权重照旧。零模板隔离版须逐位复现原生空试的每拍状态。观测同世界原生试探、无试探和此前只教双向桥参数的 `bridge` 成体作为刻度。原生试探的受体轨迹只用于正控，固定模板的受体替代不读它。

若固定模板下强制左右试探能重新得到大部分原生预测顺序和可比 MSE，则在这一环境中，原生回传的上下文特异信息超出侧别的必要性会减弱。若固定模板强于空试而明显弱于原生，则纯侧别有解释力，实测差距仍可能来源于回传的门与历史交互、状态依赖的传输或其他动力学。两门到账相反时，比较受控左右试探的排序、带真方向的预测差、追随自身试探选择后的真实行动口优选率，并另外报两门整体 MSE 与贪心实际行动口。所有真实选择都运行实体的单扇门后果。沿出生和几何根联合配对重抽样，给出各留出的差与 95% 区间。后续只据锁定的这些诊断汇报。
