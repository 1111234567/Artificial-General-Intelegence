# 真实门刺激的询问与真实旧经历的交叉干预

检验冻结的 whole、bridge、reward 各三个出生体。两套独立几何种子为 42887091 和 42887129，各使用 96 个根。每个根完整交叉问题所指的门侧、另门乘数、另门私值和受体被问对象的自然私值，共 16 行。随机对象方向、先后、身体调查侧与每个根自然的被问门乘数，依照既有世界生成器。固定此设计后再读取正式结果。

对每行，从同一个冻结身体真实走过的受体前史和两个真实门展示提取自然主→副电流。面对同一私律，两次只翻转被问门公开乘数，得到减号询问和加号询问。独立生成曾真实尝到被问物体 −1 或 +1 的两个答复身体，其余历史因素不变。答复身体在前史后都面对同一固定版本门刺激。对两种历史逐一注入自然询问的整段去程，取得四条相应的副→主电流。将四条答复分别注入同一受体。受体的历史、门刺激、初始神经状态、空白时钟和动作取样值全部固定。终末按受体真实门配置兑现。

逐行对比使用四格带符号均值 `(y[+,+] - y[+,-] - y[-,+] + y[-,-]) / 4`。主指标为行动前两拍被问门预测减去另一门预测。另报两门分别的交互、被问侧编码的最终运动 logit、实际向被问门行走的比例，以及在受体真正有严格偏好时，注入合成结果符合受体被问门自然效用与不符合时的真实收益差。向正确方向变化均以正值表示。自然行为收益单独列出。

两个对照复用行和身体。错问对照改为只翻转另一门的公开乘数，同时保持历史干预仍在原被问对象。等幅对照将每格答复减去同体自然回复，把差量在 20 个接收地址循环错排，再加回自然回复。同一地址映射用于所有格，逐行逐拍保留差量的二范数。记录询问和答复的实际差量，所有受体都先以自然去回电流同时覆写核验完整状态逐位相同。隐去受体自己的答案不会改变真实门效用。

按出生与几何根配对交叉重采样 2,000 次，逐世界报告 95% 区间与逐出生点估计。主指标须在两套世界自然交互下界均大于零、三个出生皆同向，且配对优于错问和等幅地址对照，才支持问门特异性。只看到普通电流能改变活动、单一世界或单个出生的交互、方向相反，均单独报。走向的独立判定还须按同类标准获得实际选门变化，单有运动 logit 变化不达成此判据。

这里的四格是冻结后的人工组合。完整历史也改变答复身体的主区快权和待采用增量，副区共享这些权重，并通过现有调制参与快权采用。普通电流干预可检验身体先发出的真实活动和经历的交互是否经过答复进入受体，无法把历史定位为只保存在副区，也无法证明自然行动时真的逐条询问两个假想分支。
