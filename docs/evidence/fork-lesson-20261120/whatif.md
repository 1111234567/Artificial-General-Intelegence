# 报出本人刚才在副区试过的那扇门会怎样

曾经学过双门预测的三个 40 节点图在本实验中原有参数完全冻结。主区从自身活动选一个未实际执行的动作，通过新设的神经通路把试探脉冲发到副区同源运动节点 30/31。主区只从自己的活动报一个标量，对应刚才内试的路线，不按问题编号选择不同的输出。随后让全图再运行两拍，由主区决定身体真正经过的门。内部试探脉冲从不触发外界接触或发放收益。

这是在既有网络上添加明确的试探接口，包括发送轴突、回传轴突、主区查询和运动线性读出，以及读取主区活动的单标量预测头（含 16 个瞬时隐单元）；一共 458 个可训练系数，原 40 个循环节点及其规则冻结。开发期本体只试一个方向、实际走一个方向，二者相符时才能用已兑现回报校准该次预测，按实走概率校正覆盖不均。另有实际门收益的策略梯度。正确绑定与跨生命错绑各三出生，均训练 1,280 步 × 64 路。该接口的存在及一次试探的时点由实验提供，选择哪边来自本体。[拟合及账本](whatif-fit-protocol.json) · [直接通路隔离核验](whatif-fit-audit.json)

留出使用 144 个新几何根×64 个私有历史及门配置，共两套世界。仅在冻结评估中，从同一个体、门配置和同一状态让副区分别收到未执行的左右试探，每次主区都用同一标量预告。再分别强制去左或右、等到真正结算，用四条物理延续核对未来账目。以下的“排对”只在两门实际回报不同的场景计算，预测相等算半次；自然选门行为另行报告。

| 对同样的过去只改变内部试探 | 留出一 | 留出二 |
|---|---:|---:|
| 学习时按本体意图递送，强制内试两侧的预报排对 | 93.19% [86.73, 99.31] | 92.89% [85.73, 99.31] |
| 学习时问题和递送侧跨生命错配，将相同左右试探放回冻结体后排对 | 48.03% [32.96, 63.86] | 47.66% [32.57, 62.86] |
| 正确绑定，切断试探期普通及新增回程电流 | 40.55% | 40.61% |
| 正确绑定，用通用的侧别方向替换回流差 | 91.54% | 91.61% |
| 正确绑定，改用相反旧价值历史的回流差 | 83.93% | 84.05% |

把物理上送给副区的方向固定，单改名义上的问题标签，主区预测和真实动作逐位不变。换成无试探脉冲，左右两种名义提问也产生相同的主区状态。正确绑定组对自然询问那扇门的回报符号判断约为 96.4% / 96.5%；对自然未询问的门，在相同状态里强制改问该门后，为 86.37% / 86.24%。跨私值取返程方向均值的“通用回声”还保留该受体两种回复的中点，以及每拍的差量大小。在这种有利的条件下，多数排序能力得以保留；它说明这个个体很能用副本传回“我试的是哪边”的信号，不能凭 93% 单独断言价值计算本身都发生在副区。对原差量有幅度、供体却没有可用方向的少数拍采用固定公开单位轴，逐拍幅度最大误差小于 5×10⁻⁷。[预先协议](whatif-eval-plan.md) · [逐世界、条件和配对区间](whatif-eval-results.json)

在有严格优劣的自然选择中，按自己的意图试探比在相同时间随机选一边来试，真实选优率高 0.80 [0.10, 1.83] / 0.64 [0.07, 1.37] 个百分点。绑定组与错绑组两者本来就能很好地实际走门，正确绑定组的总选优率约 97.9% / 97.8%，错绑学习组约 98.7% / 98.7%。预测的显著改善没有带来相对错绑训练组的整体行动优势。
