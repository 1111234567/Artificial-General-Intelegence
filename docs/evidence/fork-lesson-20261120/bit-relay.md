# 副区只传侧别，能复现多少预测？

对三个冻结的绑定成体，分别用独立的 96 个校准几何根得到一对固定的左、右回流模板。留出时，副区只沿同一旧经历下的空试轨迹活动。副区的活动、慢迹和以副区为接收端的快权逐拍固定，主区仍按自然方程更新，并用同一份空试副区活动计算采用和门控。给到主区的回流是该受体本来的空试回流，加上由侧别索引的固定模板。整个试探窗口中，固定模板只携带左右这一位信息。模板隔离计算结束后，才另外运行真实试探作对照。零模板在两套留出的每一拍均逐位复现了完整空试状态。[事前方案](bit-relay-plan.md) · [统计和运行指纹](bit-relay-results.json)

| 运行方式 | 反向到账时排对两门 | 双门预测 MSE | 真实动作口走到优门 |
|---|---:|---:|---:|
| 原生试探 | 93.00% / 93.08% | 0.261 / 0.260 | 98.28% / 97.72% |
| 空试副区加固定侧别模板 | 85.68% / 85.56% | 0.476 / 0.474 | 98.02% / 97.29% |

| `bridge` 成体的原生输出 | 71.75% / 71.78% | 0.992 / 0.991 | 90.32% / 89.58% |

固定侧别恢复了原生排序超出空试幅度的 83.0% 和 82.5%。原生比固定模板排序高 7.32 [−2.50, 12.83] 和 7.52 [−2.57, 13.48] 个百分点，两个配对区间均跨零，出生 735 的差方向相反。原生预测的 MSE 低 0.215 [0.112, 0.290] 和 0.214 [0.110, 0.291]，其按正确方向编码的双门预测差也较大。原生与固定模板、固定模板与空试的真实走优门率差异，其两套留出区间均跨零。

固定侧别和已有状态足以形成大部分按门排序能力。其余数值差距仍可能来自上下文相关传输、回流增益、状态耦合或副区对试探后果的计算。当前回路中，主区与空试副区都保有旧经历，后续实际行动本身也已接近满分。这组结果没有定位到哪一部分计算生成了对后果的估计，也没有显示更精确的预告提高了实际行动收益。
