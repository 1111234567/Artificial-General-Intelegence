# 只把未执行的试探送给副区之后，本体会报出哪条路的后果

训练时主区自选一个试探方向，只有副区的同源运动端收到脉冲。本体稍后用同一个标量报「要是做刚才的试探，会得到什么」。其输入没有试探索引；模拟器也没有把门值、真实动作的将来味觉或未走路线反馈给副区。在原有整张图的出生参数相同且冻结的条件下，比较试探与递送相符的教学、同预算但递送方向在训练生命之间错配的教学。两个条件的部署协议一致，分别测对正确绑定接口的利用，另列错配训练散布中仍错配递送的参考行为。模型在继续学习前已受过整体双门预测训练，此实验检测如何使用一次内部试探，不测从零学会游戏。

主检验在两个未见几何世界，种子 8619551/8619649，各 144 根；每根交叉两物私味、学习顺序、门序与两个私有味觉的公开乘子。来自三份出生的模型配对。环境普通感觉与 B 后身体起点完全相同，只在副区强制给左或右试探。每份强制试探之后分别让本体真正进左、右门并独立等到结算，得到四格；正式预测在真实选门前两拍由主区读出。对相反收益的场景，统计该单一标量的两个预报是否随试探而正确排序（并列计半）、两门预测误差、两试探预测差指向正确门的幅度；另列对自然没试的门的强制试探预测、未走门、两真值一致的情况以及自然策略的选优率。自然部署用学习后的试探/真实运动概率抽样，关闭开发期额外均匀探索；在完全相同的未来动作随机带上比较反向、与历史无关的公平随机试探。所有区间在出生与几何间交叉重抽样。

1. 保持实际递送给副区的脉冲固定，仅改变名义试探标签，主预告和运动必须逐位不变。再将自己的普通及新增回流电流逐拍注回，核对选择与预告。无脉冲时左右试探应完全等价。比较正确绑定组和错配学习组在两个世界的受益。
2. 检验克隆是否仅向已知道两门价值的本体回报一位「试了哪边」信号。在同一真实历史上从左右试探各取一条回流，固定两条的平均电流，只替换它们的半差。第一对照把同一几何、同菜单同学习顺序的四种私味历史半差平均成通用方向；第二对照取两私值反转的历史半差。逐拍把替换量缩放到原半差范数，保留原接收体与均值，报告误差。若完整组的正确排序和双门误差不能稳定优于保留侧别的对照，就不能据此确认主要的收益运算发生在副区内。普通返回之外的共享权重、局部调制与采用路径继续运行，须保留这个限制。
3. 会按试探报告收益，和会选有用的试探，分别判定。前者看两次强制试探的新世界排序、未走门的得失以及断开通道的因果对照。后者要求自然选的试探相对同几何、同随机带的公平随机试探在实际选优上有稳定正增益。测试使用分叉，原训练每条生命始终只走一道真门。
