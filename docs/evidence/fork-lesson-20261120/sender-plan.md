# 只教本体怎样向克隆区发送信号

这个追加对照训练整个个体对外承担的预测。把副区的递归、全部回程连接、主区递归、预测神经元及运动端参数固定，唯一能变的是从主区发往副区的 80 条既有慢连接。全身的生内活动、候选和快权重照常连续。推理时训练出的发送参数始终有效，主区没有替代读出。先从接受过整体预测训练的 whole 及在决策阶段去程曾被关闭的 cut_out 两个预先指定来源开始；后者检验身体在研发阶段没有这条通路时，重新开放它是否能学会使用。两者的对照相同。

每个来源的三个出生都复制出三种情况：初始冻结体、继续用真实选择的延期回报教发送轴突、以独立生命的错误配对回报教完全相同的轴突。真实与错配组同预算 768 个 Adam 更新 × 64 条单路线，学习率 0.006。主区在行动之前两拍报两门预测，误差只取后来真正走过的那一门。开发期只允许决策静默窗内的预测误差梯度流到主区发送轴突，先前经历使用相同训练中参数实跑但切断这段导数。这项续训没有直接训练副区、主区读出或运动策略。每条生命只结算所走路线，保存选择和得失账目。世界域 6238511，使用 25% 均匀探索。

正式冻结检验用新几何种子 7025311、7025383，各 128 个根；穷举独立味觉、门位置、两门乘子、学习先后，同一根内私有情况保持配对。每臂实际选一次，另在评估中强制走完左右两条路核验真实效用。在全门等权预测均方误差、未走门的误差及严格偏好情形实际选优率上对比初始及错误配对组。正的预测增益为误差减少。另做一个同身体干预，使用学后本体的真实前史和同一门口刺激，只在之后全零输入的决策窗，换回研究开始时的本体发送慢轴突；所有其它参数和状态相同。如果行为或预测差仅依赖较早记忆形成，不能归于本体在当前静默期使用了新询问方式。交换干预与全程部署分别列出。两套留出须分别看相同方向和配对区间，三次训练/出生是有效模型数。
