# 原生 40 节点的固定侧别回声检验

冻结三个原生试探绑定组终点。沿用已封存回声实验的过程，在种子 `2141086109` 的 96 个独立校准几何根上，逐出生计算左右单次原生试探的实际 5 拍回流分别减去同史空试的回流，再取平衡均值。每个几何根交叉两个旧私有值、接触次序、门位置和两个乘子，共 64 个单元。每个出生得到两份固定 5 拍 × 20 接收口模板。没有参数训练、模板搜索或从留出回推校准。

两个留出种子 `2141086197`、`2141086241` 各 96 根、每根同样 64 个单元。比较原生试探、原生空试、空试副区加固定侧别模板。替代轨迹中，主区得到同史空试原有回流加由给定侧选出的固定模板，依据真实主区状态按原方程更新。副区活动、慢迹、以副区为接收端的快权逐拍固定为空试副本，采用及快权调制使用这些空试活动。试探窗口之后才实际走一扇门。受体原生左右试探的回流或其他状态只用于正控。零模板隔离版必须逐位复现整个原生空试。估计只读主区原来的 14 号单元，选择只读原来 10、11 号运动口，模型仍为 20+20 节点。

两门相反到账时报告成对排序、预测差和主区实际走到优门的比例，同时报告整体双门 MSE。每种状态的实际路线由主区选择并物理结算，双门比较的目标也由冻结轨迹分别强制走两门获得。按出生与几何根配对重抽样，报告原生减固定模板的区间和三个出生的结果。固定侧别如果保留大量排序，说明区别侧别足以解释这部分能力。原生与模板的剩余差异同时包含状态依赖传输的可能，无法单独定位为副区计算了后果。
