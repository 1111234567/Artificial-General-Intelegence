# 满足门线索、味觉和价值约束的旧接触检验

检验 whole、reward、sham 各三个冻结出生。不训练身体。用独立种子 83179473 的 128 个几何，只根据身体真实接触物体后的两个味觉时间点，为副区活动和副→主普通电流各拟合一个旧轨道侧方向。拟合是实际左右接触对应向量的配对均值差并归一化。它从未看静默段、末端结算或后来走向。以真实接触记录的 6/7 号触觉确认方向标签。

两套留出种子为 83179603 和 83179639，各 96 个新几何。同一个几何中，物体、先后、私味、门配置、随机抽样值固定，正交改变两件物体的旧轨道接触侧，得到四条生命。在另一套同几何条件中，只同时翻转两门的公开乘数，使优门互换。两个版本均强制走左右确认一门正、一门负。每条生命的旧轨道侧在门口不会被重新展示，也不改变哪门好。按门标签对先后、左右和物体作平衡。只在四条旧轨道变体自然都走同一门的组里，另报按真实走向对齐的值，避免事后只挑选有利的单条轨迹。

以两种固定接触投影分别读取副区活动与回传电流。对同一当前菜单，计算指向真实优门旧物体的轨道侧签名和另一物体签名，主指标为两者之差。预定时间点为调查结束、门菜单最后一拍、空白第一拍和空白末三拍平均。另在完全相同旧历史上给同拍长的全零菜单，以两个门配置作标签对照。迟发的定向重现须在留出检验的实际接触上首先可读，而且两套留出的副区预测投影末段目标签名为正，并相对末菜单和首空白均增强，末段选择性相对两处基线也均增强，三个出生均同向。副→主复验单列。reward、sham 和按自然走向对齐的结果独立报告。区间按出生和几何配对交叉抽样 2,000 次。

早已有的轨道信息可体现持续记忆，门口刚消失的刺激可体现重编码。即使达到迟发判据，也只支持恢复与旧触觉一致的活动成分，其余轨迹细节、回放顺序和模型是否自主选择了回放对象均未被观测。阴性结果仅约束这个和任务收益无关的旧接触细节及这个固定线性投影。
