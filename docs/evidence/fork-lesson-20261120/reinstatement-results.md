# 暂未检出静默期对旧接触细节的定向重现

旧物体的调查轨道可以从左边或右边抵达。身体真的走过轨道，碰到物体才收到相应的左／右接触信号。这是过去发生的感知细节，两扇门都不显示它，而且改动这段轨道不会改变任何门的兑现。我们只用另一个世界的实际接触时刻确定辨认旧轨道的活动方向，再在两个新世界里测量这条方向。每个当前菜单都有相同几何、私味、旧遇见顺序和兑现的四种轨道组合。随后只翻转两个门乘数，使好门互换，平衡优门对应哪个对象、落在哪边、早晚接触。[预定方案](reinstatement-plan.md)

读出能辨认真接触。whole 两个留出世界在接触时的副区投影为 +0.192 和 +0.192，按出生与几何根配对的 95% 区间下界均约 +0.098。回传电流的接触投影为 +0.072 和 +0.070，下界分别约 +0.025 和 +0.024。reward、sham 的接触区间也都在零以上，所有出生的点估计同向。下表看决策前空白末三拍，按正确门对象的旧轨道与另一对象的旧轨道相减。正值表示更像正确门对应的旧触觉。

| 训练 | 信号 | 留出一 | 留出二 |
|---|---|---:|---:|
| whole | 副区活动 | +0.005 [−0.005, 0.020] | +0.008 [−0.003, 0.022] |
| whole | 回传电流 | +0.010 [−0.023, 0.037] | +0.008 [−0.023, 0.035] |
| reward | 副区活动 | +0.002 [−0.013, 0.016] | +0.001 [−0.014, 0.015] |
| reward | 回传电流 | −0.0003 [−0.009, 0.007] | −0.003 [−0.014, 0.006] |
| sham | 副区活动 | −0.001 [−0.007, 0.004] | −0.002 [−0.010, 0.005] |
| sham | 回传电流 | −0.003 [−0.023, 0.011] | −0.004 [−0.025, 0.011] |

whole 的副区晚段比末菜单拍对优门对象的投影更接近零，但晚段目标投影本身不稳定为正，选择性相对第一空白拍的变化仅 −0.003 [−0.022, 0.018] 和 +0.001 [−0.021, 0.024]。只看四条轨道变体都实际走同一门的场景，whole 在两个世界各保留 98.8% 和 98.4% 的门配置，按实际选门对齐的副区选择性区间仍跨零。无菜单的两种门标签在固定历史上按平衡设计严格抵消，核验了这个对照不会引入凭空的标签关联。[时间序列、逐出生与原始结果索引](reinstatement-results.json)

九个冻结身体，两套各 96 个几何根，共 13,824 条自然生命，另有 27,648 条强制路线确认兑现。这个结果约束的是一个收益无关的真实接触细节在固定接触投影上的恢复。副区依然可能使用物体价值或与历史有关的其他编码，当前测试没有识别这类表征或按顺序回放的轨迹。
