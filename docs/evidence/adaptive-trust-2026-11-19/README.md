# 个体能否根据新接触，学会多信或少信旧规律？

在 256 个独立留出世界和六个冻结出生上，接触证据门控保留了相关经历带来的早期迁移，同时减轻了无关经历的负迁移。与开发集选出的固定缩放相比，两种前史等权的早期学习增益多 **0.96 个百分点**，配对 95% 区间 **[0.54, 1.35]**。把该门控的取值交换给同一世界、同一出生、同一味觉组合的另一种前史，早期增益少 **2.56 点 [2.00, 3.11]**。[预登记](protocol.json) · [留出统计](summary.json)

## 门控学什么

上一轮实验已在相同身体上观察到，旧情境的连续映射能形成跨情境协方差先验，帮助相关前史，也会干扰无关前史。本轮沿用六个冻结出生、原来的感觉图、脉冲动作器、情境寻址及基准读写参数。新门控只向原有共享项乘一个从 0 到 1 的系数。每次两题相邻、同一公开背景地址且身体都实际收到带符号味觉，门控才从该对气味的变化、协方差沿变化方向的响应、当前感觉预测和带符号的味觉预测误差获得证据。该地址保留这些证据的泄漏平均。完成一次实际配对即可用当次证据调节写入；静默或漏掉其中一次接触都不会更新门控。[原迁移实验](../learning-transfer-2026-11-19/relation.md) · [门控实现](../../../experiments/pulse_game/trust_gate.py)

九个外层系数由反射世界中的实际探针正确率选择，两种前史等权。三批训练世界共有 152 个根，另有 100 个独立验证根。在验证集上，同目标独立选出固定倍率 0.75。学习门控、固定倍率及公开公式对照的验证目标分别为 67.49%、66.03%、67.48%。留出世界以新的根种子生成，在一个私有平面内旋转正或负 90°。每个世界的旧、新味觉正反独立交叉，相关与无关前史共用 B 的气味、味觉、呈现节奏和物理位置。门控接收继承的公开感觉与回执输入，测试时只随接触推进生内记忆。[开发候选与逐出生得分](dev-fit.json) · [选定权重](checkpoint.json) · [留出前封存](seal.json)

## 留出结果

早期学习增益是 B 在 2、4 次教学机会时的正确率均值减去 B0。每次探针的味觉锚题后，身体自行选择两个从未见过的气味之一，选择题味觉静默，超时计错。在每个剂量，每条生命分别做三个 B 探针和三个 A 探针。先在物理世界内合并四种味觉组合，再交叉重采样世界及出生。下表的区间是以同一出生、世界、符号组合的逐生命差为基础计算的。[逐生命配对数据](paired-outcomes.zip)

| 相关，学习门控 − 始终共享 | −0.005 | [−0.035, 0.011] |
| 相关，学习门控 − 仅局部学习 | +5.81 | [4.76, 6.89] |

## 实际门值与交换干预

在 B 第一对教学机会中实际取得双回执的生命里，相关前史的平均门值为 **0.9996**，无关前史为 **0.4095**，差 **0.5900 [0.5361, 0.6429]**。之后七对教学的差在 0.575 到 0.612 之间。交换时，一条生命继续用自己的实际接触、感觉和预测更新，并给共享项乘对侧生命在同一请求产生的门值。两种前史在本次留出上每次有效写入均有对应供体门值。交换使相关前史的早期增益减少 **3.24 [2.44, 4.07]** 点，无关前史减少 **1.87 [0.97, 2.76]** 点。该干预检验门值与当前证据配合的行为作用。预测误差与感觉特征各自作用需要单独操纵才能辨别。[门值、证据及写入覆盖](summary.json)

每生平均收到 23.986 / 24 次 A 味觉、15.992 / 16 次 B 味觉。两种前史的 A 接触侧逐题相同。仅保留 A 及 B 前四次机会全部真的尝到味觉的配对生命，占 98.24%。该子集的相关组相对仅局部学习仍增加 5.76 点，无关组相对始终共享仍增加 1.87 点。[完整接触敏感性检查](summary.json)

## 复验

教学两端呈现相同气味和符号，因此门控引起的味觉预测变化在左右两端相等，实际接触轨迹可在同出生内供不同候选重放。记录器用原逐拍世界生成真实接触和带符号味觉，重放只在原本会发生配对写入的时候计算不同门控。测试探针仍逐拍执行驱动和碰撞。在开发样本和每个出生首批 32 个正式留出世界上，对照原逐拍闭环验证了回放。留出验证检查了 184,320 项探针的接触侧、接触时刻、锚题回执和正确性，以及 24,576 次学习或交换门控写入与其兼容性输入。针对新门控和原关系世界的 20 项测试通过。[缓存回放](../../../experiments/pulse_game/trust_replay.py) · [核对计数](summary.json) · [产物指纹](artifacts.json)

在仓库根目录使用此前归档的[六个冻结身体](../learning-transfer-2026-11-19/relation-births.zip)即可复验。完整从头拟合时，在工作副本中先把现有证据目录的开发产物、检查点和封存文件归档，保留预登记和原六出生档案。也可以用已有封存直接执行留出测试。配对归档按出生包含 NPZ 文件。行字段 root 和 parity 标识世界和味觉组合，探针路径按实验臂、前史、剂量、新旧情境及观测组织，学习与交换门控还保存逐题门值与证据，空值表示当题没有有效配对。
