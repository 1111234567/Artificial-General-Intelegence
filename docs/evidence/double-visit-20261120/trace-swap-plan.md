# 冻结身体上的第一笔复查状态交换

这是六个配对冻结出生的附加诊断，适用已定义的第一笔变化关键对。每对两份世界只有第一次复查看到的终点不同。第一份第一次看见值 +1 的终点，应选早复查房对应门。第二份第一次看见值 −1 的终点，应选晚复查房对应门。两份末笔看到值 0 的同一终点。主报告为两份世界都使用奇置换旧图的 144 对。偶半图单独保留。冻结检查点以文件散列确认。

在第一笔复查结束的第 18 拍及第二笔结束的第 24 拍，分别把同出生、同臂、同一时刻另一份配对生命的 `h` 与 `trace` 一起移入受体，或把 `fast` 与 `candidate` 一起移入受体，或全换四类状态。另用同份生命原值重组状态作回注验证。之后受体继续自己的感官输入、原生试探和原生正式行动。一个配对世界的模型在交换后仍在受体世界真实走门并结算。核验两份输入在 18 拍以后逐位相同、同份回注逐位复现、全换逐位复现供体的后续状态及原生马达概率。

先精确积分配对共同试探与正式抽签的双对率、双错率和每支选优率，再独立报告交换对 A 受体及 B 受体的方向性影响。定义方向性影响为交换后的供体最佳门概率减去受体自然状态选择同一扇门的概率。另用每对相同的两条实际随机数生成原生试探、首次行动和实际到账作为物理审计。对每出生内的关键对等权，跨六出生自助重采样 8192 次估计配对差的 95% 分位区间。固定抽签种子 274321911，重采样种子 274321951。

单换会产生身体通常不会自行生成的状态组合，作用由被换分量、保留分量及后续动力学共同决定。双向交换分开解释。这里检验因果传递到选门的证据，单换的变化与可解码的记忆内容是不同的测量。
