# 两次房内复查后的首次真实行动

训练终点、评估模式、指标与判据在读取冻结个体评估结果前确定。评估在 `experiments.pulse_game.double_visit_eval` 执行，使用两个训练条件 `baseline` 与 `identity` 和六个出生 731–736 的最终检查点。出生配对，参数推断期间冻结。两种条件沿用相同出生的偶半图训练前身。奇半图未进入这两个检查点的前身与本轮训练。奇半图为主，偶半图仅作描述。

## 两个实际世界

- 穷举有限世界支持域中的完整旧图、进入旧门的顺序、两次复查位置、两次看见的出口和目标。世界回执应显示先走两扇原门，再从房内复查两次。复查时起点门输入为零，目标在复查结束才公布，主区提交首次正式动作之前无新世界接触。实走回执逐条核对选择的门、房间、最新终点和到账。
- 主端点的两份生命具有相同旧图、走访顺序、两次房间顺序、末次房间出口和当前目标。两次复查看不同房，最后一笔的出口价值为零。第一笔出口分别指向值 +1 与 −1 的终点，要求选同一对起点门中相反的两扇。每份生命从相同该出生的初态独立经历真实输入。主分数是两次首次正式动作都选对的比例。另列两次都错、只对其一、各生命单独选优率和实际到账。「同时正确 − 同时错误」衡量动作切换的方向性。
- 将主端点的两次复查逐对交换时间顺序，形成只有最后一笔变化、第一笔相同的对称组。另报告物理拓扑改变后应换门、应保留原优门、最终图未改、两门同归。按房间是否相同分层。对于同一间房的两次不同出口，用最新一次结算，并单列第一笔发生过改道、第二笔又改到另一出口的两次改写。两门同归时任一门有效，逐行按真实价值记录−1、0、+1到账；选中哪一门仅作描述。
- 同一物理历史仅互换两个当前可达终点的价值，要求最佳门反向。另检验交换物理房间身份、同时把旧图和两次复查的房间身份随之对应交换后，门、出口顺序、目标和收益不变时，身体的行动是否一致。严格留出仅统计对的两个成员均位于奇半图的配对。若房间对照跨划分，则单独标出。对于同房两次复查，还比较旧图、目标和末笔相同的两种被覆盖的第一笔出口，两份生命最佳门相同，应保持正确。

## 冻结身体上的对照

- 自然发生的试探由该身体原生马达倾向抽签自选，内部试探本身不走门。等时空试在完全相同的决策准备状态、相同试探抽签和相同正式抽签下，取消本次动作脉冲，保留普通桥接和所有时钟。
- 仅省略第一笔复查输入仍保持两扇旧门的真实走访、末笔、目标、全部拍数和试探窗口。主端点两份生命在该对照的输入须逐位相同，使用共同抽签时不能同时选对或同时选错。这是判据和马达带的可执行审计。
- 错配回流保留原体、试探侧别、时间和一切真实感受。供体有相同旧图、房间顺序、末次观察和目标，将第一笔观察的终点编号循环移一位。每拍从供体自然回流减供体空试回流得到方向，逐拍缩放至受体自然减空试回流的范数，叠加至受体空试回流并重放。报告回流重注入的逐位复核、增量范数误差及供体零方向时采用固定轴的次数。这个干预涉及整个回流向量。
- 借同一真实前史的两个离线试探分支读出第 3 拍的房和第 5 拍的终点身份与数值。分别按自然抽到的试探侧、自然未抽到的另一侧以及两门共同报告准确率、数值均方误差、严格场景下两门排序（预测持平计半分）。这些读数不进入正式选择。未试门的终点和数值读数来自其离线的另一分支。

## 抽签、分母与判据

- 两套事先固定的抽签种子 734590621、734590687。以不看房间编号的旧出口集合、旧门走访顺序组成六个平衡组，每组在每套随机带中各有 32 次独立采样。同一组的生命、教学臂和身体干预共用各通道相应的随机数。试探与正式马达分别采用零探索的原生概率和独立均匀随机通道。主对与其时间反转、同历史换目标以及覆盖对照共享各对内的试探与正式随机数。另给两生命各用独立正式马达随机数且共享试探随机数时的精确与实抽双对率。每套重复抽签只估计冻结行为，两套种子也不增加独立出生或物理旧图的数量。
- 在每一套抽签的第一次取样，正式选择后完整推进物理状态并核对回执。其余重复用相同的原生马达抽样，并用预先在独立身体副本中实走的两道门核对所选路线。真实世界的到账只由当前图、目标和提交门决定。
- 精确共同抽签期望按两份生命的试探概率给共享均匀随机数分段，在每段用两次正式行动概率对应区间的交集计算双对和双错。单生命按两试探分支权重混合正式行动期望。抽签结果与精确值分开展示。配对差先在每出生的有限世界上等权平均，用预先固定种子 734590703 对六个配对出生重采样 8192 次，报告 95% 分位区间。这里的区间只反映出生变化，旧图和情形已在有限支持域内穷举。两套抽签分别报告。
- 主端点分别检验 `identity/自然` 对 `baseline/自然` 和 `identity/等时空试` 的双对率差，以及 `identity/自然` 的方向性双对减双错。每项在精确期望和两套共同抽签下，跨出生配对区间的下界均须大于零。只有同体自然相对空试也达标时，才能说本轮在这个端点上进行了有行为收益的临场内部试探。仅训练差或仅报告预测提高，分别只支持相应现象。
- 同体自然相对空试还需保持在物理拓扑已改变却应保留原优门上的选优率，要求精确和两套实际抽签配对区间下界均大于 −5 个百分点。单列两次改写、仅末次变化、末笔覆盖、错配回流、两门同归和试探读数。结果均给出分母和每个出生的均值。公开冻结个体、脚本、协议和原始账本文件哈希。
