# 双复查任务的配对训练

固定六个配对出生 731–736。两组的初始权重都来自上一轮单复查的 `fit-transfer-next_room` 第 1792 步，各自重启 Adam。该继承训练从原始出生出发，只收偶置换旧地图。本轮也只训练偶置换旧地图 `(0,1,2)`、`(1,2,0)`、`(2,0,1)`，其中元组依次是房间 0 的旧终点、房间 1 的旧终点和未用终点。奇置换整图留到正式评估。原始出生继承的脉冲任务没有这个房间—终点结构。对上轮可复现世界和真实走门账本做继承核验。

每出生每组固定 1792 次更新，每次 64 条生命，其中前 256 次使用生成器的简化分布。两组共用每个出生和步上的同一世界、试探与走门随机数。世界域与随机动作域分开。每条生命包括两次原始过门、两次在房间内复查、一次目标呈现和等长的内部试探，最后只真实走一次自己选的门。两组同为 40 节点，主区既有终点读出在两组都可观测。参数、时钟、训练生命数、决策方式及实际报酬规则相同，动作及实际所得可随训练分化。

两组都用相同的主区下一房及最终净收益读出做加权平方误差。只有走门和自己试探同门时，该趟实际终点、房间和收益才有资格校准内部预测。权重是走同门动作概率的倒数，按一批有效权重之和作归一化。处理组在相同合格条目上对主区原有的三个终点读出增加权重为 1 的三分类交叉熵，目标是实际走到的物理终点编号 0–2。终点编号来自世界的结算，仅作为误差目标。副区接收梯度时经过现有回路。对照组也记录这项误差及预测准确度。

试探和走门用原生马达，以 0.45、0.30 的比例分别和均匀探索混合。两个马达的得分梯度都用该次实际到账，减去同批其他生命的平均到账。用整生命前史、目标和试探展开反向传播，结算只产生真实结果与梯度外目标。Adam 学习率 0.003，最大梯度模长 2，每 128 步保存训练现场。各组都从同一出生配对步 1792 取正式版本。

保存世界、行动抽样、真实结算、有效掩码和每项预测的账本。验证两组世界与随机数逐行相同，重建每趟真实路径和到账，核对同门权重、预测误差、奇偶划分和前史梯度。另一独立世界域仅用于训练脚本的短时烟雾检查。
