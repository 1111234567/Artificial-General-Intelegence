# 双复查后的房间终点记忆

在两次复查结束、目标尚未公布时，从全图状态能读出第一次复查的终点。第二次查另一间房后，奇旧图上首房从全状态读对 84.3%（基线）和 81.6%（终点监督），只读主区活动则为 37.1% 和 42.1%。关键配对要求两支都认对首房不同的终点，全状态达到 62.7% 和 59.3%，主区活动为 0.9% 和 3.7%。这些读数描述冻结身体已有状态的线性可读性。 [结果和逐出生、逐旧图分母](memory-results.json)

## 取样与校准

固定两个训练条件的 12 份第 1,792 步快照。第 18 拍保存完成第一笔房内复查的状态，第 24 拍保存完成第二笔复查的状态。仅重放目标公布前原环境提供的感觉。第一截面按实际感觉带取得 144 个唯一前缀，第二截面保留 864 个唯一前史。每个截面半数来自三张偶旧房图，半数来自三张奇旧房图。两个截面及每个出生、训练条件各自用偶图校准，在奇图计算准确率。第一截面尚未发生第二笔，同一个首笔前缀覆盖随后查同房或另一房的场景。

目标是房 0 与房 1 各自当前通向的三个物理终点之一。目标标签从真实门、房间、终点感觉按时序重建。每个读数用同一状态同时输出两个房间的六个身份得分。主区读数仅用 20 个活动值。全图读数使用 40 个活动值、40 个慢迹值、357–390 条有效连接的快权和 197–230 条待提交局部增量，具体连接数随出生而异。同一出生的两个训练条件与两个截面使用相同维数。每一组以偶图校准集的均值和行向量均方长度归一化。对房间与身份的六个 one-hot 目标做均方误差岭回归，正则固定 0.01，截距不加正则。图实际接收的唯一输入是物理感觉带；分析器接收保存的数值状态。
