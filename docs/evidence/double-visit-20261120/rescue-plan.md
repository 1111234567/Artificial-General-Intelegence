# 原生第五拍报告替换的行为对照

冻结双复查的原教学和终点身份教学检查点。只用主评估中 144 对严格未见旧图任务。每对生命的第一笔观察决定试探门应选还是应避。固定原生试探为通向第一笔房间的门，另一门的真实到账为 0。分别从旧走访和复查后的连续状态运行原生试探，并在两支身体实际核对首次正式行动的房、终点和到账。

模板只取同一出生、同一教学的偶半旧图。按封存自然试探策略概率为两原生支路加权，并按已实走核对的真实终点或收益分层。终点候选要求自然三节点的最大读数指向真实终点，取正确类别与次高类别的差排在该候选加权 75% 分位的一笔，保留三个原始活动。收益候选按真实 +1 与 −1 分开，要求自然读数符号正确，分别取绝对值的加权 75% 分位的一笔。每个模板取原生实际报告值。某类若没有合格供体，该出生的终点相关全对评估缺失，收益对照保留。供体只按校准图和已固定分位数选定。

第五拍完成后依次比较自身原值回填、真实与反事实终点模板、真实与反号收益模板，以及两类模板同时真实或同时反事实。反事实终点是该配对另一个生命第一笔观察对应的终点。保持其余节点活动、所有痕迹及快权不变，原样运行最后两拍，用原生马达和主评估的两套共同正式行动随机带。逐位检查自身回填复现，替换后在报告位置核对预定终点和收益符号，检查每一模板对应原生供体。每套首签实际结算，其余重复沿用已走过的确定性路径回执。

主要报告两生命都选对、各自选优和试探门选择概率。分别比较正确模板与反事实模板、正确模板与自身回填，用跨配对出生的精确期望与两套实抽计分。只在可靠拟合的六次身份出生上判断主要方向，原教学的缺失另明列。另按未经替换的固定试探中两份收益符号都正确分层，记录符合对数及实际行为分数。该对照测量特定第五拍读出在此身体轨迹上是否足以影响动作。
