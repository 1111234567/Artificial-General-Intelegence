# 定位局部更新、门到房的组合与预测对行动的作用

正式原生行为另按主评估协议计分。本诊断固定已开发的 40 节点身体，三种旧房→出口偶排列只用于校准分析读数，三种奇排列全部用于检验；每个出生单独校准。正反两个真实出口、房间身份与世界目标仅供分析计分和明确注明的干预。分析器不参加身体实际训练和部署。

1. **事实是否留在生命里。** 从同一物理前史分别在第一笔和第二笔房内复查结束时保存活动、慢迹、快权和待提交改动。末端目标尚未公布。使用均衡的一个目标副本去重，同一历史只计一次。在偶旧图用同一预定的线性岭回归读出校准每间房目前通向的终点，在奇旧图检验。分别读主区活动、全图的有效神经状态。对不同房依次更新，读首间房在第一次、第二次结束时的正确率，以及最后一间的正确率；同房覆盖时另报最新与未查房。每个时间截面单独作相同校准。线性可读性检验既有状态是否带有信息，不能替代个体能否自己调用。
2. **直接给房间，与从门试起。** 同一个目标已公布、同一已经历过的身体，比较自然试一扇门、仅把它对应的房间在原生房间感觉端呈现两拍、仅呈现实体门两拍、空试以及直接呈现真终点两拍。后三种诊断不会真的走门、发送新味觉或由外界发生额外写入。神经规则自己照常更新。所有条件都有相同七拍，再从第五拍既有主区单元读终点身份和收益。直接房分支不再发送内部侧别脉冲。为防新接口不熟导致误诊，还用一份只在偶图上校准的线性读数，无房号或试门索引输入，分别从自然门、直接房第五拍主区活动预测最后实到的终点。主要关注末观察相同、第一笔不同的配对里查询首房及末房，并分别列同房的旧出口被覆盖的情况。直接呈现终点用于检验诊断口；它不计为正式选门表现。
3. **已能回答时有没有用于行动。** 取上述配对，固定试探通往首间房的门。两条生命的另一门都只值 0，自己试的门分别值 +1 或 −1。记录从同一主区自然预报的收益差与两次实际动作（共用动作抽签）；另把第 5 拍原生 14 号预告单元和/或 16–18 号终点报告在成对两历史之间互换，再运行最后两拍。不碰主区其余活动、副区或快权。主要报告自然对照比换入错误历史值时，配对两次都选对、以及实际动作概率的变化。相同值的原位回填需逐位复现。若替换无效，只对这条干预路径作判断。另用同一所试门固定的生内推断值按零为参照作离线参照，不能据此主张真实马达做过这项比较。

校准的全状态特征分为活动、慢迹、实际连接快权及待提交局部增量，逐组用偶图数据的全局中心与均方长度归一化。岭系数固定 0.01，各旧图和每个配对等权。六出生与三份未见的旧房出口排列配对重抽样。两个目标和试探读出都不读自己的诊断得分。终点标签按真实传感器物理身份提供，未使用估值反推作为真值。
