# 用活动脉冲判断已寻址写入的符号

固定一个候选写入位置后，图的活动能提供写入方向信息。在 2,608 个正负写入结果确实有区别的封存试验中，读自身活动脉冲的写入器选对方向 68.82%，同预算零脉冲组为 50.11%，当前结构读回组为 56.98%。单次脉冲对偏置方向最有效，对边权变化和加边的方向判断仍接近随机。

## 方法

每轮生成一张四节点随机有向图，随机抽取活动初值和一个非电机节点的偏置、已有入边或缺失入边作为候选端口。三类端口在每个种子下数量相同。写入器收到候选地址，并在 `+0.25` 和 `−0.25` 两个实际命令中选一个。已有边改系数，缺失边按所选符号新建，偏置作对应位移。一次实际写入后，从原初值推进四步，用电机节点最后两步的平均活性减去写入前同样运行的均值作为行为收益。全体封存图上，固定正写入使 39.32% 改善、41.08% 变差。

脉冲相当于以四分之一剂量试验正写入的第一步。偏置端口把 `0.0625` 加到目标节点第一次更新的输入。边端口把 `0.0625` 乘发送端初始活动加到接收端第一次更新的输入。后面三步沿真实原图传播。这个脉冲只改变活动，实际写入重新从相同活动初值开始，并用改后的结构或系数持续推进。测试不需要扰动前的结构、目标系数或真实写入结果。

所有组都有候选端口地址、初始活动、四步普通活动和同样的第二次四步推进预算。零脉冲组重复普通推进。当前结构组另外读取当前支持、边权、偏置，并使用零脉冲。真实脉冲组读取自身脉冲推进与普通推进之差。供体组读取另一张图的脉冲差，同一候选地址和端口类型内配对。固定真实脉冲组权重后再换入供体差值，检查该写入器是否依赖本图的脉冲信息。

每种观察的估值网络尺寸一致。六个配对开发种子各使用 60,480 张训练图，按相同随机符号实际写入，并仅拟合所写方向的标量行为收益。部署使用冻结估值器，在另外 3,240 张封存图上各选并执行一次。正负方向穷举用于计分。供体替换、固定写正或写负、按脉冲电机响应方向的直接规则也使用同一组图。

## 读数

| 观察 | 方向选对 | 实际写入平均收益 | 写坏比例 |
| --- | ---: | ---: | ---: |
| 零脉冲 | 50.11% | +0.000065 | 39.98% |
| 当前结构 | 56.98% | +0.007957 | 34.45% |
| 本图脉冲 | 68.82% | +0.014139 | 24.84% |
| 供体脉冲 | 50.15% | +0.000061 | 39.93% |
| 真脉冲权重换成供体响应 | 49.40% | +0.000495 | 40.44% |
| 脉冲电机响应直接取符号 | 66.33% | +0.007795 | 26.94% |
| 穷举选符号 | 100% | +0.022761 | 0.74% |

方向正确率在正负两种真实写入收益相差超过 `1e-5` 的 2,608 个轮次统计。收益和写坏比例在全部 3,240 个轮次统计，低于 `−1e-5` 计写坏。本图脉冲相对零脉冲方向正确率提高 18.71 个百分点，按训练种子和封存区块配对的 95% 区间为 16.74 至 20.89。相对当前结构估值器提高 11.84 个百分点，区间为 9.29 至 14.38。分端口看，本图脉冲的偏置、已有边和加边方向正确率分别为 93.40%、56.41% 和 56.88%。

脉冲器得到预设的探测位置，只有符号可学。弱脉冲只近似一次转换，后续状态、边的发送端活动和非线性都会改变永久写入的效果。实验要求每次提交一笔写入，尚无弃权或选择剂量。外加的脉冲端口和估值器说明本图活动带有可用的自测试信号。自主发现所在地址、发起探测、学习读取以及迁移到原生终身图仍需独立测量。当前结构组的成绩对应同尺寸、同训练预算的估值器。
