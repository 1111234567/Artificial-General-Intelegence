# 随机图结构读回与编辑核验

这个实验用同一组随机循环图比较五种写入器。所有写入器都能读取同样的图节点活动，接收同样的端口地址，并且只能发出一次结构写入。变化的是结构读取通道。图结构及参数由执行器实际改变，写入后重新运行图获得行为误差。

## 图、观察与学习

图有四个状态节点、十二个候选有向边和四个节点偏置。普通活动按 `h[t+1] = tanh(W h[t] + b)` 更新。每轮随机生成地址上的边支持、边权和偏置，在真实图上秘密执行一次边权位移、加边、删边或偏置位移，另有约五分之一空扰动。地址、操作、方向和幅度由扰动生成器抽取。比较各组时使用同一图、同一扰动、同一初始激活。

每组都收到唯一的端口标识、同一个四维初始激活，以及扰动前和扰动后所有四个节点的三个逐时刻激活向量。结构槽额外包含边在位位或偏置在位位及系数。结构槽在各组的尺寸一致。

| 组 | 参考结构槽 | 当前结构槽 |
| --- | --- | --- |
| `veridical` | 同一图的扰动前读数 | 同一图的真实当前读数 |
| `current_only` | 置零 | 同一图的真实当前读数 |
| `blind` | 置零 | 置零 |
| `yoked` | 同批不同图的扰动前读数 | 同一供体图的扰动后读数 |
| `stale` | 同一图的扰动前读数 | 错置为同一图的扰动前读数 |

每种读回都训练自己的 4,858 参数上下文动作估值器。每个出生种子的网络初始化、训练图、扰动、探索开关和探索命令五组配对。每个训练轮先选择一个命令，再实际执行并取得一个标量效用。训练损失只使用已尝试命令的估值和该次标量，读取和训练路径均无扰动地址、操作、幅度标签。效用来自扰动前后图在八个固定探针上行为误差的减少量，经初始误差归一和截幅，每次命令收取 0.02。各组看到的普通活动由一次单独的初始激活产生，八个计分探针上的参考输出没有进入写入器。命令包括弃权，以及在一处对边权或节点偏置作 ±0.25、±0.5 位移，或加删边。执行器依据真实图拒绝无效命令，避免空写改变数据。删边限制为能够用现有加边命令恢复原系数的边，便于核验物理逆操作。

封存后使用独立开发种子比较过初始策略梯度和标量估值实现。正式面板给所有组同样的完整节点活动和端口标识，首次正式启动在加载封存数据前中断，重新启动后一次性运行最终配置。测量时冻结所有估值参数。一套附加面板冻结 `veridical` 权重、只替换观察通道，测量当场破坏一条读回通道的影响。均匀随机命令、均匀随机合法写入和穷举最优单次写入仅用于计分。最优基线覆盖扰动类别和空扰动。

## 命令归因

每轮用真实执行回执判定弃权、无效写入、实际生效地址、边或偏置类型、支持变化及带符号增量。评分器分别记录命令合法、命中地址、命中操作码、命中符号和命中符号及幅度。精确恢复要求图支持、边系数及偏置全部回到扰动前值。行为收益由探针误差的变化度量。上列目标地址及操作码评分只在真实扰动轮统计。

分叉以写入器实际执行后的图为起点。核验器在副本上执行该写入的逆命令，要求准确恢复到写入前的受扰动图。随后在同一来源副本把原命令落到不同的合法地址，保留操作码、边或偏置类型及实际带符号增量。删边分叉须能找到同值的另一条边。没有合法接收地址的轮不进入迁址统计。比较实际写入、撤销和等剂量迁址后的探针误差。撤销及迁址由评分器执行，用于确定改动及位置的因果作用。

## 结果

八个配对种子各训练 192,000 轮。每个种子随后评估同一组 2,048 个封存图，其中 1,629 个实际受扰动、419 个为空扰动。下表最后一列是实际受扰动轮在写入后的行为 MSE，起始 MSE 为 0.011208。

| 组 | 受扰动图精确恢复 | 受扰动轮实际写中地址 | 空扰动结构保持 | 写入后 MSE |
| --- | ---: | ---: | ---: | ---: |
| `veridical` | 62.02% | 95.41% | 51.16% | 0.002410 |
| `current_only` | 9.00% | 23.91% | 69.54% | 0.009740 |
| `blind` | 0.0077% | 0.015% | 99.97% | 0.011207 |
| `yoked` | 0% | 0.015% | 99.97% | 0.011212 |
| `stale` | 2.03% | 2.70% | 100% | 0.011111 |
| 均匀随机命令 | 0.61% | 2.82% | 56.09% | 0.015663 |
| 均匀随机合法写入 | 1.78% | 6.45% | 0% | 0.022451 |
| 穷举最优命令 | 100% | 100% | 100% | 0 |

双时点真实读回相比盲写的精确恢复率提高 62.02 个百分点，配对 95% 区间为 59.61 至 64.35。它实际写中 93.78% 的边目标、100% 的偏置目标，带符号剂量完全吻合为 62.02%。按扰动类型，随机加边、随机删边、边权位移和偏置位移的精确恢复率分别是 100%、54.55%、50.36% 和 45.33%。在受扰动且实际生效的 12,434 次写入中，撤销全部回到写入前图，平均增加行为 MSE 0.009221。另有 11,762 次存在等剂量合法迁址，改变目的地址后 MSE 平均增加 0.014804。固定 `veridical` 权重，仅切换到供体或过期读回时，精确恢复率分别降至 1.29% 和 1.56%，同时 MSE 高于写入前。

只读当前图比盲写多恢复 8.99 个百分点，配对区间为 7.52 至 10.65。事后按当前系数是否超出出生字母表分组后，475 个存在越界系数的扰动里恢复率为 28.58%，1,154 个全部处于出生字母表的扰动里恢复率为 0.94%。这个增益主要来自容易定位的分布异常。在后一个子组，读当前图相对盲写的恢复率只提高 0.93 个百分点，配对区间为 0.51 至 1.41。它能在部分扰动中帮助定位，单靠当前图仍很难选对有用的单次修改。

双时点读回的优势依赖真实可用的参考结构。这个诊断的目标恰好是恢复参考快照，图中仅有一次扰动、动作剂量有限，而且训练和封存实验共享生成机制。结果表明外加结构读回可以为这种恢复提供可用信息。空扰动组仍出现大量不必要写入，显示弃权校准有明显缺口。外部估值器和注入初态限定了该对照的范围。原生图是否自发形成结构感知、能否针对新收益规律学习修改、自主执行撤销迁址，仍需在终身写入器中测量。

## 运行与复核

```powershell
python -m experiments.pulse_game.self_write_view_study seal --directory PATH
python -m experiments.pulse_game.self_write_view_study run --directory PATH
python -m experiments.pulse_game.self_write_view_verify --directory PATH
python -m pytest -q experiments/pulse_game/tests/test_self_write_view.py
```

复核既有封存直接使用 `run` 和单独输出目录，先复制 `seal.json` 与 `holdout.npz`。运行器拒绝覆盖现有证据。`boot.json` 记录初始化种子、训练过程及两份源码的 SHA256。`summary.json` 含效果量、逐类读数、配对差值区间和证据哈希。逐轮文件按 `[训练种子, 封存区块, 区块内轮次]` 排列，数组键为 `<读回组>__<字段>`。置信区间用相同的重采样索引交叉抽样训练种子与封存区块，每次保留配对。十二种观测和计分条件均引用相同的封存试验。归档包包含封存图、冻结权重和逐轮记录的 NPZ。复核脚本重新生成封存试验，加载冻结权重，精确重放了 196,608 条写入器与计分对照记录，并核对原始证据和源码哈希。四项针对性测试通过。
