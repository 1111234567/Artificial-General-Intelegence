# 自写入的规则迁移检验

`preregistered.json` 在生成迁移结果前固定种子、分组、剂量、对照和主要统计窗口。所有供体从同一个出厂图出发，分别在稳定带噪与干净但频繁反转的环境中生活。每个供体配套独立生成的新受体世界及其私有目标整体互补版本。新气味与供体气味的编码集合分离。受体第一阶段恰好经历固定次数的接触，第二阶段改变真实好坏关系，生物只能在再次接触后收到新味道。

移植只携带相对同一出厂图的编辑器入边、偏置和支撑掩码变化。受体的其他权重与活动从出厂状态初始化，世界重新分配目标。`scrambled_writer` 在同类有效边组内置换数值增量，保留总增量范数及支撑条件。`writer_protected` 保留其余编辑通路并锁定编辑器入边，`intact_frozen_writer` 从移植状态锁定相同部位。`writer_only_no_writes` 接受同一移植但禁止所有新写入，用于观察移植单独通过活动和动作通路产生的影响。

主要量是配对等证据接触中，第 1 至 12 次接触后的有向动作读数相对本阶段接触前的改变量。读数取目标方向上的动作差经 sigmoid 的值，动作本身按核心模型的确定性读出执行。世界通过配对固定实际接触的一侧，各受体得到完全相同的气味、接触和味道。另记录自主动作条件，确认移植是否改变实际接触与表现。零接触读数、分味道剂量曲线、硬选正确率和下一编辑的因果检查均作为独立观察。区间对供体生命做配对簇自助抽样，结论依赖这一个共享出厂图。

## 结果

共 24 个供体。稳定带噪组和干净反转组的编辑器参数变化 L2 均值分别为 16.23 和 15.55，两组合计改变了 80 处编辑器入边支撑。所有 24 个供体的移植图保持强连通。用相同的初始活动、气味、动作和味道重放第一次接触，每个分组的 96 个受体都出现了编辑器之外的实际写入变化。真实味道与空味道之间的编辑差也随移植改变。强制共用整个接触前后活动时，编辑器之外的连续候选写入差为零。自由决策前的初始动作读数也随移植改变，两个供体组的平均绝对差为 0.072 和 0.089。私有目标互补使各臂的零接触得分均为 0.500。

| 供体历程 | 受体味道反转噪声 | 初次学习，完整移植减出厂 | 真实规则反转后，完整移植减出厂 |
| --- | ---: | ---: | ---: |
| 稳定带噪 | 0% | −0.0630 [−0.0851, −0.0436] | −0.0027 [−0.0205, 0.0144] |
| 干净反转 | 0% | −0.0620 [−0.0825, −0.0411] | −0.0167 [−0.0432, 0.0061] |
| 稳定带噪 | 35% | −0.0412 [−0.0743, −0.0114] | −0.0105 [−0.0210, 0.0003] |
| 干净反转 | 35% | −0.0240 [−0.0365, −0.0119] | −0.0084 [−0.0200, 0.0034] |

在预注册窗口，完整移植减乱序的各配对区间均覆盖零。完整移植后的编辑能力发生了可测变化，早期学习收益下降，没有观察到新气味或真反转后的可迁移学习改进。
