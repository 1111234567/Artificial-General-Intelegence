# 七个出厂图的规则迁移复现

预先固定使用 `102–108` 的所有七个出厂图，每个图拥有各自的新供体和受体世界种子。每个出厂图有 24 个供体、192 个受体，其中受体在 3 档味道噪声下的各条件配对复用。规则、味道剂量、编组和统计窗口继承首轮。部署时保留核心实验的自身图读回和全幅写入。区间按出厂图、供体及目标互补的受体世界配对分层抽样。原始结果与事后强连通性检验保存在 `replication_results.json`。

168 个供体的编辑器权重全部出现自主变化。4,032 个重放记录中，同一初始活动和物理接触触发的下一次编辑器之外的接受写入均改变，真实味道对比空味道的写入效应也均改变。强制共用整个接触前后活动时，编辑器之外的连续候选写入差仍为零。

| 供体历程 | 受体味道反转噪声 | 初次学习，完整移植减出厂 | 真实规则反转后，完整移植减出厂 |
| --- | ---: | ---: | ---: |
| 稳定带噪 | 0% | −0.0251 [−0.0435, −0.0067] | −0.0039 [−0.0143, 0.0056] |
| 干净反转 | 0% | −0.0199 [−0.0364, −0.0040] | 0.0018 [−0.0086, 0.0123] |
| 稳定带噪 | 35% | −0.0079 [−0.0201, 0.0042] | 0.0055 [−0.0040, 0.0156] |
| 干净反转 | 35% | −0.0032 [−0.0143, 0.0080] | 0.0029 [−0.0053, 0.0120] |

无味道噪声时的早期学习收益下降，在仅保留 160 个强连通移植的敏感性分析中仍可见。稳定带噪供体在 35% 受体噪声下的早期得分比乱序移植高 0.00781，区间为 [0.00016, 0.01690]。强连通子集的对应区间 [−0.00015, 0.01691] 跨零，与出厂编辑器的比较也未显示提升。其余与乱序移植的区间均跨零。

`102/` 至 `108/` 各自包含逐接触曲线、数字摘要和逐生命追踪。运行复现命令如下。

```powershell
.\.venv\Scripts\python.exe -m experiments.pulse_game.self_write_transfer_replication
```
