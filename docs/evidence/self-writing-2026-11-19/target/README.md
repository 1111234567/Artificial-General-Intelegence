# 写入目标值与读回

在 8 个新出生上，把写入从累加改为朝图自己发出的局部目标值靠近。有读回的图跑完 192 次接触后，权重矩阵达到限幅的比例为 **0%**。关掉同一模型的读回，稳定与变动环境分别有 **32.37%** 和 **31.84%** 的矩阵槽位达到限幅。长时程的选择正确率仍在随机水平附近，重新遇到陌生气味时，一次接触学习也大幅退化。[预登记](protocol.json) · [原始汇总和校验和](lifetime-summary.json)

## 写入方式

保留原有 16 节点、感觉和身体、接触与味觉时序、生边与退边，以及强连通守护。在每个局部地址，图的活动发出有符号指令 `c`。执行机构把它映射为目标值 `v* = A c`，把同一个指令的绝对值用作强度，并提交 `Δv = λ |c| (v* − v_seen)`。边权取 `A = 1.35`、`λ = 0.20`，偏置取 `A = 0.50`、`λ = 0.08`。目标和强度从图的活动中产生，环境只给感觉、接触和真实味觉。关闭读回时，当前值和结构候选的读回为零。各条件使用同样的非对角候选范围，地址存在性和强连通只在执行时检查。

分别给有读回和盲图的出生参数做 500 批引导。引导始终只有两种相反的陌生气味、图自己选择的一次接触、以及随后两种左右排列的选择误差。两个训练条件的新气味单次接触测验中，8 个种子的开放和保护写入端均达到 100%。此后所有写入由图的活动生成并由 NumPy 执行。真实读回和目标差的计算属于预设机制。一个保持活动不变的单元检验确认，读到高于目标的权重或偏置时，写入方向与同条件下关闭读回的方向相反。

## 从简单重复到三类气味

| 条件 | 新稳定气味对 8 次后静默正确率 | 含噪稳定末 24 次实际选择 | 可靠变动末 24 次实际选择 |
|---|---:|---:|---:|
| 真实读回，开放写入 | 88.28% | 52.00% | 48.70% |
| 同一出生图，关闭读回 | 85.48% | 50.39% | 49.70% |
| 单独在盲条件引导并运行 | 82.62% | 49.72% | 49.57% |
| 真实读回，保护写入端 | 97.85% | 50.11% | 51.87% |
| 禁写 | 47.40% | 50.72% | 49.78% |

短测每根 96 个新气味对，长测每根每种环境 24 个世界。长测与主实验使用同一种世界生成、时序和预算，采用新种子。前 48 次实际接触及第 49 次实际收到的意外味觉在两个环境间完全一致。短测的同一模型读回干预为 +2.80 个百分点，根配对的描述性 95% 区间为 [−1.43, +7.10]。相对独立引导的盲图为 +5.66 点 [+1.69, +10.35]，该比较同时改变引导条件。相对保护写入端低 9.57 点 [−17.06, −3.26]。长测的同模型读回干预分别为 +1.61 点 [−4.38, +8.36] 和 −1.00 点 [−4.01, +1.67]。

长测使用真实读回的开放组实际执行 1,030 次生边、2,069 次退边，还提交了 1,063,995 次写入端入边调权和 55,891 次写入端偏置改变。图在 87–131 条边间演化。另用一组全新气味探测成熟图的学习能力。正确率在稳定前史后由 52.34% 升至 52.60%，在变动前史后由 47.92% 降至 47.40%。出生图都能在尝一次后达到 100%。
