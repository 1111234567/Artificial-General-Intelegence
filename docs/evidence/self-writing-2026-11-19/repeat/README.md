# 重复最小原语的出厂训练

每个出厂训练样本只包含一个两气味的私有关系。生物在六次接触中自行选侧，气味所在侧随机交换，关系在样本内固定，味道准确。每次写入后，从静息态探测同一对气味的两种朝向。外部梯度只在出厂训练中使用，通过连续接受写入和接受的新边权值贯穿六轮。离散的动作和结构地址采用原有求值方式。训练仅更新出厂的权重和偏置，16 节点、写入规则以及生命中可写的位置遵循原核心。写入步骤的回归测试覆盖了连续写入、实际结构更新和三轮反向传播。

预注册了 101–104 四个出厂图、500 次训练迭代、最终检查点、全幅写入部署及两种留出评估。留出评估使用 NumPy，生物在每个世界中连续自主接触 64 次。稳定世界含一对新气味。另一个世界含三对新气味、20% 的味道反号噪声，并在第 33 次接触前反转私有好坏关系。每个出厂图在每个世界条件下使用 192 个留出生物。按出厂图和生命分别做配对分层抽样。比较对象是同种子的已有单接触检查点，两方案批量大小和经验量不同，因此结果属于两个训练方案的比较。

| 留出世界 | 实际接触窗口 | 六接触训练 | 单接触训练 | 配对差值及 95% 区间 |
| --- | --- | ---: | ---: | ---: |
| 稳定，单对气味 | 1–8 | 85.37% | 68.67% | +16.70 [9.33, 26.35] pp |
| 稳定，单对气味 | 57–64 | 51.73% | 51.33% | +0.39 [−1.74, 2.75] pp |
| 三对气味，带噪声 | 1–8 | 60.51% | 55.11% | +5.40 [2.34, 8.59] pp |
| 三对气味，反转后 | 33–40 | 47.33% | 48.99% | −1.66 [−5.45, 1.35] pp |
| 三对气味，反转后 | 57–64 | 48.76% | 49.45% | −0.68 [−2.67, 1.14] pp |

六接触训练延长了早期技能表现，稳定单对气味的晚期表现仍回落至约一半。该晚期窗口锁住六接触模型的编辑器入边后，实际正确率为 54.79%，开放编辑器的差为 −3.06 个百分点 [−5.31, −0.94]。在三对气味反转后的静息探测中，开放编辑器相对锁定有微弱优势，两组均在机会水平附近或以下，自主行动的区间跨零。

`repeat_results.json` 记录所有方案的逐接触结果及区间。`repeat_traces.npz` 保留留出世界、逐生命接触、实际味道、编辑器距离和图边数。四个检查点保留每次出厂迭代的损失与探测正确率。
