# 自改写 16 节点脉冲图

## 实验结论

图在外部优化停止后，确实根据内部活动改写了普通边、节点偏置和负责发出写入信号的节点。8 个出生图的一次接触测试，开放写入和保护写入端都达到 100%，禁写为 50.24%。进入 192 次接触的多气味环境后，开放写入相对保护写入端的末段收益没有得到支持。

| 末 24 次实际选择正确率 | 稳定规律、味觉有噪声 | 规律反复变化、味觉可靠 |
|---|---:|---:|
| 完整自改写 | 48.94% | 51.09% |
| 保护写入端，普通图仍可改写 | 48.70% | 50.61% |
| 禁写 | 49.83% | 49.48% |
| 仅在写入提案阶段打乱味觉 | 49.63% | 49.63% |
| 完整自改写，降低连续写幅 | 55.77% | 48.22% |
| 保护写入端，降低连续写幅 | 59.66% | 47.76% |

原幅度下开放减保护分别为 +0.24 和 +0.48 个百分点，按出生图配对重采样的描述性 95% 区间分别为 [−1.43, +1.95] 和 [−1.26, +2.37]。变动环境相对稳定环境的开放写入增量差为 +0.24 点 [−2.32, +2.65]。在只缩短数值写脉冲至原幅度 0.12 的敏感性测试中，增量差为 +4.34 点 [+0.17, +8.85]，主要来自稳定环境中的下降 −3.88 点 [−9.01, +0.35]，变动环境的增量是 +0.46 点 [−1.50, +2.76]。降低幅度后，稳定环境的静默探针中，开放写入比保护写入端低 8.51 点 [−14.06, −3.13]。这些结果分开了真实的改写能力、最简单任务里成功习得的一次接触学习，以及长时程改变学习方式的证据门槛。[原幅度汇总](lifetime-summary.json) · [低幅度汇总](lifetime-reduced-amplitude-summary.json) · [引导训练汇总](bootstrap-summary.json)

两种环境的开放组在原幅度下执行 4,062 次生边和 2,908 次退边。其中 4,040 条新生连接在后续接触中实际调过权。写入端的入边实际生 325 次、退 1,335 次，另有 1,236,128 次写入端入边调权及 164,159 次写入端偏置改变。稳定、变动环境各有 192 个生命，每个寿命的写入端均发生实际变化。出生为 108 条边，运行中见到 83–143 条，134 次退边因会破坏强连通而被拦截。两个环境的开放组在终点约有 38.5% 和 39.3% 的全部 256 个矩阵槽位抵达权重限幅，降低写幅后仍有约 13.3% 和 13.8% 抵达限幅。[结构写入逐类计数](structural-receipt-counts.json) · [生边后的实际调权](newborn-later-tuning.json)

## 写入如何发生

16 个节点组成同一张强连通图。两侧各 3 个感觉节点，另有 2 个接触、2 个味觉、2 个动作与 4 个写入控制节点。动作差直接决定物理接触侧，接触后才有味觉。感觉、味觉、动作和写入节点都参与递归传播。出生图有短路径和 108 条活跃边，无自环。写入执行机构允许任一非对角地址长边、已有边调权或退边，以及任一节点偏置调整。生边（最多一次）和退边（最多一次）分别抽签，概率由活动决定，地址由内部活动和候选属性加噪排序。真实地址是否存在及删除后是否仍强连通，在提交时检查。无固定出度或边数，无须配对地增一退一。

固定执行机构把两个时间点的活动解码成数值提案。接触后、味觉前后的活动张成局部边地址的场，写入端活动控制签名和值，选配读回允许自己的边权、接线状态和节点偏置影响提案。读回是预先提供的硬件接口。强连通守护和本地值解码是实验给定的。数值版本可在一次接触后同时发出许多边权和偏置更新，保护组只冻结四个写入节点的入边及偏置，其他边仍能通过改变感觉和活动反馈间接影响写入提案。本实验的保护组因此冻结的是写入端的直接参数。生命阶段的运行器只依赖 NumPy，执行内部动力学、提出编辑和验证提交。

出生图的数值参数用 Adam 引导 500 批。每批只做相同的一次接触任务，刺激为批次随机生成的相反气味，哪个气味更好独立随机。只是根据接触以后静默重测两个方向的选择误差来回传梯度。梯度通过真实执行的普通边权及偏置变化和新生边初始权重，通过选边、探索、接触决策和结构守护的路径截断。生命阶段没有 PyTorch、优化器、外部逐边误差或对真实对应关系的访问。

每个出生图在每种条件下都跑 24 个相同底本世界。每个世界引入 3 对陌生气味。前 48 次接触及第 49 次实际收到的意外味觉，在两个环境间逐生命配对相同。随后稳定环境固定真偏好并独立带 22% 的反馈噪声，变动环境味觉真实且每 48 次变更偏好。左右排列、气味微扰和试次顺序配对，实际选择由各组身体自己完成。打乱组保留给身体的真实味觉，只用其他同组同一时刻生命的实际味觉生成写入提案。所有组每个生命均获得 192 次实际接触。所有静默测验在不提交写入的分叉图上执行。[预登记和开发选择](protocol.json)

## 硬稀疏写入

另用 8 个新出生种子检验每次接触只提交少数写入的机制。按当前图发出的数值提案排序，只保留绝对值最大的四条普通候选边和一个候选偏置，低于执行阈值时放弃。原有生边和退边各保留一个可放弃的槽。拥有真实读回和无直接读回的图各自引导 1,100 批。在一次接触的陌生气味测试中，两组的开放成绩分别为 60.73% 和 66.16%，保护写入端时为 56.43% 和 58.63%，禁写为 49.45% 和 50.42%。单个出生的最高开放成绩分别为 83.89% 和 98.24%，引导效果随出生变化较大。[稀疏预登记](sparse-protocol.json) · [引导成绩和检查点](sparse-bootstrap-summary.json)

| 末 24 次实际选择正确率 | 稳定环境 | 变动环境 |
|---|---:|---:|
| 有读回引导与运行，开放写入 | 49.98% | 50.76% |
| 有读回引导与运行，保护写入端 | 51.56% | 49.39% |
| 无直接读回引导与运行，开放写入 | 50.35% | 49.63% |
| 无直接读回引导与运行，保护写入端 | 50.74% | 49.11% |
| 有读回引导，运行时关闭读回，开放写入 | 50.69% | 50.17% |

保持各自训练读回条件时，允许改写写入端的变动相对稳定增量，有读回为 +2.95 点 [−2.13, +7.96]，无直接读回为 +0.91 点 [−0.82, +2.82]。有读回开放组仍执行 1,845 次生边和 2,733 次退边，无直接读回分别为 1,514 次和 2,465 次。达到限幅的终点权重槽位降至约 2.1% 和 1.0%。这一实现显著减少饱和，长期选择仍接近随机，且大部分出生图的一次接触学习也较弱。[稀疏寿命原始汇总](sparse-lifetime-summary.json)
