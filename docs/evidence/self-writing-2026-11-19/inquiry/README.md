# 个体会不会选一次有辨别力的试吃

使用一次接触启蒙的 8 个自写图，每个图面对 64 个新物理世界。每个世界先出现三种互相正交的气味轴。A 和 B 的正负气味各有稳定结果，D 的结果随机。每个个体实际完成 12 次前史接触。随后两端都呈现曾有利的 A 气味，产生一次意外苦味。另一份相同状态收到正味，作为惊讶对照。此时存在两个与这次苦味相容的世界，一种只改变 A，另一种连 B 也反转。接下来个体有一次机会选择旧 B 气味或无诊断意义的 D。B 被呈现为原来的好气味或坏气味两种情形都测，左右位置随机；两种世界等权，两个选项的期望即时味觉均为零。继承的运动节点发出方向，采用保持该方向的脉冲驱动 PulseWorld 身体，实际碰到端点才送达味觉。保持方向是本测试的动作接口。[预登记](protocol.json) · [任务与行为实现](../../../../experiments/pulse_game/self_write_inquiry.py)

| 原幅度启蒙图的表现 | 数值 |
|---|---:|
| 意外苦味后主动选择有信息的 B 气味 | 48.24% |
| B 气味以前为好 / 坏时的选择率 | 51.37% / 45.12% |
| 意外苦味相对正味改变探查率 | +3.03 点，同时 95% 区间 [−2.15, 10.61] |
| 强制取得 B 味觉后，自主写入，下一道 B 选对 | 50.93% |
| 强制接触 D 后，下一道 B 选对 | 50.00% |
| 交换相反味觉孪生的写入信号，保留接收者活动和图，下一道 B 选对 | 49.66% |

这批个体在惊讶之前对熟悉的 B 选对 57.32%。即便强制取得有辨别力的 B 味觉，后续成绩也几乎贴着机会水平。使用已尝气味和自己取得的味觉，知道怎样在下一道物理任务中辨认同一气味的参照，取得 B 味觉后达到 100%，取得 D 味觉时为 50%。因此，线索在公开经验中可用，当前启蒙图未显示能主动挑选并有效利用它。[静默选择和配对区间](summary.json) · [公开信息参照与精确重放](verification.json)

有信息接触后，将同一原生图的这一次写入改用盲读、过期读回或地址错位读回，其余观察、节点活动和随机数保持相同。真实、盲读、过期和错位读回的后续选择率依次为 50.93%、51.03%、50.88%、50.93%。读回确实能改变候选写入和部分实际提交，但这里没有可靠的行为改善。这个试验只改变一笔写入时的读回，和在 4 节点维修任务中比较不同训练方式的效果各自独立。[逐世界行为与写入差异](raw.zip)

复算时在仓库根运行 `python -m experiments.pulse_game.self_write_inquiry` 和 `python -m experiments.pulse_game.self_write_inquiry_check`。8 个出生的 182 个记录字段逐项重放一致。
