# 16 节点写入器的当前结构感觉端口

局部结构读数可以先改变 16 节点图的递归活动，再由图活动驱动实际写入。封存的两种气味接触中，真实读回组的物理选择正确率达到 97.06%。固定这组图和写入器参数，仅关闭读回时为 80.68%，只保留偏置读数时为 86.66%。

## 感觉、写入和选择

本对照复用 [`self_write_core`](../../../../experiments/pulse_game/self_write_core.py) 的 `Graph`、`advance`、`Proposal`、`apply` 和 `motor`。图仍有 16 个节点，略缩小出生随机系数，保留出生骨架及随机边。左右气味分别通过已设定的感觉通路驱动节点 10 和 11。节点 11 另有随机偏置和一条随机有无、随机正负权重的公共输入边 `9→11`。这两个量共同影响左右选择的工作点。目标是使同一图能随两种相反气味作出不同物理选择。

在闻到测试气味之前，感觉端口把 `9→11` 的存在标志、在位时的原始系数和节点 11 的当前偏置分别注入节点 6、7、8，正常递归推进三步，再无外感推进一步。读数全部来自当前图。写入解码器只取节点 12、13 的这两个活动，用活动差驱动已寻址的节点 11 偏置写入，剂量为 `−0.34`、`−0.17`、`0`、`+0.17`、`+0.34`。执行器实际应用写入，再从静息活动分别推进两种气味，用核心的电机差选择左右。读回活动在此阶段已清空，偏置写入持续生效。

出生搜索只调整节点 6、7、8 到写入节点 12、13 的六个传入权重和写入节点的两个偏置。独立的五个出生种子中，每种感觉条件都使用同样的参数规模、图样本和候选噪声。训练的标量由实际接触的正确次数和写入代价组成。每次候选测试运行真实的图和执行器，随后用独立开发种子选择出生参数。封存评估冻结出生搜索得到的参数，无结构目标、目标系数或测试反馈提供给检查阶段。每个出生种子遇到同一组 1,536 张新图，每张图分别发生两种自然气味接触。

## 固定与分别拟合的对照

| 观察或操作 | 单次接触正确 | 同图左右均正确 | 实际写入率 |
| --- | ---: | ---: | ---: |
| 真实当前结构和偏置 | 97.06% | 94.13% | 82.24% |
| 只读当前偏置，分别拟合 | 86.79% | 73.58% | 73.85% |
| 零读数，分别拟合 | 81.09% | 62.19% | 0.03% |
| 配对供体的当前读数，分别拟合 | 80.99% | 61.98% | 2.92% |
| 固定真实组参数，改为仅偏置 | 86.66% | 73.32% | 78.11% |
| 固定真实组参数，改为零读数 | 80.68% | 61.37% | 14.25% |
| 固定真实组参数，改为供体读数 | 75.66% | 51.32% | 82.15% |
| 固定真实组参数和读数，禁止执行写入 | 81.10% | 62.20% | 0% |

固定真实组参数、图和气味，只关闭感觉时，两写入节点活动的均方根改变量为 0.442。82.07% 的试验实际写入剂量改变，16.56% 的接触改变物理选择。真实读回相对同参数零读数高 16.38 个百分点，配对 95% 区间为 15.16 至 17.83。真实读回相对同参数只读偏置高 10.40 个百分点，区间为 9.64 至 11.21。更换配对供体时，随机不相干的读数在同一实际图上驱动了错误写入。

保持原图、读回活动和写入提案，只禁止执行会损失 15.96 个百分点，配对区间为 14.81 至 17.02。另一个分叉在零读数的活动向量中只移入真实组节点 12、13 的活动，逐轮恢复了相同的提案、执行回执、电机差和物理选择。这两项分叉核验了 `当前读数 → 图内活动 → 实际写入 → 后续选择`。同图左右气味指标分别覆盖两个动作方向，避免单侧输出占优被当成稳定恢复。

这是已寻址偏置校准的受控机制。出生骨架、感觉线与双气味任务经过构造，读数端口由实验接入。感觉量对边支持和生效系数的贡献一起测量，尚未分别识别。这个实现展示了图内活动可以承接当前的局部结构读数，并控制持久写入。自主发现该读哪些边、主动选择改哪条边、以及回到连续运行的终身图，还需要独立实验。
