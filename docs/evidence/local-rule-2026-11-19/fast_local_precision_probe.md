# 局部可塑性逐 tick FP16 状态审计

把累积权重 `weight_state` 的状态存储改成 FP16，已经会改变两组的闭环动作和选拔分。把门状态 `g`、偏置 `bias`、节点痕迹 `node_trace` 一起改成 FP16，仍然出现轨迹分歧。普通单值 FP16 状态无法精确表示测得的首个权重更新，因此不能作为本轮的等价替换。

读取正式试验第 64 代每组四个岛冠军的出生基因，在第 64 代开发种子 `120261202` 上重放。每个基因 8 生，每生 64 题，每题 18 tick。基线使用正式 CUDA 核、Tensor Core 转移与双端口闭环世界核，逐个冠军复现了存档中比较的 16 个指标。两种变体使用同一 CUDA 源与课表，对相应状态逐 tick 以最近偶数舍入写入 FP16，读取后提升为 FP32。原来以 FP32 计算的表达式仍用 FP32，出生基因、更新式、累加、计数与世界判定沿用原配置。

| 规则 | 改为 FP16 的状态 | 首处动作分歧（从 1 开始） | 主端口差异 / 36,864 | 备用端口差异 / 36,864 | 四个冠军的选拔分变化（百分点） |
|---|---|---|---:|---:|---:|
| local | 累积权重 | 第 2 题 tick 9，动作 6 → 0 | 2,033 | 282 | −2.40 至 −0.43 |
| local | 四类状态 | 第 2 题 tick 9，动作 6 → 0 | 2,561 | 382 | −4.02 至 −0.23 |
| modulated | 累积权重 | 第 3 题 tick 15，动作 6 → 0 | 1,598 | 231 | −3.07 至 −1.54 |
| modulated | 四类状态 | 第 2 题 tick 16，动作 0 → 6 | 2,522 | 218 | −8.91 至 −1.39 |

这四个首处动作都发生在主端口，动作 0 是 `WAIT`，动作 6 是 `FINISH` 类动作。表中差异覆盖全部 tick，包含合法答题窗口外的动作。四类状态变体使 `local` 严格完成率下降 0.59 至 4.10 个百分点，使 `modulated` 严格完成率下降 0.98 至 7.23 个百分点。JSON 保留逐冠军选择分、严格与补救完成相关指标、双回访计数、动作轨迹 SHA256、首处分歧动作端口数值，以及首道题的状态比较。

逐 tick 检查显示，只改累积权重时，第 1 题 tick 2 的首次更新已经有 44,672 个 `local` 和 44,568 个 `modulated` 累积权重分歧，分母均是 291,840 个潜在弧状态。`local` 有一条弧从 `−0.28759765625` 变成 `−0.2876034080982208`，FP16 写回后仍是原值。下一 tick，两组有效 FP16 权重已分别出现 6,624 和 8,539 个差异，神经节点状态分别出现 125 和 176 个差异。四类状态变体在首次更新时同样出现权重分歧，偏置、门状态和节点痕迹也已分歧。

结果覆盖这一批基因在一个开发种子上的闭环行为。两个变体均保留局部表达式的 FP32 中间计算。
