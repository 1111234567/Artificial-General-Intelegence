# 本体复制参数后，能否用候选试算改善实际行动

两个 40 节点条件都让副区逐拍读取主区的出生权重和已兑现快权重。试算组在副区读到的参数上叠一份本体自己提出的候选 `D`，屏蔽组把副区读路中的 `D` 置零。两组的采用门都收到副区端点的新活动，并把本生的同一候选按比例写入主区。每组从 731、733、735 三份出生分别训练 1,536 次，每次 64 条实际路线。两组共执行 589,824 条训练路线，参数更新只用真回访的动作收益。[冻结方案](trial-plan.md)

## 试算确实影响了本体参数

冻结试算组后，只在安静期切断 `D` 的副区读路，末端主区快权重的每生最大改变量均值为 0.00451、0.00459，末端活动对应为 0.02060、0.02076。训练时已经屏蔽 `D` 的图受到相同干预时，状态和所有正式动作逐位一致。试算组干预改变了两个冲突集上 7/1,440 和 12/1,800 条生命的至少一次正式动作。主区仍收取本生的候选作为实际写入输入。

孪生候选来自同几何根、同 B/C 菜单与奖惩律、镜像且反转奖惩律的 A。实际 B 选择相同的冲突子集为 220 和 276 条生命，原生减孪生试算的双对差是 −0.45 和 0.00 点。两个候选配对的真实接触史仍可能在 A 或 C 的实际动作上有差别。

末拍同剂量混排在全角度中平均实际移动 147.20、147.13 条边，写入数、正负符号和末端活动保持相同，正负总量舍入误差都小于 1.85×10⁻⁷。两套冲突集只有第一套的一条生命改变了正式动作。这项检验覆盖最后一拍的写入落点。

静默期间，试算组实际采用的绝对权重变化总量平均为 10.68、10.61。钳零采用门后主区写入逐位为零，原生图的 B 正确率分别高 47.43、42.17 点，A 分别低 15.49、16.11 点。这个干预大幅改变了写入量，说明持续写入参与了真实新旧行为的取舍。配平候选读取与末拍剂量的对照目前没有显示内部试算选出了更有利的修订。
