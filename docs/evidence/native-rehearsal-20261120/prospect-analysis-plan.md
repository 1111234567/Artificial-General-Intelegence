# 前瞻读数的统计口径

本文件在计算留出得分前确定。读取两个完全独立的几何分割。只看静默活动差的读数单独报告；此外将同样的活动差加入包含初始活动、旧迹、草稿剂量与撤销支路静默活动的基线，估计超过这些信息的增量。每个模型和出生只用各自校准分割拟合同一种固定岭回归。错配读数在留出时用同根错配 A 的活动差替换，仍使用同一套校准系数。训练平均后果作为不读输入的对照。

主统计按每个配置分别汇总三个出生，等权使用所有角度、交叉奖惩及回访摆向；另以 15°/30° 及冲突奖惩报告。配对自助样本独立对出生与几何根重采，保留同根的成对策略与交叉单元。读数比较的正值表示均方误差下降。外部同掩码反号、错配回流干预报告真实未来运动概率边际与实际采样成败，并以未经重新校准的读数检验迁移。这些干预的效果与主读数的预测增量分别计量。
