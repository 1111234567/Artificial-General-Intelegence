# 只改变允许内部运行的时间

主评估只比较原定的 12 个空白拍。追加时长检验在独立的 192 个新几何根（27159371）上，同一条生命固定到真实 B 结束时，将外界空白延长为 0、3、6、12、24、48 拍。中间不馈入旧线索、时长指标、阶段标志或额外得分。每个时点从当时的神经状态分别作一次真正的串行 A/B 回访，摆向和动作抽样在兄弟分支间配对。考察是否安静计算越长，两需求就兼顾得越好，以及收益是否必须由第二个区实现。20 节点及同容量、不同初始化和开发期教学对照全部保留。以配对区间检验相对 12 拍的两题联合变化，预先将该项定位为训练时长以外的泛化，并在训练过的冲突 15°/30° 池单独报告。
