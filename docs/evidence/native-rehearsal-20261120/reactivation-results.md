# 静默回流对旧线索与动作做了什么

在三次训练出生和 128 个新几何根上，原生双群网络的静默回流能影响实际作答。关闭回流使无教学的复制拓扑少答对 1.78 点 A/B 对，使置换拓扑少答对 4.38 点。晚期感觉电流里，与真实旧 A 方向一致的稳定信号出现于两种线索指导配置。在无教学配置中，最清楚的旧 A 信号出现在 B 味觉结束和静默初期，随后减弱。五种配置均未达到预定的静默增强与旧 A 特异运动门槛。[诊断方案](reactivation-protocol.md) · [完整结果](reactivation-heldout.json)

## 真实旧 A 的方向还在不在

每个几何根比较真实 A 奖惩相反而 B、C 固定的兄弟生命。下表是主感觉端实际回流电流的半差，沿着真实旧 A 有利方向中独立于 B 的切向投影。单位为千分之一电流，方括号为 95% 配对区间。各个体和几何等权，作答与电流都按出生和几何根配对。20 节点单群没有从额外群流入主群的这条电流。

指导 C 后，晚期旧 A 投影较静默开头增加 2.25 [0.09, 5.09]。它相对 B 尾的区间跨过 0。指导 A、指导 C 的晚期 C 投影分别为 4.37 [0.63, 10.50] 与 9.14 [1.25, 17.09]。指导结果支持晚期回流可以带有旧方向信息，且两个旧方向可能一起出现。[完整逐拍读数](reactivation-heldout.json)

## 静默回流是不是借旧 A 方向帮助作答

自然回流对比切断回流，复制与置换拓扑合计分别多答对 1.78 [0.39, 3.61]、4.38 [0.80, 10.25] 个百分点的 A/B 对。五种配置自然回流下的双对率为单群 90.62%、复制 91.11%、置换 91.06%、指导 A 91.33%、指导 C 91.18%。这些绝对成绩在所有夹角和奖惩赋值上汇总。

将完整回流替换为反 A 律兄弟的回流，置换拓扑的 A 正确率下降 3.66 [0.20, 9.45] 点，A/B 双对下降 5.36 [0.55, 13.75] 点。将无关 C 的律翻转时，旧 A 的下降较小，两个替换臂的 A 差为 1.36 [0.05, 3.62] 点。做每拍等回流范数、等扰动范数的方向打乱后，其 A 正确率较反 A 律替换高 1.86 [−0.52, 5.67] 点。这个专属性区间仍跨过 0。指导 A 的等剂量方向打乱反而比反 A 律替换多损失 0.49 [0.03, 0.93] 点 A。四个 40 节点配置的完整检验见归档。[动作和干预差值](reactivation-heldout.json)

## 固定 C、B 的真实动作和味觉

反 A 律兄弟间的 C、B 选侧与味觉在复制、置换、指导 A、指导 C 中分别有 54.4%、76.3%、40.7%、52.9% 相同。两种 A 镜像都要匹配时，四组保留 47.3%、71.4%、32.9%、46.1%。保留的兄弟面对完全相同的 C、B 实际回执脉冲，接收这些脉冲时的内在状态仍取决于各自先前经历。条件池包含各配置 2,024 至 4,384 条真实生命，区间按条件中重抽后仍有效的分母计算。

固定后，指导 A 和指导 C 的晚期 A 投影仍为正，分别为 +6.49 [0.67, 10.71]、+10.57 [0.87, 14.09]，相对 B 尾的两个差区间仍跨 0。置换拓扑中，反 A 律兄弟替换导致 A 准确率降低 1.61 [0.06, 9.71] 点；与等剂量方向打乱直接相比，反 A 律替换多损失 0.32 [−0.70, 4.74] 点 A。复制拓扑中也看到反 A 律替换造成的 A 准确率下降 0.79 [0.04, 2.21] 点，等剂量方向打乱的 A 平均降幅为 1.08 点。固定可见 C、B 回执后，回流对后续动作有作用，旧 A 特异性的干预证据仍未达到预定界限。[条件池与配对区间](reactivation-heldout.json)

完整 20 维兄弟流在每个几何根上逐拍等能量。等范数方向打乱的最大范数误差为 1.21×10⁻⁷，以本条生命自己的电流替换时所有实际动作保持一致。复核逐一验过 15 组参数和原始档、复算 45 项分出生动作计数，并用置换拓扑出生 733 重演整组。这个诊断覆盖一次真实 B 和其后的静默回流，评测的新几何沿用训练的三个出生。[档案复核](reactivation-audit.json) · [本地原始电流账本](../../../data/native-rehearsal-20261120/reactivation-heldout/manifest.json)
