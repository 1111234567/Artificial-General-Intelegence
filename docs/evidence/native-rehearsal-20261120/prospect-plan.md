# 无输入静默活动能否预报新写入的后果

先让固定原生图真正接触旧 A、无关 C 和新 B。任务环境在 B 后的十二拍只输入全零。检验限定 `copy`、`guide_a`、`guide_c` 各三个冻结训练头，主问题是静默时同一图对 B 写入差异的活动，能否预测未来才呈现的 A、B 实际回访概率差。

- 校准几何种子 82617281，128 根。正式留出种子 82617289，192 根。每根使用任务原有的 16 个交叉单元，包含 8 种奖惩符号与同 B/C 条件下两个镜像 A。回访顺序与摆向由独立抽样决定，两者不提供给估计器。
- 主对照复制 B 后的真实活体状态。两条支路的起始活动和突触迹完全相同；一条保留原生 B 局部快权重，另一条只把快权重恢复为 B 接触前的数值。两条支路随后运行同样的静默方程和回访。预测目标是两支路中 A 与 B 各自正确概率之差。计算目标时对首题真实原生运动的两种可能动作精确加权，学习与计分均用将来菜单出现后原生端口发出的运动概率；同时记录独立实际抽样的两题动作。
- 每个冻结头在校准几何拟合固定岭回归，分别预测 A、B。基线特征包含 B 前与 B 接触后起始活动、突触迹、快权重草稿各项剂量摘要、撤去 B 改动的静默活动。主读数额外读取静默第 3、6、9、12 拍两支路的神经活动差。校准内标准化，岭惩罚 0.03，系数在留出集固定。比较均方误差与其出生和几何根配对区间。分别报告 A、B，区间下界大于零才算对应对象有留出预测增量。
- 错配活动控制只替换主读数的活动差，来自同几何根、相同 B/C 的镜像 A 且旧 A 真奖惩相反的真实历史。另分别运行两个外部干预。一是同一个随机半掩码下施以等量反号的 B 快权重变化，饱和边对称限幅。二是给原生或撤销支路的主身体接入同根错配 A 历史的第二群回流；其他状态与静默输入保持原有条件。报告这两种支路的真实未来概率差，以及同一冻结读数的迁移误差。

校准读数与状态分支只用于诊断；原生模型仍运行一张图。备选参数状态、错配回流和目标概率的计算均由评估代码强制构造。预测结果衡量内部活动含有什么信息，干预结果衡量这些内部路径对后续真实行为有什么影响。
