# 静默时的旧线索与实际行为

在读取冻结参数前固定本方案。检查 `single`、`copy`、`permuted`、`guide_a`、`guide_c` 五种训练配置及各自出生 731、733、735 的第 1536 步。前两种 40 节点配置检验未接受线索教学的双群图，两种指导配置分别给旧 A 和无关旧 C 的正对照。20 节点 `single` 用作行为及容量参照，没有额外群到主群的电流。

诊断从 `451023793` 产生 128 个新几何根。每根用固定的 B、C，两种关于 B 镜像的 A，以及全部八种 A/C/B 奖惩赋值。共同的呈现方向、顺序与动作随机数跨所有兄弟生命和条件相同。C 与 A 的真实经历顺序按几何根决定，真实 B 最后，外界随后给 12 拍全零输入。只在实验账本中从早先真正呈现的菜单、动作侧及味觉求各对象有利方向。实际图只接收当时的真实感觉脉冲和活动，静默时没有外来的菜单、味觉或目标。

## 直接测量的电流

记录最后一次真实 B 的七拍、静默期 12 拍内每拍由额外 20 节点流入主 20 节点的实际电流 (I)。六个感觉端的三维差分是 ((I_{3:6}-I_{0:3})/2)。对每条生命，用同几何、同镜像且 B/C 律相同的反 A 律生命作配对，取感觉电流的半差，再点乘本生命真实 A 有利方向中垂直 B 的单位切向。这样比较固定了 B/C，把 A/B 共用轴排除在主指标之外。真实 C 律翻转的半差投影到真实 C 有利方向作为旧 C 对照，单列未经配对的 A/C 对齐和电流强度。

所有角度等几何根加权、16 个同根生命等权，15°/30° 池作为次项。主指标为 B 味觉最后两拍、静默最初四拍和最后四拍的均值，以及静默最后四拍分别减去前两段的配对差。进到静默末期的旧 A 方向信息需要晚期投影区间下界大于 0。说静默期间旧 A 确有增强还要求两项配对增量的下界均大于 0，单独的正投影或比 B 接触时偏好更大也可能是遗留活动及慢作用。检验并行的旧 C 指标，并保留完整逐拍对齐曲线以看清趋势。这里没有候选草稿反事实，也没有用预测器分类神经活动。

## 实际运动干预

所有分叉从同一 B 接触末态开始，并只在静默的 12 拍干预额外群流入主群的完整 20 维电流。以下预先固定的替换来自自然静默的记录，复访阶段网络恢复自身实际电流。每个静默末态分两条读出支线，分别按 A→B 及 B→A 真实动作，实际正确由环境结算，两种顺序等权。

| 分支 | 静默处理 |
|---|---|
| `live` | 自发闭环，无电流替换 |
| `own` | 固定为本轨自然静默的电流，验证替换通道本身的数值效果 |
| `swap_a` | 换同世界同 B/C 同镜像但反 A 律兄弟的完整电流 |
| `swap_c` | 换同世界同 A/B 同镜像但反 C 律兄弟的完整电流 |
| `rotated` | 在每生命每拍保持 `swap_a` 的替换电流范数和对原电流的扰动范数，随机转动扰动的垂直分量 |
| `cut` | 静默期间把额外群流向主群的电流置零 |

两种真实兄弟替换各在同根内作一一置换，组内整条时序的完整电流能量严格配平，个体扰动幅度另记。随机方向对照匹配个体每拍的两种范数。静默干预结束后以实际结算评价。旧 A 起因测试要求 `own − swap_a` 的旧 A 和双对区间下界大于 0，B 区间下界大于 −5 个百分点，并且 `swap_c − swap_a` 和 `rotated − swap_a` 的旧 A 差下界大于 0。`live − cut` 表示整个反馈通道的总贡献，也可能改变 B，单独报告。只有静默末期方向信息与实际 A 结算的因果门槛都通过时，才有证据支持旧 A 信息参与了后续行为。即使通过，也没有试出同内部候选地址的写前、写后反事实。

在读取正式结果前增加固定其他实际回执的稳健性分析。对反 A 律兄弟，只保留真实接触 C、B 时各自选择相同侧且获得相同味觉的线路，并要求同几何的另一 A 镜像也保留。报告镜像筛选前后的可配对率。在这个条件子集中重算旧 A/B 双对和旧方向电流，先在各出生×几何单元保存结果与有效分母，再在每次配对重抽中重算它们的比值。该条件读数检验成功匹配这些真实回执的生命，原始所有生命仍是主池。

对出生和几何根分别有放回地重抽 8192 次，取 95% 分位数区间。所有指标在出生×几何根内配对。记录源参数哈希、逐生命动作、实际电流和干预剂量。本诊断覆盖一次真实 B 的持续作用，三次 B 的完整模型行为证据应从单独的压力测试取得。
