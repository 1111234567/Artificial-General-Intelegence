# 一次复习该给谁

冻结图在真正接触前能读到左右菜单，五拍后给出运动 logit。接触才会送入所选侧与味觉。普通菜单中的已知旧味如果由外部系统逐项保存，足以重建所经历的价值映射。候选身份和次序由环境记录，给身体的端口输入是左右各三个感官量。这里的选择器只读此次预览的候选、次序与运动信号，选择和排序在冻结图之外执行。原夜间办法对同一状态免费扫描正反菜单，主测验让每份可见菜单切实占用五拍，活动和迹线随生命连续推进。均匀、最低置信、最高置信和把分数随机分配给候选的控制，共用同一条预览带。每种策略随后只实际复习一次。活动、关闭写入、同时间静待三个分支用于估计复习结果、写入效果与总接触效应。[登记方案](value-plan.md)

## 分母与复现

两个出生组各六个。普通四项、八项各用每出生 160 个新几何，每个几何配对四份私有映射。四对象受控角度每个角用 96 个公共基础几何，每个角保留相同四份映射。两对象几何另用每出生 128 个公共几何，每个几何配对四份映射和两个学习顺序。联合六项用每出生 64 个新几何及每几何 64 份映射。场景冲突占每几何 32 份，困难三角且场景冲突占 8 份。区间用 4,000 次按出生和公共几何独立交叉重抽样，参考策略差值保持配对。
