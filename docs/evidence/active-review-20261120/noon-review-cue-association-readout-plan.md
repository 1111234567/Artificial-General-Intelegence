# 单独交换期限关联格

前一实验把反义履历产生的动作移植回原身体。额外在独立世界 original `76202671`、independent `76202672` 检查是否只交换两个手工指定的可塑关联格，就能改变实际末段收益。每出生 256 个几何，两批固定六出生。身体本身现在看到的提示、预览运动信号、写后的图、活动、痕迹、动作随机数与真期长一律固定。反事实只从反义履历调入依据其实际校准事件更新的两个格。自然和移植策略均从同一当前身体执行实际路线。对照校准允许或关闭原图写入，各比较预览较小绝对运动 logit 是否识别出初次无味项、期限脉冲的物理响应强度，以及两格干预对选择和实际收益的作用。该试验仍沿用同一末段实际采集与公开等时结束信号。
