# 同一票据身体上的共享资源读出

两批各六出生，沿用 64 个新几何与四种私有历史。所有读出用同一批封存的原票据身体和局部写入。训练只调整四个共享读出系数，所有系数部署到两批时保持封存。程序在付费门从已发布价格、预览气味和已实际收到的食物味觉痕迹采样一次。实际扣费、正常收集、收获与局部写入继续相同的物理规则。

每种读出各自按同价、同阶段及同一条生命的购买数量重排四次，随后完整回放身体。表中取每生实际收获减实际费用，阶段通过第 2、8、32 次。两批先独立重采样各自出生和几何，再等权合并。
