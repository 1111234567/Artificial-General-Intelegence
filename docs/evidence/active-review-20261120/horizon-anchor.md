# 固定采集身体，只训练回访路线

前一项试验让原生身体学会根据期限选路，同时改变了后续采集能力。本次从同样的配对教学 `paired@12000` 出发，锁住继承的边权、偏置和局部写入规则。两次初始接触、回访采集和后测发生在同一个 20 节点身体上，生内写入照常运行。只在回访路线这一动作上把小残差加到原生运动 logit。现场只走选中的一条路线。[原试验与身体变化](horizon.md) · [本次方案](horizon-anchor-plan.json)

比较两个预先登记的读出。21 系数版本读候选菜单反应后的 20 个原生节点活动和一个截距。42 系数版本再用原生左右感觉节点在三拍气味输入中的活动增量，调节同样 21 项的贡献。两个版本都用真实期限信息及同边际无信息两种方法训练。读出获得的是经历过感觉输入的身体活动。它收到的动作前输入没有额外候选预览，前后时序沿用相同 108 拍的 0／4 试验。[实现与加载入口](../../../experiments/pulse_game/noon_horizon_anchor.py)

两批各六个原亲本，每出生用 4,096 个训练几何和 512 个独立留出几何，每几何交叉两份私有映射与两种缺味身份。训练重用冻结身体在同一状态实际走完的两条路线，环境随机带在两条路线间配对。候选运动概率变了，身体在给定所选路线后的行为保持由同一原生图决定。训练 4,000 次 Adam 更新，仅保存 21 或 42 个读出系数。所有报告中的实际资源均用加载后的读出执行单路部署，再逐条核对到同状态的反事实回放。[身体冻结清单](horizon-seal.json)

## 同一部署的资源增加，仍有识别代价

42 系数版本在两批分别把回无味项的比例从短局 45.21% 和 43.31% 提到长局 56.42% 和 56.58%。配对长短差为 +11.21 [+6.06, +15.89] 和 +13.26 [+9.43, +17.20] 点。同分布无信息版本的长短差分别为 +0.38 [−1.64, +2.61] 与 −1.77 [−3.84, +0.12] 点。把相反脉冲下的实际动作换入同一接收身体，正常动作的两局等权总资源多得 +0.090 [0.042, 0.134] 和 +0.100 [0.068, 0.137] 单位。

单看长局，42 系数读出相对固定回已尝项，当场资源下降 0.474 / 0.497，后四题实际正确率提高 9.45 / 9.42 个百分点，长局累计仍多得 +0.282 / +0.257 单位。短局的损失使等权混合总分仍低于始终回已尝。21 系数版本虽分别有 +4.83 / +4.13 点的长短差，两批长局回无味项的区间都包含 50%。[原六出生](horizon-anchor-original.json) · [独立六出生](horizon-anchor-independent.json)
