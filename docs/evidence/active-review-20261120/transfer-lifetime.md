# 同一身体连续 32 次购票和收获

每条生命先遇到两个有味觉的普通对象。随后四个八次循环各呈现六个反复对象和两个新对象，期间另有八次有味觉的普通干扰接触。每个收获动作由当时图发出，有利侧记 1，其余记 0，减去实际付出的票价。起始和干扰接触供给经验。每次挑票、接触及收获后都继续使用活着的图和局部写入。

每条自然生命的购买量按相同价格和相同阶段固定，四次随机重排后都完整重放身体、味觉、后续选择和写入。因此在前 2、8、32 次，匹配随机的实际购买数与总费用逐条相同。两批分别各六出生和 64 个新几何，每个几何四种配对私有赋值。配对区间来自 4,000 次出生和几何的交叉重采样，两批分别抽样后等权合并。表中的资源与费用为每条生命的累计单位。

票据两种训练各从同一普通起点走 8,000 步。共激活证据和总剂量组从票据图内购买模型再走各 8,000 步，并共享付费菜单外的原生身体。它们的六数在整个生命仅随真实非零食物味觉累积。延迟环境在第 32 次之后依序送达实际收获的味觉。
