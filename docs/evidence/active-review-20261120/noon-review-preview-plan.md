# 同钟候选预览的额外实验

核心结果之外，验证先实际看到每位候选的熟悉双极气味能否帮助原生复习控制。仍先普通接触四种气味。相同的 2 拍双侧提示后，有状态连续展示两个 5 拍预览，期间没有本体动作回声、味觉或写入。真实预览按公平随机次序显示即将进菜单的两位候选。对照显示两个独立生成的等范数方向，方向边际分布、摆向、时间和公开提示相同。两个生命接下来看到同一个真实二选一菜单，最多只复习同样一次，使用相同的普通复习接触、末题和收益。生理活动和痕迹均延续。这套对照检验获得候选相关预览信息的价值，只匹配预览脉冲的边际分布。

冻结原图试验使用 `76202441`、`76202442`。对真实和对照的末段分别直接执行左右两次评估分叉，等概率混合是同状态随机选择；另在一边仍保留全部活动和痕迹、只强制执行另一边的选侧，以排查单纯预览刺激改变末题成绩。外置的同图预览运动信心仅作为评估读数，永不反馈入模型。

若继续训练，固定从核心 `native` 第 8000 更新暖启两队列，各续训有信息、无信息的两组。训练根 `76202433`，每出生每更新 16 个互补世界对，Adam 学习率 0.001，按出生裁到 2。每四次更新使用与主实验相同的无复习短局。只用实际均匀末题作奖励，三个采集/写入/复习选择动作通路按原信用规则更新。封存 0、1000、2000、4000、8000。在 `76202461`、`76202462` 的各 384 个新世界固定比较可用共同终点。主要补救判据是有信息训练图在测试的真实预览状态下，原生动作能超过同状态随机和来自无信息预览的动作，并且相对无信息等预算训练组保持收益。阶段零、每项边际和四项全对同时归档。
