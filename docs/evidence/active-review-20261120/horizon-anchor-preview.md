# 两次真实预览帮助固定身体按期限选路

冻结身体的无预览残差已在原亲本上提高总资源，仍低于始终回到已尝项。另一套独立留出检验额外的实际候选预览。身体先接触两项，再按独立顺序依次看到两份候选菜单。每份运行五拍，保留原生活动和迹线。预览没有味觉反馈、写入或选侧回显。四系数读出使用该身体两次运动 logit 绝对值之差、真实期限气味在两个感觉节点上的活动增量、二者乘积和截距，只修改回访路线的运动 logit。其后由同一原生身体采集和答题。[方法与预先登记](horizon-anchor-preview-plan.json) · [无预览结果](horizon-anchor.md)

同预览原生、同预览始终回已尝和两组学习策略共享十拍真实预览。等时静待原生在这十拍仅中性推进。所有比较各占 118 拍，短局兑现回访当场，长局另兑现实际连续四次选侧。新留出仍包含原与独立两批各六个亲本，每出生 512 个几何，每个几何四份配对旧历史。两种读出共享另取的 2,048 个训练几何，各学习 4,000 步。训练后重新加载四系数，单路实际走完每个被测生命。[单路部署与验证入口](../../../experiments/pulse_game/noon_horizon_anchor_preview.py)
