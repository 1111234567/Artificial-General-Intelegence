# 一条生命能否学会期限提示的含义

使用前一项已封存的 `paired@12000` 身体和 `horizon/preview_anchored` 的 `informative` 四系数。该接口先连续做两个各五拍的候选预览，随后用原生原始路线 logit 加四项残差。四项是常量、两个预览的绝对运动 logit 差、双侧期限脉冲的感觉活动响应，以及后二者乘积。本试验重新生成全部世界，冻结身体的出生参数、原局部规则和四系数。两批各六出生。主检验种子 original `76202631`、independent `76202632`，新重复为 `76202641`、`76202642`，每出生每套 256 个几何。

每条生命先连着做两个校准局，先短或先长由独立公平随机决定。两次各自用一对新气味，先按原任务各接触一次，再连续预览、呈现真实期限脉冲和实际复习。短局没有后续机会，长局有四次实际接触，按实选侧领取并感到其 ±1 味觉。每个后续位置具有一样的固定时钟，短局空位置中性推进。四个位置后两局都在相同时间收到相同的公开结束脉冲，发生在机会和资源之后。校准采用外界公平抽取的实际身体动作，在反映射配对的生命里逐次执行同一物理侧、物体、摆向、味觉和等待；图继续接收这些实际输入并允许按原局部规则写入。唯一改变是校准局的在场脉冲交换强弱语义。校准的新气味与最终待选两件无关。

每个世界交叉气味价值的互补符号、哪个先行接触没有味觉、原固定映射或反向映射，以及最终物理提示的两个摆向。每条生命只看到自己的校准映射，试题实际长短由同一生命的映射控制。最终先普通接触一对新的气味，身体从两个校准局持续携带图、活动与痕迹。为了使最终作选择之前的全部味觉也能精确配对，这两次接触仍共享预抽物理侧，允许写入。随后的复习选择与真正付费采集恢复原生动作。接下来执行与四系数正例相同的两个五拍候选预览、实际脉冲和路线选择。所有策略同样实际复习一次；短局随后静待，长局真正运行四次原生付费选择，最后在同钟公开结束。策略从未接收映射编号或未来机会数，也无法从公共时钟预先得到此次期长。真实付费动作与原规则一样计分。报告复习即时收益、后四题收益和合计资源。

冻结比较含原生侧、四系数侧，以及让完全相同的当前视觉脉冲在另一条反映射校准史上产生动作，再只把该动作移植回原接收图的分叉。另在校准阶段禁写但继续观察所有物理事件，最终两次新气味接触仍开放写入。原固定含义以主实验里保持旧映射的配对生命为对照，并加等时静待两个校准局的冻结身体用于检查原任务接口，静待也照常看到共同结束脉冲。主指标为翻转私人映射时，同一个物理脉冲所导致的无味项选择变化，以及自然侧减跨生命捐赠侧的真实合计收益。以条件真期长的长减短衡量策略会不会依自身经验更换路线。各政策的真实末段按同事件带重放。
