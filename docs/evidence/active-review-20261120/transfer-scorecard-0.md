# 旧任务冻结交叉评估 · 起点

两批各六出生，在各自相同的未见世界比较。每个模型以同一具封存身体和局部写法进入所有任务。普通题、七接触快照、真实串答、难三角均允许原有的生内写入，成绩表主列无额外复习。四项及八项另列统一外置复习的因果分叉。

普通题各 128 个共享气味世界，七接触和串答分别使用各自 96 个世界，难三角用 128 个旋转世界。普通题的联合选择来自同一末状态。冲突 A、B、标记和六项同样取同一末状态，表中三种支持顺序等权。两次串答确实依次行动，首题味觉输入为零，同时保留这次动作后的状态。旧难三角成绩取两个等值映射，六个支持顺序及两种运动摆向等权。百分点差的括号为出生与世界配对交叉重采样的 95% 区间，共 4,000 次。
