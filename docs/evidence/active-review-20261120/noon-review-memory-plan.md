# 复习侧是否取决于旧味觉

四种气味的冻结诊断。两个额外根种子分别为 `76202411`、`76202412`，每出生 384 个新世界，每世界两个互补赋值生命。以核心终点和未续训亲本作比较。先保留真实生命，再以相同气味、摆向、普通采集侧和写入抽样重放；只在其中改掉一份候选的历史味觉。左右候选各测一次，另测一份非候选味觉的同等干预。反事实只产生一次公开复习菜单上的新左右动作。原来的图、活动、痕迹和待选菜单继续在原生命执行这个捐赠动作，取得原世界中相应物体的真实味觉，随后原生命按实际表现评分。另分别用反事实图和反事实活动/痕迹算出捐赠动作，执行过程一样。两侧实际终题结果提前以严格配对的评估分叉获得。干预只改测试时用于捐赠动作的状态，没有修改训练和策略输入。

主指标是该捐赠动作改变实际末题正确率的量，辅指标是改变左右选择的比例、绝对选择概率变化和以分支真实读数加权的策略增益。动作变化只证明这一决策对过去那一份味觉敏感。实际收益差才能说明这份记忆帮助了当前复习选择。在非候选也改变时，不能把敏感性说成候选特异。
