# 冻结复习选择的反事实诊断

本方案先于留出评估登记。冻结旧留出报告所用的均匀回访 8,000 步终点，以及长短信用各半修复 2,000 步终点。两批已有独立训练出生分别为 731–736 和 811–816。不训练选择器，不按留出表现挑身体。

## 策略可见的东西

原生菜单由左右各三个感官量输入。身体运行五拍后从两个运动节点产生 `2.5 × (h11 − h10)`。只有接触之后才输入所选一侧及实际味觉。现有 `interleave_review_choice.py` 从同一快照、对所有候选免费读正反摆向的 logit，以 `|l+ − l−|/2` 排序。它识别了外部可读取的信息。

主诊断在同一条生命中随机顺序展示候选，每个可见候选实际占用五拍，传入菜单，保留发生的活动和迹线。身体每次仅感知一份菜单。预览阶段没有味觉及写入，保存候选 `|logit|` 和带方向的运动读数。只读同快照的正反半差作为外部对照单独运行。折返时所见的实际摆向、运动抽样、局部编辑抽样、评价对象及评价结果均在选择后使用。无监督或外部规则只读候选身份、展示顺序、可见菜单及当时的 logit。

- 全可见及半可见各用统一随机排列。半可见分成同一生只在可见集合内选、同一生可在全体选两种准入设置。第二种下另做固定全体候选、将不可见候选分数以同生可见中位数填充的弱/强策略，并报告实际选中不可见项比例。半可见余下时间走等长静待。全体可选但没有菜单信息走全部静待，仍可按已认识的对象标签选择。
- 同一预览和准入设置内比较均匀、最低置信、最高置信、打乱候选内置信、最早、最新。精确同分用一份共享独立随机优先级。低/高配对隔离信号方向，真实/打乱配对隔离信息对应，均匀在相同预览之后隔离读取信号与预览本身的影响。
- 原生有限预览仍由外部选择器读取和排序。遮挡条件既没有隐藏标签、状态复制或未来回报进入选择器，也不声称现有图能在自身内部保存并比较多候选分数。

## 实际复习的价值

从决策快照起，以相同摆向和运动抽样解析每个候选的一次真实接触。活动分支执行原生写入，匹配对照接收同一次接触的所选侧与味觉、保留全部经过时间和迹线，仅关写入。另有等时静待对照。每条线总时钟匹配，实际策略用一次真实接触。活动相对无写入估计写入效应，活动相对静待估计包含接触的净变化。各候选共享复习随机数；实际策略从未见到这些随机数。

主要终点是所有对象都对、每个对象均匀请求时的正确率。所有终测从同一复习后快照分叉；各自摆向和各自随机选侧独立，分支间共享给定末测随机数。每个活动/无写入单元同时保留真实选侧成绩、对正反末测摆向与独立末测随机选侧积分后的期望。六项补充同一生命两次实际终局选择，一次考前三角，一次考场景 A/B/标记，顺序随机；第一题后采用既有两次有偿终局规则，让选侧与零味反馈推进身体再测第二题。

事后计算候选收益排名与负置信度的世界内配对秩关系，同时分别计算被复习项与非复习项的变化。计算候选之间差异超过 **1 个百分点**的世界占比，活动优于该对象同接触无写入的世界占比，以及提升被复习项且任一别项被损害的发生率。阈值同样用于判断两个估计折中均存在的受益及干扰。记录获益与伤害的幅度和最近邻结果，避免仅看二值门槛。

每个候选使用两组各八个相互独立的复习随机带。每组内四条正摆向、四条反摆向；运动和局部编辑抽样独立。先在 A 折选、在 B 折估值，反向同做后均匀平均。记同折最高的选择优势、异折复算优势、同一实际随机带事后挑赢家的乐观高估、两折排名一致性。用活动端点与活动减匹配无写入分别做事后排序。异折选择可用真实标签和另一次模拟的结果，仅用于测量冻结身体内部还留有多少候选差异。一般策略的成绩仅从预先定义可见信号产生的选择计算。
