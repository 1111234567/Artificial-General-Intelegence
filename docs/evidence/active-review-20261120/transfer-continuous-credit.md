# 连续身体的当次信用与以后实际净资源信用

两批各六出生，同一起点分到两种训练，均做 1,500 次更新。每步真的完成八次连续购票、复习和收获。当次信用给本轮随机动作，累计信用还包括此后实际收获与费用。收获后写入按发生时点归于以后回报。两臂共享物理规则、世界、随机数、感知和局部写入权限。身体改变后，其自行选侧和真实经历可以分化。

单次留出用三种价格与配对的已知、未见和仅见未得味觉的历史。32 次留出沿用延迟味觉长生命，按同价格及同阶段重排每条自然轨迹的购买并完整重放。区间以出生和世界分别重采样 4,000 次，两批等权。
