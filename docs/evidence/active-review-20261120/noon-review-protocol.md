# 复习选择的预先协议

2026-11-20 北京时间上午冻结。亲本 `retention-objective` 的 731–736 与 `retention-objective-confirmation` 的 811–816，均取 `odor/uniform` 第 8000 更新。全部出生、三个训练臂配对，使用同样数量的更新、新生命、普通接触和复习机会。图保持 20 节点，沿用既有局部写入公式、出生/退边抽样、感知和运动端口。

每个复习生命先普通接触四种新气味。气味为三维随机单位方向乘 1.35，私有正负价值独立生成。每次普通接触以 `x, -x` 显示同一对象，原生左右动作决定实际味觉，允许一次局部写入；之后等 4 拍。接着让一对同值的气味通道发出 2 拍公共复习提示，从已见对象中均匀、不放回、按随机左右放置抽取两个候选，用原生气味端口同时显示 5 拍，每侧显示该对象的独立随机摆向。选择复习动作只产生 3 拍左右本体感觉，气味和味觉端口此时均为零、也没有提交写入。随后入选对象以新的独立摆向进入一次普通接触，并由新的原生搜集动作取得味觉和写入。等 4 拍后，均匀抽一个已见对象做最后一次普通左右动作。用于训练的回报只有实际最终动作的 ±1，抽题不依赖复习对象。每四次更新有一次统一的无复习普通任务（在两种和四种已见气味间交替），损失与其余生命一致。

`native` 使用原生选择抽样并给其策略梯度。`random` 在同一候选集合用独立公平抽签执行左右。`uncertain` 在冻结亲本身上重放同一普通接触世界和随机数，以亲本在当时两个候选上的正反摆向运动 logit 半差绝对值为信心，复习较低者，平手独立公平抽签。亲本支路可以在自己的普通接触时局部写入，选择估计只跑只读分叉，不影响受训主生命的活动、痕迹或时钟。外部臂的执行侧也真实回传，普通接触、写入和最终动作都参与相同的策略梯度，外部选择本身无梯度。辅助更新三个臂行为协议相同。出生内使用留一世界对的基线，反号史共用所有感知和动作随机数。

训练域 `0x61A120`、根种子 `76202117`，按出生号和步数确定。每出生每步 16 对互补私有赋值，Adam 学习率 0.002，梯度范数按出生裁到 2；预先规定 0、128、256、512、1000、2000、4000、8000、16000 更新封存点。以在北京时间 11:25 前三臂、两批均完整的最大共同封存点为主终点。初筛阶段使用 original `76202211`、independent `76202212`，主终点留出评估使用 original `76202261`、independent `76202262`，每出生每负荷 384 个独立世界和两个互补史。训练与两评估域分离。主要负荷为 4；2、8 以及异分布诊断为次要分析。初筛可使用更小固定前缀，留出不得参与选步。主结果按出生等权配对，以分批报告和合并对比给出真实四题实际正确比例，所有题同时正确率为次要读数。各题评估从同一末状态独立叉开且使用同一动作随机数。

冻结试验在相同普通历史和同一已抽样复习动作后分叉。自然、翻执行侧且正常改变对象、只换接触对象且保留执行侧、各自的接触禁写，另加同样菜单和执行侧但无接触的等时静待。进一步用同一图跑随机与亲本不确定性选择，剥离继续训练对普通记忆和收集的作用；另比较配对训练完的各臂自然流程，跟踪保留普通任务。阶段 0 重放使用亲本。真实选择的补充门槛是效应同时能抵抗同图翻侧及随机，且用禁写差确定获得的收益是否来自实际复习的参数写入。所有候选抽样、摆向、抽题、私有价值和评分均由环境独立生成；主图选择代码的输入仅为图状态及公开气味与固定模式提示。源代码、输入亲本、模型及原始结果在执行时另行登记哈希。
