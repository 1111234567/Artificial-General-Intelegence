# 两对象几何对照

四对象角度实验旋转 B，B 与第三、四对象的夹角也会随之变化。另登记只学习 A/B 的角度实验，使干扰只来自同一对对象。登记时已查看普通四对象初步结果，未查看受控角度或冲突六项结果。

固定 A 的方向和 B 的旋转平面，B 相对 A 处于 15°、45° 或 75°。各角用相同的 128 个基础几何、同一 A/B 价值映射、同一旧接触摆向与随机数。每个几何重复实验并交换学习次序 A→B 和 B→A。两种次序都保留各对象原来的摆向与接触抽样。两个旧物体各预览五拍，展示顺序与学习次序独立。活动与无写入仍共用一次真实复习接触，等时静待作为第三条分支。每候选沿用两折各八次复习随机带，末测两对象独立读出。两批各六个既有出生，各用均匀旧图和混合修复图。留出根由 `246112013 / 246112071 + 9127` 派生。

主要读数为复习目标的正确概率、另一对象的正确概率、两项都对的概率，各比较活动和同接触无写入。A 和 B 作为复习目标等权，两种学习次序等权。A/B 同值和反值先分层，然后计算 15° 相比 75° 的夹角对照及它与反值的交互。45° 点和次序分层用来了解变化形状。均匀复习、最低置信复习和最高置信复习的真实两项全对率作为次要终点，三种策略有相同菜单、时间和接触预算。按出生及共同几何交叉重抽样。同一几何四映射、两种次序与两折重复均留在该几何内。
