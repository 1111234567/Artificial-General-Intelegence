# 先测短局和长局的路线价值

从配对教学的 `paired@12000` 冻结检查点出发，保留原有 20 节点、运动端口和局部写入规则。两个气味都经历相同长度的实际接触。一个接触送入该侧的真实正负味，另一个确实送入零味。四个同几何历史交叉两个互补私有映射、分别是哪项送零味，候选左右位置与旧接触顺序独立。

两次接触结束后，先用既有复习模式脉冲两拍，再用左右相同的等幅气味脉冲三拍。负号预定表示短局，正号预定表示长局。候选菜单、决策时间和行动回显相同。短局只计算回访实际选侧得到的 ±1。长局在相同连续身体上依次进行更多正式选侧，每对机会恰好各问一个气味，对内顺序独立随机。每次结果由自身实际选侧和真实价值确定，也按 ±1 计分。后续选择回显进入身体，资源在本局交割，选择之间没有额外味觉教学和写入。短局其余时钟为空白，回访前时钟完全配平。评估的两个反事实路线用相同随机数各执行一次真实回访，并在各自持续的身体上发生后面的真实选择。

初始校准使用两批各六个出生，两个全新种子 `268201032` 和 `268201038`，每出生 256 个公共几何。脉冲两种符号均回放。计算回到零味项减回到有味项的当场资源，以及随后 1、2、4、6、8、12 个得失累加后的值。用正负脉冲本身对应的物理条件检查短长反向。事先按 2、4、6、8、12 排序，选择两批正脉冲下长局差值都为正、两批负脉冲下短局都为负的最短长度，并检查按出生与几何配对区间。若反向不成立，保留校准结果，再单独登记改动后的新世界生态和种子。正式训练与封存验证的随机带将独立于本校准。
