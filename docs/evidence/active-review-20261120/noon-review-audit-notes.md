# 核心复习试验的执行与诊断记录

核心训练使用标准 `local_trace_train.load_checkpoint` 格式。训练清单、权重、规则、逐出生训练指标与各封存点的 Adam 状态均在 `data/active-review-20261120/core`。亲本权重哈希和代码哈希登记在 `core/run.json`。评估结果按评估种子、共同阶段、队列和独立世界数分别存放，原始结果与参与的模型文件各有哈希。

阶段 0 曾用 96 个世界做通路试跑。这一批和 192 世界的阶段 512、2000 共享屏幕根种子，但生成器按整个批次分别消耗世界流，所以 96 世界的完整公开事件并非 192 世界文件的逐项前缀。阶段间配对只用完全相同的世界数和种子。主阶段与亲本的留出评估均使用 384 个世界，分别对两个队列固定，原始事件按阶段逐项可核对。出生级区间外，也重采样出生和共享世界几何，始终把一对互补赋值留在同一世界内，并保持整个对比的配对。

摆向检验源于屏幕里的一个探索性发现。若一份当前气味呈示在普通采集里的名义价值为正、另一份为负，旧身体往往选正。评估器用负的私有符号乘本次呈示摆向，事后统计名义价值。后续在新根种子 `76202421`、`76202422` 上，只将当前显示的气味方向反转，候选物体与之后真实接触的独立摆向固定。反转显示所产生的复习侧单独送回原始的活体状态，再让原世界按执行侧继续实际接触和答题。

`test_noon_review.py` 核对私有表不进入固定状态上的选择、公共提示和回声端口的时序、真实接触受执行对象控制、禁写完整保留图、两类预览具有同钟和无味觉/写入，以及捐赠动作评估使用原生命的实际分叉。历史反号干预细节与新世界另见 [味觉记忆计划](noon-review-memory-plan.md)。

几何变化留作次级新世界诊断。用额外根 `76202471`、`76202472`，每组固定 384 个新世界，在随机三维旋转下从两条互相垂直的轴各生成一对夹角 15° 的气味，并随机洗牌四种物体。价值、采集、菜单候选与末题照常独立生成。按候选同簇或异簇拆读，只在同一冻结原生图上比较自然、随机、原身体不确定性与禁写；也报告复习前普通采集和相同事件的独立球面世界。它检验相近气味造成记忆干扰时策略是否仍可用。
