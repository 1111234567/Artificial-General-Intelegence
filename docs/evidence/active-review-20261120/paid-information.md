# 付费信息在短局和连续生命中的证据

票据实验给身体一次购票或跳过的机会。买票实际扣费，并提供一次目标气味的真实味觉。净资源是末次真实选择得到的 0 或 1 减实际票价。原出生 731–736、独立出生 811–816 各六个。下文两批始终按此顺序列出，方括号为已存配对 95% 区间。同额重排在相同票价和配对历史间调换购买，保留购买量与费用。只按票价的基线在另一个校准库确定其买入或跳过规则。这两种比较分别衡量购买如何分配与策略能挣多少。[票据方案](ticket-plan.json) · [新市场预先登记](market-confirmation-plan.json)

**票据与共激活痕迹。** 同次付费保留而移除新味觉时，原生票据策略净资源少 0.1284 / 0.1389。单纯同额重排的差值为 0.0031 / 0.0033，两批区间均跨零。加入味觉门控共激活痕迹后，曾展示却未送味的目标比已尝目标多买 6.84 / 12.64 个百分点。换痕迹的动作对照把替换后的动作送回原来身体，表中差值因此针对选路。痕迹的六个数来自实际感觉与味觉，感觉菜单接收由六数计算出的目标方向投影。[票据原组](ticket-original-8000.json) · [票据独立组](ticket-independent-8000.json) · [共激活原组](coverage-original-8000.json) · [共激活独立组](coverage-independent-8000.json)

**侧向绑定。** 在附加信号能量匹配、票价与菜单相同的条件下，固定绑在票侧和固定绑在跳过侧的净资源差为 +0.0020 / −0.0023，两批区间均跨零。绑定到票侧仍有同额分配收益 +0.0046 [0.0015, 0.0078] / +0.0064 [0.0029, 0.0096]。这些数值支持原生动作能利用侧向信号，票侧相对双侧或固定反侧的净优势尚未建立。[绑定方案](option-binding-plan.json) · [原组](binding-original-8000.json) · [独立组](binding-independent-8000.json)

**显式购买读出。** 四系数把截距、公开票价、痕迹总量及当前气味方向的共激活投影映射到购买概率，再把购票动作送到可见的标记侧。三个种子各用原六出生的冻结票据身体和真实单路线回报训练 2,000 步，所得读出原样部署到两批。方向读出的短局实得净资源为 0.7797 / 0.7878，高于同额重排 +0.0123 [0.0099, 0.0151] / +0.0142 [0.0117, 0.0168]。独立批验证的是固定读出对新身体的迁移。[读出方案](resource-readout-plan.json) · [原组](resource-readout-original.json) · [独立组](resource-readout-independent.json)

**新市场复验。** 固定原生票据、痕迹及侧向绑定的端点，每批使用 320 个新几何和独立的 96 个校准几何。主分布等权三种票价（0.05、0.25、0.55），已尝占一半，全新与已见无味各占四分之一。原生票据再次胜过随机训练分配 +0.0264 [0.0173, 0.0367] / +0.0316 [0.0175, 0.0507]。真实新增味觉相对同付费无味觉增加 +0.1271 / +0.1425。共激活痕迹的同额分配优势为 +0.0056 [0.0009, 0.0103] / +0.0097 [0.0050, 0.0152]，对应净资源仍低于只按票价 −0.0448 / −0.0344。票侧相对固定反侧的净资源差仍跨零。[原组](market-confirmation-original.json) · [独立组](market-confirmation-independent.json)

## 累积干扰与适用边界

- **多次旧接触。** 在单次报价的压力库里，两次原支持后追加 14 次无关真实接触，共激活组的强制购票相对跳过，终局正确率仍高 +8.59 / +10.58 个百分点（费用另算）。同额分配收益已降至 −0.0013 / +0.0004，区间均跨零。方向购买读出的同额分配收益在同类压力下为 +0.0002 / +0.0004，也均跨零。方向读出在 15° / 75° 条件中，相对只按票价的净差为原组 +0.0128 / +0.0374，独立组 +0.0192 / +0.0534。票据训练后的普通 A/B 全对率，也在两批都比普通起点低约 6.15 个百分点。[共激活压力原组](coverage-stress-original-8000.json) · [独立组](coverage-stress-independent-8000.json) · [绑定压力原组](binding-stress-original-8000.json) · [独立组](binding-stress-independent-8000.json) · [方向读出压力原组](resource-readout-stress-original.json) · [独立组](resource-readout-stress-independent.json) · [普通记忆迁移与固定选侧回放](transfer-scorecard-ticket-coverage.md)
- **连续 32 次购票和收获。** 已完成的长生命部署只覆盖预定首种子 1177001，两批各 64 个新几何。以收获味觉整局延迟 / 立即输入分别计，在第 32 次，方向读出相对价格读出的两批合并净资源增加 +0.293 [0.103, 0.480] / +0.388 [0.184, 0.585]，相对总量读出仅 −0.057 [−0.219, 0.111] / +0.002 [−0.155, 0.148]。同价、同阶段、同生命购买量固定后，单独两批的方向择时收益在延迟条件为 +0.034 / +0.031，立即条件为 +0.081 / +0.074，四个区间均跨零。第 32 次时，两种反馈的痕迹总量都超出原短局训练范围。立即反馈下，方向读出在原 / 独立批分别有 100% / 98.4% 的购买概率落在 0.01 以下或 0.99 以上。这些结果支持累计净资源改善，方向成分在高负荷时的独立择时价值仍缺少证据。[两批合并与痕迹分布](transfer-resource-readout.md) · [原组逐阶段](transfer-resource-readout-1177001-original.json) · [独立组逐阶段](transfer-resource-readout-1177001-independent.json) · [原生长生命对照](transfer-lifetime.md)
