# 四个路线系数只从走过的路线学习

前一项四系数实验让训练器比对同一身体上两条实际路线。本次保留相同的冻结亲本、两次连续五拍预览、期限感觉信号和短 0／长 4 的实际支付。在线训练的每条生命按当时的运动概率抽取一个回访方向，再只走这一条。更新只使用这条路线的实得资源和动作概率，基线是此前已兑现的同期限收益的指数平均。短局立即结算一次回访，剩余四槽为等时中性推进，实际不问后四题。单路训练文件逐条保存当时发出的动作、该路线中发生的选择及实际得失。[预先登记](horizon-online-plan.json) · [原配对预览](horizon-anchor-preview.md)

同时重新训练配对信用组，匹配真正执行的次数。每次更新在线组走两个几何的四种旧历史和两种期限，每条实际执行一路。配对组走一个几何的四种历史和两种期限，每条分别执行左右两路。每个出生、每个训练流、每个组共走 32,768 条路线，短长各半，共 98,304 次实际付费选择。在线组以同预算遇到两倍不同公共几何。两组共 2,048 次更新，四系数均从零开始，亲本的身体和规则在外层保持固定，生内局部写入正常运行。[单路与配对训练代码](../../../experiments/pulse_game/noon_horizon_online.py)

原与独立两个出生组各六个身体，每个身体用两个独立训练流重新拟合。正式留出每个出生用 512 个新几何，四种旧历史保持配对。每个训练终点都重新加载，直接走一次部署路线，评估才执行相反动作作为对照。同一出生与几何上的两个训练流先等权平均，然后按出生和几何交叉重抽样。逐训练流的结果也单独保留。[留出程序](../../../experiments/pulse_game/noon_horizon_online_eval.py)

## 单路在线训练也学会了按期限切换

短局实选无味项原六出生为 15.04%、独立六出生为 14.09%，长局分别为 84.84% 和 84.20%。长短差为 **+69.80 [+60.71, +79.29] 和 +70.10 [+64.68, +75.36] 个百分点**。两个训练流分别看，四个组的长短差区间都为正。保留身体状态和真实期限，只把路线动作换成相反期限气味下发出的动作，两局等权资源少 0.537 [0.435, 0.636] 和 0.544 [0.452, 0.626] 单位。

## 原生路线的贪心复算

在更早的原生整图训练实验中，从已封存的 12,000 步信息组档案，另按运动 logit 的正负直接确定路线。回访和后四题仍沿用同一实际回放的动作。两批短局回无味分别为 35.57% / 41.70%，长局为 63.50% / 58.28%。短长等权的实际资源为 1.646 / 1.279，比原定随机路线分别多 0.0161 [0.0047, 0.0283] 和 0.0164 [0.0054, 0.0283] 单位。对同身体始终回已尝，短局差 −0.244 / −0.231，长局差 +0.238 [0.120, 0.349] / +0.177 [0.064, 0.288]，等权差 −0.003 [−0.045, +0.036] / −0.027 [−0.077, +0.015]。把路线改为确定选侧有小幅收益，原生整图在这套等权期限下仍未显示超过固定已尝。随机选路保留为两项实验的主读数。[原生路线贪心复算](horizon-greedy-native.json)
