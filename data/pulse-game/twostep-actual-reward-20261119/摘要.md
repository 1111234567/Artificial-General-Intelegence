# 实际端点信号的补充结论

以下模型从随机权重训练，只在真实触果后看到 ± 回执，未触果的训练回报为 0。他们直接发物理脉冲。潜键值结构使用实际公开事件写入。最严格的统一触觉组取消了四个阶段提示与独立入口触觉端口，保留真实触觉身份、可见房间、实得回报和公共回合起点。没有教师动作。

- **只优化实际正回执可以学会。** 核心潜键值模型在 3640000–3640255 的独立无奖首入口测试中，确定转移为 511/512，80/20 为 510/512。联合动态重估、统一触觉模型在 3660000–3660255 的独立 80/20 四格中为 855/1024，135/256 生命四格皆对。它在 3680000–3680255 的四格同体控制中为 861/1024。遮任一种需要的房身份为 512/1024，均匀替换学得的接触角色选择为 739/1024。实际负回执仍参与记忆更新。
- **逐回合实际有符号目标在冷启动遇到行动瓶颈。** 同种子、同预算，从头优化真实 +1、真实 −1、未触果 0 的核心和统一触觉模型，在独立测试中都没有到达入口。实际运动记录中部分生命发脉冲，位移不足以到达入口。正回执暖启后换成逐回合有符号目标，统一触觉分支仍多数接触入口，首入口为 502/1024、0/256 四格皆对。
- **统一触觉的第二个实际正回执初值复现。** 使用 144×96 生命与早段简单课程。在独立 3700000–3700255 的 80/20 四格中为 926/1024，189/256 生命四格都对。相同初始化、训练世界与预算的逐回合有符号和跨回合折现有符号冷启动均为 0/1024 且无入口接触。逐回合有符号冷启动在实验的三个独立初值上都未形成入口接触。
- **已有探索时，后续实得回报的信用能部分保留策略。** 同一统一触觉初值共享完全相同的前 64 个正回执训练轮，剩余 48 轮改用折现的真实未来有符号回报。80/20 独立为 738/1024、63/256 四格皆对，遮任一房间信息约 50%。四格同体的另批独立为 759/1024、77/256 四格皆对。无奖路测没有产生任何虚构回报。

核心原始对照在 `reports/core-actual-reward-3640000.json`。统一触觉的同预算结果为 `reports/untyped-actual-reward-3660000.json`，强同体为 `reports/untyped-positive-matched-3680000.json`，切换目标对照在 `reports/untyped-positive-to-signed-3660000.json`。方法、命令、种子清单及 SHA256 见 `README.md`、`source` 与 `manifest.json`。
