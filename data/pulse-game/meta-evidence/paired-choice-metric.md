# 首次实际选择的配对口径

修正后只把两边都实际发生首触的目标差异算作切换。相关与非相关目标的定义和先前相同。“全机会切换率”包括全部配对生命，至少一边超时的配对在分子记零。为了保留分母信息，另列双方首触覆盖率和双方都实际触到后发生切换的条件率。

| 字段 | 含义 |
|---|---|
| `switched` | 新口径的逐对 0/1 值。两边都首触且实际选择的目标类别不同才为 1 |
| `paired_first_contact` | 两边都实际首触的逐对 0/1 值 |
| `switch_given_paired_first_contact` | 全部已发生配对首触中的切换比例。分母为空时是 `null` |
| `first_side_even` 与 `first_side_odd` | 各臂第一探题的真实接触侧，−1 表示超时 |

只有同时含 `paired_first_contact` 与真实首触侧的结果才使用新 `switched`。此前的对称性和 recurring 封存 JSON 文件保留旧口径，其中 `switched` 只是比较“是否触到相关目标”两个布尔值。若一边碰到相关目标、另一边超时，旧口径也会记作切换。旧报告里的 `first`、`both` 和全部探题平均的 `contact` 定义没有变化。晨报中的实际切换以新口径重算的结果为准。

新口径的相同历史零假设直接检查真实首触侧，超时也纳入等值检验。用原生身体实测 32 对一边沿固定方向运动、另一边静止的诊断轨迹，旧口径误记 18 次，新口径记零，条件率为空。在一组真实冻结的 read/write consolidation 策略中，32 对均首触，两种口径都得到 24 次实际变化。该样本说明超时校正如何工作，各封存任务是否出现覆盖差异仍由其各自重算结果决定。[实际运动样本](paired-first-choice-physical-sample.json)

统一场景中 `B_after_0` 之前已有一道真实 B 锚题。其两端提供相同气味和相同当次味道，固定 A 关系时不提供 B 关系差异。16 世界根的四族原生复核中，每个生命确实获一个可见 B 锚题结果。固定 A 关系后，完整公开观察和自主脉冲在首道 B 探题结束前逐值相同。后续深度项计提供的 B 关系配对数。校准实际获得多少回执时要另外计身体的真实接触。[统一场景先兆检验](paired-first-choice-physical-sample.json)
