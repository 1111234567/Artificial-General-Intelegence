# 当日审计的适用范围和监督来源

此清单记录下表游戏路线截至约 06:00 的可复核证据。正式确认、开发成绩和继续开发中的实现分别读。实验协议与其他路线的主记录见[一夜实验记录](../../../docs/pulse-game-night-2026-11-19.md)，元学习检查点见[本索引](README.md)。

## 先确定所报告的行为

| 项目 | 可以依据现有测试报告 | 适用范围 |
|---|---|---|
| 两目标原游戏 | 实际接触结果能在同一生命改变后续目标身份选择。换边、错回执、去写和同状态回执分叉给出行为因果证据 | 两个可辨别的目标，规则在一生固定，单次正负接触足以辨别该格的好目标。全分母成绩和已接触回访分层分别列出 |
| 单拍线索元学习 | 第 0 拍后的线索缺失仍可保持关联地址，隔八道干扰仍用相应结果。相同生命基于精确错快写地址可产生明显行为差 | 使用单拍训练的冻结模型和指定世界。仍应单独报告二拍、四拍与噪声范围，持续显示训练只能支持对应可见条件 |
| Scout 主动探查 | 由实际身体越标获得背景脉冲后，可按已学映射折返。可在不需背景且正确端点在反侧时直接到达。在同一负回执分叉中，一笔快权可以触发下一遇重新探查 | 固定模拟力学、两个端点、单探标、指定感知脉冲。奇偶分割覆盖整张二元目标表的新组合，零至四个敏感线索覆盖这一场景族 |
| 圆轨四果实 | 首次咬的正确率明显高于错配、去奖励和去写。可借真实的坏味排除尝到的果实 | 首次实际咬且超时入分母。允许反复尝试的最终命中是另一个指标，盲扫也可高分。新气味、少样本表征与更长决策链按各自相同口径另测 |
| 旧符号题本移植 | 在同一 32 世界、同一闭环记分代码与各自训练流程下，候选能提高严格完成及双回访 | 感觉痕迹、运动竞争、可塑性和经历采样均可能不同。代数、参数预算或出生个体跨架构等效的问题还需匹配研究 |

原游戏在持续可见、单拍和 Scout 三种设置用了不同模型。双目标普通可见模型风险最低的因果结论是快权承载回访。单拍独立 A/B 和 Scout 在去慢循环时显著掉分，支持这些具体设计中慢循环的重要性。四果实和旧题本的冻结模型去除一部分内部递归后仍可高分，相关机制证据指向保留的感知时间常数、可塑性和动作竞争。

## 每种路线允许使用的训练信号

| 路线 | 模型外训练或搜索 | 生命内更新和实际评估 |
|---|---|---|
| 稀疏 LIF 对象选择 | 参数和出生网络经过开发筛选。姿态到运动和对象选择时机使用指定路由，正向对照的联合表征也由实验设计给出 | 真实回报调制资格迹，从零开始修改关联边。闭环仍靠实际运动与接触。随机图和有指定联合表征的结果应分报 |
| 两个原生运动神经元 LIF | 只用游戏成绩搜索标量、时间尺度及相关配置。神经元到左右物理通路由接口固定 | 两个运动输出实际推动身体，回报只在接触后出现。随机图、回执错配和一拍线索表现分别有效，训练预算受本轮试验限制 |
| 两目标元学习 | 自己已收到的正回执将被接触身份标为好目标，负回执标另一个身份。先前同情境线索有回执后方才监督本次运动，快权读出用同一历史，内容探针用当前签名回执。单拍主体没有示范动作或门时序监督 | 神经网络只收公开观察并自己运动，快权和循环状态随生命变化。历史表只构造训练损失和诊断，初始化与实际评估的网络输入中没有私表。带随机脚本暖身、有门监督和地址约束的训练臂各有单独标签 |
| Scout 手写原语与公开快特征 | 手写版含运动原语及公开回执更新。直接神经动作版使用指定四假设快权特征。其高分 PPO 流程外层使用真实回报，有课程、初始化和对称共享 | 直接动作模型自行发左右或静默。真实回报训练的结论覆盖外层优化与动作学得，寿命内快权如何组成仍有明示结构 |
| Scout 24 通道学地址和内容 | 主路径先用公开历史老师的实际轨迹，再用混合历史，最后老师只标注学生实际轨迹。辅助监督包括已出现的公共背景、先前同 cue/context 自身接触的目标、签名回执内容和同 cue 地址稳定。可选门标签只给公开事件是否发生 | 正向冻结策略仅从原始 24 通道和循环与快权状态决定动作。无门版仍使用公开经历相关语义辅助。无老师动作的自标签版仍包含外层设计的公开探标目标和已经获得的回执标签 |
| Scout 实际奖励微调 | 初始化来自已有公开监督训练，后续梯度只用实际回执和公开接触、运动、探标代价，未加入老师的动作或语义目标 | 性能变化是固定检查点在配对生命上的后续改进。较早与已接近上限的初始化分别列出速度、探查率及准确率 |
| Scout 从随机权重的公开自标签 | 没有历史老师。外层用先前真正获知的背景和回执生成已知方向，并用公开探标方向引导缺信息时的探索。未知情境目标时的运动一致性只取自己后来实际触到的端点身份 | 完整运动轨迹均为模型产生。冻结步 320 在新生命中末段可折返并直接到达。第二种子只用偶校验训练图，奇图独立测试复现。更严格的语义监督假设须另检视这套公开自标签 |
| Scout 从随机权重的实际奖励 | 原始 24 通道、可学快权，仅用实际回执与公开接触、探标和运动代价更新 | 已冻结的两个架构在新生命整体为 63.78% 和 72.92%，关写约一半。去情境表现基本相同，支持回报依赖的线索记忆。标准和探标后相关探索的两份纯奖励全敏感课程均未取得可靠折返 |
| Scout 额外预测已试端点 | 同一奖励流程另外让模型预测自己实际触到的端点收到的签名。只监督已试端点，既不把负回执复制成未试端点的正标签，也不查询私表 | 学到部分目标表征和少量实际情境决策，整体动作覆盖下降。可读性、同状态换背景的当拍动作和全分母成绩分别给出 |
| Scout 触端列对照 | 固定两个物理身份对应的快权价值列。实际负回执只将已经触到的这一列向 −1 更新，正回执向 +1 更新，未尝列保持。地址和运动网络继续学习。开放写入的物理事件筛选、列的含义及修正后的增益下限 0.25 是实验新增先验 | 该控制可检验知道回报归属以后，模型能否从结果学习情境条件下的运动。针对所有线索敏感的课程与普通二敏感世界分别报告 |
| Scout 物理课程与未来观测预测 | 初期暂时遮真实回执符号。缩短端点和探标的距离，给真实接触、实际越标、先越标后到另一侧这些发生的物理结果奖励。随后连续恢复原场并过渡到只用实际端点签名。预测臂另外从当前活动与实际选择的脉冲预测下一拍位置和速度、未来三拍实际发生的两种物理事件 | 预测目标完全来自执行过的轨迹。身体训练是设计过的课程，学会先探再折返只代表运动技能。何时应该折返、是否记住了规则，按恢复原场后的真实结果和因果检验分别报告 |
| Scout 冻结表征的内部进展训练 | 保留已训练的触端列地址与学习参数，只训练读出和 critic。两个臂均用实际签名。内部进展项用实际探标时自身计算的价值差乘以后续真实位移，物理坐标到端点身份的关系由公开布局定义 | 同状态改读数和闭环错误读数检验价值是否影响动作。进展奖励与动作选择是两个层次。执行已学值的固定物理中继只作为诊断对照，其高分单列 |
| 四果实局部规则和元学习 | 局部协方差路线有公开果实与回执的显式关联形式及运动竞争。另一个度量学习分支只拟合实际尝到果实的符号 | 坏味不会提供未尝果实的身份。首次咬评估才检验利用记忆，重复试吃可另测搜寻效率。弱时序和新编码的模型仍在迭代，已落盘的失败一起保留 |

## 因果对照和统计口径

- 冻结检查点和选择协议后才执行对应的新世界测试。同任务新生命种子说明不同经历下可复用学习，奇偶切分额外说明目标表全组合的结构外推。开发集、干预诊断和独立确认分别注明。已经诊断过的模型版本保持原始哈希。
- 对元学习目录，另核对了训练启动记录的完整计划种子区间和带种子的诊断或审计文件，未发现训练或开发种子进入这些文件的评估列表。比较干预时在审计之间使用配对生命。[区间核对](seed-space-audit.json)
- 全程准确率、末段准确率、覆盖率和严格完成使用各自记录的分母。超时包含在全机会和首次咬的指标中。按接触回访、必须折返、已见上下文和严格首次意外分层给出事件数，这些条件子集只能代表相应可观察经历。
- 生命是重采样单位而非一拍。不同模型固定在新生命上的配对区间解释世界随机性。这些区间对应所列出生图或训练种子，训练配方跨随机初始化的一般可靠性还需要更大的多种子研究。
- 原地错写最强对照在计算完真正的写地址以后修改去向，保留同拍实际动作和慢活动。用另一生命的波形替换结果与在本体时点替换语义应分别报告。第一个控制可能一起改变时序，第二个隔离结果含义。模型在无背景、错背景和同拍背景互换时的影响也分别记录。
- Scout 严格重启探查的 69 个生命，未来规则不可见，第一处公开分歧只有本体未探时接触负回执。随后必须是直接下一次同 cue，且旧目标在探标反侧。压掉这一笔快写会压掉重启探查。当前证据支持重启信息获取，首次试探正确 29/69，更新后的准确率须另看。
- 从头公开自标签模型也给出类似机制证据。匹配的 1,015 个应折返探标时刻，翻转同一物理时点的一拍背景使全部运动方向改变。1,033 个非敏感探标动作不变。独立的 70 生首次隐藏负回执分叉中重启 52 次，抹掉这笔快写或仅更换其符号对应的写入时均为零。[单脉冲背景分叉](../meta-scout-self-observed-2328/audit-self-sensor-fork.json) · [回执分叉](../meta-scout-self-observed-2328/audit-self-transfer.json)
- 出生全随机的奖励分支目前的困难可定位到情境与偏好的联系。真实获得背景的敏感题中，离线慢活动线性读出可恢复 1,870/1,870 个背景，实际方向和线性目标身份读出仍约一半。这个诊断测量冻结状态中的线性可读性，行为正确率仍按实动计分。[状态读出](../meta-scout-raw-reward-scratch-2341/offline-state-probes.json)
- 额外尝试端点预测时，已探并见过两情境回执的 1,222 个敏感事件中，实际端点头排对 934 次，当拍运动对 646 次。另一批 256 生的末段实际探标里，对 50 个真脉冲给出正确反向运动的同状态事件换背景，49 次改发相反脉冲。但全机会末折返只完成 63/1,001，整体 51.29%。[状态读出](../meta-scout-tried-outcome-2344/offline-outcome-prediction-1248.json) · [实际情境分叉](../meta-scout-tried-outcome-2344/audit-outcome-prediction-1248.json)
- 奖励路线的探索塑形单列。全敏感课程给实际越标一个公开可验收的额外收益。相关探索在本体实际越标后对左右动作加相反的随机偏置，并在该回合余下动作重用这组偏置。估计梯度时重建同一采样分布。评价用无该偏置的冻结策略。普通探索与相关探索的闭环不等同于收集到的动作多样性。[探索对照](../meta-scout-raw-reward-post-noise-2348/paired-exploration-816.json)
- 跨回合收益对照从相同恢复原场检查点开始，两臂均使用新优化器及同样的后续生命。用于信用分配的全部后继奖励均由当前生命自己的真实轨迹产生。训练输入仍为此前已实际出现的公开观察。只在回合内累计与在同一生命跨回合累计分别标记。
- 签名长期不出现的场景和有持续反馈的稳定生活不同。遮掉签名却保留接触身份使已有模型误写。实验性冻结后续快写可救回保持。含缺奖经历的训练是生成更稳健策略的另一办法，应同时报告正常世界的代价。规则持续变化后的恢复也应与第一次新规则上的机会分别列出。
- 功能测试覆盖原版环境和 Torch 逐拍一致、恢复权重、留出场景生成与训练标签权限。测试数是实现核对。最终依据是冻结后的实际策略计数与对照报告。

## 统一场景与首触配对补查

统一场景的 512 个确认根与现有元训练、开发、物理搜索和物理开发根无交集。三对只调运动和全参数的搜索，在每一代共享根世界和场景，评估预算相同。六个已冻结表型逐值重建，当前感知和运动祖先文件也与记录的校验和吻合。读写合并路线的三个 1,024 生确认包没有复用读头开发、写入训练、写入开发或祖先表型训练根。[种子、配对及检查点复核](unified-seed-and-checkpoint-audit.json)

`B_after_0` 是首次 B 关系探题，之前有一题普通可见的 B 锚回执。锚题在固定 A 关系、只改变 B 规则的两臂中一致。后续深度按提供的 B 配对数命名，真实获得的回执由实际身体接触决定。等感知对照消除特定的感知标记，阶段变化仍能给模型带来时间线索。在两种内层更新和五种地址路由中扰动静默探题的外层分数，代入极端评分后没有改变任何生命内预测。[实际身体和静默输入复核](paired-first-choice-physical-sample.json)

早期归档中的 `switched` 会将与超时相配的相关目标接触也计入。只有保留真实左右首触及 `paired_first_contact` 的新记录才用于实际动作切换。旧的 `first` 和 `both` 保留全机会口径。[修正定义、归档字段与实测](paired-choice-metric.md)
