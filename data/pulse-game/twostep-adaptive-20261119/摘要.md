# 两步动态学习补充摘要

本卷模型的环境只在真实触果后显示 ±，训练效用还把未触果判为失败 −1。无奖路测没有 PPO 得分。未触果回报为 0 的逐字端点条件另见相邻 `twostep-actual-reward-20261119`。

- **无奖路测之后重学转移。** 转移在 16 次不付奖的实际入门路测中于逐生随机时点改变。12 次房果探访随后独立改变价值。确定型自适应模型四格 1024/1024，80/20 为 926/1024，四格皆正确 194/256。相同纯回报母模型和 112×96 训练生命下，累计写入对照为 541/1024。配对差 37.60 个百分点，95% 区间 [35.25, 39.84]。模型读取真实入口和房间的事件，四个阶段提示通道为零。测试只计独立的首次无奖入口。
- **统一触觉，角色从实际回报习得。** 从随机权重开始，纯终端 PPO 训练 112×96 全程原生生命。四阶段提示与专用入口触觉均去掉，模型只读两类实体共有的实际触觉身份、可见房、终端符号和回合起点等公开输入。独立四格确定型 995/1024。80/20 为 872/1024，四格全对 138/256。遮任一类房观测为 512/1024，均匀角色注意为 768/1024。学到的门给真实入口、伴随得分的触觉和无入口访视的空连接分别赋予 0.524、0.131、0.715 平均权重。
- **四格共用身体历史。** 独立 3540000–3540255 的初测前，各条件共用事先指定一侧控制器生成的真实运动，首测恢复自主。核对了初测前身体轨迹以及所有非结果输入，在第一探针原始输入上逐项相同。80/20 下阶段清零的纯回报自适应模型为 941/1024，统一触觉纯回报冷启动模型为 898/1024，分别是 206/256 和 162/256 四格全对。
- **同世界和同初始权重的阶段提示对照。** 原始价值重估任务用相同 128×96 个真实回报训练生命。从随机权重全程清四阶段提示，独立 80/20 由有提示的 494/512 降为 464/512。确定型两者均为 507/512。候选仍读取可见房和真实的两种接触回执。清标签的一组第 77 轮仍为 50%，随后学会。
- **纯回报短读出。** 从随机权重混合常开与短读出训练，完全真实终端结果、160×64 个生命，8/16/32 tick 后在独立测试为 509/512、510/512、511/512。清活动均为 256/512，换脑状态分别为 3/512、2/512、1/512。只切静默期复发边保留 99.41%、98.24%、70.12%，交换等幅非目标扰动为 49.02%、38.28%、32.42%。这组对一般干预敏感。之前封存的行为克隆混训组采用同体等幅对照，抗扰更强。纯回报、只看短读出的一个冷启动种子 670481 在 128 轮后各档仍为 50%。

完整脚本与复现命令见 `README.md` 和 `source`。最重要的原始结果分别为 `reports/rewire-paired-3420000.json`、`reports/rewire-adaptive-curve-3450000.json`、`reports/untyped-cold-confirm-3420000.json`、`reports/matched-phase-tags-3100000.json` 与 `reports/flash-reward-mixed-confirm-3500000.json`。上一批常开、短读出和潜键值的封存见相邻 `twostep-20261119` 目录。
