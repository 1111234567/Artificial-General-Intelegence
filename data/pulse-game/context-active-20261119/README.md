# 同一个冻结主体的规则学习与付费探查

实验日期 2026-11-19，Asia/Shanghai。选用已注册第一独立出生 374853277 的冻结感觉与身体参数、局部原型规则记忆和已登记的 RLS 重开。全程 CPU。模型根据真实出现的连续栖息地脉冲分配地址。`arena` 整数供环境安排场景、菜单和费用使用。决策头读取当前地址的可观测规则幅值、方差、实际既有购买或脉冲经历、价格与余票。

一个生命只初始化一次脑。牌侧将学习头的购票意向通过手写强侧向电流注入同一对持续积分的膜电位与脉冲神经元。牌和吃味共用该对状态。真实触及的牌决定是否扣费与进入哪张物理菜单。牌侧映射属于工程部分。每次实际触果都能写入记忆，包括收获的末端结果。只有实际收获末端结果与实际扣费进入经济收益。锚味与探查味道单独只作学习证据。未吃的填充时隙没有回报。

## 小头训练

普通实际净回报 actor–critic 的 108 次更新选成不买。在独立 3870000–3870255 的净收益为 3.8516，与无探完全相同。之后用 14 系数的小头做确定性净收益搜索，候选中包含固定每处一次及任意扰动，选择准则仅为实际净收益。训练与开发使用 3830000–3830191、3850000–3850079，测试用独立的 3910000–3910255。

另一种训练让买/不买两支先经历完全相同的真实历史，再各自执行身体动作并真实结算，用实际净收益差拟合小头。实际开发收益最终选中固定每处一次。独立 3930000–3930255 的净收益 4.6992，与该固定策略逐项相同。这两条训练记录都保留。

## 实物收费和时机

净收益为每生命单位。学习头冻结后，各对照使用同一物理世界，以实际购买数量和费用匹配随机时机。一次固定是在某个原型地址上第一次遇见且尚有余票时买，其他选择继续由相同动物真实执行。

| 头策略 | 新生命 256 生 | 先有旧 A/B 的连续 192 生 |
|---|---:|---:|
| 实际收益选择的小头 | 4.976 | 4.838 |
| 无探 | 4.035 | 3.667 |
| 每处固定一次 | 5.005 | 4.860 |
| 每处固定两次 | 3.029 | 3.004 |
| 同生同处同次数同费随机时机 | 3.106 | 3.149 |
| 匹配随机且尽量排除最后一票 | 3.304 | 3.356 |

新生命 2210/2210 次牌触及意向侧，学习头每生买 2.012 次。对无探的配对净增益为 +0.940，95% 区间 [0.590, 1.296]。对同费随机为 +1.870 [1.630, 2.121]，尽量排除随机末票后为 +1.672 [1.444, 1.908]。对固定一次为 −0.030 [−0.087, 0.025]。

## 同一个生命的两个环境

独立 3890000–3890191 先经历长 48 对竞争的 A/B 规则场，接着进入两种新可分的感官。旧环境的末次观察与新环境的首次门选择之间没有脑重置。96 个旧规则冲突生命中，A 回访正确 85/96，末次 B 正确 81/96，两者都正确 72/96。之后 1640/1640 次牌实际按意向触及；平均识别 3.943 个地址；整个神经时钟为 4142 tick。每生 2 次付费，学习头净收益对无探为 +1.172 [0.697, 1.665]，对同费随机为 +1.689 [1.403, 1.984]，排除随机末票后为 +1.483 [1.201, 1.785]。对固定一次为 −0.022 [−0.091, 0.053]。

## 决策头输入干预

同一冻结头在付费选择时，用初遇值替换局部输入。新生命中联合替换规则幅值与协方差后，每生买 3.957 次，净收益 2.538。只替换地址脉冲熟悉度后，每生买 3.754 次，净收益 2.995。两组都替换后，每生买 7.672 次，净收益 −2.459。有旧 A/B 的连续生命得到同方向变化，三项净收益分别为 2.378、3.071、−2.161。各干预保留先前实际购买经历，改变了买票量，此处估计冻结头对成组输入的敏感性。幅值和协方差的单独贡献仍未知。
