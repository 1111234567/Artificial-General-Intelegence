# 局部地址参照与旧栖息地回访

实验日期 2026-11-19，Asia/Shanghai。全程 CPU，复用 `unified-physical-sealed` 的真实脉冲身体、冻结嗅觉网络、实际触果回执和运动神经元。未修改原研究代码或权重。本目录记录独立外测、代码副本与精确输入版本。

## 手写与生内形成的部分

参照每次只处理真实出现的两通道感觉脉冲。按 0.09 弧度的预设角距分配或复用少量原型地址，按实际脉冲更新原型。一个新地址复制最先由感觉发现的地址上已有的规则作默认。两者仍用同一冻结接触学习律，只有实际入账的触果回执写规则。配对的同体检查在回访 A 的首个查询前逐步共用一个真实控制器发出的运动，按 root 事先随机确定驱动器，四个私有规则变体复用该分配。首个查询恢复两边独立实际脉冲。

地址容量、角距阈值、新地址默认、以及更新作用域是手写先验。满槽时就近复用已有原型，随后更新其原型和规则。原型和规则来自各生命实际经历，模型不见私有规律、A/B 语义索引或阶段重置。身体冻结协议的感觉脉冲先于最早的触果回执。每个查询仍带一次独立实际锚味，查询本身静默。

## 长 48 对冲突的旧 A

三冻结模型共用 192 个新 root。每模型有 384 个冲突回访 A 机会。以下同体均核对首个查询前的真实触碰侧、时点和已显示回报，且第一查询输入相同。

| 冻结模型 | 自由跑原生 A | 自由跑局部 A | 同体原生 A | 同体局部 A | 局部 B48 |
|---|---:|---:|---:|---:|---:|
| s1373 | 43.23% | 89.32% | 42.97% | 89.06% | 88.80% |
| s6547 | 38.28% | 88.54% | 38.02% | 88.28% | 88.54% |
| s8539 | 36.46% | 88.02% | 36.98% | 87.76% | 88.54% |

以 root 配对、三模型作为固定候选聚合，同体 A 增益为 49.05 个百分点，生命层级 bootstrap 95% 区间为 [42.01, 55.82]。共享单槽 A 只有 10.42%–10.68%。三个冻结的全局保留系数都为 1，乘性衰减对照与局部保留结果相同。

保留原来学得的连续 (c(h)) 读写方向，按感觉原型仅分开存完整规则向量 (g) 与 RLS 协方差，独立 128 roots 的同体旧 A 分别为 85.94%、86.72%、86.33%。原生为 43.36%、37.89%、33.59%。配对增益 42.58、48.83、52.73 个百分点，三个区间下界分别为 33.59、39.84、42.97。这说明改变存储及更新的作用域足以修复大部分冲突覆盖。该干预同时分开了两类状态。

## 可辨识性与默认启动

同一 48 对长课程只变更物理脉冲。近邻场中局部 A 为 88.28%–88.54%。对相同的近邻感觉，预设较粗的 0.35 弧度合并边界将 A 降到约 10.68%。两处感觉严格重合时，局部 A 为 10.68%–11.46%。这些数据区分了可分、被代码合并和感觉相同三种情形。

同族、先有实际锚味而尚无 B 配对教学的 B0，复制默认后为 88.28%–88.80%，空先验为 48.96%–51.30%。长 B 之后把最后的锚味和查询改成此前没出现的第三种物理脉冲。所有感觉、动作、触碰时点与可见结果在两套隐式新规律下逐项相同。新规律和默认一致时冲突家族正确率约 87.5%–88.0%，真规律相反时约 11.46%–12.24%。这测到的是初始迁移方向。

## 三、四处外推

冻结感知和身体不变，每处的 ± 规律逐生独立。没有把处数或处名送给模型。每种感觉第一次预测前有独立真实锚味，随后 12 对学习，最终打乱顺序回访。s1373 的 192 个独立生命如下。

| 可辨识栖息地数 | 2 槽回访 | 3 槽回访 | 4 或 6 槽回访 |
|---|---:|---:|---:|
| 3 | 445/576 | 509/576 | 509/576 |
| 4 | 535/768 | 601/768 | 673/768 |

容量不足的组，192/192 生命有至少一对栖息地回访时共用地址。容量足够时为 0/192。4 处时全部正确回访的比例随 2、3、足额槽变为 41/192、72/192、117/192。s6547 冻结复现了 4 处次序，分别 70.70%、78.39%、88.41%。4 处中，6 槽相对 3 槽的配对增益为 9.38 和 10.03 个百分点，95% 区间分别为 [7.16, 11.72] 和 [7.81, 12.24]。

把第一和最后一处的物理脉冲做成完全相同，6 槽也发生 192/192 生命的地址复用。在两处规则相反的 101 个生命中，s1373 第一处回访从 87/101 降为 45/101。可用槽充足仍要求感觉可分。

可分的四处中，复制默认在符合首规律的新处首次选对 267/297，反首规律的新处为 30/279。空先验分别为 140/297、151/279。在 576 个尚未教的首次查询上，只交换静默测试真值，真实触碰和所见奖励逐项相同，分数由 297/576 变为 278/576。一个机会没有实际触端。

## 路径与复现

`reports` 保存逐 root 原始结果，`summary.json` 保存配对汇总。`source` 是新增代码副本，`frozen-inputs` 保存复制的冻结输入。`manifest.json` 记录归档文件与仓库依赖源码的哈希。在仓库根目录 `F:\agi` 运行以下命令。输出参数可改到新目录以保存另一份记录。

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
$base='F:\agi\data\pulse-game\context-local-20261119'
python -m pytest experiments/pulse_game/context_local_test.py -q
python -m experiments.pulse_game.context_local_run --out "$base/reports" --worlds 192 --root-seed 98562344 --controls
python -m experiments.pulse_game.context_local_multi --out "$base/reports/multihabitat-1373.json" --worlds 192
python -m experiments.pulse_game.context_local_multi --out "$base/reports/multihabitat-6547.json" --worlds 192 --model-filter 6547
python -m experiments.pulse_game.context_local_bank --out "$base/reports/banked-native.json" --worlds 128
python -m experiments.pulse_game.context_local_summary "$base/reports" --out "$base/summary.json"
```
