## 结果所回答的问题

在共同未剪枝来源的即时冻结消融中，家族 0 严格完成率差在 initial 和 return 的种子间方向不一；withdrawal 三个种子均为小幅正差。选中坐标具有非零权重，归零也改变了实际行为，但本轮未显示一致的大幅完成损失。其证据范围限于这些固定历史身份、三个实际继承时点和当前 2,048 tick 短条件。

这是看到此前继承系统的保持结果后冻结的事后实验。它估计当前未剪枝系统对这些坐标的即时依赖；保留的历史隐藏状态含有消融前的影响，来源训练历史没有重做。它不能分解此前两个系统的全部纵向差异，不能替代在线退边后的训练对照，也没有随机坐标对照。
