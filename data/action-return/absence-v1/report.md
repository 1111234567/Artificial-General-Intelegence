# 旧任务外部撤出与返回：完整结果

2026-11-03。三个配对种子，六个真实连续训练分支。比较上一轮实际退出过弱边的系统与原排名、允许全删的配对系统；本轮均固定各自继承的资格集合并继续更新权重。

主指标是已获得部分能力的 family0 短任务严格完成率。撤出阶段，弱边系统相对对照的初值校正差为 **−0.0008 ± 0.3851 个百分点**；返回后为 **−0.2083 ± 0.5156 个百分点**。这里的 ± 是三个配对差的样本标准差。该比较没有显示弱边系统的保持优势。历史 family0 复习始终保留，因此结果不是零复习条件下的记忆保持证据。

## 协议与对照边界

- 起点为两组实际 147,456 tick 完整端点，各自保留隐藏状态、世界、已安排事件、随机流、Adam、recorded512 信用历史、旧经历库及历史记录。每种子两臂的外部命令流相同，动作回执与内部状态随各自行为演化。
- 147,456→163,840 tick：未来 NEW 仅从 family1/2/3 产生，128 次更新、16,384 tick。163,840→172,032 tick：未来 NEW 仅产生 family0，64 次更新、8,192 tick。只改未来抽样策略，不重置已有世界。原存档主训练边界 196,608 tick 没有被改写。
- 待执行的第16次结构提案完整归档并永久取消；本轮不再生长、删除或探测。资格 mask 和数值非零 mask 每次更新均核对等于继承端点，非零边的数值正常学习，未活动坐标的原有 Adam 动量保留。
- 每个新端点做四个家族×短任务/长处理加长空档×2,048 tick 的冻结自由行动评估，直接执行完整11动作 argmax。复用48个已绑定的初始评估，新增96个评估；均按成熟的分叉后请求计分，空闲动作使用实际空闲机会为分母。
- 两个继承系统在上一轮已经形成不同的权重、优化器状态、隐藏状态和行动历史。本轮估计其总策略差异的后续变化；不能把差异单独归因于删除掉的边。该协议是在知道上一轮退出结果后、看到本轮行为结果前冻结。

## 验证与可解释范围

- 六个完整起点均核对原结果与存档SHA及完整语义绑定。每臂撤出/返回的12个新存档均实际恢复并核对；额外机械验证在种子0副本上比较恢复后的下一次真实更新，结果逐位相同。
- 每臂精确执行128次撤出更新和64次返回更新；新增结构探测为0，资格及数值非零集合保持原值。保留的模型权重继续学习，没有重置信用或优化器。
- 配对训练分支的外部事件、调度器与实际家族暴露一致；评估的actor/case身份、外部命令流和成熟请求指纹一致。冻结评估未改变完整训练源状态。
- 独立复核程序重新核对144行端点计数、648项配对原始/初值/阶段校正值及三种子均值/样本标准差，全部通过；另重验原排名协议33项、弱边协议37项执行源码指纹，覆盖原生训练循环和两个评估器。独立复核的范围与输入SHA保存在对应JSON中。
- 本轮保留了旧经历复习；比较的是两个已经不同的继承系统；只覆盖三个种子和给定时间预算。短任务结果没有显示额外保持优势，长任务的零完成不能被解释为保持成功。
